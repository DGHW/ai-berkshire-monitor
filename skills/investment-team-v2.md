# 投研团队 2.0：四大师 + 红队对抗辩论 + 强制站队

对 $ARGUMENTS 执行三层架构投研（分析师层 → Bull/Bear 红队辩论层 → 裁判强制站队层）。本 skill 是 `investment-team.md` 的升级版，融合 TradingAgents 多空辩论机制与预期差定价审计，专治两个顽疾：①风险挖掘浅（risk-assessor 退化为 8 维度 checklist）②结论和稀泥（team-lead 输出"建议观望"）。

## 设计哲学：为什么是"对抗"，不是"综合"

旧版四大师是"综合路线"——各看各的、最后汇总。汇总 Agent 面对对立合理观点时，默认输出"两边都有道理，建议谨慎"——这是最安全也最没价值的回答。v2 引入**结构化对抗**（复刻投行红队传统）：

- **角色锁定**：Bull 被分配"为买入找最强证据"，Bear 被分配"为卖出找最强证据"——不是客观分析多空，是为立场辩护（法庭辩论逻辑）
- **裁判强制站队**：禁止 Hold 式和稀泥，必须基于最强论据给出明确方向

## 三层架构

```
第一层 分析师层（四大师）→ 只做研究、摆证据，不给买卖结论
第二层 辩论层（红队）     → Bull ⟷ Bear 多轮对抗，猎杀利空
第三层 裁判层（team-lead）→ 强制站队 + 概率加权回报 + 证伪清单
```

## 执行流程

### 第 0 步：信息评级 + 口径校准

沿用旧版 A/B/C 研究偏见评估；用户自带资料时先做口径校准（时点/单双季/分母/官方口径 vs 反推口径），无法验证的数字标注置信度。

### 第 1 步：分析师层（四大师并行）

**沿用旧版 `investment-team.md` 的四份任务书**（商业模式/财务估值/行业竞争/风险评估），但增加两条硬约束：

> **约束一：四大师报告禁止输出"总体结论/买卖建议"**——只负责把各自维度的证据挖出来、摆上桌。方向判断交给辩论层。
>
> **约束二：行业估值难度纪律**——lead 派工前先跑 `python tools/industry_valuation.py lookup --code {code}`，把返回的行业卡片（星级/宏观命中/额外维度/首选方法/PE陷阱/隐藏资产负债表）附进每份任务书。financial-analyst 按星级选方法：★~★★ 常规 PE/PB/DCF；★★★ 常规+额外维度；★★★★ 切换首选方法（PS/NAV/情景加权/分部估值）+ 增速腰斩测试；★★★★★ 穿透隐藏资产负债表，PE 只作最后参考。无映射时 lead 判断行业后用 `map` 子命令回写。财务估值报告的"数据核验"字段注明行业星级与所用估值方法。

产出落盘：`reports/{code}{名称}-商业模式分析.md`、`-财务估值.md`、`-行业竞争.md`、`-风险评估.md`（沿用旧版规范，含 `## 量化结论` 五字段的仅财务估值报告）。

财务数据双源交叉（按 `skills/financial-data.md`），估值验算用 `python tools/financial_rigor.py`（Windows 用 `python`；`three-scenario` 的 `--growth` 必须用小数如 0.15，不能写 15）。

### 第 2 步：辩论层（红队，核心）

四份报告到齐后，创建两个研究员角色（各自收到四份报告全文）：

#### Bull Researcher（多头研究员）任务书

```
You are a Bull Researcher advocating FOR investing in {公司}.
Your task is to build the strongest possible case for buying — NOT to be
"objective". You are assigned a stance; find the strongest evidence for it.
When refuting the Bear, use data, not dismissal.

立论任务（Round 1）：
1. 最强多头论据（5-7条）：成长、护城河、现金流、股东回报、催化剂
2. 预判 Bear 会攻击的点并准备反驳数据
3. 给出你的估值判断与目标价
```

#### Bear Researcher（空头研究员 / 利空猎手）任务书

```
You are a Bear Researcher advocating AGAINST investing in {公司}.
Your ONE core question: "如果这只股票要暴跌 50%，最可能因为哪一条致命原因？"

猎杀清单（逐项排查，每条必须落到可验证证据，模糊担忧不算数）：
1. 财报造假/质量信号：应收与营收背离、经营现金流长期低于净利润、
   存货/在建工程异常、商誉减值风险、毛利率异常波动
2. 管理层诚信污点：减持/质押/关联交易/资本运作历史、监管处罚、问询函
3. 业务颠覆路径：技术替代、渠道崩塌、政策扼杀、大客户流失
4. 财务脆弱性：高杠杆、债务到期、担保/或有负债
5. 对 Bull 论点的反驳：逐条指出假设漏洞与过于乐观之处
6. 估值方法陷阱（行业难度★★★★+ 时必查）：Bull 是否用错了估值方法？
   保险拿PE论便宜（利差损未计）、银行不看隐含不良、地产不测存货减值、
   半导体不做情景测试直接吃高PE——方法用错比数字算错更致命

若未发现致命项，明确说明"我做了哪些猎杀动作、为何空手而归"——空手而归是合法成功。
```

**利空武器库（复用仓库既有 skill，无需重写）**：
- 冷信息挖掘：`skills/small-cap-diligence.md` + `tools/small_cap_diligence.py`（应收/存货突变、股东户数、大宗/龙虎榜、公告分类）——**推广到所有标的，不限小盘股**
- 诚信污点：`skills/management-deep-dive.md`
- 异动归因：`skills/news-pulse.md`
- 去劣信号：`skills/quality-screen.md`
- 一手披露：巨潮/港交所公告原文（问询函及回复、年报附注）

产出落盘：`reports/{code}{名称}-多头立论.md`、`reports/{code}{名称}-空头猎杀.md`

### 第 3 步：Round 2 交叉辩论

- Bull 逐条反驳 Bear 的猎杀清单（每条：Bear 论点 → 反驳 + 数据 → 净判断）
- Bear 逐条反驳 Bull 的论据（同格式），并给出致命利空最终排序（Top 1-3）+ 下行空间测算
- **论点收敛即停**（默认 2 轮封顶）：若 Round 2 无实质新论据（双方重复自己），立即进入裁判层
- 辩论纪律：每轮必须引用对方上一轮的具体论点；每条论据必须落到数据；禁止人格攻击式反驳

### 第 4 步：定价审计（衔接预期差）

裁判站队前补一道硬校验（反推市场隐含假设）：

- 价值型（保险/银行/高股息）：价格 ÷ 每股EV → 拆 ANV+VIF → 反推隐含长期收益率 → 与现实对比
- 成长型（消费品/医药/科技）：正常化净利 → 真实PE → 反推隐含增速 → 与天花板/份额路径对比
- 周期型：峰值/谷值/均值利润三口径 PE

判断标准：隐含假设处于"可辩护区间"的哪一沿？过度幅度 ≥100bp（收益率）或 ≥2 倍标准差（增速）才有博弈价值。

### 第 5 步：裁判强制站队（team-lead）

裁判 prompt 必须包含（对抗 LLM 安全偏好）：

> "Avoid defaulting to Hold simply because both sides have valid points; commit to a stance grounded in the debate's strongest arguments."

最终报告结构：
1. **一句话结论（明确方向：买入/观望/回避，禁止"建议关注"式废话）**
2. 辩论纪要（Bull 最强论点 vs Bear 最强论点逐条对照 + 裁判逐战场裁决）
3. 定价审计（隐含假设反推 + 已计价/过度计价/未计价/计价不足四分类）
4. 概率加权回报（乐观/基准/悲观/极端四档，**悲观与极端必填**；概率加权年化 + 累计分布区间）
5. 仓位建议 + 证伪清单（每条利空必须有数据支撑）
6. 数据校正小节（跨 Agent 分歧及裁决）+ "不构成投资建议"声明

产出落盘：`reports/{code}{名称}-终审.md`

## 执行纪律

1. **先备锚点再派工**：lead 先用 WebSearch 取核心锚定数据（价格/市值/关键比率/卖方观点），写进每个 Agent 任务书
2. **429 处理**：逐个 spawn（一条消息一个）；限流期间 lead 直接合成并显式标注「lead 合成，非独立子报告」——**禁止编造 Agent 报告**
3. **辩论轮响应慢**：Round 2 的 Bull/Bear 常需多次催交（实测各催 2-3 次）；催交时用"三行式交卷"降级指令（论点→反驳+一个数据→净判断），避免卡死
4. **跨 Agent 互查**：不同 Agent 对同一数据（汇率/每股口径/时点/现金含量单双季）常给不同数字——lead 用自己的验证锚点裁决，终稿列「数据校正」小节
5. **证伪清单红线**：每条利空必须落到可验证证据（财报科目异常/问询函/减持质押/裁判文书），模糊的"行业竞争加剧"不算数——防红队为否定而否定污染闸门
6. **与六道闸门的接口**：Bear 的"致命利空命中"（有数据支撑）→ 闸门否决项；"证伪清单"→ 持有期监控指标（衔接 `skills/thesis-tracker.md`）
7. WebSearch 权限预检沿用旧版（spawn 前确认白名单）；联网失败禁止伪装
8. 本 skill 仅供学习研究，不构成投资建议

## 与其他 skill 的关系

- `investment-team.md`（旧版）：保留，用于快速四视角研究；本 skill 用于"要深挖、要方向明确"的场景，**优先于旧版**
- `expectation-arb`（如已安装）：本 skill 第 4 步直接调用其"反推隐含假设 + 定价审计"；专门做"市场已定价什么"的审计时单独使用
