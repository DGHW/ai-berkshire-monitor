# 投资速评 Lite：批量快速研判（investment-team 轻量版）

对 $ARGUMENTS 执行轻量级投资速评。**这是 `/investment-team` 的阉割版，用于第一批批量筛选**——每只 5-6 分钟，一批跑 5-6 只；等剩下几十只时再上完整版。

## 定位：漏斗的第二层

```
全A 5539 → 初筛 890（脚本） → 【本 skill：速评 ~300-400】 → 完整 investment-team ~50-100 → 监控池
```

| 对比 | /investment-team（完整版） | /investment-team-lite（本 skill） |
|------|---------------------------|----------------------------------|
| Agent 数 | 4 个并行 + Team Lead | **1 个** |
| 耗时 | 30-45 分钟/只 | **5-6 分钟/只** |
| 深度 | 七模块全方位 | 六关速评 + 数据卡 |
| 输出 | 完整报告 | **PASS / HOLD / FAIL + 一句话理由** |
| 用途 | 最终候选深研 | **批量初筛** |

## 执行流程（每只 5-6 分钟）

### 第一步：领取任务（批量调度器）

```bash
python3 tools/batch_review.py prepare --pool small --batch 0   # 生成数据卡（小盘池第一批）
python3 tools/batch_review.py claim --worker {你的编号}         # 领取下一只待处理股票
```

claim 输出该股票的**数据卡**（已预填：PE/市值/ROE/毛利率/净利率/负债率/营收增速/净利润——**无需重新搜索基础数据**）。

### 第二步：六关速评（基于数据卡，2 分钟）

| 关 | 问题 | 用数据卡的哪个字段 |
|----|------|------------------|
| 1 能力圈 | 这生意你能理解吗？ | industry + 常识判断 |
| 2 好生意 | 赚钱容易吗？ | 毛利率/净利率/ROE |
| 3 护城河 | 凭什么不被抢？ | 行业地位（需 1 次快速搜索） |
| 4 管理层 | 值得信任吗？ | 数据卡无 → 跳过或快速搜索 |
| 5 估值 | 便宜吗？ | PE + 行业对比 |
| 6 财务健康 | 会爆雷吗？ | 负债率/净利润/营收增速 |

**评分**：每关 1-5 星，加权 = ROE(25%) + 毛利(15%) + 净利(15%) + 估值(20%) + 财务健康(25%)。≥3.5 → PASS，2.5-3.5 → HOLD，<2.5 → FAIL。

### 第三步：冷信息补充（1-2 分钟，可选）

小盘股（市值 <80亿）跑冷信息挖掘补充信号：

```bash
python3 tools/small_cap_diligence.py {代码} --signal
```

重点看：应收/营收比率（>1 = 收入质量差）、股东户数筹码变化、存货激增。

### 第四步：提交结果

```bash
python3 tools/batch_review.py done {代码} \
  --verdict PASS \
  --summary "一句话理由：PE 14 倍 + ROE 22% + 毛利率 26%，制造业龙头低估"
```

**PASS**：值得进入下一轮完整深研 / **HOLD**：存疑，标记待定 / **FAIL**：明确排除。

## 并发策略（30 分钟跑 5-6 只）

1. 开 **5-6 个窗口/Agent**，每个窗口运行本 skill
2. 每个窗口循环：`claim` → 六关速评 → `done`，然后 claim 下一只
3. progress.json 是唯一协调点，互不冲突
4. 一批 30 只 ≈ 30-40 分钟（5-6 并发）

## 关键原则

1. **快胜过全**——这是筛选不是研究，5-6 分钟必须出结论
2. **数据卡信任**——基础数据已预填，不要重新搜索浪费时间（除非数值明显异常）
3. **宁 HOLD 勿 FAIL**——不确定的标 HOLD，留给完整版深研，不要误杀
4. **理由要具体**——"PE 低"不够，"PE 14 倍 vs 行业 20 倍"才有用
5. **完整版衔接**：PASS 的股票进入 `data/screening/batch/` 的待深研清单，用 `/investment-team` 跑完整版
