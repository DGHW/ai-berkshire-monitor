# 预期差博弈与定价审计（Expectation Arbitrage）

对 $ARGUMENTS 执行预期差审计：判断市场已经定价了什么、漏掉了什么、错杀了谁。**本 skill 只产生预期差审计结果，不做最终估值**——最终估值与回报模型归 `forward-return`（收益率期限结构）与裁判层。本 skill 回答的是："我们的预期 vs 市场的预期，差在哪、差多少"。

## 定位：本 skill 的边界

| 负责 | 不负责 |
|------|--------|
| 反推市场隐含假设（Price-Implied Expectation） | 最终内在价值/目标价（归 forward-return/裁判） |
| 汇总市场共识预期（Consensus Expectation） | 仓位建议（归 Kelly/组合层） |
| 定价状态矩阵（已计价/过度/未计价/计价不足） | 基本面深度研究（归 investment-team-v2） |
| 错杀/高估排序、预期差量化 | 买卖执行（归六道闸门） |

**为什么单拆**：super-research 的 S3 调用本 skill，但此前它是"嵌入式规范/外部依赖"未落盘。本文件把它正式独立成可版本控制的模块，接口清晰（输入=S1/S2 基本面证据，输出=预期差审计表）。

## 核心理念（三条公理）

1. **股价 = f(市场预期)，不是 f(基本面)**。基本面只通过"预期修正"影响股价。赚钱 = 预期修正幅度 × 该预期在定价中的权重。
2. **表观指标对利润质量敏感的行业全部失真**。利润中"一次性/周期性/浮盈"占比越高，表观 PE/PB 越"假便宜/假贵"。任何估值比较前先做利润正常化（PE 膨胀倍数 = 真实PE ÷ 表观PE）。
3. **便宜必须拆解**：每家公司的低估值拆成「该折的（风险真实，永久折价）」和「多折的（预期差，可修正）」——只有"多折的部分被修正"才赚钱。**禁止**把行业共性折价当成个股错杀证据。

## 预期的二分法（核心框架）

每条预期必须从两个维度分别获取，不能混为一谈：

### A. Consensus Expectation（市场共识预期）——市场公开说了什么

来源：分析师 EPS/目标价一致预期、管理层指引、社区主流叙事、券商研报。Web Agent（T3 Web Research 层）擅长获取。产出：《市场共识清单》。

### B. Price-Implied Expectation（价格隐含预期）——价格实际上要求什么

**不能简单用 PE→隐含增速**（PE 与增长无一一映射，还取决于 ROIC/再投资率/增长久期/利润率/派息/折现率/终值倍数）。用 **Reverse DCF / Reverse Earnings Model**：固定其他假设，只 solve 1-2 个关键变量。

- 例：当前 EV = PV(未来 FCFF)，solve "市场隐含的未来 5 年营收 CAGR = X%"
- 例：拆分部，solve "市场给某新业务（如多多买菜）赋予的未来利润贡献 ≈ Y"
- 价值型（保险/银行）：拆 EV = 调整净资产 + 有效业务价值，反推市场给 VIF 的定价 → 隐含长期投资收益率（实例：新华 H 股 0.40x P/EV 反推隐含长期收益率 ≤2.5%，低于负债成本=定价"永久利差损"，过度悲观 100-150bp）

**只有 B 可量化，A 是参照。预期差 = 我们的预期 − (B 价格隐含预期)**，用 A 做交叉验证。

## 五步工作流

### 第 0 步：口径校准（增量信息审计）

用户自带资料时先校准：逐项核对数字与已验证锚点，输出「增量信息/口径需修正/无法验证」三分类。常见口径陷阱：时点混用、单双季口径、分母口径（总资产vs投资资产、扣成本EV vs 账面EV）、汇率/税率、官方口径 vs 反推口径。无法验证的标置信度，禁止当事实引用。

### 第 1 步：反推市场隐含假设（Price-Implied，硬方法）

按上文"B. Price-Implied Expectation"的方法反推。产出《隐含假设反推卡》：价格 → 隐含假设 → 该假设的历史分位/可辩护区间 → 过度悲观/乐观幅度。

### 第 2 步：四大师定价审计（团队分工）

用 TeamCreate + Agent 组建 4 角色（或 lead 直接合成，见执行纪律）。按行业替换指标：

| 角色 | 分工 | 核心交付 |
|------|------|---------|
| 巴菲特（定价审计师） | 逐项审计市场预期，判定价状态 | 定价状态矩阵 + 反推卡 |
| 段永平（信号分析师） | 治理/分红/回购/管理层行为信号；证伪"XX开关修复→估值弹性"类叙事 | 信号解读 + 叙事证伪/证实 |
| 芒格（同业对比师） | 统一口径横向表；每家折价拆「该折+多折」；错杀排序 | 对比表 + 错杀排序 |
| 李录（尾部风险师） | 尾部风险：当前价格已计入百分比；安全垫击穿条件；期权型利好期望值（防负偏） | 尾部审计表 + 击穿清单 |

**定价状态四分类**（每条预期必归其一，附数字证据）：
- **已计价**：市场按此定价，无预期差
- **过度计价**：把周期性/一次性当永久性 → 修正则上涨
- **未计价**：基本面已变但市场用旧惯性定价 → 最大预期差来源
- **计价不足**：尾部真实但价格只反映一部分 → 下行保护不足

### 第 3 步：合成定价审计总表

输出：①定价状态矩阵（每条预期：市场隐含假设/实际数据/定价状态/预期差大小）②预期差排序（Top3：修正弹性最大+触发条件）③尾部风险排序（哪些计价不足）④四大师共识与分歧（分歧诚实呈现+裁决依据）。

### 第 4 步：关键监测指标排序

回答"接下来盯哪个指标"。每个指标给：连接哪条预期差/安全线与证伪线/数据来源与频率。排序原则：①安全垫类（股息/现金流）优先 ②催化剂类次之 ③叙事型信号（治理/评级）标"必要非充分"。

### 第 5 步：概率加权回报模型（输出给 forward-return，不做最终估值）

**年化回报 = 股息/现金流 + 增长（EPS/EV/营收） + 估值修复（PE/PEV/PB分位回归）**，三段给区间，按情景×概率加权。情景 4 档（乐观/基准/悲观/极端，悲观极端必填），每档给概率+年化+可证伪触发条件；概率加权年化 + 累计分布区间（分布宽度即仓位约束依据）。

**注意**：本步输出的是"回报情景框架"（给 forward-return 和裁判用），**本 skill 不输出最终目标价/单一涨幅**。

## 行业适配要点

不同行业的反推变量/正常化口径/监测指标不同，先确认行业类型再执行：

| 行业 | 反推变量 | 正常化口径 | 专属监测指标 |
|------|---------|-----------|-------------|
| 保险 | P/EV 拆 ANV+VIF 反推隐含投资收益率 | 剥离投资价差（表观净利不可持续） | 净投资收益率/偿付分档/NBV/利差损/承保财务损益 |
| 消费品 | PE 反推隐含增速 | 剔除渠道压货/一次性提价 | 提价落地/渠道库存/复购/合同负债 |
| 医药/科技 | PE/DCF 反推隐含增速与管线价值 | 研发费用正常化、管线期权单独计 | 集采/审批/竞品/研发里程碑 |
| 周期/全A股 | 峰值/谷值/均值三口径 PE | 扣非+现金流验证 | 周期位置/政策传导/内部人信号/商誉减值 |

**通用前置（利润质量四问）**：①可重复占比（剔除投资收益/公允价值/处置/补助）②现金流验证（经营现金流÷净利≥0.8为落袋）③杠杆放大器（总资产÷净资产+FVTPL类占比）④一次性项目识别。

## 输出模板要点

- **定价状态矩阵**：预期项 / 市场隐含假设(定量) / 实际数据 / 定价状态 / 预期差大小 / 证据来源——"市场隐含假设"必须定量，禁止"市场比较悲观"式定性
- **隐含假设反推卡**：价值型（PEV拆解）/ 成长型（PE反推）/ 周期型（三口径）三种格式
- **错杀排序表**：行业共性折价（单列，不算错杀）+ 公司特有折价（该折）+ 未计价改善（多折）
- **回报模型**：四档情景×概率加权，悲观/极端必填，触发条件可证伪
- **监测指标表**：指标/连接的预期差/安全线/证伪线/数据来源频率

## 执行纪律（实战教训）

1. **先备锚点再派工**：lead 先用 WebSearch 取核心锚定数据（价格/市值/EV/利润/关键比率），写进每个 Agent 任务书——Agent 拿到"已验证事实+待验证清单"，不是空白任务
2. **429 处理**：逐个 spawn（一条消息一个）；429 报错自带重置时间，重置前 spawn 必失败——此时 lead 直接合成并标注「lead 合成，非独立子报告」，**禁止编造 Agent 报告**
3. **跨 Agent 互查**：不同 Agent 对同一数据（汇率/每股口径/时点/单双季）常给不同数字——lead 用自己的验证锚点裁决，终稿列「数据校正」小节
4. **诚实三规则**：无法验证标注置信度；用户资料的乐观假设也要压力测试；"内部人信号"（分红/回购/增减持）比研报观点权重高
5. **数据分层**：财务事实必须用 `financial-data.md` 的 canonical 数据（T0/T1/T2 层），Web 研究（T3）只用于产生研究证据/共识预期，不得覆盖 canonical 财务事实
6. 仅供学习研究，最终报告必须带"不构成投资建议"声明
