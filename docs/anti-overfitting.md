# 防 Agent 过拟合现价：反锚定设计说明

> 本文档说明 AI Berkshire 买卖闭环如何防止 LLM Agent 在决策中**基于现价过拟合**——即用当前股价倒推结论，而不是从基本面推导价值。
> 适用版本：v7（买卖闭环）。

---

## 一、问题本质：为什么"现价"是过拟合源头

Agent（LLM）在研究中能看到实时股价。危险倾向：

1. **锚定效应**：现价下跌 → Agent 觉得"市场知道什么我不知道" → 下调建仓价；现价上涨 → 追高上调
2. **倒果为因**：用现价反推 PE，再宣称"PE 合理"——估值变成了价格的应声虫
3. **后视污染**：LLM 训练数据包含该股票的历史走势，可能用"未来信息"解释当前价格
4. **自我实现循环**：价格跌 → 建仓价下调 → 永远等不到"更低" → 系统失效

**价值投资的唯一正确用法**：市场价只是"报价"，内在价值由基本面推导。建仓价 = 内在价值的映射，**与现价无关**。

## 二、防线总览（四层）

```
┌─ 提示词层：反锚定硬约束（每次重研强制）
├─ 机械层：lock_entry_price 漂移检测（确定性代码，不依赖 LLM 自觉）
├─ 交易层：闸门拦截 + 8+4 分批 + 高开低开纪律
└─ 回测层：参数冻结 + PIT 信息集（见 docs/agent_backtest_brief.md）
```

## 三、逐层说明

### 1. 提示词层（agent_driver._build_prompt_full）

重研提示词中的硬约束：

- **先读旧报告对比基本面**，判断"基本面有无实质变化"
- **基本面无变化 → 建仓价必须沿用旧值**（允许 ±5% 微调，需在数据核验字段说明）
- **只有基本面实质恶化**（业绩下滑/行业证伪/治理爆雷）才允许下调，且须逐条列出证据
- **禁止以"股价下跌"作为下调建仓价的理由**；现价变化与建仓价无关
- 四视角独立检验：不得延续旧结论、不得互引估值、关键数字必须重算

### 2. 机械层（agent_driver.lock_entry_price）——防过拟合的核心

**锚定效应判据 = 时间序列漂移**：

```
若 新 gain_med ≥ 旧 gain_med − 10pct（基本面无实质恶化）
且 新建仓价较旧值下调 > 15%
→ 判定锚定嫌疑，建仓价机械锁定回旧值（groups.entry_med + pool.buy_zone）
→ 仅保留新 gain_med（承认估值刷新，但不允许价格漂移）
```

- 接入 review / run-one / batch2 三个入口，**零 LLM 依赖**
- 双重存储：`portfolio_groups.json`（entry_med/entry_min）+ `pool.json`（buy_zone）互相校验

### 3. 交易层

- **六道闸门第 5 关**：实时现价 > 击球区上沿 → 拦截买入（不追高）
- **8+4 分批**：初仓只打 8%（不因价格好看就打满）；补仓价锚定报告 entry_min，**禁止随股价下移**；每笔最多补 1 次
- **低开降级**（futu_bridge.decide_reorder）：挂单未成交时，现价 < 原挂单价 → 撤单回滚观望，不接飞刀
- **高开回滚**：现价超出击球区上沿 → 撤单回滚，等回落由系统重新触发（不追价买入）

### 4. 回测层（开发中，见 docs/agent_backtest_brief.md）

- **参数冻结**：所有阈值（止损/仓位/容忍度）是先验值，回测只能验证不能调优——"调参到最优"即过拟合
- **PIT 信息集**：历史时点决策只能用 ≤t 的信息（新闻时间戳截断 + 财报披露日对齐）
- **匿名化**：遮住公司名与可识别特征，防 LLM 训练数据后视

## 四、判断清单（研究每只股票时自查）

| # | 问题 | 回答"是"则违规 |
|---|---|---|
| 1 | 建仓价下调的理由里出现了"股价/现价/近期走势"？ | 违规 |
| 2 | 基本面没变，但建仓价变了 >5%？ | 违规（锁定） |
| 3 | 用"现价对应 PE 处于分位"作为建仓价依据？ | 弱违规（估值须由基本面推导，PE 分位仅作交叉参考） |
| 4 | 报告中的估值数字与现价"凑巧"高度一致且无推导过程？ | 嫌疑 |
| 5 | 补仓价随股价下跌而下移？ | 违规（锚定报告值） |

## 五、已知局限（诚实声明）

1. LLM 知识边界无法完全消除：提示词锚定"你是 T 时点的分析师"只能缓解，无法根治
2. 框架后见之明：六道闸门/阈值本身是 2026 年设计的，带有设计者的后见之明
3. 机械层只拦"大幅漂移"（>15%），小幅漂移（5-15%）靠提示词层自觉
