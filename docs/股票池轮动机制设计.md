# 股票池轮动机制设计（v2 Phase D · 轮动层）

> 目标：从"一次性初筛"升级为"持续运营的活池子"——每周自动重筛，财务恶化的移出，
> 新晋达标的移入，研究/监控/持仓三层联动。

---

## 一、五层股票池架构

```
┌─────────────────────────────────────────────────────────────────┐
│  Pool 0 · 全A市场（5539只）                                      │
│  来源：Tushare stock_basic（每日同步）                           │
└──────────────────────────┬──────────────────────────────────────┘
                           │ Layer 0+1 初筛（每日/每周）
┌──────────────────────────▼──────────────────────────────────────┐
│  Pool 1 · 初筛池（~500-1000只）   ← stage1_pool.json             │
│  规则：非ST/非亏损/非高PE/市值>30亿/ROE>8%/毛利>15%/净利>5%        │
│  状态：ACTIVE（达标）/ EXCLUDED（被剔除，留理由）                  │
└──────────────────────────┬──────────────────────────────────────┘
                           │ LLM 深度研究（每周批跑）
┌──────────────────────────▼──────────────────────────────────────┐
│  Pool 2 · 研究池（~50-80只）    ← reports/{公司}/ 深研报告        │
│  规则：Stage2/3 通过（4Agent 深研 + thesis 建立）                 │
│  状态：RESEARCHED / THESIS_DUE / STALE（论文>90天）               │
└──────────────────────────┬──────────────────────────────────────┘
                           │ extract_targets 提取击球区+仓位
┌──────────────────────────▼──────────────────────────────────────┐
│  Pool 3 · 监控池（~20-30只）    ← data/monitor/pool.json         │
│  规则：有 buy_zone + kelly 仓位                                  │
│  状态：WATCHING → TRIGGERED → REVIEW_DUE（6h任务驱动）            │
└──────────────────────────┬──────────────────────────────────────┘
                           │ 到价 + thesis-drift 复审通过
┌──────────────────────────▼──────────────────────────────────────┐
│  Pool 4 · 持仓池（实盘）      ← 实盘记录/实盘操作记录.md          │
│  规则：买入后进入，受卖出条件.md 约束                             │
│  状态：HOLD / SELL_SIGNAL / REVIEW                              │
└─────────────────────────────────────────────────────────────────┘
```

**关键原则：池子之间的流动是双向的**——不仅"向上晋升"，还有"向下淘汰"。

---

## 二、轮动规则（进出双向）

### 2.1 向上晋升（入池）

| 动作 | 条件 | 频率 |
|------|------|------|
| 全A → 初筛池 | Layer0+1 全部指标达标 | 每日（Layer0 秒级）+ 每周（Layer1 全量） |
| 初筛池 → 研究池 | LLM 深研通过（评分 ≥ 3.5 且有 thesis） | 每周批跑 |
| 研究池 → 监控池 | extract_targets 提取出 buy_zone + kelly>0 | 每周 |
| 监控池 → 持仓池 | 到价 + thesis-drift 复审无漂移 + 人工确认 | 实时 |

### 2.2 向下淘汰（出池）——三层淘汰逻辑

**Level 1：硬性淘汰（自动，每日检查）**
- 变 ST/*ST → 立即移出（无论论文多好）
- 净利润连续 2 期为负 → 移出
- 退市/暂停上市 → 移出
- 市值跌破 30 亿 → 降级观察 30 天，仍不恢复则移出

**Level 2：财务恶化（自动，每周对比）**
- ROE 年化较上期下滑 > 5pct → 标记 WEAKENING
- 毛利率下滑 > 3pct → 标记 WEAKENING
- 营收同比转负 → 标记 WEAKENING
- 连续 2 周 WEAKENING → 触发 thesis 复审（`/thesis-drift`）

**Level 3：论文失效（LLM 判断，每周）**
- 论文 > 90 天未复审 → STALE
- thesis-drift 判定"事实改变"（非措辞改变）→ INVALIDATED → 移出
- 到价但复审不通过 → 移出监控池，可留研究池观察

### 2.3 轮动频率（与你现有定时任务对齐）

| 任务 | 频率 | 做什么 |
|------|------|--------|
| 初筛 Layer0 | 每交易日（并入 6h 任务） | 价格/市值/ST 状态刷新，秒级 |
| 初筛 Layer1 | 每周日 22:00 | 全量财务指标重跑，更新通过名单 |
| 研究池批跑 | 每周（多窗口并行） | Stage2/3 深研新晋标的 |
| 监控池体检 | 每周日（已有） | WEAKENING/STALE/论文过期检查 |

## 三、轮动状态机（每只股票一份）

```json
{
  "ts_code": "600519.SH",
  "name": "贵州茅台",
  "pool": 3,
  "pool_history": [
    {"pool": 1, "enter": "2026-08-07", "reason": "Layer0+1通过"},
    {"pool": 2, "enter": "2026-08-14", "reason": "深研评分4.7"},
    {"pool": 3, "enter": "2026-08-15", "reason": "buy_zone+凯利12%"}
  ],
  "health": {
    "roe_yearly": 34.46,
    "gross_margin": 91.18,
    "trend": "STABLE",        // STABLE / WEAKENING / INVALIDATED
    "weakening_weeks": 0
  },
  "thesis": {"file": "reports/茅台/茅台-thesis.md", "age_days": 5, "status": "FRESH"},
  "last_screened": "2026-08-07"
}
```

**轮动引擎职责**：读取 stage1_pool.json + pool.json + thesis 状态 → 计算每只的 health/trend → 执行升降级 → 生成轮动报告。

## 五、实现（新增 tools/pool_rotator.py）

```
python3 tools/pool_rotator.py --weekly          # 每周轮动（Layer1 重跑 + 健康检查）
python3 tools/pool_rotator.py --health-only     # 只做健康检查（每日，快）
python3 tools/pool_rotator.py --report          # 生成轮动周报
python3 tools/pool_rotator.py --stats           # 各池数量统计
```

轮动引擎数据源：
- Pool1: data/screening/stage1_pool.json（Layer0/1 结果）
- Pool2: reports/{公司}/ 深研报告 + thesis 文件存在性
- Pool3: data/monitor/pool.json（监控池）
- Pool4: 实盘记录/实盘操作记录.md（手动维护）

## 六、与现有系统的集成

| 现有组件 | 轮动怎么用 |
|---------|-----------|
| 6h 数据清洗任务 | 加一步：`pool_rotator.py --health-only`（每日健康检查） |
| 24h 深度复盘 | 加一步：读轮动周报，对 WEAKENING 股票触发 thesis 复审 |
| ashare_screener.py | 轮动的 Pool1 数据源（Layer0/1） |
| extract_targets.py | 研究池 → 监控池的转换器 |
| 多窗口批跑 | 研究池补新标的（Stage2/3 深研） |
