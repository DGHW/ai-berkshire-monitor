# 东方环宇(603706.SH) 供气供热行业格局与竞争态势 — 芒格视角

> 分析人：industry-researcher（芒格视角）
> 日期：2026-08-09
> 速评卡基准：PE 15.3 / 市值 36.3亿 / 毛利率 31.9% / 净利率 25.1% / 营收增速 4%
> **数据核验预警：速评卡"净利率25.1%"与年报口径不符（2025年报净利率约16-18%），营收增速4%对应2026Q1而非2025年报（全年-7.77%），详见§8。已同步team-lead及财务分析师。**

---

## 0. 核心结论摘要

1. **行业定性：成熟、低增长、被强监管的公用事业**。2025年全国天然气表观消费量4265.5亿方，同比仅+0.1%（国家发改委快报）～+1.9%（《中国天然气发展报告2026》两种口径），告别2019-2024年均6-9%的高速增长期。城燃行业全面进入"存量博弈"，接驳费（地产红利）断崖式下滑，利润普遍承压。
2. **竞争格局：巨头的游戏，但对东方环宇而言是"井水不犯河水"**。昆仑/华润/新奥/中国燃气/港华五大巨头年销气量300-600亿方，东方环宇仅2.14亿方，是千分之一量级的区域小票。但城市燃气本质是**特许经营权下的区域垄断**，巨头无法进入昌吉、伊宁，东方环宇在本地无实质竞争者。
3. **东方环宇的护城河 = 特许经营权 + 区域垄断 + 双主业（气+热）**。昌吉市管道燃气独家经营权、伊宁市供热龙头（伊宁供热+伟伯热力覆盖主城区），供热收入已占营收47%，对冲了燃气销量的下滑。
4. **行业趋势对公司的含义**：顺价机制推进（毛利修复利好）、管网公平开放（上游直购直销或带来气源优化）、新能源替代（长期威胁热力业务）、"一城一企"整合（小票可能被并购或持续边缘化）。
5. **芒格视角定性：一门"还不错的生意，但不是伟大的生意"**——类债券属性，垄断稳定、现金流好、分红率高（5%左右），但增长天花板低、政策依赖性强、没有定价权。属于"合理估值买入赚股息+缓慢增值"的类型，而非"深度低估的击球机会"。

## 1. 行业规模与趋势

### 1.1 宏观数据（最新）

| 指标 | 数值 | 来源/置信度 |
|---|---|---|

| 2024年消费增速 | +7.3%；城市燃气占比34%（+11.1%） | 《中国天然气发展报告2025》【A】 |
| 2025年规上工业天然气产量 | 2619亿方，+6.2% | 公司年报引述【A】 |

| 乌鲁木齐配气价 | 综合0.26元/方（居民0.52/集中供热0.11/工商业0.78） | 官方公示【A】 |

**关键判断**：天然气在中国一次能源占比仅8.8%（世界平均约24%），长期仍有提升空间，但**短期增速已显著换挡**。2025年消费量几乎零增长，主因工业用气受气价与替代能源竞争压制、宏观经济偏弱。中金此前预测2025年+6.2%明显落空，行业进入"量增停滞"时代。

### 1.2 行业结构性变化（对城燃的影响）

- **接驳断崖**：房地产深度调整→新房接驳费大幅萎缩，过去"接驳费+销气量"双轮驱动模式终结。
- **"工弱居强"**：工业用气收缩（陶瓷、玻璃等），居民/商业用气成为销量压舱石，但居民气价受管控、毛利低→"增量不增利"。
- **利润分化**：2025年五虎中仅新奥股份归母净利正增长(+4.19%)，华润燃气-13.24%、昆仑能源-10.30%。反映单纯销气价差模式已难维系。

### 1.3 政策面（顺价机制是关键变量）

- **国家层面**："管住中间、放开两头"，发改委2025年9月《油气管网设施公平开放监管办法》、2025年10月《石油天然气基础设施规划建设与运营管理办法》（2026.1.1实施，管网运销分离、支持上下游直购直销）、2025年12月《城镇供水供电供气公用企业价格行为合规指南》。
- **地方层面**：各省市密集出台居民用气上下游价格联动机制，2025-2026采暖季多地已联动上调终端气价。**但顺价存在"最后一公里梗阻"**：居民气价联动滞后、冬季保供高价LNG成本难以完全传导，"购销倒挂"依然存在。
- **对东方环宇**：公司在年报中明确"持续向政府部门提出价格联动申请，努力克服政府为稳物价暂缓或延迟联动……联动幅度不能完全覆盖上游成本上涨"。→ **顺价是其毛利修复的核心变量，也是政策不确定性所在**。

### 1.4 新能源替代（长期威胁）

- **热泵**：2025年4月发改委等《推动热泵行业高质量发展行动方案》，地源热泵、电采暖在北方供热领域规模化替代燃气。
- **电/热替代**：北京新能源供热规模化（地源热泵+中深层地热）明确"每年替代燃气约750万方"。
- **分布式能源/氢能**：头部城燃转型"综合能源服务商"（冷热电多能联供+光伏+储能）；燃气掺氢、生物天然气入网为长期路径。
- **对东方环宇的含义**：其供热业务（占营收47%）基于燃煤热电联产+燃气锅炉，长期面临清洁供热替代压力；但新疆电采暖推广受电价、补贴制约，短期替代速度慢。此威胁为**5-10年级别的慢变量**，不构成近期投资否决项。

## 2. 行业竞争格局

### 2.1 全行业格局：央企龙头领跑、全国性运营商分层、区域小票边缘化

**城燃五虎2025年业绩对比**（置信度A）：

| 公司 | 2025营收 | 销气量 | 归母/股东溢利 | 同比 | 看点 |
|---|---|---|---|---|---|
| 昆仑能源 | 1939.79亿(+3.7%) | 592.6亿方(+9.4%) | 53.46亿 | -10.3% | 资源+市场全产业链，工业气占零售77.7% |
| 新奥股份 | 千亿级 | ~280亿方 | ~ | +4.19% | 唯一正增长，泛能业务高毛利 |
| 华润燃气 | ~980亿 | 401.8亿方(+0.7%) | ~ | -13.24% | 纯城燃渠道霸主，接驳断崖拖累 |
| 中国燃气 | ~900亿 | ~370亿方 | ~ | 下滑 | 接驳依赖度高，压力最大 |
| 港华智慧能源 | ~750亿 | ~160亿方 | ~ | 承压 | 价差0.58元/方，综合能源转型 |

行业特征：**"一快四平"，总量停滞、利润分化、整合加速**。中研普华判断"上游资源集中化、中游管网互联化、下游消费多元化"，"一城一企"政策推动份额向头部集中，中小城燃面临被并购或退出。

### 2.2 东方环宇的卡位：新疆区域小龙头（"井水不犯河水"的垄断）

- **体量**：2025年营收13.31亿元，行业排名25/31；销气2.14亿方，不足五虎的1/200。属典型区域小票。
- **经营区域**：
  - 城燃：昌吉市行政区域（含主城区、各乡镇、园区），**长期特许经营权，独家垄断**；
  - 供热：伊宁市（子公司伊宁供热+伟伯热力），**伊宁市规模最大、最主要的热力供应企业**，覆盖主城区核心商圈和大型生活社区；供热用户超28万户、供热面积约4000万平米。
- **卡位特点**：
  1. **区域垄断无实质竞争**：燃气/供热特许经营天然排斥外部巨头进入，昌吉市范围内东方环宇就是"唯一供给者"。
  2. **双主业对冲**：供热收入6.31亿(+3.27%)占比47%，2025年燃气销量-16%时靠供热+利润率提升稳住净利(+9.43%)。
  3. **气源条件优**：昌吉地处新疆气源富集区（周边新疆油田、吐哈油田），境内有西气东输二线/三线、北疆天然气环网、国家战略储气库，供应商为中石油新疆销售、中石化、庆华能源。
  4. **股息率高**：2025年度拟10派9元，按现价约19元计股息率约4.7%，具备类债券属性。

### 2.3 同省可比公司

- **新天然气(603393)**：体量大于东方环宇，2025H1净利率30.5%（行业最高），布局新疆+收购扩张，是区域内更具进攻性的标的。
- **新疆火炬(603080)**：喀什/克州区域燃气，体量与东方环宇接近。
- **对比结论**：东方环宇在新疆三小龙中业务结构最"重"（供热占比高、类重资产公用事业）、增长最依赖本地城市化与顺价，弹性居中，防御性最强（供热保民生刚需）。

## 3. 核心竞争者威胁评估

| 威胁来源 | 威胁程度 | 分析 |
|---|---|---|
| 五大巨头进入昌吉/伊宁 | **极低** | 特许经营权地域排他，市政管网资产不可复制。巨头只能通过并购进入，而东方环宇国资属性+稳定盈利，被恶意并购难度大。 |
| 新疆本土同业（新天然气/新疆火炬） | **低** | 经营区域不重叠（昌吉 vs 喀什/克州等），无正面冲突。 |
| 气源单一依赖（中石油体系） | **中** | 上游"一年一签"购销合同，中石油新疆销售是主供应商；公司称未发生气源短缺，但议价权在上游。管网公平开放政策或带来直购直销优化空间。 |
| 替代能源（电采暖/热泵/电锅炉） | **中-长期** | 供热业务47%收入占比是最大软肋，北方清洁供暖政策若向电采暖倾斜将侵蚀热力基本盘；新疆短期受电价/财政补贴制约，替代速度慢。 |
| 政策监管（价格管制/反垄断） | **中** | 公用事业反垄断监管趋严（2025年12月价格行为合规指南），顺价申请可能被推迟或打折，毛利修复空间受限。 |
| 单一客户集中（昌吉城投） | **中**（历史事件） | 昌吉城投2024-2025采暖季未采购天然气，公司已通过债务重组收回部分应收款。此类政府平台拖欠风险需持续监控。 |

**芒格式总结**：东方环宇面临的"竞争"不是同行对手，而是**监管者（价格政策）与能源替代（长期）**。它没有需要打败的敌人，但有需要伺候的"裁判"。

## 4. 行业趋势：气价市场化、分布式能源、氢能

### 4.1 气价市场化 → 双刃剑
- 利好面：管网公平开放+运销分离支持上游与城燃/工业用户**直购直销**，气源多元化后采购成本有望优化；顺价机制完善修复购销价差（港华2025年综合价差已升至0.58元/方）。
- 利空面：市场化意味着价格波动加大，冬季保供高价LNG成本传导仍困难；居民气价政治敏感性高，顺价比例提升缓慢。
- **对东方环宇**：其气源已较多元（中石油+中石化+庆华），管网改革后有机会在新疆本地寻找更低成本气源；顺价是其2026年盈利改善的核心驱动（2026Q1净利+26.4%已部分验证）。

### 4.2 分布式能源与综合能源服务 → 转型方向
- 头部城燃从"卖气郎"转型"综合能源服务商"（冷热电气多能联供、光伏、储能、充电桩）。
- **对东方环宇**：公司已具备天然气供热及制冷（直燃机制冷）、分布式能源供热能力，具备切入综合能源的基因；但体量小、资本有限，转型以跟随为主。

### 4.3 氢能 → 远期期权
- 燃气掺氢、生物天然气入网、可再生能源制氢是长路径；2030年前对城燃公司业绩无实质贡献。
- 东方环宇在此方向无公开布局披露，仅作远期观察项。

## 5. 产业链与价值分配

```
上游(气源)         中游(管输+城燃)         下游(用户)
中石油/中石化/      国家管网公司(长输管输费)   居民(刚性,气价受管控)
庆华能源等          ↓                    商业(刚性)
基准门站价1.03元/方 城燃(配气费+购销价差)    工业(价格敏感,气价高位时收缩)
(新疆全国最低)      ↓                     CNG汽车/采暖
                   终端销售价(政府指导价)
                   供热(热电联产+燃气锅炉)
```

**价值分配逻辑**（芒格视角）：
1. **上游拿走大头**：新疆门站价全国最低（1.03元/方），但近年中石油合同气价格上浮（非采暖季综合上浮约41%），上游强势地位不变。
2. **中游城燃赚"过路费"**：城燃盈利=终端售价−(采购价+配气成本)，本质赚**受管制的合理回报**（准许成本+合理收益）。乌鲁木齐配气价仅0.26-0.78元/方，意味着城燃毛利空间被政策锁定、向上游议价权弱。
3. **下游居民最弱**：气价政治敏感，顺价滞后，居民用气毛利被压缩。
4. **东方环宇的特殊性**：供热业务（热电联产+政府定价）提供稳定现金流，等于在气+热两个受管制环节同时"收租"，价值分配上比纯燃气公司多了一条腿，但两条腿都受政府定价约束。

**核心结论**：这是一条**价值被政策锁死的中游产业链**——不会暴利，但也不太会暴亏；上游强势、下游弱议价、城燃靠区域垄断赚稳定钱。符合芒格对公用事业"平庸但稳定"的定性。

## 6. 东方环宇卡位评估（芒格框架）

| 芒格问题 | 评估 |
|---|---|
| 这门生意容易理解吗？ | **是**。天然气+供热，需求可见，模式简单。 |
| 有没有持久的竞争优势？ | **有，但属"政策赋予型"而非"经营构建型"**：特许经营权=区域垄断；管网近3000公里=重资产壁垒；伊宁供热龙头=规模优势。护城河真实但宽度有限、受政策调控。 |
| 增长空间有多大？ | **有限**。昌吉/伊宁城市化接近成熟，燃气渗透率已高（居民用气仅+1.45%），增长依赖：①顺价修复毛利；②农村煤改气（已完成9乡镇107村1.63万户）；③并购（伊宁供热并购成功范例，未来或有复制）。 |
| 行业竞争会毁灭它吗？ | **不会**。区域垄断+民生刚需，无直接对手。 |
| 最大风险是什么？ | 政策（顺价不达预期）、单一区域经济（昌吉/伊宁增长放缓）、新能源替代供热、政府平台应收款。 |
| 管理层资本配置？ | 分红慷慨（10派9，分红率约79%），并购审慎（伊宁供热案例成功），未乱铺摊子。**这一点芒格会点赞。** |

**芒格综合定性**：**"不错的生意，不是伟大的生意"**。属于可长期持有的类债券型资产：PE15.3倍、股息率4.7%、盈利波动小、区域垄断稳，但缺少伟大生意应有的定价权与成长性。定性为**合理估值、赚股息+缓慢增值**，而非深度低估的击球机会。

## 7. 行业层面关键风险

1. **顺价不及预期**：政府稳物价诉求→居民气价联动延迟/打折，购销价差修复慢（公司在年报中明确承认此风险）。
2. **工业用气需求持续疲软**：2025年非居民销量-22.99%，若2026年昌吉工业/商业经济不回暖，燃气主业将继续拖累。
3. **新能源供热替代**：电采暖/热泵政策加码→供热面积增长停滞甚至收缩（长期慢变量）。
4. **"一城一企"整合**：行业向头部集中，中小城燃或被并购（东方环宇作为盈利稳定的区域资产，可能成为并购标的——双刃剑）。
