# 明月镜片(301101.SZ)行业竞争分析——芒格视角

> **分析框架**: 芒格"行业竞争格局"视角——这门生意是否具备长期竞争优势？竞争格局对参与者是否友好？价值如何分配？
> **报告人**: industry-researcher-301101（芒格视角）
> **数据截止**: 2026-08-11（市值59.5亿、PE-TTM 29.5x取自标的卡片；行业数据均标注来源日期）

---

## 一、芒格视角总评（先说结论）

**一句话**: 明月镜片所处的是"**需求长坡、国产替代进行中、但格局分散且价格战未止**"的镜片行业——离焦镜细分是近视防控赛道里增长最快的"好赛道"，明月是**唯一能与外资三大巨头同台竞技的国产品牌**，这是真实的竞争力。但芒格会给出**🔴红灯**：行业低端产能过剩（CR5出货量仅约52%）、外资在高端和临床数据上仍占优、公司2025年营收仅+7.43%（**显著跑输离焦镜市场+24.5%的增速**，说明没充分吃到赛道红利）、ROE仅11.30%平庸、PE 29.5x对应2026E仍达27x不便宜。**"不错的生意、普通的价格，好赛道里的国产小巨人，但现价没有安全边际。"**

## 二、行业规模与增长：镜片大盘平稳，离焦镜是唯一"高增长引擎"

### 2.1 镜片大盘：千亿眼镜市场中的"半壁江山"

| 维度 | 数据 | 来源/截止 |
|---|---|---|
| 中国眼镜零售市场规模 | 2024年约933亿元，其中镜片约409亿元（占44%） | 艾瑞《2025中国眼镜行业白皮书》2026-03 |
| 镜片零售市场预测 | 381.5亿元(2024)→537.1亿元(2029)，CAGR约6-8% | 明月官网转引白皮书2025-04 |
| 中国近视人口 | 儿童青少年近视率超50%，近视人口近7亿 | 国家卫健委/公开数据 |

**判断**: 镜片是"必选+低频升级"消费，大盘增速温和（6-8%），但**结构性分化剧烈**——普通单光镜片量价双平，功能镜片（近视防控/防蓝光/高折射/渐进）是唯一增长主线。

### 2.2 离焦镜：近视防控最强细分，"抢OK镜客户"的赢家

| 维度 | 数据 | 来源/截止 |
|---|---|---|
| 离焦镜市场规模 | 2024年约128.6-130亿元，同比+24.5%；2025E约160-186亿元 | 艾瑞2026-03/docin行业报告2026-06 |
| 离焦镜占镜片市场比重 | 约32%，眼镜行业增长最快细分赛道之一 | 艾瑞2026-03-09 |
| 离焦镜销量 | 2023年国内约700万副 | 天风证券 |
| 角膜塑形镜(OK镜) | 2024年约70亿元（渗透率1.5%），增速放缓、被离焦镜分流 | 雪球行业分析2025-04 |
| 离焦镜 vs OK镜 | **欧普康视、爱博医疗、昊海生科年报"异口同声"：离焦框架眼镜抢走了OK镜的客户** | 界面新闻2025-05-13 |

**关键行业信号（对明月最有利的一条）**:
1. **OK镜进入"增速换挡"调整期**——昊海生科2025年角膜塑形镜收入同比-11.73%，欧普康视/爱博医疗同受冲击；而OK镜（三类医疗器械）还面临集采风险（河北已开集采先例），**离焦镜是普通消费品、无集采风险**——这是赛道选择的制度性优势。
2. 离焦镜渗透率仍低：青少年近视率超50%，离焦镜当前销量700万副/年，相对1.5亿+近视青少年渗透率不足5%，长坡确定。
3. **明月正是离焦镜国产替代的头号受益者**（详见第三节）。

### 2.3 明月镜片自身增速：赛道快，公司慢

- 2025年营收8.28亿元（+7.43%），归母1.93亿元（+9.13%）——**大幅跑输离焦镜市场+24.5%的增速**。
- 公司离焦镜"轻松控"系列：2024年销售额1.64亿（+22.7%）、2025Q1 0.50亿（+22.1%），剔除产品升级回收后2025Q1 +33.8%——**增速逐年降档**（2024Q1 +33.8% → 2025Q1 +22.1%）。
- 2025年增长动力主要是 **PMC超亮（+46.1%）、1.74高折射（+130.5%）** 等高端产品放量，而非离焦镜——产品结构升级是当前主逻辑。

**芒格点评**: "赛道是好赛道，但公司业绩只是'温和成长'，说明离焦镜还没成为它的利润引擎，或者说竞争远比想象激烈。投资者买的是'近视防控+国产替代'的故事，但2025年报表兑现的是7.4%的增长——**故事与报表之间有差距，这个差距要靠时间或降价弥补。**"

## 三、竞争格局：分层清晰的"外资高端主导 + 国产中低端混战"

### 3.1 整体格局：三组梯队

| 梯队 | 代表 | 特点 |
|---|---|---|
| **国际一线** | 蔡司、依视路（含收购的万新）、豪雅 | 高端（出厂额）绝对主导，临床数据/光学技术/品牌力最强 |
| **国产第一梯队** | **明月镜片**、康耐特光学 | 明月=品牌+零售（国产第一品牌）；康耐特=制造+出口（规模更大但品牌弱） |
| **国产二线/白牌** | 汇鼎、鸿晨、新天鸿、优立等 | 出货量大、低价走量，价格战主力 |

### 3.2 市占率多口径对比

| 口径 | 第一 | 第二 | 第三 | 第四 | 来源/年份 |
|---|---|---|---|---|---|
| **按出货量** | 依视路（含万新）**17.1%** | **明月镜片 12.0%** | 汇鼎 8.8% | 鸿晨 8.7% | 2024年 |
| **按零售量** | **明月镜片 12%**（并列） | 万新 12%（并列） | 鸿晨 7% | 汇鼎 6% | 2023年 |
| **按出厂销售额** | 蔡司 **18%** | 依视路 | **明月 9%** | — | 2023年 |
| **离焦镜（四强）** | 蔡司/依视路/豪雅/明月合计 **69.4%**，**明月为唯一国产品牌** | | | | 2024年白皮书 |
| **离焦镜出厂额** | 明月+三大外资合计 **62%** | | | | 天风证券（2023年700万副） |

**核心结论**:
- **零售量与出货量口径，明月=国产第一、全行业第二**（仅次于依视路+万新合并体）；**出厂销售额口径，外资仍主导高端**（蔡司18%+依视路）。
- **离焦镜细分是明月竞争力最强的战场**——四强格局中明月是唯一国产品牌，凭性价比（轻松控Pro 2.0指导价约2000元 vs 星趣控/新乐学终端3500元+、医院渠道4000元+）卡位"国产替代"主升段。
- **依视路收购万新后**（依视路+万新合并出货量17.1%居首）——外资通过并购实现"高中低通吃"，是明月最现实的强敌。

### 3.3 明月竞争定位总结

| 优势 | 劣势 |
|---|---|
| 国产唯一第一梯队品牌（连续九年全国销量领先认证） | 高端（1.74/渐进/个性化）仍逊于蔡司/依视路 |
| 离焦镜四强中唯一国产、性价比定价 | 整体营收体量小（8.28亿，仅为依视路中国零头） |
| 原料一体化（KR树脂/PMC膜层/1.71专利材料，阿贝数37） | ROE仅11.30%，品牌消费品的资本回报平庸 |
| 直销占比约61%（眼镜连锁/医院直供，渠道掌控力强） | 低端市场被汇鼎/鸿晨等白牌价格战侵蚀 |
| 品牌认知度国产第一 | 离焦镜增速降档，未充分吃到+24.5%的市场红利 |

## 四、核心竞争者威胁

### 4.1 依视路（EssilorLuxottica）+ 万新：并购型"高中低通吃"
- 依视路通过收购万新将出货量份额做到17.1%全行业第一，且星趣控（H.A.L.T多点近视离焦）是离焦镜头部产品，医院渠道渗透极深。
- 背靠全球最大视光集团，研发/品牌/渠道三线碾压。
- **威胁等级: ★★★★★（结构性最强对手）**

### 4.2 蔡司、豪雅：高端+临床数据"护城河"
- 蔡司出厂额份额18%居首，"小乐圆"（C.A.R.E同心环带微柱镜）；豪雅"新乐学"（DIMS，396微透镜，**6年长期临床数据、延缓近视进展59%**）是离焦镜行业标杆。
- 外资拥有更长期的循证医学背书——**临床数据时长是离焦镜信任状的"硬通货"**，明月"3个月临床结果"曾被质疑观察期过短（2022年媒体事件）。
- 1.74核心原料MR-174仅日本三井化学量产，蔡司/豪雅/依视路全部依赖——超高端环节外资原料占优。
- **威胁等级: ★★★★（高端市场长期压制）**

### 4.3 康耐特光学：规模更大的"制造出口型"对手
- 港股上市（02276.HK），收入规模约为明月3倍（2024H1营收9.76亿/+17.5%），专注1.67/1.74高折射率镜片，出口80多国。
- 但康耐特是"制造/代工+出口"属性，国内品牌知名度弱，与明月"品牌零售"路线错位竞争，直接冲突有限。
- **威胁等级: ★★（错位竞争，高端原料端存在共同瓶颈）**

### 4.4 白牌厂商价格战
- 汇鼎（8.8%）、鸿晨（8.7%）等低端厂商以低价走量，2025年行业价格战加剧——明月2025H1毛利率57.9%（-1.5pct）、镜片业务毛利率62.4%（-1.08pct）实证压力。
- 功能性镜片（防蓝光等）门槛低，内卷激烈。
- **威胁等级: ★★★（周期性价格战，侵蚀毛利）**

## 五、行业趋势（四条主线）

1. **近视防控政策+渗透率提升双轮驱动**：国家《综合防控儿童青少年近视实施方案》持续加码，青少年近视率超50%，离焦镜渗透率不足5% → 长坡厚雪，离焦镜2025E仍将+20%以上。
2. **国产替代主升浪**：以明月为代表的本土品牌在离焦镜、高折射、防蓝光等细分已能与外资同台竞技，零售量口径国产份额反超；2026年三井MR-174原料供给紧张、外资1.74涨价8-20%、交期拉长4-8周，**为国产高折射替代提供窗口期**（明月1.71专利材料+自研原料是差异化抓手）。
3. **离焦镜替代OK镜的结构性转移**：OK镜增速放缓+集采风险 vs 离焦镜消费品属性无集采风险，需求流向利好镜片厂。
4. **AI眼镜题材（谨慎看待）**：2025年中国智能眼镜出货246万台(+87.1%)，明月为小米AI眼镜官方独家光学合作伙伴（2025Q3末该业务收入仅651万元、毛利率78.6%）——**目前是纯题材期权，对业绩贡献可忽略**，须警惕题材透支估值。

## 六、产业链分析：价值分配——"原料自给率决定利润率"的好生意

```
上游（树脂原料/MR原料/镀膜） → 中游（镜片制造） → 下游（眼镜连锁/医院/电商）
  三井化学垄断1.74(MR-174)    明月/蔡司/依视路/   博士伦/宝岛/医院渠道/小米AI眼镜
  明月自研KR树脂/PMC膜层       康耐特/白牌         单副终端价200-4000元
```

| 环节 | 议价能力 | 说明 |
|---|---|---|
| 上游原料 | 中 | 1.74核心原料被三井化学垄断；明月靠KR树脂+1.71自研材料部分绕开（这是明月毛利率57%高于康耐特等制造同行的重要原因） |
| **中游品牌制造（明月）** | **中偏强** | 品牌+渠道+原料一体化，直销占比61%；但低端无定价权（价格战实证） |
| 下游零售/医院 | 中 | 眼镜零售单副毛利极高但分散；医院渠道是离焦镜高溢价关键（外资占优） |

**芒格式判断**:
- **好的一面**: 镜片是"高毛利消费品"（明月毛利率57.35%、净利率24.62%），远超一般制造业；**原料一体化（KR树脂、PMC、1.71材料）是真实的护城河**——同业（康耐特、白牌）依赖外购原料，明月成本结构与产品差异化双优；品牌"连续九年全国销量领先"+直销占比61%说明渠道掌控力强。
- **坏的一面**: 行业整体**格局分散、低端混战**（CR5出货量仅52%），价格战周期性发作（2025H1毛利率-1.5pct）；**高端价值链仍被外资收割**（出厂额蔡司18%）；离焦镜的信任状（临床数据）外资有6年积累，明月需持续投入追赶。
- **芒格会怎么说**: "这是一门不错的消费品生意，有真实的品牌与成本护城河，但它所在的市场并非寡头垄断，而是'诸侯混战+外资压顶'。它不会是可口可乐，更接近一个**成长中的、需要持续奔跑的消费品牌**。买它必须在合理价格——29.5倍PE买入一家ROE仅11.3%、2025年只增长7.4%的公司，是对'赛道'而非'公司'付了溢价。"

| 毛利率 | 55.2% | 2025年报毛利率 **57.35%**，2025H1 57.9%（-1.5pct） | 卡面略保守，基本一致 ✅ |

| 营收增速 | 18.3% | 2026Q1单季+18.32%；**2025全年仅+7.43%** | **Q1单季口径**，非全年，方向性高估 ⚠️ |

**行业视角重要补充（非速评卡口径）**:
1. **增速口径陷阱是本次最大失真点**: 速评卡"营收+18.3%成长稳定"会让人误以为公司处于高成长，实际2025全年仅+7.43%，2025Q4单季+7.55%仍是个位数——**18.3%是2026Q1的脉冲值**（PMC/1.74新品放量+离焦镜升级回收影响），2026全年能否保持需中报验证。
2. **离焦镜增速降档**: 轻松控系列从2024Q1 +33.8% → 2025Q1 +22.1%，且占收入比重仅约25-30%，尚未成为利润引擎。
3. **现金流隐患**: 2026Q1经营活动现金流-2564万元（上年同期+641万元）转负——Q1为行业淡季+备货因素，但需8月中报确认全年OCF仍为正（2025全年OCF 2.83亿/+33.9%、净现比1.47质量良好）。
4. **分红**: 2025年10派5元，股利支付率52%、股息率约1.7%——对消费品牌而言中等，不是红利逻辑。

## 八、芒格视角综合判定

**"镜片行业是一门好生意吗？"——分层回答:**

1. **行业层面**: 🟢 **是长坡赛道**。镜片大盘CAGR 6-8%稳定，离焦镜细分+24.5%高增长、渗透率不足5%、无集采风险（vs OK镜），政策友好（近视防控国策）。需求确定性好。
2. **竞争格局层面**: 🟡 **中等偏弱**。格局分散（CR5出货量仅52%），低端价格战持续（2025H1毛利率-1.5pct实证）；外资在高端出厂额（蔡司18%）、临床数据（豪雅6年）、1.74原料（三井MR-174）三维度仍占优。明月是国产唯一第一梯队，但**并非行业格局的主导者**。
3. **明月个体层面**: 🟡 **"好赛道里的国产小巨人"**。品牌（国产第一）、原料一体化（KR树脂/PMC/1.71）、渠道（直销61%）三重护城河真实，离焦镜四强中唯一国产，是国产替代的最大受益者之一。但**ROE仅11.30%平庸、2025年增速7.43%平淡、离焦镜增速降档**——护城河"宽但不够深"，还撑不起高成长估值。
4. **估值层面**: 🔴 **现价没有安全边际**。PE-TTM 29.5x，对应2026E约27x；一家ROE 11.3%、增速10-18%的消费品牌，合理PE中枢应在22-25x。29.5x是在为"离焦镜高增长+AI眼镜期权"支付溢价，而2025年报表只兑现了7.4%的增长。

**芒格结论**: **🔴 红牌——"好赛道、不错的公司、太贵的价格"**。芒格会承认明月是国产镜片里最值得关注的标的（唯一能挑战外资的国产品牌、原料一体化、长坡赛道），但会说："**等待是投资者最有力的工具。29.5倍PE买入一家增长温和、ROE平庸的消费公司，等于用未来的好消息预付今天的账单。**" 需要等价格回到合理区间，或中报证明离焦镜+高端产品放量让全年增速站上20%再重新评估。

## 量化结论

- 内在涨幅: **-8%**（三情景加权：乐观2026E归母2.3亿×30x=69亿/+16% [25%权重]；中性2.2亿×25x=55亿/-8% [50%权重]；悲观2.0亿×20x=40亿/-33% [25%权重] → 加权中枢约55亿 vs 现市值59.5亿。参考券商2025-2027预测1.9/2.2/2.4亿）
- 击球区: 🔴 **未到**——离焦镜国产替代长坡+原料一体化护城河真实，但PE 29.5x（2026E约27x）对2025年实际+7.43%的增速和11.30%的ROE明显偏贵，赛道红利未充分转化为公司报表增速
- 目标建仓价: **24.0 元**（对应2026E归母2.2亿×22x=48.4亿市值，即2026E PE 22x——对ROE 11.3%、增速15-20%的成长消费股合理估值上沿）
- 二次补仓价: **20.0 元**（对应2026E PE 18.3x、市值40.2亿——价格战恶化或增速回落至个位数的悲观情形，下行保护来自原料一体化毛利优势+净现金17亿+连续九年国产销量第一的品牌底）
- 数据核验: ✓ **已核验**（PE-TTM 29.5 vs Tushare 29.73一致；**ROE速评卡12.5%=Q1年化口径，2025年报加权真值11.30%，偏差+10.6%**；毛利率55.2% vs 年报57.35%基本一致；净利率24.6%与年报24.62%吻合；**营收增速18.3%为2026Q1单季口径，2025全年仅+7.43%，方向性高估**）
