# 长江证券(000783) 商业模式分析 — 段永平视角

> 分析日期：2026-08-11 | 收盘参考：9.04元(2026-08-07) | 市值：499.9亿 | 总股本55.3亿股
> 段永平式提问：这是门好生意吗？它有护城河和定价权吗？管理层本分吗？现在这个价格我愿意拿十年吗？

---

## 一、生意本质：靠天吃饭的"市场Beta生意"，不是创造价值的生意

段永平投资的第一原则是"看懂生意"。券商这个生意，我认为是**最难懂、最不值得长拿的生意类型之一**，长江证券更是典型。

### 1.1 收入结构：六成靠通道+利息，两成靠"拿股东的钱炒股"

按2025年报口径拆解（营收105.48亿，+59.86%）：

| 业务 | 2025年收入 | 占比 | 性质 |
|---|---|---|---|
| 经纪手续费 | 37.7亿 | 35.74% | 通道生意，佣金率长期下行 |
| 利息净收入(信用/两融) | 23.75亿 | 22.52% | 加杠杆赚息差，随市场两融余额波动 |
| 自营投资 | 21.77亿 | **20.64%** | **拿股东的钱炒股票债券，业绩+524.66%** |
| 投行 | 约4亿 | 3.78% | 短板，项目制 |
| 资管 | 约2.9亿 | 2.79% | 短板，依赖长信基金(规模破2000亿) |

**核心判断：** 六成收入来自经纪佣金+信用利息，本质是**市场成交量的Beta**；两成来自自营，本质是**市场行情的Beta**（2025年自营收入暴增524%正是牛市beta，不是经营能力）。市场一冷，这两块同时收缩——这是"双Beta"生意，赚的是市场景气度的钱，不是公司自己创造的价值。

### 1.2 周期性的实锤

- 2024年归母净利18.35亿（历史低谷）→ 2025年36.96亿(+101.44%) → 2026H1预告31.26-33亿(**+80-90%**，Q2单季约16.4-18.1亿还高于Q1的14.86亿)
- 两年利润翻三倍，全靠市场回暖。这种盈利曲线**不可外推、不可预测**，与段永平喜欢"十年可预测"的生意完全相反。
- 长江证券历史上最差年份归母仅个位数亿，最好年份近37亿——**波动倍数4倍以上**。

段永平会问："如果明天市场冷三年，这家公司还能赚多少？"答案是：盈利可能腰斩再腰斩，而营业成本刚性，杠杆还要付息。

### 1.3 为什么"看不懂"就不碰

段永平说过，券商的问题在于**你不知道它的真实资产质量**（自营仓位、两融风险、股票质押踩雷），也不知道它明年赚多少。长江证券2026Q1负债率78.71%——这在券商算正常杠杆，但意味着**8毛多钱是借来的**，赚的是息差+市场钱，亏起来也是杠杆放大。这不是"本分"的生意模式。

**生意本质评分：2/10（很差）。** "刚需行业里的类化工生意"（自营=拿股东的钱做高波动投资）是往好了说；往实了说，这是**牌照加持下的杠杆赌场**，段永平大概率直接PASS。

## 二、护城河：牌照是门槛，不是护城河；长江没有差异化

### 2.1 牌照型"伪护城河"

券商牌照限制准入，但同质化严重——通道佣金率被价格战打穿，牌照不值钱。**护城河的定义是"别人抢不走你的生意"，牌照只能挡住新进入者，挡不住同行竞争。**

### 2.2 区域优势（湖北）：真实存在，但正在贬值

- 湖北地区IPO在辅排名第1、新三板挂牌并列第1、债券承销规模前3——区域投行有真实卡位。
- 但经纪业务佣金率市场化的当下，区域网点优势**不构成定价权**，只是获客入口。佣金率该降还是降。
- 湖北省属券商身份（湖北长江产业集团为第一大股东）能带来区域国资项目资源，这是**关系型优势**，可持续性取决于国资支持力度。

### 2.3 研究所是相对亮点

长江证券研究所长期是行业第一梯队（刘元瑞是"新财富白金分析师"），佣金分仓收入是真实现金牛。**但研究不直接创造终端价值**，且2026年7月多名首席离任——相对优势正在被人才流失侵蚀。

### 2.4 投行、资管是短板，无第二增长曲线

投行仅占营收3.78%、资管2.79%。在一个靠自营和通道吃饭的公司里，两块"真正考验专业能力、能形成差异化的业务"恰恰最弱——说明**管理层的能力圈也没做出差异化**。

**护城河评分：1/10（极浅）。** 无品牌、无网络效应、无转换成本、无成本优势。唯一的"湖北区域+国资关系"护城河浅得可怜，且**不可货币化验证**（区域优势没有带来高于同业的佣金率或ROE）。

---

## 三、定价权：完全没有

段永平检验生意质量的核心问题："它提价容易吗？"

- 经纪佣金：行业佣金率持续下行，靠**降费抢量**而非提价。
- 两融/信用利率：市场定价，无自主空间。
- 自营：随行就市，连"定价"都没有，纯被动。
- 投行费率：项目制，靠竞争投标。
- 资管费率：被动管理为主，主动管理能力存疑（资管占比2.79%）。

**定价权评分：0/10。** 这是典型的"被市场定价"的生意，长江证券没有任何一项业务拥有提价能力。

---

## 四、企业文化与"本分"：历史污点重，国资入主后边际改善但远未证清

段永平买公司就是买人、买企业文化。长江证券的治理史是**减分项**。

### 4.1 历史不本分：派系斗争

- 2015年刘益谦(新理益)入主后，长江证券陷入**无控股股东、无实控人**的"三足鼎立"格局（新理益/三峡系/湖北国资），内部派系斗争不断。
- 2017年总裁邓晖离职，市场传闻系股东博弈"逼退"，被形容为"宫斗大戏"——**资本大佬与管理层互撕，是典型的股东不本分、公司文化内耗**。
- 刘益谦投资长江证券累计亏损约55亿让位，本身就是一笔"资本运作失败"的教训。

### 4.2 合规污点：处罚不断

- 2025年3月：证监会因投行业务执业问题（质控现场核查制度执行不到位）"责令改正"。
- 2025年6月：湖北证监局因投顾业务推广及客户回访记录留存不完整出具警示函——**3个月2次被罚**。
- 2025-2026年：薛丹、李相佳等多起营业部/员工警示函；2026-08-01湖北证监局又对公司出具警示函。
- 员工违规炒股、泄露客户信息、经纪人管理不到位——**合规体系不完善是系统性证据**。

### 4.3 湖北国资入主后的变化：边际改善，但"本分"待验证

- 2025-08-06过户完成，湖北长江产业集团持股17.41%成为第一大股东（**锁定5年**），湖北能源、三峡资本彻底退出。湖北国资同时控股长江证券、天风证券、华源证券三家上市/挂牌券商——**"湖北系"整合预期**是当前股价的重要支撑逻辑。
- 加分项：连续19年现金分红（2025年度每10股派3元，合计16.59亿，分红率约45%）；2026-07-24董事长提议最高2亿回购。
- 减分项：2026年7月**研究所多名首席离任**（研究是公司相对优势，人才流失=护城河受损）；长信基金换帅调整（刘元瑞卸任长信董事长）。
- 风险点：地方国资主导下，存在"服务湖北、整合做大"的**政绩导向**——与天风证券的合并传闻不断但官方否认（长江证券明确"无收购天风/华源计划"），财联社2026年3月分析三家券商横跨省市两级国资平台，"协调成本极高"。**整合预期若兑现可能摊薄股东利益，若不兑现则是概念炒作后的一地鸡毛。**

**企业文化评分：3/10。** 历史派系斗争+系统性合规处罚="不本分"实证；湖北国资锁定5年+回购+连续分红是改善信号，但**"为政绩整合、损害中小股东"的风险仍在**，且研究人才流失暴露内部管理问题。整体未到"值得信赖"程度。

## 五、估值：价格不算贵，但"普通生意"需要"便宜价"，现在不是

### 5.1 金融口径用PB（券商正确打开方式）

**数据核验（强制交叉验证）：**

| 指标 | 速评卡 | 核验结果 |
|---|---|---|
| ROE年化 | 14.03% | **⚠️ 口径存疑**：Tushare年化9.11%，交叉验证偏差**21.24%**。2025年报加权ROE实为**10.02%**（已是上市以来最好），2026Q1单季加权ROE 3.94%。速评卡14.03%为周期顶部TTM/年化口径，**正常化参考值8-10%** |
| PE-TTM | 11.9 | ✓ 一致（Tushare 11.87，偏差0.14%）。但PE对券商周期股**失真**——2026H1净利+80-90%是景气高点，周期顶部低PE是"顶部陷阱" |
| PB | "约1.7倍" | **❌ 与事实不符**：账面PB约1.11倍（净资产约438亿/499.9亿市值），审慎PB(扣除60亿永续债)约1.28倍，动态PB约1.42倍 |
| 净利率44.2% | | 2026Q1单季口径(14.86/33.67=44.1%)，非年报口径(年报为35.04%) |
| 营收增速34.65% | | 2026Q1同比口径，非全年(全年+59.86%) |
| 负债率78.71% | | ✓ 2026Q1券商正常杠杆水平 |

**券商估值锚：PB。** 现价9.04元对应：
- 账面PB约**1.11倍**（净资产2026Q1末约438亿/55.3亿股≈7.92元/股）
- 审慎PB（扣永续债）约**1.28倍**
- 动态PB（2026E年化ROE约15%的景气预期）约**1.42倍**

**正常化盈利测算：** 正常化ROE取8-10%（2025年报10.02%已是历史最好、不可作为正常值），净资产438亿 → 正常化归母净利**35-44亿**。ROE 8-10%的券商，合理PB区间约**0.9-1.2倍**。现价1.11倍账面PB处于合理区间**中上沿，无显著安全边际**。

### 5.2 三情景加权（段永平视角，对周期股保守取权重）

| 情景 | 假设 | 合理市值 | 对应股价 |
|---|---|---|---|
| 乐观(20%) | 市场景气延续+湖北国资整合落地，ROE维持14-15% | PB 1.4倍≈613亿 | 11.1元 |
| 中性(50%) | 市场平稳，盈利回归正常化40亿，ROE约9% | PB 1.05倍≈460亿 | 8.3元 |
| 悲观(30%) | 市场转冷，盈利回落至25亿，ROE约6% | PB 0.85倍≈372亿 | 6.7元 |

**加权内在价值 = 613×0.2 + 460×0.5 + 372×0.3 ≈ 465亿元**（约8.4元/股）

**对应当前市值499.9亿（9.04元），内在涨幅约 -7%。**

### 5.3 段永平式结论

- 这不是"好生意"，所以**不会用合理价买**，只会在"很便宜"时考虑。
- 1.11倍PB、TTM PE 11.9（十年4.8%分位）看起来便宜，但**周期顶部低PE陷阱**（2026H1净利+80-90%的高景气盈利不可外推）让这个"便宜"打折扣。
- 若PB回到**1.0倍以下（约7.9元）**才具备段永平意义上"普通生意便宜价"的初步吸引力；0.85倍PB（约6.7元）才谈得上安全边际。
- 湖北国资整合、并购预期是**催化剂而非价值**——段永平不为概念付钱。

## 六、总结：为什么PASS

1. **生意本质差**：经纪+利息+自营三块收入全是市场Beta，盈利随牛熊波动3-4倍，十年不可预测，"看不懂"。
2. **护城河极浅**：无品牌、无定价权、无网络效应；投行资管双短板，唯一的区域+国资优势不可货币化。
3. **企业文化不本分**：刘益谦时代派系斗争+系统性合规处罚（2025年3个月2罚、2026年仍持续）；研究首席批量离任；国资入主后改善是"预期"而非"已证"。
4. **价格不便宜**：1.11倍账面PB处于ROE 8-10%券商的合理区间中上沿，正常化盈利对应内在涨幅约-7%；周期顶部低PE+并购概念撑起的股价没有安全边际。
5. **催化剂不构成价值**：与天风/华源的整合预期若兑现恐摊薄股东，若不兑现则概念破灭。

> 段永平会说：**"这是靠天吃饭的生意，我不懂它明年赚多少，也不知道它的资产里有没有雷。看不懂就不碰，宁可错过。"** 这不是可以拿十年的生意，现在这个价格也不是值得冒险的价格。

## 量化结论
- 内在涨幅: **-7%**（三情景加权内在中枢约465亿/8.4元，vs 现价9.04元/市值499.9亿）
- 击球区: 🔴未到 + 券商为"市场Beta+浅护城河+治理有污点"的普通生意，现价1.11倍账面PB处合理区间中上沿、无安全边际，周期顶部低PE陷阱+并购概念撑价，不构成段永平意义上的买入机会
- 目标建仓价: **8.0 元**（约1.0倍账面PB，普通生意的"合理价上限"）
- 二次补仓价: **7.0 元**（约0.88倍账面PB，正常化ROE 8-9%对应的安全边际区）
- 数据核验: ⚠️ 跳过-口径存疑（ROE速评卡14.03% vs Tushare年化9.11%偏差21.24%，年报真值10.02%，速评卡为周期顶部年化口径；PB速评卡"1.7倍"与实测1.11-1.28倍不符；PE-TTM 11.9 ✓一致）
