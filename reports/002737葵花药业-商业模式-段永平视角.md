## 1. 商业模式本质：一门靠"营销烧钱+品牌心智"驱动的中成药OTC生意，正在被集采与品牌乱象双向侵蚀

葵花药业是A股老牌OTC中成药企业，业务=中成药OTC（2025占营收65.47%）+化学药+其他，三大支柱产品：

| 产品 | 地位 | 2025年动态 |
|---|---|---|
| 护肝片 | 黄金单品，2023年破10亿，原研+国家质量银奖 | 2026-05拟中选第四批全国中成药集采 |
| 胃康灵胶囊 | 独家研制、年销超10亿粒，中成药胃药市占前二 | 2025营收整体下滑 |
| 小儿肺热咳喘口服液 | "小葵花"核心单品，儿童药旗舰 | 2026-05同批中选集采 |

**段永平式理解**：这是一家典型的**"营销买来的品牌"公司**——6年砸74亿营销（2024年数据），广告费曾是命脉。2024年"广告费用少花了7亿"营收立即暴跌40%；2025年"广告费涨131%"却增收失效、营收再降31%。**品牌力对广告投放的依赖度极高，说明这不是茅台/白药式的"心智自动复购"，而是"投钱才有的销量"。** 这正好解释段永平最警惕的一个信号：**毛利率高（56%）≠定价权，要看增长的钱从哪来。**

### 1.1 生意周期的极端波动是"结构性的"，不是一次性的
- 2023年：营收57.00亿、净利11.19亿（疫情后呼吸类需求爆发+压货）
- 2024年：营收33.77亿（-40.76%）、净利4.92亿（-56.03%），Q4单季转亏-0.95亿
- 2025年：营收23.18亿（-31.36%）、净利-2.58亿首亏、扣非-3.10亿
- 2026Q1：营收8.44亿（+27.19%）、归母1.10亿（+93.11%）、扣非1.06亿（+166.22%）——**低基数修复**

两年间营收腰斩、利润从11亿变-2.6亿。**段永平会说："好的生意不该让你反复猜它明年赚多少。"** 呼吸类需求的高基数效应+渠道压货模式的双重叠加，暴露了这门生意的需求波动本质——它卖的是可被库存周期和舆论周期放大的大众OTC药，而非稳定复购的必需品。

### 1.2 2025年亏损的三重原因（均指向经营质量而非单纯会计）
1. **主动渠道去库存**：行业渠道库存积压，公司剥离向经销商压货的粗放模式、控发货收缩——营收大降的主动因素，2025年报称"渠道梳理工程基本结束"（这是2026年修复的逻辑基础）
2. **减值出清**：商誉减值（衡水得菲尔+1233.65万、襄阳隆中+1820.22万，同比+536%）+存货减值，合计超1.1亿
3. **费用错配**：销售费用5.80亿（+34.60%）、广告费涨131%，销售费用率12.76%→25.03%，而营收反向大跌——**越亏越烧钱，花钱买增长失败**

OCF 5.75亿（+286.99%）为正，说明亏损确为减值+费用等非现金/经营决策项，家底未烂。但**销售费用率翻倍至25%本身，就是"品牌力不硬、需要猛砸钱"的反向证据。**

## 2. 护城河：儿童药心智真实存在，但正在被四只手拆墙

### 2.1 真实的部分："小葵花"是稀缺的儿童药国民品牌
- 2007年"小葵花妈妈课堂"起家，2008年儿童药战略，儿童OTC市占率超30%（机构口径）
- "葵花"+"小葵花"双品牌，机构评估品牌价值365.78亿元
- 护肝片、胃康灵、小儿肺热咳喘有原研/独家属性，零售终端品牌力真实

### 2.2 但拆墙之手有四只：
1. **集采破定价权（最致命）**：2026-05护肝片、小儿肺热咳喘口服液/颗粒、健胃消食片全部拟中选第四批全国中成药集采。**OTC品牌药进集采=价格端主动让利，品牌溢价被行政力量直接打穿。** 段永平会说："你引以为傲的品牌，在集采面前不值一分钱。"
2. **品牌授权乱象**：2026年5-6月央视《财经调查》曝光"葵花"商标授权贴牌乱象——第三方以"葵花品牌授权"名义销售驱蚊喷剂，实测香精兑水、驱蚊效果为零、包装复刻小葵花卡通IP；央视调查更指"商标注册人按成本价20%收取授权费，明知不合格仍默许打上品牌"。葵花药业声明"从未授权"撇清，但**品牌管控缺位已造成心智污染**。
3. **营销依赖**：广告费涨131%仍增收失效，证明品牌力=烧钱函数，钱停了销量就塌（2024年实证）。
4. **行业竞争与监管**：中成药OTC同质化严重，护肝片/胃康灵赛道竞争者众；叠加中药集采扩围的长期趋势。

**护城河结论：窄而变浅。** 有真实品牌资产，但既无绝密配方（对比云南白药/片仔癀）、也无技术代差，护城河是"广告堆出来的消费者习惯"，而这类习惯最容易被集采低价、竞品替代和品牌丑闻击穿。

## 3. 定价权：几乎没有，且正在被集采正式剥夺

| 定价权证据 | 说明 |
|---|---|
| 集采中选 | 2026-05三大核心品种进第四批中成药集采，价格由联盟采购办公室定，**公司对核心产品的价格失去自主权** |
| 广告依赖实证 | 2024年砍广告营收-40.76%；2025年加广告营收-31.36%——**销量不随品牌自发增长，随投放摇摆** |
| 渠道弱势 | 经销商压货模式暴露渠道掌控力弱，被迫清库存 |
| 中药材成本 | 上游药材涨价只能自吞（毛利率被压缩），无向下转嫁能力 |

**段永平定价权三问：能不能提价？答：不能（集采+竞争）。消费者非买不可吗？答：不是（OTC可替代）。别人抢得走吗？答：抢得走（同质化+贴牌乱象）。三项全挂，定价权判定：❌。**

## 4. 企业文化/本分：段永平视角的一票否决项——这是全报告最沉重的部分

段永平最看重"本分"，而葵花药业的治理历史是教科书级的反面案例：

1. **实控人刑案（2018-2020）**：创始人、实控人关彦斌2018年12月涉嫌故意杀人被捕（与前妻纠纷致其重伤），2020年12月二审维持**有期徒刑11年**。公司当时仅以"年龄原因"披露辞职，直到2019年3月年报才含糊披露"实控人因纠纷被采取强制措施"——**信披严重滞后，隐瞒实情**。
2. **"关二代"仓促接班与退场**：长女关玉秀（现任董事长）、次女关一（2026年2月提前16个月辞任总经理，转任副董事长）——家族治理色彩浓厚，职业经理人周建忠2026年2月接任总经理，新班子磨合未定。
3. **2026-08-01证监会警示函（最新实锤）**：因关联交易未按规定履行审议程序和披露义务，证监局对公司及**董事长关玉秀、总经理关一、董秘周广阔**出具警示函并记入诚信档案——**治理瑕疵不是历史，是当下**。
4. **品牌授权乱象（2026年5-6月）**：央视曝光"葵花"贴牌驱蚊产品造假，品牌管理失责。
5. **微弱的正面**：2025年亏损年仍派现1.17亿（每10股派2元），上市以来累计分红41.62亿；2026-2028年发布分红规划"优先现金分红"；管理层2025年整体降薪6.86%（董事长降9.09%至200万）。

**段永平式判断**："做对的事，把事做对。葵花药业这些年，坏事做了不少（实控人刑案、信披隐瞒、警示函、品牌失控），好事做了点（分红）。**企业文化这一项，直接一票否决——哪怕它明天业绩翻倍，我也不会碰。**"

## 5. 段永平"好生意"五问评估

| 问题 | 结论 | 说明 |
|---|---|---|
| 1. 是否有定价权？ | ❌ | 集采中选三大核心品种+广告依赖+同质化竞争，无提价能力 |
| 2. 是否差异化且不可复制？ | ⚠️ | 品牌心智有，但无配方/技术壁垒，营销可复制（6年74亿营销就是"买"来的） |
| 3. 生意是否可预测（成长性）？ | ❌ | 57亿→23亿两年腰斩，利润11亿→-2.6亿，预测性极差 |
| 4. 是否消耗资本/轻资产？ | ✅ | 负债率23.3%、OCF为正，资产负债表干净是唯一加分项 |
| 5. 企业文化/本分？ | ❌❌ | 实控人刑案、信披隐瞒、2026年警示函、品牌授权乱象——一票否决 |

**段永平一句话结论**："这不是一门好生意（无定价权、需求高度波动），更不是一家本分的公司（治理硬伤累累）。哪怕现在便宜，我也不会接飞刀——因为我不确定它未来的盈利能力，更不信任它的管理层。这类公司，跌到再低也与我无关。"

## 量化结论

- 内在涨幅: **-34%**（三情景加权：悲观30%→3.5亿×10x=35亿/6.0元；中性50%→4.5亿×12x=54亿/9.2元；乐观20%→5.5亿×14x=77亿/13.2元；加权52.9亿→约9.1元，对现价13.66元）
- 击球区: **🔴 未到**（治理一票否决+集采打破定价权+盈利可预测性极差，且现价对应2026E PE约16-18x、PB约2.0x并不便宜，无安全边际）
- 目标建仓价: **9.0 元**（≈2026E PE 11x、PB约1.1x，需以集采影响可控+治理实质性改善为前提）
- 二次补仓价: **7.5 元**（≈2026E PE 9x、PB约0.9x，为历史估值下限区间）
- 数据核验: **⚠️ 部分跳过**（速评卡ROE 11.3%=2026Q1年化 vs Tushare 2025年化-6.28%方向相反，正常化约10-11%；速评卡PE为N/A且Tushare缺失，PE-TTM -38.98为亏损态无法使用，采用2026E估算16-18x；营收增速27.2%=Q1低基数口径）
