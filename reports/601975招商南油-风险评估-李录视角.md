## 一、李录投资框架对照

李录的核心是"长期确定性 + 管理层诚信与能力 + 安全边际"。对招商南油的逐项评估：

| 李录关注点 | 招商南油表现 | 评估 |
|---|---|---|
| 生意长期确定性 | 油轮运输是**强周期、弱特许经营**行业，运价由全球供需+地缘决定，公司无法定价 | ❌ 弱确定性 |
| 10年维度生意形态 | MR成品油轮有结构性需求（炼能东移、俄乌/红海重构贸易流），但2027-2028新船交付潮将冲击供给 | ⚠️ 中低 |
| 管理层诚信 | 央企招商局体系、规范治理，但历史上曾因激进造船导致退市 | ⚠️ 有前科 |
| 资本配置能力 | 当前处置老旧船+有序订新船（12-22艘），较克制；但**分红率仅9.64%**，回报股东意愿不足 | ⚠️ |
| 安全边际 | 现价3.71元，PE-TTM 11.97x（47.8%历史分位），处于运价超级周期顶部，无显著安全边际 | ❌ |

**核心矛盾**：资产负债表是航运业罕见的顶级水平（净现金43.5亿、负债率11.08%），但生意本身是强周期商品运输，且当前盈利正处景气峰值——李录最忌讳的"在周期顶部用峰值盈利给估值"。

## 二、管理层评估

### 2.1 历史血泪教训（重大扣分项）

招商南油前身为**长航油运**，是A股历史上第一家因亏损退市的央企：

| 时间 | 事件 |
|---|---|
| 2008-2012 | 高油价下激进订购VLCC大船，恰逢行业运力过剩 |
| 2010-2013 | 连续四年亏损，累计亏损近80亿元 |
| 2014-06 | 因连续四年亏损被上交所终止上市（A股首家央企退市） |
| 2014 | 破产重整，未分配利润达-76.01亿元 |
| 2019-01-08 | 完成债转股重整后重新上市，成为"A股重新上市第一股" |
| 2022-04 | 董事长辞职（人事更替） |

**李录判断**：这家公司管理层曾因**灾难性的资本开支决策**（盲目造船扩张）几乎毁灭公司。今天的"低负债+净现金"是退市重整后重建的成果，**不是管理层一贯审慎的证据**。对管理层的历史决策质量必须打上问号。

### 2.2 当前管理层与治理结构

- **股权结构**：最终实控人国务院国资委；控股股东中国长江航运集团（招商局集团100%持股）持股约29.99%；**第二至五大股东为建行/中行/工行/中信银行等债转股银行**（合计持股超30%），属重整遗留结构。
- **治理**：央企体系规范，无大股东质押记录（未检索到控股股东质押信息）；但债转股银行股东历史上持续**缓慢减持**（如建行江苏分行2022年两度减持，2025Q3仍在减持）。
- **分红记录（重要瑕疵）**：
  - 2019重新上市至2024年**几乎零分红**（受弥补历史亏损约束）；
  - 2025年报首次恢复分红：**10派0.27元，支付率仅9.64%**，现价股息率约**0.73%**；
  - 计入2025年4亿元回购后，现金分红+回购合计占净利**40.14%**。
  - A股重新上市以来累计派现仅**1.26亿元**（即2025年一次）。

### 2.3 当前资本配置评估

| 项目 | 内容 | 评价 |
|---|---|---|
| 船队 | 运营74-75艘/289万载重吨，MR成品油轮67艘（远东第一、全球领先），原油船21艘（内贸第二） | ✅ 细分龙头 |
| 更新计划 | 手持12艘新船订单（投资30-35亿元）：2026H2交付4艘MR、2028年集中交付8艘（LR2/Panamax/化学品/气体）；2026-07再订4艘5万吨MR（1.828亿美元，广船国际，2029交付） | ✅ 更新换代克制 |
| 老船处置 | 2026Q1处置4艘老旧MR船，贡献非经常性收益0.8亿元 | ✅ 有纪律 |
| 分红 | 2025年支付率9.64%（+4亿回购后40.14%） | ❌ 偏低 |
| 融资 | 2024年曾发15亿中期票据（央企双重审批），当前有息负债仅6.84亿 | ✅ |

**管理层总评**：央企治理规范、船队更新有序、处置老船有纪律——**但**历史退市前科+分红率偏低，按李录标准**管理层只能给"及格偏上"，达不到"值得信赖的卓越管家"标准**。

## 四、经营风险

### 4.1 运价周期（核心风险）

| 指标 | 数值 | 说明 |
|---|---|---|
| BCTI（波罗的海成品油指数） | 2026-08首周**1186点**（周环比+16%、同比+98.1%） | 景气高位 |
| 2026H1 BCTI季度均值 | **1412点，同比+106.7%** | 超级景气 |
| MR船日租金 | 2026H1平均3.77万美元/天（同比+186.7%）；2026Q2 MR即期一度突破**10万美元/天** | 历史级高位 |
| TC7（澳新线） | 2026Q1均值2.5万美元/天（+37%）；2025H1仅1.91万（-49.4%） | 波动剧烈 |
| 2025全年运价 | MR市场高位回落，公司2025净利-31.73% | 周期下行即现原形 |

**李录判断**：当前运价处于**罕见超级景气周期**（招商轮船2026H1预增214%-248%佐证行业性景气）。**历史上油运运价从峰值回撤50%以上是常态**，2025年已演示过一次（净利-31.73%）。在景气顶部谈"营收增速14.2%可持续"是危险的。

### 4.2 营收增速14.2%的口径核查

- 速评卡"营收增速14.2%"= **2026Q1单季同比**（15.68亿，+14.19%）；
- **2025全年营收58.20亿，同比-10.13%**（方向相反）；
- 2026Q1净利+51.73%中，**0.8亿元为处置4艘老船的非经常性收益**（占Q1归母净利18.5%），扣非净利+24.68%；
- 净利率27.7%（速评卡）= Q1单季含非经；剔除后扣非净利率约22.4%。

### 4.3 船队利用率与客户集中度

- 内外贸兼营+MR POOL（总规模超31艘，含13艘外部运力）对冲单一市场波动 ✅
- 内贸原油客户：中石化/中石油/中海油/民营炼厂，客户集中度中等 ✅
- 苏伊士以东外贸成品油市占率25-35%，细分定价权 ✅

## 七、长期确定性（10年后招商南油会怎样？）

**正面逻辑**：
1. MR细分赛道格局好——全球MR新船供给2026-2027受限（船坞被LNG/集装箱占用），公司是远东第一+苏伊士以东市占率25-35%；
2. 净现金43.5亿+零质押，**极端运价下行周期也能活下来**（对比历史上曾资不抵债的教训）；
3. 船队年轻化（平均约9年）+环保新船，合规成本占优；
4. 平陆运河2026年9月通航（西南—北部湾增量）+炼能东移（运距拉长）是结构性慢变量。

**反面逻辑（李录最担心的）**：
1. **新船订单同比+500%**（2026年油船市场超预期爆发），MR/LR2交付集中在2027-2029，届时运价大概率回落——2026年的超级景气可能透支2027-2028；
2. 油运本质是商品运输，**公司无定价权、无转换成本、无网络效应**，护城河极浅，10年后大概率还是强周期股；
3. 分红回报不稳定——2019-2024几乎零分红，2025才恢复且支付率9.64%，长期股东回报主要靠股价波动而非现金流回馈。

**李录10年结论**：这是一家"**资产负债表顶级但生意模式平庸**"的公司。10年后它大概率还活着（净现金托底）、还是MR龙头，但**盈利中枢取决于不可预测的运价周期**，不属于"买入后可以安睡10年"的生意。若按现金奶牛标准（高分红+稳定盈利），它不合格。

## 量化结论

- 内在涨幅: **-5%**（计算依据：周期正常化净利取16亿元[2024年19.21亿/2025年13.11亿/2026E 18.9亿的保守中枢]，李录不给周期顶部盈利溢价，按10.5x合理PE→合理市值168亿≈3.53元/股 vs 现价3.71元，-4.9%≈-5%；若按2026E峰值盈利18.9亿×9x=3.63元，同样得出"现价无安全边际"）
- 击球区: 🟡 资产负债表顶级（净现金43.5亿/零质押）+MR远东第一+央企治理，但当前处于运价超级周期顶部+分红率仅9.64%+筹码分散+融资余额90%分位，李录标准下现价无安全边际，**等回调至3.3元以下分批建仓**
