## 一、商业模式拆解

### 1. 生意的本质：资源开采商 + 冶炼加工商

西部矿业是青海省属国有控股的多金属矿业公司，核心业务链条：

```
矿山采选（铜/铅/锌/钼/铁/钒） → 冶炼（铜/铅/锌） → 贸易
```

**关键判断**：这是一门**产品完全同质化、无定价权、盈利随商品价格周期大起大落**的生意。铜、铅、锌的价格由全球供需决定，公司是"价格接受者"。用段永平的话说，这是典型的**"靠天吃饭"的生意**——盈利质量与经营团队的努力相关性弱，与铜价走势相关性极强。

2026年上半年归母净利41.69亿元（+123%），核心驱动不是产量增长（矿产铜8.97万吨，同比-2%），而是**铜价上涨**（沪铜均价10.2万/吨，同比+31%）。这是周期股盈利的本质特征：**利润是价格给的，不是经营给的**。

### 2. 玉龙铜矿：公司的"皇冠明珠"（核心资产）

- 全球少有高品位、低成本大型斑岩铜矿，位于西藏
- 2025年：营收116.5亿、净利润59.9亿，**净利率51%**，单吨铜税后利润3.94万元
- 2026H1：净利润50.59亿（持股58%），产量8.24万吨，占公司矿产铜91.8%
- 玉龙三期2026年底完成基建，矿石处理量2280→3000万吨/年（**产量+1/3**）

这是公司真正的护城河：**处于全球铜矿成本曲线最左端的低成本资产**。铜价下跌时别人亏损它仍盈利——这是资源股唯一的"差异化"，也是段永平愿意认可的竞争力。

**但风险集中度极高**：91.8%的矿产铜来自单一矿山，"单一铜矿依赖症"是市场公认担忧。一座矿的扰动、一处品位的变化，都直接决定公司业绩。

### 3. 铅锌冶炼：传统基本盘 + 正在扭亏的"苦生意"

- **锡铁山铅锌矿**（发家之地）：铅锌矿石资源量1666.7万吨，铅锌金属储量130万吨，**品位7.8%**——优质资产，证载规模150万吨/年
- 其他：获各琦铜多金属矿、会东大梁、呷村银多金属矿；2026年新增四川有热铅锌矿（铅29.7万吨/锌43.1万吨）
- 2025年矿产铅6.30万吨(+16.7%)、矿产锌12.88万吨(+20.3%)
- 冶炼板块：产能铜35万吨/锌20万吨/铅20万吨/年。过去两年因改扩建磨合+折旧拖累，**2025下半年扭亏，2026H1冶炼净利5.95亿**

**判断**：铅锌矿端（锡铁山高品位）是好资产；冶炼端是加工费生意，利润薄、受加工费周期波动，属于"苦生意"——但正在从负贡献转正。

### 4. 资源禀赋与成长期权

| 资产 | 状态 | 评价 |
|---|---|---|
| 玉龙铜矿 | 三期2026底基建完成，产能+32% | 确定性最高的增长引擎 |
| 茶亭铜矿（安徽） | 86.09亿竞得探矿权，铜金属量174.8万吨+金248吨 | 远期期权，力争2030年投产，周期长 |
| 四川有热铅锌矿 | 已获采矿证 | 铅锌资源补充 |
| 双利二号铁矿 | 2026Q1试生产 | 铁板块增量 |
| 铁矿石资源 | 总量2.78亿吨 | 稳定基本盘 |

资源储量合计约1200万吨有色金属。成长路径清晰，但**伴随大额资本开支**：茶亭86亿+玉龙三期约50亿，将长期占用现金流。

## 二、段永平视角审视（生意模式×企业文化×安全边际）

### 段氏五问：

**Q1：这是不是我能看懂的生意？**
部分能看懂。矿业逻辑（成本曲线、资源禀赋、供给刚性）是清晰的；但**铜价十年后的中枢无法预测**——这决定了它不属于段永平偏好的"简单、稳定、可预测"的生意。

**Q2：生意模式好不好？**
**中等偏下**。无定价权、产品同质化、盈利强周期，是硬伤；玉龙铜矿的低成本是唯一亮点，但单矿依赖放大了波动。对比段永平偏好的生意（茅台、苹果、腾讯——有品牌/网络效应/生态），西部矿业属于**"好资产 + 一般生意"**。

**Q3：企业文化如何？**
国企体制，管理层执行力不错（冶炼扭亏、资源并购果断），但**股东回报意识弱**——2025年净利36.43亿，每10股仅派0.6元（分红率约4%），大量利润投入资本开支。段永平看重"对股东好"，这一点减分。

**Q4：安全边际够不够？**
**严重不足**。当前PB 4.52、动态PE 12.15，股价一年内从约25元涨到43元（+70%+），处于历史绝对高位。周期股在盈利最高峰时"看起来便宜"（低PE），恰恰是风险最高的时候——这是巴菲特/芒格反复提醒的"周期股低PE是卖出信号"陷阱。

**Q5：现在是不是好的击球点？**
**不是**。铜价10.5万/吨是历史高位，公司盈利处于周期顶部（年化ROE 40.8%不可持续），市场已充分定价2026年乐观盈利。段永平的原则是"人多的地方不去"、"宁可错过，不可做错"——当前是全市场追捧铜板块的热闹时刻。

## 三、ROE 数据核验

工具核验结果（`financial_rigor.py cross-validate --field roe`）：

```
速评卡 40.8%      ❌ 偏差 33.11%
Tushare年化 20.5% ❌ 偏差 33.11%
参考中位数 30.65%  ⚠️ 存在来源偏差 >2%
```

**判定**：40.8%为**2026H1单期年化ROE**（H1净利41.69亿×2/净资产约227亿≈37-41%），由铜价暴涨驱动，**不可作为长期正常化ROE**。历史口径：2025年实际ROE≈16%（36.4亿/约227亿净资产），2024年≈16%。**正常化ROE约16-20%**，当前40.8%是周期顶部假象。

## 四、量化估值（正常化盈利法）

### 正常化盈利测算（假设铜价回到中枢9万/吨，介于2025年8.3万与当前10.5万之间）

| 板块 | 正常化归母净利估算 |
|---|---|
| 玉龙铜矿（16万吨铜×单吨利润2.5-3万） | 23-28亿 |
| 其他矿山（获各琦+铅锌+钼+铁+银金） | 12-17亿 |
| 冶炼板块 | 0-5亿 |
| **合计（当前产能）** | **约40-50亿** |

考虑玉龙三期2027年投产后产量+32%、铜价长期中枢上移（供给刚性+电气化/AI需求），**2027-2028年正常化盈利可提升至55-60亿**。

### 合理估值

- 周期资源股合理PE区间：10-12倍（周期股不给高估值）
- 正常化盈利中枢：55亿 × 11倍 = **605亿市值** → **约25.4元/股**
- 保守口径（当前产能45亿×10倍）：450亿 → 18.9元
- **内在价值中枢：约19-25元，中值22元**

### 当前股价对照

- 现价 43.07元 vs 内在价值中枢22-25元 → **当前高估约70-95%**
- 内在涨幅 ≈ **-42%**（需回调约40%才进入合理买区）
