# 陕西能源(001286) 行业竞争分析——芒格视角

> 角色：行业竞争分析师（芒格视角）
> 日期：2026-08-11 | 现价约 10.47 元 | 总股本 37.5 亿股 | 市值 392.6 亿

## 一、核心判断

**火电是一门"监管管制的公用事业 × 强周期商品"混合生意，同质化、无品牌、无定价权。陕西能源是这个平庸行业里靠"煤电一体化"成本优势跑出来的优等生——护城河真实但非宽（成本型，非品牌/网络型），长期面临新能源结构性替代，确定性中等。**

一句话芒格式结论：**"在一个持续被技术替代的行业里，拥有一个低成本的身份，比在好行业里拥有平庸身份强，但也仅此而已——这不是一个可以躺赢的伟大生意，只是一个体面的公用事业。"**

---

## 二、行业格局：火电进入"电改深水区 + 现货市场"新周期

### 2.1 行业本质：同质化商品 + 强管制

- 电力=标准化商品，发电企业无差异化、无品牌溢价、无定价权；上网电价受发改委基准价 + 市场浮动（±20%）管制，2021年1439号文后燃煤电量全部入市。
- 2026年是"电力现货元年"：现货市场全面转入正式运行，全国统一电力市场体系推进（2026年2月国办意见）。上半年行业格局重构——**"告别煤价单边下跌即可全线躺赚的时代，进入电改政策和现货市场主导的运营周期"**（行业中报综述）。

### 2.2 结构性逆风：新能源挤压 + 电能量电价下行

- **新能源冲击**：截至2026年5月，风光装机19.2亿千瓦，占全部装机47.9%，风光发电量占全社会用电近1/4；非化石能源装机占比62.4%。新能源"零边际成本"持续压低现货电价，火电利用小时数趋势性承压。
- **电能量电价下行实证**：国电电力2025年火电营收同比减少近百亿，平均上网电价降至400.90元/兆瓦时（-28.92元）；华能蒙电2026Q1归母净利-24.63%。火电从"卖电人"变"稳压器"。
- **容量电价托底**：2026年114号文完善发电侧容量电价机制，煤电容量电价上调（湖南由165→330元/千瓦）。容量电价给火电"固定成本回收"保底，缓解电能量电价下行冲击，但上限明确，难改火电利润中枢下移趋势。

### 2.3 竞争格局：五大集团 vs 地方省属平台

- 行业由五大发电集团（国家能源/华能/大唐/华电/国家电投）+ 地方能源集团构成。五大集团正大规模转向新能源（国家电投清洁装机72.71%、华能51.8%），传统火电增量主要由地方平台承接。
- **火电新增装机向西部煤炭/电力基地集中**，"西电东送"规模持续扩大（"十五五"规划明确西部强化能源开发）。
- **陕西能源定位**：陕西省内统调装机第二（仅次于大唐陕西分公司），**省属企业第一**；陕投集团旗下唯一煤电一体化上市平台，前身汇森煤业（2003年）。

## 三、竞争地位与护城河：真实但窄，靠"成本"不靠"品牌"

### 3.1 煤电一体化 = 核心成本护城河（真实）

- **装机结构**：煤电总规模1725万千瓦（在役1123万 + 在建402万 + 筹建200万）。其中**煤电一体化/坑口电站装机占比61.57%**（另一口径69.64%），42.43%机组为"西电东送"配套（陕武、宝德、吉泉直流 + 榆横-潍坊特高压）。
- **煤炭资源**：保有资源量约42亿吨；核定产能3000万吨/年，已投产2200万吨，在建800万吨（赵石畔煤矿2026H2联合试运转）。
- **成本优势**：长协煤比例100%，自产煤自用比例74.74%（2023），内部煤电对冲煤价周期。结果：**2026Q1毛利率39.15% vs 行业平均18.24%，接近2倍**；2025年全年毛利率37.83%（vs 行业18.24%）。

### 3.2 护城河宽度评估（芒格式拷问）

| 维度 | 评估 |
|---|---|
| 成本优势 | ✅ 真实且强（煤电一体化+坑口），行业内一流 |
| 品牌/定价权 | ❌ 无。电力同质化，电价由市场/管制决定，公司是价格接受者 |
| 网络/转换成本 | ❌ 不适用 |
| 资源独占性 | 🟡 中等。煤炭储量有保障，但煤炭本身同质化可外购，壁垒来自区位+配套 |
| 规模效应 | 🟡 中等。省内第二/省属第一，但与五大集团体量差距悬殊 |

**结论：护城河是"成本型"而非"特许经营型"。它能让你在行业景气度下行时比同行多活几年，但不能让你获得超越行业平均水平的资本回报。ROE 11.82%（2025年报加权）即实证——成本优势没有转化为超额ROE。**

### 3.3 区域地位与消纳保障（加分项）

- 42.43%机组为西电东送配套（陕武/宝德/吉泉直流），利用小时数和电价稳定性优于省内纯内销机组；西北电网跨区输电价格是几大电网**唯一下调**（-0.21分），边际利好外送。
- 新疆吉木萨尔坑口电站（2×660MW）+ 收购江西信丰能源51%（2×1000MW在建）= 突破省内天花板，全国化布局雏形。
- 但注意：跨省外送同样面临落地端电价市场化、新能源竞争，非"避风港"。

## 四、长期确定性：中等，有托底无惊喜

### 4.1 托底因素（确定性来源）

1. **容量电价机制**：2026年114号文上调煤电容量电价，固定成本回收有制度保障。
2. **在建装机成长**：在建402万千瓦（商洛二期/延安热电二期/信丰2×1000MW）+筹建200万千瓦（赵石畔二期），2026-2028年装机与电量确定性增长；煤炭产能同步释放（3000万吨核定）。
3. **煤价周期对冲**：煤价下跌时电力盈利改善，煤价上涨时自产煤受益——一体化平滑周期。
4. **高分红承诺**：2025年度10派4.1元，分红率51.09%，股息率约3.7-3.9%；上市以来分红率持续超50%。

### 4.2 侵蚀因素（确定性损耗）

1. **新能源结构性替代**：火电从"主力电源"转向"调节电源/稳压器"，利用小时数长期趋势性下降——2026Q2发电量87.80亿千瓦时，**同比-9.83%、环比-29.46%**，已现端倪。
2. **电能量电价下行**：市场化+现货+新能源全面入市（2026年1月起），电量电价承压是行业性、长期性趋势，成本优势只能对冲、不能逆转。
3. **重资产资本开支**：负债率53.2%，在建+筹建约600万千瓦，资本开支庞大，ROE被资产规模稀释（ROIC约8.6%）。
4. **2025年先例**：2025H1归母13.34亿（-13.45%）、2025Q1发电量与煤价双降致净利-28.78%——盈利对电量/煤价/电价三因素敏感。

### 4.3 机构盈利预测参考

- 同花顺/F10预测2026-2028归母净利：**33.32 / 34.98 / 35.15亿元**（EPS 0.89/0.93/0.94），对应2026E PE约11.8x。
- 华福证券（2026-04下调后）：2026E 31.7亿——提示电价回落及成本端波动。
- 注：2026Q1归母8.88亿（+26.3%）的高增长含赵石畔煤矿投产放量（Q1煤炭产量664万吨+52.65%），**不可线性外推**；Q2发电量-9.83%已提示电量端压力。

## 五、关键风险清单

1. **电能量电价持续下行**（现货+新能源入市）——行业级风险，无法通过公司经营化解。
2. **新能源挤压利用小时**——2026Q2发电量环比-29.46%的警讯。
3. **煤价波动**——虽有一体化对冲，但外销煤（2026H1自产煤外销839.6万吨，+46.71%）暴露于煤价下行。
4. **重资产扩张风险**——600万千瓦在建/筹建，若电价环境恶化，增量不增利（参照国电电力2025年火电营收-近百亿）。
5. **2025年业绩警示**——营收-0.86%/归母+0.03%几乎零增长，增长依赖新机组而非存量提效。

## 八、芒格视角总结

1. **行业**：火电=管制公用事业×强周期商品，同质化无定价权，正被新能源结构性替代——"平庸且逆风"的行业。
2. **公司**：行业优等生。煤电一体化成本护城河真实（毛利率2倍于行业），区域地位扎实（省内第二/省属第一），西电东送消纳有保障。
3. **护城河**：**成本型、非特许经营型**——能防亏损，不能创超额ROE。ROE 11.82%证实"好成本、平庸生意"。
4. **确定性**：中等。容量电价托底+600万千瓦在建装机+煤电对冲提供下行保护；但电价下行与新能源替代是长期结构性侵蚀，2026Q2发电量-9.83%已是预警。
5. **买点判断**：好资产（稳健公用事业+高分红）但非好买点——现价已隐含2026E 11.8x，与行业持平，无犯错空间。**"合理价格买入普通生意，不如等待合理偏低价。"**
