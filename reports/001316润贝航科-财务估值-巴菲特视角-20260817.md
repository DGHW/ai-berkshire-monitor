### 4.1 五年期三情景（与第十八轮同框架，基准 TTM EPS 更新为 1.3083 元）

基准：TTM 归母 = 1.84 − 0.3404 + 0.6061 = **2.1057 亿**；TTM EPS = 2.1057 ÷ 1.6094 = **1.3083 元**。

**① 乐观（年增 15%，22x）**
```
1.15^5 = 1.15² × 1.15³ = 1.3225 × 1.520875 = 2.01136
第5年EPS = 1.3083 × 2.01136 = 2.6315 元
目标价 = 2.6315 × 22 = 57.89 元 → 57.9 元（+117.7%）
```

**② 中性（年增 8%，18x）**
```
1.08^5 = 1.08² × 1.08³ = 1.1664 × 1.259712 = 1.46933
第5年EPS = 1.3083 × 1.46933 = 1.9223 元
目标价 = 1.9223 × 18 = 34.60 元 → 34.6 元（+30.1%）
```

**③ 悲观（年增 0%，12x）**
```
第5年EPS = 1.3083 × 1.0 = 1.3083 元
目标价 = 1.3083 × 12 = 15.70 元 → 15.7 元（−41.0%）
```

**概率加权（乐/中/悲 = 30%/45%/25%）**
```
0.3 × 117.7% + 0.45 × 30.1% + 0.25 × (−41.0%)
= 35.31% + 13.55% − 10.25% = 38.61% ≈ +38.6%（5 年）≈ 年化 6.7%
```

（第十八轮为 +38.2%，差异仅来自 TTM EPS 1.3083 vs 1.31 的尾数）

**⚠️ 中性情景的 8% 增速假设本轮承压**：Q2 单季中值 +2.7% 若延续至 H2，2026 全年增速将不足 20%（华泰 2.31 亿 = +25.5% 已是中性偏乐观）。若正式中报 Q2 单季负增长，中性情景增速应下修至 5%，对应第 5 年 EPS = 1.3083 × 1.27628 = 1.6698 元 × 18x = **30.1 元**。
