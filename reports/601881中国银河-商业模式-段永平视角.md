# 中国银河(601881) 商业模式深度研究 — 段永平视角

> 视角：商业模式分析师（段永平）｜核心问题：这是不是一门"好生意"？企业是否"本分"？价格是否有安全边际？
> 数据基准：2025年年报（2026-03-30披露）+ 2026年一季报 + 2026-08-12 数据
> 信息丰富度：A级（头部券商，券商覆盖密集，媒体曝光充分）——重点做反面检验：聪明人为什么不买？

## 一、标的卡片速评：ROE 与 PE 均无口径陷阱（✅），但"9.8% 的 ROE 卖 1.1 倍 PB"是核心问题

| 指标 | 速评卡 | 年报/真实值 | 判断 |
|---|---|---|---|
| ROE | 8.7% | **Tushare 年化 8.69% 吻合**（2025 年报加权 9.8%，研报口径；差异源于加权平均 vs 期末净资产算法） | ✅ 一致，非陷阱 |
| PE | 10.6 | Tushare-TTM 10.50，交叉验证✅ 一致 | ✅ 真值，但为**牛市盈利口径**（2025 年 +24.81% 创新高） |
| 净利率 | 45.1% | 2026Q1 单季口径（33.2/73.55）；2025 全年约 44.2% | ✅ 方向一致（券商净利率天然高） |
| 营收增速 | 15.7% | = 2026Q1 单季同比（73.55 亿 +15.66%）；2025 全年 +24.34% | ✅ 方向一致 |
| 负债率 | 84.1% | 券商高杠杆常态（2025 末总资产 8557 亿） | ✅ 行业属性 |
| 市值 | 1357亿 | 现价约 12.41 元（总股本 109.34 亿股）；归母净资产约 1234 亿 → **PB≈1.10x** | ✅ 券商用 PB 锚 |

**关键口径解释**：速评卡 ROE 8.7% 与 Tushare 一致✅，且为保守口径（2025 年报加权 9.8%）。但 9.8% 本身是**牛市年的最好成绩**——2024 年加权 ROE 约 8.3%、2022-2023 年约 8% 出头，**正常化 ROE 中枢约 8-9%**。PE-TTM 10.6 处于 2017 年以来 **10.4% 分位**（30% 分位 14.08x / 70% 分位 22.22x），绝对分位低，但 TTM 盈利 128 亿处于周期高点（2022 年约 78 亿），**周期顶低 PE 陷阱需打折扣**。

**冷信息核验**：
- "2025 归母 +24.81% 创新高"为真（125.2 亿），但 **2025Q4 单季净利仅 15.5 亿，同比 -49%**——四季度计提减值 9.7 亿（信用类业务预期信用减值风险增加），牛市里资产质量仍在下修，这是被"创新高"掩盖的暗点。
- "2026Q1 净利 +10.08%"（33.2 亿）增速为**头部券商末位**（同业普遍 +30~50%），Q1 营收 +15.66% 中投资收益贡献大，经纪/两融弹性未跑赢同行。
- "评级三连降"属实：2024 年度投行业务质量评价降至 C 类（此前两年 B 类）、债券业务执业质量评级自 2022 年 A 类连降至 2025 年 C 类，96 家参评券商仅 19 家 C 类。

## 二、生意本质：全国网点最多的"市场 Beta 中介"，不是段永平的能力圈

段永平第一问：**买股票就是买公司，这是不是一门好生意？** 答案：**不是。**

1. **券商 = 杠杆化的市场行情函数**。中国银河 2025 年收入结构：财富管理 134.72 亿占 47.6%、投资交易 70.26 亿占 24.8%、投行 8.3 亿仅 2.9%。媒体直接点题——**"靠行情吃饭"收入占比超 75%**。经纪佣金率由行业竞争决定且持续下行，两融是利差生意，自营是市场行情的函数。**每一个主要利润来源都不在自己手里。**

2. **盈利是周期函数，不可外推**。2022 年归母约 78 亿 → 2025 年 125 亿，ROE 在 8% 和 9.8% 之间波动；2026Q1 增速已在头部券商中垫底。段永平在茅台、苹果上要的是"十年可预测"，而券商的盈利曲线是"三年不开张、开张吃三年"的反面——**下一年赚多少完全取决于市场给多少成交量和涨跌幅，超出能力圈。**

3. **规模是行业第六，不是"好生意"的证据**。2025 年营收 283.02 亿行业第 6（中信 748.54 亿的 37.8%）、净利 125.2 亿行业第 5。头部排名背后是**同质化的通道竞争**——经纪、两融、自营、代销，各家产品没有本质差异，规模排名只说明"分到的蛋糕大小"，不说明"蛋糕的成色"。

4. **投行是结构性短板，且不是"短板待补"而是"评级被否"**：2024 年 IPO 保荐颗粒无收（0 家上市），2025 年仅完成 1 单 IPO（超研股份，承销保荐费仅 0.3 亿），股权承销 86.97 亿排第 12 全靠 8 单再融资撑量；投行收入 8.3 亿仅相当于中信（超 41 亿）的 **15%**，不如国金证券、东方证券等二线券商。一家定位"财富管理+投行"的头部券商，投行端连续两年在 C 类评级里挣扎，**等于第二主粮是坏的**。

**段氏判断**：这是"网点优势换不来定价权、好年份靠天吃饭、坏年份露馅"的周期中介生意，ROE 中枢 8-9%。**不是好生意。**

## 三、护城河：网点数量是真的护城河（宽而不深），但价值在被佣金下行侵蚀

1. **真实资产：全国最大的网点网络之一**。458 家证券营业部 + 37 家分公司，覆盖 31 个省市，营业部数量长期位居行业前二（2020 年 493 家居首、经纪市占率 4.2%）。2024 年经纪业务手续费净收入 61.89 亿行业第 5（中信 107.13 / 国泰君安 78.43 / 广发 66.5 / 华泰 64.47）。客户规模持续扩大，2022 年新开户市占率 7.48% 创七年新高。**线下网点和零售客群是真实的规模资产，也是银河区别于同业的唯一显著特征。**

2. **但这是"渠道型护城河"，不是"品牌型护城河"**：
   - 网点多 ≠ 客户忠诚。一人可开多户、互联网开户零成本，券商客户迁移成本极低；网点优势在佣金率趋零（万 2-万 2.5 已是常态）的时代，从"收入引擎"变成"成本包袱"——2025 年经纪收入增长主要靠市场成交放量的 Beta，不是份额扩张的 Alpha。
   - 财富管理转型（2020 年首批基金投顾试点、买方投顾升级）方向正确，但代销/投顾规模与中信、华泰差距悬殊，**尚未形成"客户为服务付溢价"的证据**——投顾服务费在收入结构里仍是零头。
   - 两融/信用业务随行就市，无自主定价。

3. **护城河定性：4/10——宽而不深**。网点规模给了"下限保护"（市场份额不至于快速丢失），但保护不了利润率；且护城河的价值高度依赖"中国资本市场长期活跃"这一外部前提，与段永平要的"客户必须用、离不开、能提价"的标准相差两个档次。

## 四、定价权实证（段永平核心问题）：无定价权，最典型的反证是"投行以价换量"

**无定价权，证据链完整：**
1. **经纪**：佣金率由行业竞争决定、长期下行，银河佣金率无溢价（网点优势用来获客，不是用来提价）。
2. **投行最刺痛**：银河投行靠**"以价换量"的激进低价策略**抢债券承销份额（2025 年债券承销 3272.62 亿 +82.8%），为此债券业务执业质量评级连降至 C 类、引发监管关注——**一家公司要靠贱卖服务才能抢到业务，就是"无定价权"的最直接证明**。反过来看，中信 IPO 承销市占 24.36% 靠品牌和项目质量，银河 IPO 两年颗粒无收，品牌是负资产而非溢价来源。
3. **自营**：随行就市，2026Q1 投资收益贡献了大头增长，市场一冷就现形。
4. **两融/信用**：利率市场定价；2025Q4 计提 9.7 亿信用减值，说明**连自己的客户资产质量都无法定价和掌控**。

**段氏判断**：一门完全没有定价权的生意，盈利多少取决于市场给多少饭。**银河在"给多少饭"这件事上，只有网点数量这张牌，没有一分钱议价力。**

## 五、企业文化与本分：汇金央企底色"规范"，但评级三连降 + 激进策略 + 减值计提是三个扣分项

段永平第二问：**管理层是否本分？** 答案：**大体守规矩，但"以结果论"不及格。**

**股权底色（加分项）：**
- 控股股东中国银河金控持股 47.43%，实控人中央汇金（直接+间接合计约 32.95%）——**国家队背书、零减持风险、零质押风险**，资本属性长期化，这是银河最硬的底子。
- 分红持续改善：2025 年全年派现 38.27 亿（中期 13.67 亿 + 末期 24.6 亿），**分红率 30.57%**，连续实施中期+末期双分红，现价股息率约 2.8%。
- 王晟（原中金投行负责人）2022 年上任后三年战略执行有果：2023-2025 营收净利连续增长，国际业务突破（银河国际 2025 年创 15 年新高、港股 IPO 保荐首进香港前十），机构业务爆发。

**扣分项（减分项，分量不轻）：**
1. **投行业务质量评级三连降**：2022 年 A 类 → 2025 年 C 类，96 家券商仅 19 家 C 类。评级是监管对内控管理、执业质量的官方打分，**连续三年下滑说明投行内控不是"运气问题"而是"系统性问题"**。2024 年 2 月还被央行处罚（反洗钱——未按规定履行客户身份识别义务）。
2. **"以价换量"的激进打法**：靠低价抢债券承销规模撑投行收入，引发监管关注——这是"业绩导向压过质量导向"的不本分苗头，段永平最警惕"为了报表数字牺牲长期声誉"的管理层。
3. **资产质量下修信号**：2025Q4 计提 9.7 亿信用减值（Q4 单季净利 -49%），牛市里还在为信用类业务"补窟窿"——两融/股票质押/债券自营的潜在风险是券商报表里最不可穿透的部分。

**段氏判断**：银河是"守规矩的央企大公司"——比方正（北大系前科）、比中金（高管贪腐案）干净，但**投行评级连降 + 反洗钱罚单 + 激进抢单 + 减值计提，说明它离"本分到值得重仓"还差得远**。央企不会骗你，但央企也未必替股东创造超额价值——ROE 中枢 8-9% 就是答案。

## 六、估值：PB 1.10x 对 ROE 9.8%，无安全边际（券商用 PB 锚）

**价格数据（2026-08-12）：**
- 现价约 12.41 元，总市值 1357 亿，总股本 109.34 亿股
- PE-TTM 10.6x（TTM 净利约 128 亿）——**牛市盈利口径**，正常化盈利（ROE 8-9%）对应实际约 **12-13x**
- PB ≈ **1.10x**（归母净资产约 1234 亿，BVPS 约 11.28 元）
- 股息率约 2.8%（分红率 30.57%）
- 2026 年内股价一度下跌 21%（截至 2026-04-24），7 月末 12.32 元，已从年内高点回落但仍处历史中低位

**段氏视角的"便宜"检验：**
1. **PE 10.6 是周期顶低 PE 的温和版**：TTM 盈利 128 亿是 2025 牛市高点（2022 年仅 78 亿），正常化 100 亿上下；用周期顶盈利算的 10.6x，对应正常化盈利约 **12-13x**，并不便宜。
2. **PB 1.10x 与 ROE 9.8% 勉强匹配、与正常化 8.5% 不匹配**：戈登反推（ROE 8.5%、要求回报 10%、永续增长 2.5%）合理 PB 约 **0.80x**；即便按 2025 年 9.8% 算也就 0.97x。**现价 1.10x 已隐含"ROE 持续 10% 以上 + 汇金整合溢价"的双重乐观预期。**
3. **汇金整合预期是把双刃剑**：2025 年 2 月中金+银河合并传闻让银河两周涨 15%；2026 年 5 月又传"申万+银河+光大"三强合并；但最新进展是**中金"三合一"（吸收合并东兴、信达）已先行推进，银河只是为异议股东提供现金选择权的第三方**——说明银河自身未被并入中金，整合路径高度不确定。**段永平不为"可能的合并"付一分钱溢价，合并是题材不是价值。**
4. 对照同业：中信 PB 1.28x（ROE 10.58%）、方正 1.14x（ROE 8.01%）——银河 1.10x 对 9.8% ROE 与同业**相对公允，但绝对不便宜**。

## 七、三情景估值（市值 1357 亿、现价约 12.41 元、BVPS 11.28 元为基准）

**悲观（30% 权重）**：市场转冷，成交和两融收缩，ROE 回落至 6.5-7%（2022 年水平），投行 C 类评级继续拖累，PB 回落至 **0.80x** → 约 9.0 元，**内在涨幅 -27%**

**中性（45% 权重）**：市场平稳，盈利回归正常化（ROE 8.5%），无并购落地，PB 回到 **1.00x**（含少量网点龙头溢价）→ 约 11.3 元，**内在涨幅 -9%**

**乐观（25% 权重）**：市场活跃度维持 + 汇金系整合落地（市场流传的申万+银河+光大任一组合）带来 ROE 提升至 10%+，PB 给予 **1.25x** → 约 14.1 元，**内在涨幅 +14%**

**加权中枢**：9.0×0.3 + 11.3×0.45 + 14.1×0.25 ≈ **11.3 元**
**治理折价（评级三连降 + 反洗钱罚单 + 以价换量激进策略 + 减值风险，-5%）**：≈ **10.7 元**
**内在涨幅**：10.7/12.41 - 1 ≈ **-13%**

**段氏总结**：现价把"牛市延续 + 汇金整合"的乐观情形打了个七折卖给你，却把"评级 C 类拖累、信用减值、周期回落"的风险留给了买家。**ROE 9.8% 的生意卖 1.1 倍 PB，每一层价格都是公允价，没有任何一层留给安全边际。**

## 八、结论

**段永平会说**：中国银河是一家"网点最多、央企最纯、但生意最平庸"的头部券商。财富管理 47.6% + 投资交易 24.8% 的"靠行情吃饭"结构，决定了它赚的是市场周期的钱，不是自己创造价值的钱；458 家营业部是真实的渠道资产，但佣金趋零让网点从资产变成成本，护城河宽而不深；投行评级三连降、IPO 两年颗粒无收、靠低价抢债券份额——**一家要靠贱卖服务才能抢到业务的公司，定价权是零分**。治理上汇金央企底色干净、分红率 30.57% 持续提升，这是加分；但评级连降、反洗钱罚单、牛市里还在计提 9.7 亿信用减值，说明它只是"守规矩"，谈不上"本分"。按"好生意 × 本分的人 × 合理的价格"三关检验：**生意不过（周期中介无定价权）、本分勉强（央企规范但有硬伤）、价格不过（1.1 倍 PB 无安全边际，PE 10.6 是牛市盈利口径）——三关过不了一关半。** 券商整体不在段永平能力圈内，银河在券商里也不属于值得破例的标的。等 PB 回到 0.9 倍以下再说。

---

## 量化结论
- 内在涨幅: **-13%**（三情景加权 11.3 元 × 治理折价 5% ≈ 10.7 元，vs 现价 12.41 元/市值 1357 亿；正常化 ROE 8.5% 戈登公允 PB 0.80x，现价 1.10x 已含整合溢价）
- 击球区: 🔴未到 — 无定价权的周期中介生意（靠行情吃饭占比超 75%）、ROE 正常化仅 8-9% 却卖 1.10 倍 PB、投行评级三连降 C 类是系统性内控短板、汇金整合预期反复炒作未落地，"三关过不了一关半"
- 目标建仓价: **10.2 元**（PB≈0.90x、PE-TTM≈8.7x、股息率≈3.4%，普通生意"合理价上沿"）
- 二次补仓价: **9.0 元**（PB≈0.80x、PE-TTM≈7.7x、股息率≈3.8%，正常化 ROE 6.5-7% 对应的安全边际区）
- 数据核验: ✓ ROE 已核验（速评卡 8.7% 与 Tushare 年化 8.69% 一致，偏差 0.08%；2025 年报加权 9.8% 为牛市年最好成绩，正常化中枢 8-9%）；PE 10.6 ✅ 与 Tushare 10.50 一致（偏差 0.45%）；券商适用金融豁免以 PB 为锚，现价 PB≈1.10x
