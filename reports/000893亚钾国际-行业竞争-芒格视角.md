## 2. 竞争格局：全球寡头垄断，中国"内外双雄+老挝新势力"

**结构判断**：CR4（Nutrien+白俄+乌拉尔+Mosaic）约占全球产能62%，是典型的寡头垄断行业。寡头曾通过BPC联盟（白俄+乌拉尔）控制全球定价，2013年破裂后转向"份额优先"。**行业格局对现有玩家友好——高集中度带来高于成本曲线的价格中枢，但玩家自身无定价权，只能做价格接受者。**

## 3. 核心竞争者威胁：价格周期、寡头与新产能三重压制

### 3.1 价格周期下行风险（最核心威胁）

- 2026年8月7日：国内氯化钾价格继续弱势下滑20-50元/吨，港口库存升至340万吨以上（同比高140多万吨），市场流通货源明显增加，贸易商让利出货。
- 2026年大合同348美元/吨，印度383美元/吨——长协价已为2026年定下高位锚点，但**边际供需转弱**（进口到货持续增加+国产大厂产量恢复+下游复合肥开工低位+秋肥以高磷为主）是短期主要矛盾。
- **情景测算**：若国内均价从3300元回落至2800元（-15%），按亚钾单吨成本约1000-1100元估算，单吨净利将从1004元降至约700元，300万吨满产对应净利约21亿——**较2026年华安预测28亿下修25%**。周期股盈利弹性极大。

### 3.2 全球寡头与新产能

| 威胁源 | 具体内容 | 对亚钾的影响 |
|---|---|---|
| BHP Jansen | 2026年底一期435万吨投产，本十年末翻倍 | 全球供给2027-2028年显著增加，价格中枢承压 |
| 白俄制裁解除 | 2025年12月美国解除对白俄钾肥制裁，占全球贸易量约20% | 供给恢复，全球价格弹性下降 |
| 俄白出口体系重构 | 已通过俄港+对华铁路完成重构，出口量恢复 | 对中国低价供应可能减少，反而利好国内价格 |
| 老挝内卷 | 藏格/东方铁塔/富嘉金源等持续扩产 | 老挝矿产品同质化，销售竞争加剧 |
| 刚果(布)等新矿 | 埃塞俄比亚、摩洛哥、巴西、刚果等远期新矿 | 2028年后远期供给增量 |

### 3.3 进口替代逻辑的双刃剑

- **利好面**：亚钾2025年占中国自老挝进口约18%，2026年1-5月中国自老挝进口126.5万吨(+50%)。国家"在开放中增加议价能力和安全余量"——老挝钾肥是战略保供，政策支持力度大（中老最高级别联合声明纳入钾肥）。
- **风险面**：亚钾产品"国内+国际"双循环销售，一旦全球价格回落，其老挝产能（远离中国腹地、需经中老铁路/公路运回）在国内销售需让利竞争；海外销售则直面Nutrien/Mosaic/乌拉尔的全球竞价。

## 4. 行业趋势：战略资源属性+低成本扩产+地缘政治重构

1. **战略资源属性**：钾肥已上升为国家粮食安全战略物资，"十五五"明确内外发力。亚钾作为"中国海外钾仓"标杆，政策顺风确定性高，但政策红利不等于商业暴利。
2. **低成本产能扩张**：行业逻辑清晰——谁的成本曲线最低、谁的产能扩张最快，谁就在下一轮周期中占据主动。亚钾300→500→700万吨的规划正是这一逻辑的兑现。
3. **地缘政治重构**：俄乌冲突后全球钾肥贸易流重构（俄经俄港/对华铁路、白俄绕道俄港），制裁→解除制裁的反复使价格波动加大。2025年12月美国解除白俄制裁后，全球价格前景反而更疲软——**供给恢复是未来2-3年钾肥价格的最大压制项**。
4. **老挝成为中国"出海找钾"主战场**：亚钾、藏格、东方铁塔、富嘉金源等扎堆老挝，中国钾肥"走出去"从单点突破走向集群竞争，亚钾的先行者优势（唯一300万吨在产）正被逐步追赶。
5. **伴生资源延伸**：亚钾拓展溴素（2026年8月溴素30天上涨30%）、盐化工、煤化工、复合肥——锦上添花但非核心矛盾，主业仍是氯化钾。

## 5. 产业链分析：价值分配在资源端，传导路径清晰

```
钾矿资源端（储量/品位/成本） → 氯化钾（标准品，无差异化） → 复合肥/农资（薄利加工）
```

| 环节 | 毛利水平 | 特点 |
|---|---|---|
| 钾矿开采+氯化钾（亚钾） | 57%-59% | 资源端最肥，成本曲线决定超额利润 |
| 盐湖提钾（盐湖/藏格） | 45%-52% | 成本曲线陡峭，高成本产能对价格敏感 |
| 下游复合肥 | 低（普遍个位数-20%） | 充分竞争、受上游价格挤压 |

**价值分配结论**：钾肥产业链利润高度集中于资源端，谁的成本低谁就活得久。亚钾毛利率57-59%、单吨净利约1000元，处于全球成本曲线低位+中国进口替代的黄金交叉点上。

**价格传导**：全球大合同价（中国348美元/吨）→ 国内港口价/国产出厂价 → 复合肥成本。亚钾是国内价格的接受者，无法左右价格，只能靠"低成本+放量"穿越周期。

## 6. 芒格视角判定：钾肥是"一门好生意"吗？

### 芒格式"好生意"清单检验

| 检验项 | 结论 | 理由 |
|---|---|---|
| 需求是否刚性/永续？ | ✅ 强 | 粮食安全刚需，需求年增2%-3% |
| 是否有定价权？ | ⚠️ 部分 | 行业寡头高集中度带来价格中枢，但个股无定价权，是价格接受者 |
| 竞争是否激烈？ | ⚠️ 温和但恶化 | 全球寡头默契定价，但老挝内部扩产内卷+新产能（BHP）在路上 |
| 资本开支重不重？ | ⚠️ 重 | 矿业属性，扩产需巨额资本开支，分红率低（2025年10派1.1元） |
| 盈利是否稳定可预测？ | ❌ 否 | 强周期，盈利随钾肥价格剧烈波动（2022年500美元→2024年2178元→2026年3300元） |
| 护城河是否持续？ | ✅ 中强 | 浅埋光卤石低本优势+中国海外钾仓战略卡位，但品位低于加拿大，护城河靠"成本+规模+政策"维系 |
| 管理层是否理性？ | ⚠️ 待观察 | 扩产激进（500→700万吨），2#主斜井地质问题曾致暂缓修复并计提减值（扣非>归母即源于此），执行风险真实存在 |

### 芒格总判

> **钾肥是一门"好的生意"，但不是"最好的生意"。** 资源垄断、需求刚性的行业格局对玩家友好（比纯周期制造业强得多），但强周期+无个股定价权+资本开支重的三重属性，使它无法达到芒格偏爱的"印钞机"标准（如可口可乐、喜诗糖果）。

> 亚钾国际在这门生意中的位置是**全球成本曲线低位+中国战略卡位+产能成长期**——属于"好行业里的好选手"，但买点必须在**周期价格和估值的安全边际**上做文章。芒格会欣赏这门生意，但会拒绝在周期高点用高估值追涨。

## 7. 结论与量化判定

### 核心结论

1. **行业景气**：全球钾肥供需2026年仍偏紧（中国1-5月表观消费+21.5%、国产产量-17.5%），价格高位运行，但2026年8月已现港口库存340万吨+、价格回落20-50元/吨的**顶部松动信号**。
2. **竞争地位**：亚钾是全球成本曲线低位+中国海外钾仓稀缺标的，300万吨产能国内第二（仅次盐湖500万吨）、老挝第一，战略价值突出。
3. **最大威胁**：不是同行，而是**钾肥价格周期**。BHP Jansen 2026-2027投产+白俄制裁解除+老挝内部扩产，2027-2028年全球供给增量集中释放，价格中枢下移是大概率方向。
4. **估值现状**：现价48.23元，PE(TTM)24.45x（10年55.9%分位），对应2026E净利28亿约15.9x、2027E约14.1x——**处于周期高位的盈利给这个估值，安全边际不足**。

### 量化测算依据
