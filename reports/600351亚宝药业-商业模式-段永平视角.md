## 1. 商业模式本质：一张"丁桂儿脐贴"撑起半壁江山的儿科中成药生意

### 1.1 一句话定性
亚宝药业 = **"丁桂儿脐贴"单品牌驱动的儿科中成药OTC企业**。核心不是"中成药龙头"这个标签，而是**一个34年的儿童止泻外用贴剂品牌 + 一个小池塘**。

### 1.2 收入结构（核心事实）

| 板块 | 2025数据 | 说明 |
|---|---|---|
| 丁桂儿脐贴 | **4.72亿（占营收21.1%）** | 独家儿科中成药，OTC甲类，零售药店终端占比98%+，儿童止泻外用贴剂品类**68%份额**（IQVIA 2025），34年历史 |
| 儿科类合计 | **6.36亿（占28.4%，毛利率76.43%）** | 薏芽健脾凝胶、小儿腹泻贴、儿童清咽解热口服液等36款儿童药，连续多年儿科中成药一级集团前十 |
| 心脑血管 | 盐酸倍他司汀注射液1.03亿（2025Q3） | 成人药补充，体量小 |
| 医药批发 | 2025Q3占营收16.4% | 低毛利配送业务，非生意 |
| 化药 | 十批集采累计5个品种中选（硫辛酸/甲钴胺/胞磷胆碱钠/拉考沙胺/地诺孕素） | 集采压缩利润，非核心利润源 |

### 1.3 段永平式判断
这门生意的"好"是**真实但有限的**：
- **真实的品牌**：丁桂儿脐贴34年长红、品类68%份额、独家品种（配方/批文壁垒）、OTC甲类（绕开医院集采、消费者自主决策复购）——这是中成药OTC里少见的"品牌慢生意"。
- **但池塘太小**：儿童止泻外用贴剂是一个**极小品类**（全品类约3-5亿规模），且天花板被人口结构锁死——中国新生儿数量从2016年1786万腰斩到2023年902万，**儿科市场是存量萎缩市场**。
- **无第二增长曲线**：营收从2023年29.10亿降至2025年22.40亿，**三年缩水23%**；成人药、创新药、生物前沿均未成气候。

**结论：这是一门"小池塘里的好品牌"生意——不是伟大的生意（不具复利扩张性），属于"还不错的生意"里偏弱的一档。**

## 2. 护城河：品牌型护城河真实存在，但窄且浅

### 2.1 护城河四要素评估

| 维度 | 评估 | 证据 |
|---|---|---|
| 品牌 | **中上** | "丁桂"34年心智，儿童止泻品类68%份额，2019-2025三大终端年销均超3亿，稳居儿科止泻中成药TOP1 |
| 独家品种 | **中** | 17个独家品种（丁桂儿脐贴/薏芽健脾凝胶等），配方与批文构成准入壁垒 |
| 渠道 | **中** | OTC零售为主（药店98%+），绕开集采与医院回款风险；但受连锁药店/电商平台强势挤压，无自主定价空间 |
| 转换成本/网络效应 | **弱** | 无网络效应，消费者可自由切换竞品（丁桂儿虽第一但品类内竞品多） |

### 2.2 护城河的本质：是"注册租约"还是"心智垄断"？
段永平会问：**"别人能抢走你的生意吗？"**
- 丁桂儿脐贴的护城河**介于"品牌独占"与"注册租约"之间**——比纯仿制药的注册保护强（34年消费者心智+OTC自主复购），但远弱于云南白药类国家绝密配方（不可配方复制）或片仔癀类稀缺资源。
- **弱定价权实证**：丁桂儿单价约6元/贴**多年不动**（2023年9600万贴/5.76亿≈6.0元、2025年7859万贴/4.72亿≈6.0元），且**销量三连降**（9600万贴→8583万贴→7859万贴，两年-18%）——有品牌却无提价能力，增长靠营销投入而非产品力溢价。
- **集采风险低但非零**：OTC甲类+零售渠道绕开化药集采（正面）；但中成药全国集采扩面、医保合规监管趋严（公司2025年报自述"集采常态化扩面、医疗合规监管趋严"）仍是行业性逆风。

## 3. 定价权与盈利质量：高毛利≠强定价权

- **毛利率54%是"中成药会计红利"而非"定价权红利"**：儿科线76.43%高毛利来自中药贴剂成本结构（草药+贴剂辅料，成本极低），而非品牌溢价能力——丁桂儿单价6年不动即是证明。
- **2025年利润是"减量增利"式盈利**：
  - 营收-16.6%，归母+31.86%（3.20亿）——但**扣非仅2.32亿（+7.48%）**，差额0.88亿靠非经常项：出售太原制药62%股权一次性收益（+利润总额约5900万）+ SY-009研发终止计提减值5579万，一进一出基本抵消；
  - 销售费用同比**-31.74%**——利润增长主要靠砍费用，**不是主业扩张**。
- **净现比优秀（真实现金流）**：2025 OCF 5.74亿（+21.64%），净现比约1.79；2026H1 OCF 3.53亿（+7.81%）——现金流质量A级，盈利无水分。
- **成长性为零**：扣非增速三年连降（+106.11%→+19.60%→+7.48%），2026H1扣非1.79亿（+12.28%）略有回暖但体量小。

## 4. 企业文化与本分：分红慷慨、家底干净，但转型屡败+大股东质押偿债

### 4.1 "本分"的正面证据（加分项）
- **回报股东连续且慷慨**：上市以来累计分红23次共14.63亿；2025年合计10派3.5元（Q3派2+年报派1.5）共2.42亿，**分红率75.6%**；2026年中期**首次实施中期分红**10派2（1.38亿）。
- **回购注销**：2026-07-31公告拟1-2亿回购并**全部注销**（上限6.95元/股）——真金白银护盘（注：2025年8月仅执行20万股/126万，执行节奏偏慢，需跟踪）。
- **财务极度稳健**：负债率15.03%、短期借款为零、货币资金9.21亿、无大额商誉并购——不激进加杠杆，家底殷实。
- **聚焦主业**：2025年剥离持续亏损的太原制药（2024年亏1537.85万）"甩包袱"。

### 4.2 "不本分"的瑕疵（减分项）
- **大股东质押"用于偿债"**：控股股东亚宝投资（芮城欣钰盛科技曾用名）2025年9-11月连续质押，累计质押一度达其持股40.93%，用途为**偿债**；历史上2019年质押率曾高达**91.15%**——大股东资金链有持续抽血迹象，虽当前无冻结/平仓风险，但反映大股东财务状况。
- **创新转型屡败屡亏**：两年内**叫停2款降糖1类新药**（SY-009投入8786.98万打水漂，计提减值5579.33万），追热门赛道（降糖）失败；2025年研发费用1.17亿（-15.95%）、2026H1研发费用4342万（-10.55%）**研发持续收缩**，账上9亿现金"等待时机"or"缺乏方向"存疑。
- **2025年利润靠压费+卖资产**：营收三年缩水23%背景下，利润增长依赖费用压缩与一次性处置，非内生。
- **家族交接待验证**：2026-06董事会换届，任武贤（1960年生，66岁，全国劳模/人大代表，从芮城制药厂改制一手带大公司，2025年薪酬410.69万）仍任董事长，**其子任伟（1984年生）任副董事长兼总经理**正式接班——二代能力与"继续本分"待时间检验。

### 4.3 治理小结
**"分红本分 × 经营平庸 × 转型摇摆"**。段永平看管理层，最看重"本分"——亚宝在回报股东和财务纪律上是本分的（低负债、高分红、回购、剥离亏损），但在资本配置与战略执行上不完美（追热点失败、研发收缩、大股东质押偿债）。**整体评级：B+，非减分项主导，但无加分到"值得溢价"的程度。**

## 5. 估值：表面便宜（PE 14.6x），用正常化盈利看并无安全边际

### 5.1 关键估值指标（工具验算）
- 当前股价 6.82 元，2025 EPS 0.46 → **PE-TTM 14.75x**（✅一致）
- BVPS 约4.15 元 → **PB 1.64x**
- 2025年分红2.42亿 → **股息率 5.13%**（2026年预计2.4-2.8亿 → 5.1-5.9%）
- **但扣非口径 PE ≈ 20.3x**（扣非2.32亿）——盈利含一次性与费用压缩水分，真实估值比表面贵40%
- 正常化盈利：**2.4-2.6亿**（扣非+常规非经常项），对应正常化 PE 约18-20x

### 5.2 三情景估值（正常化EPS 0.36 基准，3年预测期）

| 情景 | 权重 | 年增速 | 目标PE | 目标股价 | 涨跌幅 |
|---|---|---|---|---|---|
| 乐观（儿科抗跌+成人药放量） | 25% | +10% | 18x | 8.6元 | +26% |
| 中性（零增长，股息支撑） | 50% | 0% | 15x | 5.4元 | -21% |
| 悲观（儿科萎缩+转型继续失败） | 25% | -5% | 12x | 3.7元 | -46% |
| **加权** | | | | **5.8元** | **-15%** |

（用归母EPS 0.46口径、给更宽松PE 12-18x，加权约+6.7%——两个口径的差异正是"盈利质量折价"的体现，本报告按段永平原则**优先扣非/正常化口径**。）

### 5.3 段永平式结论
- **"便宜"是假象**：PE 14.6x 放在零增长+扣非20x+的背景下，属于"低估值陷阱"边缘——市场用低价已经表达了对其成长性的悲观，这是**合理的低估值，不是错杀的便宜**。
- **安全边际不足**：现价6.82元对应2026E股息率约5.3%、PB 1.64x，对一个营收三年-23%、丁桂儿销量三连降、无第二曲线的生意，**没有留出犯错空间**。
- **买点应出现在"股息率>6.5%"或"PB<1.3x"**：此时市场的悲观预期已被充分定价，分红+回购提供向下保护。

- 内在涨幅: **-15%**（正常化口径加权 5.8 元 vs 现价 6.82 元；乐观+26%/中性-21%/悲观-46%）
- 击球区: 🔴未到 —— 生意真实但零增长+扣非口径20x+无安全边际，"表面便宜实为价值陷阱边缘"，需等更深折扣
- 目标建仓价: **5.5 元**（≈PB 1.33x、股息率6.4%、2026E扣非PE约15x）
