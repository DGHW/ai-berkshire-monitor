## 三、盈利指标与费用结构：巴菲特式"高净利率+高研发"

- **毛利率**：2021年48.75% → 2022年44.10% → 2023年39.83% → 2024年42.98% → 2025年42.14% → 2026Q1 43.49%。**5年中枢约43%，2021-2023曾因MLCC价格战下滑9个百分点，2024年起价格修复回升**。
- **净利率**：2020年36.1% → 2021年32.4% → 2022年29.3% → 2023年27.7% → 2024年29.7% → 2025年29.1%。**A股元器件行业顶级净利率（风华高科仅6.7%）**。
- **费用结构（2025年报）**：研发投入6.53亿元，占营收**7.25%**（+12.1%）——公司是陶瓷材料IDM全产业链闭环（陶瓷粉→流延→烧结→MLCC），研发投入持续，全产业链一体化+垂直整合是毛利率的核心来源。
- **ROE**：2021年14.89% → 2022年9.04% → 2023年8.95% → 2024年11.50% → 2025年12.61% → 2026Q1年化14.36%。**ROE区间9%~15%，反映周期波动；当前处于周期上行中段。**

## 七、安全边际与MLCC周期位置：买在周期中段的高价，非巴菲特击球区

### 7.1 MLCC周期位置判断

- **本轮上行驱动是结构性的**：AI服务器MLCC单机用量爆发（普通服务器0.3-1.5万颗 → AI训练3万颗 → 英伟达GB300达44万颗 → Rubin超60万颗），高盛预测AI服务器MLCC市场CAGR 80%；日韩头部厂商（村田/三星/太阳诱电）对AI/车规高端MLCC涨价15%-30%；高端产能建设周期1.5-2年，2026-2027年存在"产能真空期"。
- **但MLCC本质仍是周期行业**：历史上2021-2022年即经历过价格暴涨→崩盘（三环毛利率从48.75%跌至39.83%、净利-25%）。本轮"AI结构性需求"延长了上行，但**当前TTM盈利28.76亿、2026E约40亿均处于周期高位，一旦AI资本开支放缓或日韩/国产产能集中释放，盈利回撤30%-50%属正常剧本**。
- **机构共识**：摩根大通供需模型显示行业从2025年约10%过剩 → 2027-2028年5-6%短缺，即**景气至少延续至2027-2028年**。这与悲观情景的"5%增速"存在方向分歧——但估值上，当前价格已透支到2028年的乐观情形。

### 7.2 内在价值估算（巴菲特正常化盈利框架）

| 方法 | 假设 | 内在价值 |
|---|---|---|
| 正常化PE | 正常化净利24-26亿（2024-2025均值），EPS 1.25-1.30 × 35-40x（周期股合理估值） | **44-52元** |
| 2026E PE | 2026E EPS 2.00 × 40-45x（结构成长龙头溢价） | **80-90元** |
| 2027E PE | 若AI景气兑现2027年净利45亿，EPS 2.25 × 40x | 90元 |
| 综合 | 结构性成长+周期风险折中 | **公平价值中枢≈92元** |

**安全边际：现价126.90元 vs 公平价值中枢92元 → 溢价约27%~38%，内在涨幅约-27%。**

### 7.3 巴菲特视角结论

**公司质地：A级。** 陶瓷材料IDM全产业链闭环（国内唯一）、全球光纤陶瓷插芯市占率70%+、晶振封装基座40%、净利率29%、负债率17%、净现金、商誉占比1%、OCF/净利常年>95%、分红率33%——完全符合巴菲特"伟大的生意+优秀的资本配置"标准。

**但价格：完全不提供安全边际。** 巴菲特买入原则是"以合理价格买入伟大公司"，而当前88x TTM PE是在**周期高峰盈利**上乘以**周期高峰估值**——双重风险叠加。历史上三环曾在2022年净利-25%而估值同步压缩，2019年-34%。**投资三环应等估值回归至合理区间（建仓90元以下、对应2026E 45x或正常化盈利60x以内），或等周期证伪/证实的验证窗口（2026中报8月底、2027年日韩扩产节奏）。**
