## 一、行业规模与趋势：好赛道的"第二段"

### 1.1 市场规模：仍在扩容，但增速换挡

| 口径 | 数值 | 来源 |
|------|------|------|
| 2025年眼科医疗服务市场规模 | 2521.5亿元（Frost & Sullivan 预测口径） | 中研普华 |
| 2025年眼科医疗服务市场规模 | 1561亿元（另一口径） | 搜狐行业报告 |
| 2020-2025 CAGR | ~16% | 东方财富行业报告 |
| 屈光手术细分 2025 | ~730亿元（占眼科市场33%） | 百度财经 |
| 眼科医院数量 2025 | 2205家（民营2133家，公立72家） | 东方财富行业报告 |

**芒格式判断：这是典型的"好行业，增速换挡期"。** 三条底层需求长期不变：
1. **老龄化**：中国60-89岁人群白内障发病率约80%，90岁以上超90%。百万人口白内障手术率(CSR)已从2017年2205提升至超3000，但相较欧美(万人级)仍有数倍空间。
2. **近视存量**：全国近视人口约6亿，8成高中生戴眼镜。屈光手术渗透率与成熟市场差距巨大，"考公参军"视力矫正成为青年刚性准入消费。
3. **青少年近视防控**：0.01%阿托品2024年3月获批、0.02%/0.04%浓度2026年1月获批（兴齐眼药），OK镜、离焦镜、视光服务构成长期复购现金牛。

但**行业已从"跑马圈地"转入"存量竞争、结构优化、龙头集中"**（十五五行业报告原文）。2024年下半年起民营眼科医院扩张出现逆转，部分竞争力不足机构陆续关闭——**行业洗牌正在发生，这对龙头是利好（出清对手），但同时也意味着单店增长红利消退。**

### 1.2 集采影响：短期压价，长期利好龙头

- 2024年全国集采：人工晶体价格下降约50%，单焦晶体手术费低至800元起。
- 白内障业务毛利率：爱尔2025年仅33.5%（同比-1.2pct），为最低毛利板块。
- DRG/DIP付费模式下，医院更倾向用集采中选晶体。
- **反面看**：集采清洗了二三线品牌与低端产品，规范化的市场反而有利于龙头（爱尔/华厦）凭借规模与高端自费项目对冲。屈光性（多焦/EDOF）人工晶体集采放量，客单价结构上移。

**结论：集采压缩的是低端白内障毛利，但爱尔屈光/视光占营收63%且全自费，医保收入占比仅~21.6%，集采对整体毛利冲击可控。**

## 二、竞争格局：一超多弱，"半个爱尔"碾压全场

### 2.1 格局总览

```
民营眼科市场（约32%爱尔斯占第一，第二梯队合计<15%）
├── 第一梯队：爱尔眼科（营收223.5亿，净利32.4亿，市占率~32%）
├── 第二梯队：华厦眼科（41.4亿，净利4.4亿）| 普瑞眼科（~28亿，亏损~0.6亿）
│           何氏眼科（~11亿，微利）| 朝聚眼科（~14亿，净利1.8亿，港股）
├── 第三梯队：光正眼科（亏损）| 希玛医疗（港股，扭亏）
└── 隐性对手：公立医院眼科（72家公立专科 + 综合医院眼科科室扩容）
```

**2025年度A股四家眼科盈利对比**：

| 公司 | 2025营收(亿) | 2025归母净利(亿) | 同比净利 | 状态 |
|------|-------------|-----------------|---------|------|
| 爱尔眼科 | 223.53 | 32.40 | **-8.88%** | 首次年度负增长 |
| 华厦眼科 | 41.39 | 4.41 | +~3% | 最稳健 |
| 普瑞眼科 | 27.5-28.5(预告) | -0.5~-0.6 | 减亏 | 亏损 |
| 何氏眼科 | ~11 | 0.24-0.36(预告) | 扭亏 | 弱盈利 |

**芒格的第一反应：这是典型的"赢家几乎通吃"格局。** 爱尔的营收 = 华厦+普瑞+何氏+朝聚之和的3倍多，净利更是远超全部第二梯队之和。规模差距如此悬殊，第二梯队在品牌、人才、采购、教研上均无法形成正面威胁。

### 2.2 爱尔份额与卡位

- **规模卡位**：全球842家机构（2025年末）——境内663家（391家医院+272家门诊/诊所）、海外179家。全国最大连锁，覆盖31省市，下沉至县域。
- **模式卡位**："1+8+N"分级连锁（1家世界级长沙医学中心+8家区域中心+N家地市/县域），配合"上市公司+产业并购基金"模式实现体外培育-成熟并表，历史上大幅降低扩张风险与资本消耗。
- **业务卡位**：屈光37.5%+视光25.9%=63.4%为全自费消费医疗，抗医保政策风险；白内障15.6%为刚需基本盘。
- **教研卡位**：自建医教研体系+眼科医生培养体系，员工超5万人、眼科医生超1.1万人，与中南大学等共建——这是第二梯队最难复制的壁垒。

## 三、核心竞争者逐一拆解（芒格"解剖对手"清单）

### 3.1 华厦眼科（301267）—— 唯一的"体面"对手

- 2025营收41.39亿(+~4%)、净利4.41亿(+~3%)；2026H1营收+4.31%、净利+6.20%。
- 壁垒：厦门眼科中心+成都爱迪双三甲医院，深耕沿海，64家医院+67家视光中心，院士团队。2025屈光收入+13.75%（增速最高）。
- **威胁评估：中低。** 稳健、审慎（暂停部分扩张、把赣州医院盘给普瑞），但体量只有爱尔的1/5，区域性防御有余，全国进攻不足。对爱尔构成的是"区域钳制"而非"全面威胁"。

### 3.2 普瑞眼科（301239）—— 扩张后遗症典型样本

- 2025营收27.5-28.5亿，净利亏损0.5-0.6亿（较2024年亏1.1亿减亏，但2025H1净利仅1466万，-66%）。
- 特色：深耕屈光业务，昆明普瑞、东莞光明为现金牛。
- **威胁评估：低，且是反面教材。** 扩张导致的亏损说明：眼科连锁不是"多开店就多赚钱"的生意，规模经济背后是管理半径、医生供给与合规成本的约束。这对爱尔是利好（对手犯错=龙头份额）。

### 3.3 何氏眼科（301103）—— 区域利基者

- 2025营收约11亿、净利0.24-0.36亿（扭亏）；扎根辽宁，视光特色+综合诊疗差异化。
- **威胁评估：极低。** 营收同比下滑、盈利微薄，本质是区域性视光连锁，无全国扩张能力。

### 3.4 朝聚眼科（02219.HK）—— 华北地头蛇的困境

- 2025净利1.77亿；2025H1营收6.98亿(-4.91%)、净利1.14亿(-16.72%)。
- 2026年公告：华北地区（爱尔/普瑞/何氏围猎区）多医院实际营收现金流远低于预期，计提商誉减值，商誉总额承压。
- **威胁评估：低，且正在被"卷"。** 其公开减值恰恰印证：爱尔下沉+全国龙头挤压正在让二三线连锁的本地基本盘失血。

### 3.5 光正眼科 / 希玛医疗 —— 边缘玩家

- 光正：2025亏损1500-2000万，依赖基础白内障，价格战中被挤压。
- 希玛：港股，2025大幅扭亏，靠关闭低效网点+成本控制，规模12.6亿，主要布局港澳大湾区。
- **威胁评估：可忽略。**

### 3.6 公立医院眼科 —— 最被低估的"对手"

- 政策面"十四五"眼健康规划明确加强综合医院眼科建设，公立扩容是确定性方向。
- 公立在疑难杂症、医保覆盖、专家信任度上有天然优势，且"患者信任公立"的心智根深蒂固。
- **威胁评估：中，且结构性上升。** 但公立医院体制决定了其难以在消费医疗（屈光/视光）提供与民营同等的服务体验与市场化运营，两者更多是"公立保基本、民营做消费"的双轨分工。爱尔的核心护城河恰在消费医疗的服务体验。

## 四、行业趋势：四股力量塑造未来5年

1. **存量竞争与龙头集中**：十五五期间增速放缓、结构优化，中小机构出清，头部集中度提升——利好爱尔。
2. **技术迭代驱动客单价上移**：全飞秒4.0（蔡司2025上线，1.8万/眼级）、全光塑、全飞秒Pro、ICL V5/V6晶体（STAAR，3.5-4.4万/眼）持续推高屈光客单价；爱尔屈光客单价已企稳回升。**但反面：技术平权使各民营机构都能采购同款设备，"设备军备竞赛"降低差异化，价格战风险上升。**
3. **近视防控政策红利**：阿托品浓度梯队放开（0.01%/0.02%/0.04%）、OK镜验配规范化、视光中心渠道下沉——视光是爱尔占比第二、毛利率52%的现金牛，政策规范化反而利好合规龙头。
4. **AI与远程医疗**：爱尔"AI眼底筛查+远程医疗中心+智慧医院"闭环，AI眼底筛查系统累计调用超60万次。数字化是第二梯队难以复制的重资产投入。

## 五、产业链与价值分配：谁在产业链上赚钱？

```
上游（高毛利、强话语权）        中游（爱尔所在环节）        下游（患者）
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│ 设备：蔡司VisuMax │    │ 爱尔/华厦/普瑞/    │    │ 近视患者(~6亿)    │
│      爱尔康/强生   │    │ 何氏/朝聚/公立     │    │ 白内障老人(老龄化) │
│ 耗材：人工晶体     │    │ 毛利率47%         │    │ 青少年(近视防控)   │
│  (爱尔康/强生/蔡司/ │    │ 净利率14.5%       │    │ 支付：医保+自费    │
│   爱博医疗)        │    │ (龙头亦仅此水平)   │    │ (自费占爱尔~78%)   │
│  ICL晶体：STAAR    │    │                  │    │                  │
└─────────────────┘    └──────────────────┘    └──────────────────┘
  议价权：★★★★★       议价权：★★★☆☆         议价权：极低
  毛利率：60-80%        毛利率：47-55%(屈光/视光)   但复购粘性极高
```

**芒格式洞察：眼科服务是中游，赚的是"辛苦但可持续"的钱，且比上游更抗周期。**

- **上游是真正的利润丰谷**：蔡司、爱尔康、强生、STAAR在设备与晶体上毛利率60-80%。集采后国产人工晶体份额从<20%升至33%（爱博医疗占国产59%），但高端多焦/EDOF仍被外资垄断。**爱尔作为中游，耗材成本与设备更新是被上游"抽成"的——这是其毛利不可能长期高企的结构性原因。**
- **中游爱尔的护城河不在"毛利"而在"周转与复购"**：视光（OK镜、配镜、防控）是长期复购，屈光是高客单价低频，白内障是刚需。三者组合使爱尔在净利率14.5%（行业内领先）的水平上维持现金流59.7亿（+18%）。
- **下游患者对价格不敏感，但对"信任"极度敏感**——这正是品牌+医生资源的护城河所在，也解释了为何品牌丑闻对爱尔是真正的风险源。

## 六、芒格护城河清单：10年后还在吗？

| 护城河类型 | 强度 | 证据 | 10年可持续性 |
|-----------|------|------|-------------|
| 规模效应 | ★★★★★ | 842家机构、营收是第二名5倍，采购/教研/IT摊薄成本 | 高——规模是时间+资本堆出来的 |
| 品牌信任 | ★★★★☆ | "爱尔"全国心智第一；但2026年品牌风波有侵蚀 | **中——需持续维护，丑闻是最大变量** |
| 医生/教研壁垒 | ★★★★★ | 1.1万眼科医生、自建培养体系、中南大学共建 | 高——第二梯队10年内难复制 |
| 分级连锁网络 | ★★★★☆ | 1+8+N，下沉县域，网络效应+转诊导流 | 高——但县域盈利兑现慢 |
| 转换成本 | ★★★☆☆ | 患者跨院迁移成本低，复购靠习惯与信任非锁定 | 中——需靠服务体验维持 |
| 牌照/政策 | ★★★☆☆ | 社会办医放开、无总量限制；集采/DRG是双刃剑 | 中——政策中性偏利空中小机构 |

**芒格的追问：这生意10年后还是好生意吗？**
答：**是的，但护城河结构在变。** 设备技术平权（各家都能买全飞秒/ICL）、医生多点执业与人才争夺、公立扩容，会持续侵蚀技术差异化；而爱尔的真正壁垒已经从"手术技术"迁移到"体系能力"——分级网络、教研、品牌、供应链、数字化。体系壁垒比技术壁垒更难被攻破，但前提是**品牌不出大事故**。

## 七、反面检验（A级信息必须质疑）

> 行业报告普遍说"爱尔龙头地位稳固、长期逻辑不变"。我刻意找了三组反面证据：

**① "增收不增利"是否意味着行业逻辑已破？**
- 2024年扣非净利已首次负增长(-11.82%)，2025年归母净利再降8.88%，2025Q4净利仅1.26亿。盈利能力的持续走弱，说明行业性"内卷"（价格战、人力成本、OK镜资质核查）真实存在，并非一次性。
- **但**：2026Q1净利+12.46%回升，屈光/视光收入重回+10%/+9.6%，客单价企稳。行业更像"筑底"，而非崩塌。

**② 商誉是达摩克利斯之剑？**
- 商誉初始113.66亿，2026Q1账面商誉94.37亿（占资产~25%）。2024计提1.88亿、2025计提1.56亿。历史上2017-2023累计计提13.77亿。
- **反面看**：商誉占比高是真，但爱尔有并购基金模式+成熟期并表的历史成功记录；且商誉减值是非现金项，2025年经营现金流59.7亿(+18%)说明真实造血能力未恶化。风险在于"县域下沉新并购"的兑现节奏。

**③ 合规与治理丑闻是否会动摇根基？**
- 2026年2月"爱尔系"品牌风波（董事长关联精神病院骗保传闻，上市公司切割）；2026年5月补税5.24亿（3.48亿税款+1.76亿滞纳金，占2025净利16%）；医保被罚密集；股价2026年从高点大幅回撤（市值一度873亿后跌至820亿）。
- **这是芒格最警惕的一类风险：管理层声誉与治理质量。** 补税自查+港股IPO（2026年5月27日递交）暴露的财务管理瑕疵，与"品牌信任"护城河直接冲突。**若治理问题再发酵，品牌护城河强度需从4星下调至3星。**

## 九、结论：芒格式总结

**这是一家好公司，身处一个长坡厚雪的行业，但在一个困难的时点。**
- 行业角度：眼科是少数兼具"老龄化刚需+消费升级+低渗透率"三重逻辑的医疗赛道，长逻辑未破。
- 竞争角度：爱尔对第二梯队呈碾压式优势，护城河在"体系能力"而非单一技术，10年维度稳固。
- 但当前：行业增速换挡、龙头利润首次负增长、治理与合规事件频发、估值24.3x并不便宜。
- 芒格会说：**"这家公司值得长期关注，但此刻不是击球区。让子弹飞一会儿，等估值回落或治理出清。"**
