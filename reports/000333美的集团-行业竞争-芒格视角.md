# 美的集团(000333.SZ)行业竞争分析——芒格视角

> 研究员：md-industry | 视角：查理·芒格（行业格局 / 竞争壁垒 / 逆向思考）
> 报告日期：2026-08-10
> 速评卡参照：PE 14.4 / 市值 6357.2亿 / 毛利 25.6% / 净利 9.8% / 营收增速 2.6%（对应2026Q1口径）

---

## 〇、芒格开场判断

> "投资的本质不是寻找伟大的公司，而是寻找那些**能在困难环境中依然出色**的公司。洗衣机、空调这种生意无聊、平淡，但正因如此，才不会有太多聪明人挤进来。关键是——**这个行业里最后站着的是谁。**"

美的正处在一个**"好行业进入存量期、但格局持续向龙头集中"**的关键节点：
- 行业总量见顶（2025年家电零售 8931亿，-4.3%；2026H1 空调销售 -6.3%）；
- 但龙头分化加剧（美的 2025 营收 +12.1%，格力 -9.9%）；
- 增量逻辑从"地产拉动"切换为"以旧换新政策 + 出海 + ToB"。

**核心问题：这个存量内卷的行业，美的会不会是"最后站着的那一个"？** 我的答案是：大概率是，但过程不会舒服，市场先生正在给一个不算便宜的价格。

## 一、行业规模与趋势：总量见顶，结构重排

### 1.1 市场规模数据

| 指标 | 数据 | 来源 |
|------|------|------|
| 2025年中国家电零售市场规模 | 8931亿元，同比 **-4.3%** | 奥维云网 |
| 2025冷年(2024.8-2025.7)全球家用空调出货 | 2.21亿台，同比 **+12.9%** | 奥维云网 |
| 2025H1中国家用空调销量 | 12310.8万台，+8.3%（内销+9.0%/出口+7.5%） | 产业在线 |
| 2025年全年空调出口量 | 约8226万台，**-3.2%**（2024年为+28.3%） | 机电商会 |
| 2025年前11月出口：冰箱/洗衣机/电扇 | +1% / +8.5% / +14.3% | 海关总署 |
| 2026H1空调行业销售 | 11023万台，**-6.3%**（内销5967万台-6.2%） | 奥维云网PSI |
| 2026H1空调零售额 | **-15.9%** | 奥维云网 |
| 2026Q1空调零售量/额 | -13.0% / -13.8% | 奥维云网 |
| 2026H1家电出口总额 | 3609.6亿元，+2.4% | 海关总署 |
| 城镇百户空调保有量 | 176台（增量红利快速收窄） | 奥维云网郭梅德 |
| 2026年8月空调内销/外销排产 | -13% / -1.2% | 奥维云网 |

**芒格解读**：
- **总量逻辑已死**。百户保有量176台意味着空调从"买第一台"进入"换新+增购"，行业进入**零和甚至负和博弈**的存量阶段。2026H1 零售额 -15.9%、排产连月双降，是芒格最警惕的"行业景气下行"信号。
- **但出口是唯一确定性增量**。2026H1家电出口3609.6亿 +2.4%，空调虽受高基数影响回落，冰箱/洗衣机/电扇仍在增长。出海是中国家电龙头的共同出路，但**最终谁能把"代工"变成"品牌"，谁才真正受益**。

### 1.2 三个宏观变量

**① 地产影响（持续负面，但脱钩加速）**
- 空调、厨电与地产竣工高度相关。地产长期下行是行业总量见顶的主因。
- **反面检验**：家电需求对地产的弹性正在减弱——以旧换新政策驱动存量换新，2026年国补延续（1级能效产品按售价15%补贴，每件上限1500元），部分对冲地产拖累。奥维数据显示2025年以旧换新对空调内销拉动明显（2025H1内销+9.0%），但2026年补贴边际效用递减、门槛提高（已转向更严格能效要求），Q1内销转负。

**② 以旧换新政策（短期托底，长期透支）**
- 2025-2026年连续两年国补，2026年延续"15%补贴、单件≤1500元"。
- **芒格提醒**：政策是"镇痛剂"不是"生长激素"。补贴可以平滑周期，但**透支未来需求**——2026年Q1空调内销 -9.2%、零售 -13% 已经显示补贴退坡后的真实需求。依赖补贴的行业增长，价值要打折。

**③ 出海（结构性机会，关税是变量）**
- 2025年美的海外收入1959亿元（+16%），占比约43%；
- 海尔海外占比更高（约52%），格力最弱。
- 风险：欧美关税、地缘政治（美的已通过东南亚/欧洲本地化工厂+OBM转型对冲）。2026H1欧盟空调出口+43.2%创新高，但这是低基数+免安装移动空调等新品类的贡献，**持续性存疑**。

## 二、竞争格局：空调"双雄"变"一超多强"，美的确立第一

### 2.1 空调市场最新份额（口径差异大，需交叉验证）

| 数据源/时间 | 美的 | 格力 | 海尔 | 小米 | 说明 |
|------|------|------|------|------|------|
| 奥维云网全渠道（2026.1） | **29%** | 17% | 15% | ~11% | 全年口径 |
| 新浪/GfK中怡康（2025.7第29周） | 28.9% | 24.9% | 26.8% | - | 周度零售 |
| 新浪（2025.7，销量口径） | 26.8% | 17.2% | - | 13.7% | 月度 |
| 雪球/财经（2025.7） | **32%** | 28% | - | 11% | CR3>70% |
| 格力2025年报自述 | - | 线上零售额第一(24%) | - | - | 格力口径 |

> **数据口径陷阱（重要）**：不同口径（全渠道/线上/线下、量/额、累计/周度）差异极大。格力擅长"按对自己有利的口径"发声。**但有一个趋势是不可争议的：美的稳居第一，格力从2017年峰值约37%一路下滑至25%左右，海尔稳步上升，小米强势闯入前三。**

### 2.2 2025年报三巨头财务对比

| 指标 | 美的集团 | 海尔智家 | 格力电器 |
|------|---------|---------|---------|
| 营收 | **4585亿（+12.1%）** | 3023亿（+5.71%） | 1704亿（**-9.9%**） |
| 归母净利 | **439.5亿（+14.0%）** | 195.5亿（+4.4%） | 290亿（**-9.9%**） |
| 毛利率 | 26.39%（-0.03pct） | ~31%（持续提升） | 29.81%（+0.38pct） |
| 净利率 | 9.7% | ~6.5% | ~16.9% |
| 海外收入占比 | ~43%（1959亿） | ~52% | 最低 |
| 业务结构 | 全品类+ToB多元 | 高端化+全球化 | **空调依赖近80%** |
| 2026Q1营收/净利 | +2.55% / +2.03% | 微增 | 承压 |

**芒格点评**：
- **格力的问题是"单一业务+品牌老化"**。营收只有美的的1/3强，且连续两年下滑。高净利率（16.9%）是空调垄断时代留下的遗产，但份额流失（2017年37%→2025年25%）正在侵蚀这个遗产。芒格会说：**"一家公司如果只有一种产品，而那个市场正在萎缩，它需要祈祷的不是更好的管理，而是更好的运气。"**
- **海尔的问题是"增长靠堆费用"**。高端化（卡萨帝）+全球化方向正确，但净利率6.5%远低于美的，费用率拖累赚钱效率。海尔是"稳健的跟随者"，不是"规则的改变者"。
- **美的的优势是"全品类+ToB+出海"三引擎**。当空调内卷时，楼宇科技（+25.7%）、机器人与自动化（+11.8%）、海外（+16%）仍在增长。**这是芒格最喜欢的"多元化缓冲垫"——它不是分散投资，而是在主业见顶前已经培育了第二曲线。**

### 2.3 份额与卡位判断

```
第一梯队（全能选手）：美的 —— 空调第一、全品类前二、ToB第二曲线
第二梯队（专业化/高端）：格力（空调）、海尔（冰洗+高端）
第三梯队（进攻者）：小米（线上价格战）、海信（差异化）
第四梯队（区域性）：奥克斯、TCL、长虹等
```

**美的的卡位优势**：
1. **空调第一且份额稳定**（29-32%，未像格力那样大幅流失）；
2. **冰洗双前二**（美的系：美的+小天鹅/COLMO），海尔第一；
3. **中央空调国内第一**（商用多联机/离心机/模块机市占率均为第一）；
4. **上游核心部件全球第一**（家用空调压缩机、空调电机、洗衣机电机全球销量份额第一，美芝压缩机自供）。

## 三、核心竞争者威胁：逐家拆解

### 3.1 格力电器（000651）—— 威胁等级：中，且威胁在下降

- **优势**：空调品牌心智最强（"好空调格力造"）、高净利率现金牛、渠道改革后线上发力（2025年线上零售额24%居第一）。
- **劣势**：空调依赖近80%，第二曲线（新能源、装备制造）至今未成气候；管理层动荡；2025年营收/净利双降近10%。
- **对美的的威胁**：价格战中最顽固的防守者。2026年铜价暴涨下格力宣布"家用空调不涨价"，挤压全行业利润。但**长期看，一个份额持续下滑的对手，威胁在递减**。
- **芒格判断**：格力的存在对美的更像"锚"，保证行业不陷入毁灭性价格战——两个巨头有默契地避免同归于尽。**反证**：如果格力继续失血，可能引发其孤注一掷的价格反扑，这是行业最大变量之一。

### 3.2 海尔智家（600690）—— 威胁等级：中高，稳步上攻

- **优势**：冰洗绝对龙头（国内洗衣机线下份额47.4%）、卡萨帝高端、全球化布局最均衡（海外占比52%）、三翼鸟场景生态（2025套系收入破1050亿）。
- **劣势**：净利率低（~6.5%）、海外并购整合费用高、空调是短板（仅15%份额，但2025年线下份额+0.99%在逆势提升）。
- **对美的的威胁**：**在空调上正成为最大追赶者**。2025年GfK周度数据显示海尔空调份额一度与格力交替第二。若海尔将冰洗的成功经验复制到空调，美的的第一位置将承压。
- **芒格判断**：海尔是"高质量但低盈利效率"的对手。它在空调的进攻暂时伤不到美的的份额基本盘，但会拉低行业均价。

### 3.3 小米集团（1810）—— 威胁等级：高（短期），但结构性天花板明显

- **数据**：2025年7月空调销量份额11-13.7%（+53.9%），线上反超格力；高盛预测小米2026年将占约10%份额，倒逼全行业降价、行业利润-6%。
- **打法**：生态链+极致性价比+线上流量，均价2430元逆势上涨（靠产品结构升级而非单纯低价）。
- **对美的的威胁**：**价格战的最大推手**。小米没有自建压缩机/电机能力（代工+小米生态），成本结构依赖供应链，规模上来前盈利能力存疑。
- **反面检验（关键）**：小米空调低毛利（代工模式），主要价值是"生态入口"而非利润来源。**高盛情景分析明确：美的在小米冲击下最具韧性（全品类+自供核心部件+渠道多元化），格力最脆弱。** 小米更可能先咬碎奥克斯/TCL/长虹等二三线，而非美的格力的一线份额。
- **芒格判断**：小米是"低价竞争者的经典案例"——它会把行业毛利压得更薄，但**无法颠覆具有核心部件自供+品牌+渠道的龙头**。美的需要警惕的，是行业均价下移对自己盈利的侵蚀，而非份额的丢失。

### 3.4 海信家电 / 奥克斯 / TCL —— 威胁等级：低

- 海信：差异化（新风空调、容声冰箱、日立中央空调），份额有限；
- 奥克斯：线上性价比品牌，受小米挤压最严重；
- TCL：黑电起家，白电规模小。
- **芒格判断**：这些是"市场份额的搬运工"——它们之间互相消耗，抢的是小米留下的低端残渣，伤不到美的核心。

### 3.5 其他跨界威胁

- **华为**：全屋智能（鸿蒙智家）做生态不做硬件制造，合作大于竞争；
- **字节/京东/拼多多等平台**：掌握渠道话语权，2026年"仅退款/低价内卷"挤压品牌溢价，但美的作为头部品牌有议价力；
- **格力式"友军"**：无。

## 四、行业趋势：五条主线重塑家电业

### 4.1 空调格局：存量内卷，龙头份额继续集中

- CR3 超70%，行业进入"零和博弈"。
- 格力份额长期下滑，美的+海尔缓慢上升，小米从零到10%+。
- **芒格判断**：空调的终局是"美的与格力双寡头+小米价格扰动者"。美的已领先身位，且不再需要打价格战保份额（产品结构升级、中央空调、海外是利润池）。

### 4.2 消费电器：全品类+高端化对冲单一品类风险

- 美的智能家居2025年收入2999亿（+11.3%），覆盖白电+厨电+小家电全品类；
- COLMO/东芝双高端品牌对标卡萨帝；
- **芒格视角**：全品类是"对抗单品周期"的生意结构。消费者买了美的空调，下次买冰箱大概率还选美的——**品牌忠诚度和渠道复用，是家电业最便宜的护城河**。

### 4.3 机器人（库卡）：确定性最高的第二曲线

- 库卡2025年国内工业机器人销量份额9.6%（行业前三），**300kg以上重载机器人份额47.4%**；
- 机器人业务2025年收入约310亿（+9%），2026Q1收入82亿（+11.8%）；
- 已发布5款人形机器人并进厂落地；
- **反面检验**：机器人业务利润率低、竞争激烈（发那科/ABB/安川+国产新锐），且美的在机器人上已累计大额投入多年才转正。**它是期权，不是现金牛**——给不了短期的利润弹性，但给未来10年一个想象空间。
- **芒格判断**：投资机器人对美的是"为未来付的学费"，方向正确（制造业自动化是确定趋势），但要防止"为想象付费过高"。

### 4.4 ToB转型：商业及工业解决方案成新引擎

- 2025年ToB收入1227.5亿（+17.5%），明显快于ToC；
- 楼宇科技357.9亿（+25.7%）——中央空调+楼宇自控，受益于数据中心/商业地产；
- 工业技术272.3亿（+10.2%）——压缩机/电机/新能源车零部件（如车规级热管理）；
- 新能源、医疗、物流多点布局。
- **反面检验（重要）**：2026Q1 工业技术收入**-11.7%**（新能源车零部件竞争+价格战），ToB并非无忧增长。芒格会说：**"多元化的诅咒是，你进入的每个领域都有一个比你更专注的对手。"** ToB是美的的期权组合，但必须持续证明盈利质量。

### 4.5 全球化：从"Made in China出口"到"Local for Local"

- 美的海外收入1959亿（+16%），占比43%，OBM（自有品牌）占比持续提升；
- 东芝、库卡、Eureka等海外品牌+东南亚/欧洲本地化工厂；
- 2026年关税环境复杂（美国对华关税），但美的全球化纵深（多基地+多品牌）优于同行。
- **芒格判断**：全球化的关键是**本土化经营的深度**。海尔海外占比更高但利润率低，美的的平衡（43%海外+ToB+国内现金流）结构更健康。

## 五、产业链：价值分配与美的的"垂直一体化"护城河

### 5.1 产业链结构

```
上游原材料：铜（占空调成本20-35%）、铝、钢、制冷剂、塑料
    ↓
核心零部件：压缩机、电机、两器（冷凝器+蒸发器）、芯片
    ↓
中游整机制造：美的/格力/海尔/海信/奥克斯/小米
    ↓
下游渠道：线上（京东/天猫/拼多多）+ 线下（KA/专卖店/工程）→ 地产/消费者
```

### 5.2 价值分配：利润被"上游原材料+下游渠道"两头挤压

| 环节 | 议价力 | 特征 |
|------|--------|------|
| 上游铜/钢 | **强** | 大宗商品定价，家电厂是价格接受者。2025-2026铜价暴涨36%+，一度破10万/吨，下半年每台空调成本+约100元 |
| 压缩机/电机 | 中强 | 美的（美芝）/格力（凌达）自供，**国产替代+垂直整合使成本下降18%**；第三方供应商（东贝等）2026H1转亏 |
| 中游整机 | 中 | 品牌+规模决定定价权；价格战挤压毛利（行业均价毛利约22%） |
| 下游渠道 | **强** | 线上平台掌握流量+补贴核销权，压价狠；以旧换新补贴变相让利给平台 |
| 地产/消费者 | 弱 | 需求端，地产下行是行业天花板 |

### 5.3 美的的垂直一体化优势（芒格最看重的部分）

1. **核心部件自供**：美芝压缩机、威灵电机全球第一，自供比例高——**铜价上涨时，美的的采购规模和自供对冲能力优于纯组装厂**；
2. **全产业链数字化**：从原料到物流（安得智联）全链条自控，行业龙头良品率98.5%；
3. **规模采购议价**：年采购铜/钢数千亿级，供应商定价优势显著；
4. **反向挤压**：东贝等第三方压缩机厂2026H1转亏，说明**产业链利润正在向掌握"部件+整机+渠道"的巨头集中**。

**芒格结论**：家电行业是"两头受气"的生意（上游大宗+下游渠道），但美的通过垂直一体化把"两头受气"变成了"两头通吃"——这是它毛利率25.6%能维持、且净利率还在提升的根本原因。**这是真护城河，不是报表粉饰。**

### 5.4 成本端2026年压力（反面检验）

- 铜价破8万/吨（格力口径铜占空调成本约20%），叠加制冷剂涨价；
- 家电行业平均毛利约22%，原材料上涨压缩利润3-5pct；
- 美的2026Q1毛利率承压（扣非净利-14%），**成本压力已在报表显现**；
- 但美的可部分通过提价+产品结构升级对冲（高端占比提升），且Q1扣非下滑另有汇兑/金融资产等非经营因素。

### 6.2 芒格终局判断：美的会是"最后站着的那一个"吗？

**是，但有三个前提：**

1. **守住空调份额**（29%+）：小米会蚕食二三线而非一线，格力在下滑，美的份额大概率稳中有升；
2. **ToB证明盈利质量**：楼宇科技+机器人+工业技术目前是"收入增长、利润贡献有限"，未来3年需看到ToB净利率向ToC靠拢，否则只是"大而不强"；
3. **不犯大错**：不做激进并购、不在人形机器人上烧掉太多现金（美的已回购+100%分红，资本配置纪律良好）。

**反面检验——什么会推翻这个判断？**
- 空调行业陷入毁灭性价格战（小米+格力+海尔三方互杀），行业利润-20%以上；
- 铜价持续暴涨且无法转嫁；
- ToB业务（尤其新能源车零部件）被比亚迪/宁德等跨界者击穿；
- 全球关税升级导致海外利润池被侵蚀。

**芒格名言应验**：
> "要在鱼多的地方钓鱼。但如果池塘已经没水了，那么最聪明的鱼也要找出路。" 美的的出路（ToB+出海+机器人）已经找好了——**关键不是方向，而是执行和利润兑现。**

### 6.3 对美的的芒格式定性

- **这是"好公司 + 平庸行业 + 合理价格"的组合**：芒格最喜欢的不是这类公司（他偏爱"好行业+好公司"），但它符合"**以合理价格买伟大公司**"的变体——美的是"以合理价格买优秀公司"。
- **相比格力（单一下滑业务）和海尔（低利润率）**，美的是白电三巨头中**唯一同时具备"行业第一 + 多元缓冲 + 全球化 + 高分红"**的公司。若必选其一，芒格会选美的。
- **估值锚**：2026年机构一致预期净利470亿（+7%）、EPS 6.18元。当前83.5元对应动态PE约13.5x、TTM PE约14.7x（10年分位53%，中间位置）。白电龙头的合理PE区间约12-16x，当前不算贵也不算便宜。
