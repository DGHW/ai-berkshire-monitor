## 二、公司概览与商业模式本质

**一句话：一家"全球塑料卫浴泵隐形冠军 + 国内不锈钢泵第一梯队"的民用水泵制造商，出口为主、极低负债、超高分红的小而美制造企业。**

| 要素 | 内容 |
|---|---|
| 成立/上市 | 前身源于1977年；1993年股份制；2017-07-11深交所中小板上市 |
| 实控人 | 王海波、施宗梅夫妇（合计约32%流通股），专注水泵主业40余年，极少跨界 |
| 主业 | 民用离心泵研发制造，三大产品线：塑料卫浴泵/不锈钢泵/通用泵 |
| 市场地位 | 塑料卫浴泵**全球市占率60-70%**（浴缸泵/SPA泵/泳池泵，全球隐形冠军）；不锈钢泵国内第一梯队；出口近100个国家和地区 |
| 2025年营收/净利 | 17.22亿（+8.17%）/ 4.55亿（+2.83%），扣非4.38亿（+1.82%） |
| 盈利特征 | ROE 19.46%、净利率26.4%、负债率7.58%、经营现金流=净利1.01倍 |
| 分红 | 2025年10派10元，派息率78.9%，股息率约6.2%（按现价），**连续9年高分红**，上市后累计派现26.14亿 |

**商业模式本质拆解（段永平"好的生意"三要素检验）：**

1. **卖什么**：水泵是"把水从A搬到B"的成熟机电产品。凌霄做的是**家用/民用场景的标准化离心泵**——按摩浴缸循环泵、SPA泵、泳池泵、农业灌溉泵、市政增压泵。非高科技、非定制化，是**标准化制造的规模生意**。
2. **卖给谁**：海外为主（境外收入占比约54%，主攻北美、欧洲），对接大型卫浴/泳池设备品牌商与渠道商（ODM/OEM为主）+ 自有"凌霄"品牌出口；国内对接水利基建、农村与市政渠道。
3. **怎么赚钱**：**靠规模+效率+成本控制赚钱**——单一品类全球60-70%份额带来规模经济，四十多年制造工艺积累良率优势，低费用率（无有息负债、财务费用为负、销售费用极低），把净利率做到22-26%。
4. **钱能赚多久**：下游需求是欧美存量房/泳池的**替换与翻新**（相对刚性、非周期性爆发）+ 国内水利/农业政策驱动（有支撑但非高速赛道）。市场总量平稳，**蛋糕不大且增速慢**。

**段永平式判断（商业模式本质）：**
- 这不是"别人抢着要给钱的生意"（无品牌溢价、无强定价权），而是"别人也做不了这么便宜、这么好、这么大的生意"（规模壁垒+制造效率）。
- 赚钱辛苦但赚钱踏实：需求稳定、几乎无负债、利润全部变成现金并分掉。属于**"优秀的制造生意"而非"伟大的品牌生意"**——生意质量约70-75分（段永平标准），赚钱质量极高。

**区域结构（关键）：**
- 境外收入占比约**54%**（2024年数据，主北美/欧洲），境内约46%。
- 2025年**国内销售+17.57%**（卫浴泵国内+25%、不锈钢/通用泵+10%以上），对冲海外关税压力；**海外受贸易政策影响需求承压**，靠拓展亚洲/欧洲等新市场对冲。

## 四、护城河分析（段永平：差异化/定价权/可持续竞争优势）

| 护城河 | 强度 | 分析 |
|---|---|---|
| **规模与成本** | ★★★★ | 全球60-70%市占率的单一品类规模优势，模具/产线/采购摊薄成本，制造效率业内顶级。竞争对手（君禾、泰福、大元）均为中小体量，无法撼动其成本曲线。 |
| **客户与渠道认证壁垒** | ★★★☆ | 欧美卫浴/泳池设备商对供应商有UL/CE等安全认证与多年合作粘性，客户切换成本存在；但OEM客户谈判力强，存在被压价/分散下单风险。 |
| **制造工艺与品质** | ★★★ | 40余年电泵制造积淀，良率与可靠性口碑是"隐形冠军"的底色；但水泵技术门槛不构成专利级壁垒，工艺优势可被时间追赶。 |
| **品牌（"凌霄"驰名商标）** | ★★ | 国内有品牌认知（驰名商标），但海外终端以贴牌为主，**缺乏C端品牌溢价与提价能力**——这是护城河最弱的一环。 |
| **定价权** | ★★ | 2025年对美关税最高145%时客户观望、公司需共同承担部分关税；2026Q1毛利率降至32.32%（同比回落）直接反映**提价受阻、成本上行**。无定价权，靠量不靠价。 |

**综合判断：护城河为"制造效率型"而非"品牌定价型"。**
- 段永平最看重的"差异化/定价权"：凌霄只有**成本与规模差异化**，**没有需求差异化与定价权**。
- 但护城河**真实存在且持久**：规模优势+客户认证+工艺积淀，让竞争对手"造不出这么便宜的好泵"，这足以支撑高ROE与稳定分红。
- **结论：护城河"宽但不高"**——足够挡住国内同行，挡不住宏观政策（关税）与客户议价。

## 五、用户/客户价值分析

**终端用户结构：**
1. **欧美家庭（核心）**：按摩浴缸、SPA、地上/地下泳池的循环过滤泵。需求来自**存量设备维护与替换**——泵是易耗部件（寿命3-8年），替换需求刚性、抗周期。
2. **国内农业/农村用户**：灌溉泵、潜水泵，受益乡村振兴与高标准农田建设。
3. **市政/工业用户**：二次供水、净水设备、水利基建，政策驱动。

**客户价值主张：**
- 对欧美品牌商：**质量可靠+认证齐全+成本最低+交期稳定**，成为其最省心的中国泵供应商（全球60-70%份额即证明）。
- 对终端用户：便宜耐用、售后无忧、替换方便——水泵是"功能件"，用户不关心品牌，只关心"能用几年不坏"。

**用户价值本质（段永平视角）：** 凌霄给客户的不是"惊喜"而是"省心"——这是一个**性价比生意**，客户价值 = 高性价比 + 可靠交付。这决定了生意模式是**量价齐稳、无暴利、但可长期复利**的"老干妈式制造"而非"茅台式品牌"。

## 六、2026Q1增收不增利 + 应收激增36.1%：扩张还是恶化？（商业模式视角甄别）

| 指标 | 2026Q1 | 同比 | 性质判断 |
|---|---|---|---|
| 营业收入 | 4.32亿 | +17.95% | 真实订单扩张（Q1冲量，公司互动平台确认"订单增加"） |
| 归母净利 | 0.98亿 | **-6.13%** | 增收不增利 |
| 扣非净利 | 0.97亿 | -1.03% | 主因成本上升+**信用减值损失大增** |
| 毛利率 | 32.32% | 同比回落 | 原材料/关税成本上行，提价受阻 |
| 经营现金流 | **-0.01亿** | **-102.33%** | 由正转负 |
| 应收账款 | **+36.1%** | — | 增速远超营收（+17.95%），**回款质量恶化信号** |

**商业模式视角解读（公司与互动平台的官方解释）：**
> "经营现金流转负主要是**订单增加、应收账款增加、采购的原材料增加**所致。"

**甄别结论——"扩张性失血"，但质量存疑：**
1. **支持"扩张"的证据**：营收+17.95%为真；公司主动备料（购买商品现金+10%+）；订单增加需要垫付采购款；Q1本就含春节季节性（回款集中在Q4与H2）；2025全年经营现金流4.59亿=净利1.01倍，**现金流底色是好的**。
2. **支持"恶化"的证据**：应收+36.1%**两倍于营收增速**——放账期换订单的迹象；信用减值损失大增直接吞噬利润（净利-6.13%）；毛利率回落显示成本无法转嫁。
3. **结论**：短期（Q1）是**为冲订单/备货的扩张性现金流支出**；但若**H1经营现金流仍不能回正、应收继续超营收增速增长**，则定性转为"增收质量恶化"。**这是本标的当前最重要的跟踪点，须在2026中报（8月底）验证。**

**段永平式提醒**："如果增长的代价是应收款堆积和利润下滑，这种增长不要也罢。"——当前处于是非分界线，**不能因低PE高股息就忽视盈利质量下滑**。

## 七、关税与海外风险（商业模式最大外部变量）

| 事实 | 内容 |
|---|---|
| 2025年关税冲击 | 对美最高145%关税期间客户观望；日内瓦经贸会谈后保留30%关税，订单逐步恢复 |
| 关税承担方式 | **主要由客户支付、反映在单价中，公司亦承担部分** |
| 2026年现状 | 出口总体平稳；**美国需求疲软、销售下降**；欧洲及其他国家增长；客户数量增加、市场空间仍在 |
| 管理层态度 | 对2026年业绩持谨慎态度（营收/净利预计波动），2025年曾定目标"销售利润-15%~+5%" |

**影响评估（商业模式视角）：**
- 公司商业模式**依赖海外（54%境外收入，其中美占出口30-40%）**，关税是"生意模式本身的风险敞口"，非一次性事件。
- 但公司应对弹性尚可：关税主要由客户承担 + 开拓欧洲/亚洲新市场 + 国内市场高增对冲——2025年海外收入承压但总盘仍+8.17%即为佐证。
- **结构性弱点**：无定价权→无法完全转嫁关税；OEM客户可转移采购→存在份额流失风险。这是护城河"不高"的代价。

## 八、段永平"好生意"最终判定

**评分框架（段永平：商业模式=差异化+定价权+可持续；企业文化=诚信+专注；价格=安全边际）：**

| 维度 | 评分 | 说明 |
|---|---|---|
| 商业模式差异化 | ★★☆ | 品类隐形冠军+规模成本，但无品牌/需求差异化 |
| 定价权 | ★★ | 无提价能力，成本上涨只能内部消化+客户分担 |
| 可持续竞争优势 | ★★★☆ | 规模+认证+工艺壁垒持久，但受关税/客户议价侵蚀 |
| 赚钱质量 | ★★★★★ | 净利率22-26%、负债率7%、经营现金流=净利、分红率79%、连续9年分红 |
| 需求稳定性 | ★★★★ | 欧美替换需求刚性+国内政策驱动，抗周期性强 |
| 成长性 | ★★ | 行业总量低速，2025年净利仅+2.83%，增收不增利苗头 |

**综合判定：**
- **是不是"好生意"？** 是"**好但辛苦**"的生意。段永平说"商业模式最重要的是定价权，没有定价权就是辛苦钱"——凌霄赚的是**效率与规模的钱**，不是**品牌与垄断的钱**。生意质量70-75分，赚钱质量95分。
- **值不值得买？** 值得作为**高股息类债券资产**配置：6.2%股息率+12.8倍PE+7%负债率+19.5% ROE，下行有分红保护、上行有估值修复空间。但**不适合期待高成长**——它是一台"印钞机"，不是"变形金刚"。
- **最大的两个瑕疵**：①无定价权（关税、原材料、客户三方挤压盈利）；②增长靠量不靠价（净利增速连续两年落后营收）。
