# 赣能股份(000899) 商业模式深度研究 — 段永平视角

> 视角：段永平（生意本质 / 护城河 / 定价权 / 企业文化 / 本分）
> 报告日期：2026-08-11 ｜ 现价参考：约10.92元 ｜ 市值：106.5亿元 ｜ 总股本9.757亿股（全流通）

## 一、生意本质：这是什么生意？

**江西唯一电力上市平台：区域火电为主（86%）的综合电源公司，本质是"无上游煤资源的纯发电商"。**

- **装机结构（2026Q1末631.05万千瓦，同比+53.12%）**：火电540万千瓦（丰城340万千瓦=2×70万超临界+2×100万超超临界；上高200万千瓦=2×100万超超临界二次再热）+ 水电10万千瓦 + 光伏69万千瓦 + 风电6万千瓦。
- **收入结构**：电力销售占收入约97%（2021年口径96.9%），上高2026Q1转商运后发电量同比+64.87%。
- **2025年业绩**：营收73.98亿(+6.90%)，归母10.07亿(+40.97%)，扣非10.05亿，OCF 21.82亿(+76.32%)。

**段永平会怎么看？** 这是典型的**"产品自己不会说话的生意"**——电是100%同质化商品，无品牌、无客户粘性、无差异化。公司赚的是"**煤价-电价价差 + 容量电价政策**"的钱，是**靠天（煤价）、靠政策（电价管制/容量电价/核准）吃饭**的生意，与茅台、苹果那种"有定价权的生意"完全不在一个量级。

**最关键的一点：这不是煤电一体化，而是纯火电。** 对比陕西能源（自产煤坑口直供、成本锁死），赣能**没有自有煤矿，煤炭100%外购**——长协为主、市场为辅、进口煤补充（来源：2025-07互动平台）。2021年煤价暴涨期火电全行业亏损的历史说明，**纯火电的盈利完全暴露在煤价周期之下**，是最苦的生意模式。

**一句话**：江西火电卖铲人，但铲子（煤）在别人手里，电价在市场和政府手里，自己只剩机组效率和区域地位。

## 二、护城河：有没有？多深？

| 护城河来源 | 具体内容 | 深度评估 |
|---|---|---|
| 区域牌照 | 江西省唯一电力上市平台，实控人江西省国资委，电源项目核准制壁垒 | 真实，但**由政策赋予，可被政策收回** |
| 区域供需 | 江西为电力净输入省，火电利用小时高、需求有保障 | 真实，但属区域Beta非公司能力 |
| 机组效率 | 丰城4台大机组（2×70万+2×100万超超临界）、上高2×100万超超临界二次再热，煤耗指标省内同类领先 | 真实，但**属可复制的资本开支，无独占性** |
| 大股东协同 | 江投集团（37.78%）+国投电力（33.22%）双国资股东，合计71%；陕煤集团煤电联营供煤保障 | 真实，**但关联依赖也是风险** |

**护城河评级：浅。** 没有一条是"越用越深"的。区域地位保护的是"量"（发电小时），不保护"价"；机组效率保护的是"成本"（煤耗），不保护"价格"。**这是典型的"牌照+资本"型护城河，不是"品牌+心智"型**——段永平眼中护城河的价值在于"能让人睡不着觉的定价权"，赣能一条都没有。

## 三、定价权：关键检验（不本分的起点）

**检验结果：无定价权，三个实证：**
1. **电价被市场交易主导**：2026H1市场化交易电量91.34亿千瓦时，**占上网电量92.24%**。电价由江西省电力市场决定，公司是价格的接受者。2024年业绩预告明说"受区域电力市场交易及新能源影响，平均上网电价及火电厂发电量同比有所下降"。
2. **毛利率是火电标准水平**：2026Q1毛利率17.49%，2025全年21.6%(+5.9pct)——无任何溢价成分。对比有定价权的生意（茅台90%+/片仔癀45%+），火电毛利是"成本型"毛利。
3. **盈利被煤价周期撕扯**：2021年煤价暴涨期火电行业普遍亏损、2023年归母仅4.90亿、2024年7.14亿、2025年10.07亿——**归母利润三年翻倍主要靠煤价下行+上高投产+容量电价，不是靠提价能力**。

**补充：容量电价是政策的"恩赐"，不是公司的"能力"。** 江西煤电容量电价2025年100元/千瓦·年，2026年上调至165元/千瓦·年（发改能源规〔2026〕114号）——这部分约可增厚利润（参考公司口径），但**这是全国统一的政策红利，所有火电都有，赣能没有任何超额**，且政策可随电力市场化改革再调整。

**结论：无定价权，是段永平框架里最核心的减分项。**

## 四、成长性：营收+52.4%是"假象"，成长"成色"不足

速评卡最亮眼的"营收增速52.4%"必须拆穿：

1. **口径**：52.44%是**2026Q1单季**同比（2025全年营收增速仅+6.90%）。放大的原因是上高2×100万千瓦机组1号机2025年9月投产、2号机12月投产，2026Q1为商运期——**是装机投产带来的外生增长，非经营内生动能**。
2. **更关键：营收暴增52%，归母利润只增4.69%。** 公司自己解释："子公司少数股东损益影响显著"。上高发电赣能持股51%、陕煤电力持股48%、中南院1%，**上高49%的利润直接计入少数股东损益**。2026Q1新增的利润大头是上高贡献，其中49%被陕煤电力分走。
3. **未来增长同样大比例让渡**：
   - 上高二期2×100万千瓦（2024年4月核准、预计2027年投产）：**陕煤电力51%、赣能49%**——参股非控股，归母只享49%；
   - 赣县抽蓄4×300MW（控股子公司投资、主体施工）：2029年+才投产，重资本低回报期长；
   - 新能源75万千瓦（光伏69万+风电6万）：2025年发电7.83亿千瓦时(+70.22%)，但体量仅占营收个位数，且新能源电价同样市场化下行。

**段永平的判断**：这不是"企业成长"，而是"**上市公司资产负债表为集团煤电联营战略服务**"——江投集团引入陕煤电力建上高，用上市公司51%的资本和折旧，换来陕煤的稳定供煤，利润对半分。**股东（尤其是散户）承担了扩张的资本与周期风险，陕煤电力分享了增长的利润。** 对股东而言，这种"成长"的含金量要大打折扣。

## 五、企业文化与本分：双国资壳里的"不本分"烙印

**股权**：江投集团37.78%（第一大，江西省属国企）+ 国投电力33.22%（第二大，央企国投集团旗下，2026-04仍持32.81%），双国资合计71%，实控人江西省国资委。

### 🔴 减分项（红旗）
1. **丰城"11·24"事故（2016年11月24日）——企业文化最深的历史烙印**：丰电三期冷却塔施工平台坍塌，73人死亡、2人受伤、直接损失1.02亿，国务院认定特别重大生产安全责任事故。**江投集团党委委员、丰电三期建设指挥部总指挥邓勇超因重大责任事故罪+贪污罪+受贿罪+滥用职权罪判18年**；赣能丰城二期计划经营部原经理杨岳辉判11年；共28人获刑。事故暴露"大干一百天"赶工期、安全管理失控。2020年4月才复建、2022年底才投产。**对"本分"而言，这是公司/大股东体系用生命代价写下的一课，段永平会高度警惕这类"重规模轻安全"的基因是否还在。**
2. **控股股东2022年7月高位减持1.94%**：2022年6月28日-7月8日赣能9连板成"妖股"，7月19-21日江投集团火速减持1892.54万股（减持价约15元区间，**显著高于现价10.92元**）。大股东在情绪高位套现，历史上并非"从不减持"。
3. **2026年5月题材炒作后筹码溃散**：5月11日公告1.38亿现金收购东电公司（东津水电站）100%股权——履行2008年重组"同业竞争"承诺（江投承诺2026-12-31前解决，东电是唯一标的，体量小：修河源头中小水电站）。市场以"资产注入+同业竞争解决"为由炒作，5月28日涨停至14.08元、市值137亿，随后回落至10.9元。**股东户数+61.6%筹码分散**——题材高位接盘的是散户。
4. **关联交易依赖加深**：2026年预计关联交易总额38.94亿，其中向**陕赣煤炭（江投与陕煤合资）采购燃煤38亿，较2025年实际24.87亿+52.78%**。上高投产后，公司燃料对集团体系关联方的依赖比例进一步上升，定价"协议价"需持续盯公允性。
5. **0元转让上高39%股权**（2024年3月/8月）：将上高39%未实缴股权0元转让给陕煤电力，换来煤电联营供煤保障。有商业合理性（未实缴部分不承担资本义务），但**实质是主动稀释了未来上高的利润归属**，让渡49%给陕煤。

### 🟢 加分项（本分证据）
1. **分红真金白银**：上市以来累计分红20次、累计27.97亿元；2025年10派5.67元，分红率**54.96%**，按现价股息率约**5.2%**——公用事业该有的本分。
2. **盈利质量真实**：2025年扣非10.05亿 vs 归母10.07亿，**扣非纯度99.8%**；OCF 21.82亿、净现比2.17，现金流强劲，无商誉减值问题。
3. **承诺兑现**：2008年重组7项承诺已履行6项，2026年收购东电履行同业竞争承诺（虽体量小但态度在）。
4. **双国资大股东稳定**：国投电力持股33%+从未减持（央企风格），江投集团2022年后未再减持。

### 企业文化总评：**"国资壳里的半本分"——分红与盈利质量过关，但'重规模'基因（丰城事故）+大股东高位减持前科+上市公司为集团战略让利（上高利润对半分）+题材炒作传统，构成持续减分。** 给"本分"5.5/10。段永平会认为：**这家公司赚的是政策+周期的钱，大股东优先考虑的是集团（煤电联营、同业竞争、关联供煤）而非上市公司股东的利益最大化。**

## 六、数据核验（速评卡口径陷阱）

| 指标 | 速评卡 | 真实值 | 判定 |
|---|---|---|---|
| ROE | 12.3% | **2026Q1加权3.09%×4=12.36%（Q1年化）**；2025年报加权16.50%、2024年报13.03% | ⚠️ **Q1淡季年化，反向低估全年**（工具共识14.40%），正常化中枢12-14% |
| PE-TTM | 10.5 | 10.61（Tushare-daily），市值106.5/TTM归母约10.05亿=10.6x | ✅ 一致 |
| 营收增速 | 52.4% | **52.44%=2026Q1单季**（新机组投产）；**2025全年仅+6.90%** | ⚠️ **Q1单季口径，量增外生，非内生** |
| 净利率 | 11.4% | Q1归母口径9.0%、含少数股东口径约11.4%；**2025年报归母口径13.6%**、Tushare年报14.36% | ⚠️ Q1口径偏低，年报约13.6-14.4% |
| 毛利率 | 17.5% | 17.49%=2026Q1单季；2025全年21.6%(+5.9pct) | ⚠️ Q1口径偏低 |
| 负债率 | 63.3% | 63.33%（2026Q1末） | ✅ 一致 |

**核心陷阱**：速评卡ROE 12.3%是**2026Q1淡季年化的反向低估**（2025年报真值16.50%），但因为上高2026年全年折旧爬坡+少数股东稀释+净资产膨胀，2026全年ROE大概率回落到12-14%区间——**卡面值反而接近2026年真实中枢，属于"数值巧合下的方向正确"**。真正的陷阱在**营收增速52.4%**：这是装机投产的外生量增，且利润大头归少数股东，**用营收增速评估这家公司会被严重误导**。

## 七、三情景估值（段永平视角）

**估值锚**：正常化盈利中枢8-10亿（2023年4.90/2024年7.14/2025年10.07亿，煤价上行期会明显回落）；2026E归母约10.5-12.5亿（上高全年贡献但51%归赣能、容量电价上调、煤价低位）；可比公用事业合理PE 10-12x。现价10.92元/市值106.5亿，对应2025 PE 10.6x、2026E PE约9-10x、PB 1.61x、股息率5.2%。

- **乐观（权重3）**：煤价低位+容量电价165元/千瓦·年+上高满发+2027上高二期兑现（49%），2026E归母12.5亿×12x = 150亿 → **+41%**
- **中性（权重4）**：2026E归母11亿（Q1淡季年化+折旧爬坡），周期中枢9-10亿，给10.5x = 115.5亿 → **+8%**
- **悲观（权重3）**：煤价反弹（2021式周期重演）+电价市场化继续下行+上高49%利润继续被分走，正常化8亿×9x = 72亿 → **-32%**

**加权内在价值 ≈ 111亿元（约11.4元/股），内在涨幅 ≈ +4%**

**段永平结论**：**"规模好看的普通火电，不是能赚大钱的好生意。"** 盈利真实（扣非纯度99.8%、OCF强劲、分红率55%）、区域地位稳固，但——**无定价权（市场化电量92%）+无自有煤矿（纯火电暴露煤价周期）+成长成色不足（营收+52%但归母+4.7%，新增利润49%归陕煤）**。当前10.5x PE+1.6x PB对一家ROE中枢12-14%、成长靠让利换来的公用事业**谈不上便宜**，5.2%股息率是唯一的实在回报。加上控股股东高位减持前科与丰城事故的历史烙印，**这不是段永平愿意"重仓+长持"的生意，只适合以明显低于内在价值的价格收息**。

## 量化结论
- 内在涨幅: **+4%**（三情景加权内在111亿 vs 现市值106.5亿，中枢约11.4元）
- 击球区: **🟡附近** — PE 10.5x不高但PB 1.61x+无定价权+成长成色不足（上高利润49%归陕煤）+控股股东有高位减持前科，安全边际不足，等回调或中报验证2026H1归母兑现
- 目标建仓价: **9.5 元**（对应2026E PE约8.3x、PB约1.40x、股息率6.0%）
- 二次补仓价: **8.3 元**（对应2026E PE约7.2x、PB约1.22x、股息率6.8%）
- 数据核验: **⚠️部分通过** — PE-TTM 10.5✅一致（Tushare 10.61）、负债率63.3%✅；ROE 12.3%=2026Q1加权3.09%×4年化（年报真值2025=16.50%/2024=13.03%，工具共识14.40%，Q1淡季反向低估）；**营收增速52.4%=Q1单季口径（2025全年仅+6.90%）且系上高新机组投产的外生量增、归母仅+4.69%**；净利率11.4%/毛利率17.5%均为Q1口径（年报约13.6%/19-20%）
