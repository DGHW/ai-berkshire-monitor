# 恒瑞医药(600276.SH) 行业竞争格局研究 —— 芒格视角

> 分析日期：2026-08-10 | 现价：54.18元（2026-08-10收盘）| 总市值：3584.36亿元（A股口径）| PE-TTM：44.29
> 本报告聚焦"行业格局是否友好"——芒格说：买股票就是买生意，而好生意的先决条件是"所处的行业有结构性的好日子"。

---

## 〇、一句话结论

**恒瑞所处的是"政策顶格扶持 + 出海红利兑现 + 增速全球领先"的成长型行业，但这是一个"赢家通吃 + 靶点内卷 + 医保单一支付方压价"的行业——结构性友好（规模、政策、壁垒）与战术性残酷（内卷、降价）并存。恒瑞凭"管线最宽、BD兑现最强、资产负债表最干净"三重护城河，是中国创新药行业格局中最友好的位置，但代价是44倍PE的估值已把部分美好预期计入价格。**

## 一、行业规模与增长：中国创新药正处"拐点兑现期"

### 1.1 市场规模：从4000亿到未来数万亿的爬坡

| 指标 | 数据 | 来源/截止 |
|---|---|---|
| 2024年中国药品市场总销售额 | 1.86万亿元 | 2026-05公开数据 |
| 其中创新药市场规模 | 突破4000亿元，占比约21.5% | 同上 |
| 2021年创新药占比 | 约11%（三年近乎翻倍） | 同上 |
| 美国创新药占药品市场比 | 近80% | 同上 |
| 日本/德国 | 超50% | 同上 |
| 2026年政府工作报告定位 | **首次将生物医药列为"新兴支柱产业"**，对标集成电路 | 2026-03 |

**解读**：中国创新药占药品市场比重仅21.5%，距日德的50%+、美国的80%有2-4倍提升空间。行业"天花板"极高，且政策从"压价"转向"扶持"——这是行业格局最重要的边际变化。芒格视角：**行业坡道足够长、雪足够厚**。

### 1.2 医保谈判：从"灵魂砍价"到"对真创新表达真支持"

| 谈判批次 | 关键数据 |
|---|---|
| 2024年国谈 | 新增91种，平均降价63%；创新药谈判成功率90% |
| 2025年国谈 | 123个到期品种续约；**148种简易续约仅15种降价（平均降幅8.4%）**；30种重谈续约平均降幅13.8% |
| 2026年新版目录 | 新增114种药品平均降价超60%（2026-01-01落地），近90%为近5年新药，部分获批仅15天即入保 |
| 2026年制度红利 | ①预申报机制，创新药医保准入周期**缩短约1年**；②首版商保创新药目录19种（5款CAR-T破冰）；③纳入2025商保目录药品可突破"5年内上市"限制 |

**解读**：医保谈判对**存量成熟品种**仍残酷（首谈平均降价60%+），但对**续约品种**已大幅温和（2025年续约平均降幅仅8-14%）。叠加商保目录、预申报机制，"降价周期"对创新药的边际伤害在衰减。芒格视角：**"看不见的手"被政策修正——支付方在给真创新留活路。**

**解读**：中国创新药出海从"偶发大单"变成"常态叙事"，中国已成为全球BD交易的"卖方中心"。芒格视角：**这证明中国创新药资产已被全球最聪明的大药企真金白银背书——这不是泡沫，是价值发现。**

### 2.2 三条主赛道竞争态势

#### (1) PD-1：已从"明星产品"退化为"基石资产"（红海确认）

- **卡瑞利珠单抗（恒瑞）**：2019年获批，国内获批适应症/瘤种覆盖长期领先，但收入占比已从巅峰期**20%降至10%左右**；全球市场2025年约6.75亿美元，2032年预计14.31亿美元（CAGR仅6.7%）
- **替雷利珠单抗（百济）**：2024年销售43.14亿元，2025H1 23.45亿元，国产PD-1销售额第一，但增速已回落至个位数
- **信迪利单抗（信达）、特瑞普利单抗（君实）**：进入常态化竞争

**芒格判断**：PD-1是典型的"同质化内卷"样本——医保压价+适应症拥挤+玩家众多=利润稀薄。**恒瑞的智慧在于没有把公司押在PD-1上**，其收入占比已主动稀释至10%，转型成功。

#### (2) ADC：恒瑞最锋利的第二曲线

| 管线 | 靶点 | 状态 |
|---|---|---|
| SHR-A1811（瑞康曲妥珠单抗/艾维达） | HER2 | **已获批3个适应症**（肺癌、乳腺癌、2026-08-06结直肠癌=国内首个结直肠癌ADC） |
| SHR-A1921 | TROP-2 | III期（预计2027-2029获批） |
| SHR-A1904 | Claudin 18.2 | III期（胃癌/实体瘤） |
| SHR-A2009 | HER3 | 临床 |
| SHR-A2102 | Nectin-4 | III期（尿路上皮癌） |
| SHR-A1912 | CD79b | 血液瘤 |
| SHR-4849 | DLL3 | 已授权IDEAYA（首付7500万美元） |

**解读**：恒瑞用"同一linker+payload复制粘贴"的平台化打法批量造ADC，管线深度为国内唯一。对标DS-8201（第一三共）证明了ADC能再造千亿收入。芒格视角：**平台化管线 = 制造业思维做药 = 可复制的竞争优势。**

#### (3) GLP-1：全球最肥赛道，中国价格战已打响

- 全球：2026H1诺和诺德GLP-1收入173.46亿美元（占64%）、礼来276.93亿美元（占65%），**两家半年合计超450亿美元**——人类医药商业史上前所未有
- 中国：礼来替尔泊肽、诺和诺德司美格鲁肽2025年底率先降价风暴（替尔泊肽一度降至两折）
- 国产竞争梯队：闻泰医药VCT220（首个申报上市的口服小分子，2026-07-20获受理）、**恒瑞HRS-7535（口服小分子III期临床已达标）**、华东医药HDM1002（III期入组完成）、信达玛仕度肽（2025年7月获批，2026年预计销售18亿，2027年看40-50亿）
- **恒瑞GLP-1的聪明打法**：不自己硬刚国内红海，而是2024年5月把GLP-1组合（HRS-7535/9531/4729）全球权益（除大中华区）授权Kailera（原Hercules），1.1亿美元首付+最高60亿美元+19.9%股权；**2026年4月Kailera纳斯达克IPO（发行价16美元，首日冲26美元），恒瑞摊薄后约9.8%股权价值约3亿美元**——用NewCo模式把海外风险转嫁、把海外期权留在表外

**芒格判断**：GLP-1是"人类历史上最肥的品类"但也是"全球最强双巨头碾压的修罗场"。国产玩家在国内靠医保+渠道打价格战，**恒瑞的"授权+股权"模式是这场红海中风险收益比最优的选项**。

#### (4) 双抗：差异化新赛道

- SHR-1701（PD-L1/TGF-βRII双抗，瑞拉芙普α）：**全球首个该靶点获批**，2025年胃癌一线获批，宫颈癌/肺癌III期数据2026年读出
- 康方卡度尼利（PD-1/CTLA-4双抗）2023年销售13.58亿验证了双抗的商业化可行性

## 三、核心竞争者威胁评估（芒格式"五力"扫描）

### 3.1 威胁一：创新药"靶点内卷"——最大的同质化风险

- PD-1红海已验证；GLP-1国内价格战已开打；ADC热门靶点（HER2/TROP-2/CLDN18.2）国内玩家拥挤
- **数据**：中国License-out约58%全球占比的另一面，是中国药企扎堆同类靶点互相"内耗"
- **对恒瑞**：靠管线宽度（25款1类创新药获批+百余个分子）分散风险，单一靶点失败不伤基本面

### 3.2 威胁二：医保降价——单一大支付方的定价权

- 首谈平均降价60%+是常态；但续约降幅已收窄至8-14%
- 对恒瑞：创新药销售58%靠院内医保放量，"以价换量"是双刃剑——量增通常能覆盖价降（2025创新药收入+26%证明）

### 3.3 威胁三：Biotech"用命换速度"的追赶

- 信达（玛仕度肽超预期+与礼来第七次合作）、荣昌（RC148授权艾伯维6.5亿首付/49.5亿里程碑）、康方（双抗）
- Biotech轻资产、单点突破快，但**普遍缺乏恒瑞式的：①全国公立医院学术推广体系（院内刚需渠道）②62%创新药收入占比的自我造血能力 ③负债率10%的财务安全垫**

### 3.4 威胁四：BD"退货率"——纸面金额的注水风险

- **关键风险数据**：2020年达成的62起License-out交易中25起已明确终止；2021-2022年启动交易退单率约20%
- **对恒瑞**：其BD大单（GSK 5亿首付、MSD 2亿首付、BMS 6亿首付）**首付款真实到账、里程碑多为"纸面期权"**。芒格提醒：**不能把152亿美元当已经到手的收入，要看首付+里程碑的实际兑现率**

### 3.5 威胁五：政策/地缘（FDA、COINS法案）

- 恒瑞卡瑞利珠"双艾组合"赴FDA上市遭两封CRL（2024-05、2025-03，均为生产场地问题，已整改完毕）——**创新药出海美国仍有合规门槛**
- 美国COINS法案等生物安全相关立法为中国创新药出海增加不确定性

## 四、行业趋势：四大结构性变化（芒格"十年后看今天"）

1. **出海从"授权"到"自主商业化"**：恒瑞2025年5笔BD、2026年BMS 152亿美元大单（13款早期项目，双向资产+联合开发），中国药企正从"卖分子"升级为"全球共同研发"。市场对BD的估值开始从"只认首付"转向"认里程碑"（重阳2026-08观点）
2. **ADC/GLP-1/双抗新赛道爆发**：恒瑞ADC平台进入收获期（SHR-A1811三适应症获批）、GLP-1授权+股权双赢、SHR-1701全球首创
3. **研发投入军备竞赛**：恒瑞2025年研发87.24亿（费用化69.61亿，占营收22%）；全球15处研发中心，3000+临床团队
4. **仿制药战略收缩**：恒瑞仿制药收入因集采持续下滑，2026Q1创新药占比61.7%——"仿制药时代"正式结束，纯创新定价逻辑确立

## 五、产业链分析：价值分配是否对恒瑞友好？

```
上游（CRO/原料/试剂）
     ↓ 采购
创新药企（研发+生产+销售） ←恒瑞在此环节，掌握了最全价值
     ↓ 学术推广+渠道
医院/药房（处方终端）
     ↓ 报销
医保（单一大买方，定价权强）
```

### 5.1 价值分配判断

| 环节 | 议价力 | 说明 |
|---|---|---|
| 上游CRO/原料药 | 弱→中 | 恒瑞自建研发平台，对CRO依赖低；原料自给率高 |
| **创新药企（恒瑞）** | **强** | 专利壁垒+品牌+院内渠道，毛利率86.6%证明掌握了大部分价值 |
| 医院/药房 | 中 | 院内药品零加成政策下医院无加价动力，创新药靠学术推广驱动处方 |
| 医保 | **极强** | 单一支付方，谈判定价权强大——这是产业链上恒瑞唯一"受制于人"的环节 |

### 5.2 研发投入对比（护城河厚度）

| 公司 | 2025研发投入 | 占营收比 |
|---|---|---|
| **恒瑞医药** | **87.24亿**（费用化69.61亿） | ~27%（2026Q1为27.32%） |
| 百济神州 | 全球临床团队3000+，研发投入强度极高 | 40.6%（含资本化口径155亿） |

**解读**：恒瑞研发投入绝对额国内第一梯队，且费用化比例高（利润真实性高）。百济研发强度更大但处于持续亏损转盈阶段。**恒瑞是"已经用利润养研发"的成熟龙头，而非"用融资烧研发"的Biotech。**

## 六、芒格视角判定：这是不是"一门好生意"？

### 6.1 芒格式"好生意"检验清单

| 芒格问题 | 恒瑞的回答 | 评级 |
|---|---|---|
| 行业有长期结构性需求吗？ | 肿瘤/慢病/代谢，全球老龄化+创新药渗透率21.5%→50%+空间 | ✅ 优秀 |
| 有持久的护城河吗？ | 专利壁垒+25款创新药矩阵+全国公立医院学术推广渠道+品牌（50年） | ✅ 优秀 |
| 资本回报高吗？ | 毛利率86.6%、净利率28%、ROE 14.6%（2026Q1年化）、负债率仅10% | ✅ 优秀 |
| 行业格局友好还是内卷？ | **半友好**——政策扶持+出海红利 vs PD-1/GLP-1红海+医保压价 | ⚠️ 中等偏上 |
| 需要持续巨额资本开支吗？ | 研发投入大（69.61亿/年）但已能由经营现金流覆盖（OCF 112亿） | ⚠️ 可承受 |
| 管理层值得信赖吗？ | 孙飘扬掌舵，A+H上市、10-20亿回购（已回购1375万股）、零质押（质押比例0.9%） | ✅ 优秀 |
| 定价合理吗？ | PE-TTM 44.29（10年3.5%分位），2026E动态37.9倍 | ⚠️ 不便宜但历史低位 |

### 6.2 芒格的三个核心判断

1. **"恒瑞不是简单的好公司，而是好公司+好行业中的顶级位置"**。芒格会说：中国创新药是"一个注定长大的行业"，而恒瑞是这个行业里"拥有最长产品管线、最强自我造血、最干净资产负债表"的公司——这是**在赢家通吃的行业里站在赢家一侧**。

2. **"行业的内卷不伤害真正的领先者"**。PD-1红海、GLP-1价格战——内卷挤压的是同质化跟随者，而恒瑞靠管线宽度（62%创新药占比）+平台化ADC+授权出海（把红海资产卖成美元期权）实现了"反内卷"。

3. **"但好生意不等于好价格"**。芒格最著名的原则是"以合理价格买入伟大公司"，而44倍PE-TTM（对+13%营收增速）并非"便宜"。不过两个细节值得注意：①44倍处于恒瑞10年历史3.5%-5.6%分位（历史中枢52-69倍），**是"相对自己历史极便宜"**；②2026E动态PE仅37.9倍，对净利+22%增速PEG≈1.7——**绝对不便宜，相对自己便宜**。

### 7.2 芒格式内在价值测算（给2026E净利95亿）
