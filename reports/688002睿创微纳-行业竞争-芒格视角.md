## 四、核心竞争者逐个威胁评估：谁在抢谁的份额

### 4.1 高德红外 —— 唯一全面竞争者（威胁度：🔴高，但错位竞争）

| 维度 | 高德红外 | 威胁判断 |
|---|---|---|
| 技术路线 | **制冷碲镉汞+二类超晶格+非制冷**三条批产线全球唯一 | 制冷高端领域睿创无法正面对抗 |
| 军工地位 | 国内唯一民企武器系统总体资质；2026年2月签**18.51亿**完整装备系统独家供货大单（占2024营收69%） | 军工整机市场睿创（非制冷配套率仅25%）不占主导 |
| 业绩 | 2025年扭亏（净利7-9亿，+689%~857%）；2026H1预告**12.7-14.5亿**（+602%~701%） | 增速比睿创更猛，弹性更大 |
| 车载 | 获比亚迪、长安、理想、广汽定点；理想L系列、比亚迪高端越野2026H2全系标配；月产能12万套 | **正在抢车载份额**，单价2000-4000元/套更下沉 |

**芒格点评**：高德不是"竞争者"，是**互补的错位对手**——高德占制冷+武器总体，睿创占非制冷+民用规模化。真正的争夺在**车载**：高德已切入8-15万中端车型，价格带更低，睿创占据60%前装份额的先发优势，但面临高德车规认证+量产追赶。两者不会互相摧毁，但会互相压制定价空间。

### 4.2 大立科技 —— 威胁有限（威胁度：🟡中低）

- 2026H1预计亏损9000万-1.15亿元，在手订单仅约2.8亿；2025年刚结束连续亏损。
- 电力巡检传统优势，氧化钒+非晶硅双路线，但像元技术止步12-17μm（无8μm产品）。
- **结论**：研发投入攻坚期+规模劣势，短期无夺单能力，是"退出竞争"而非"参与竞争"。

### 4.3 海康微影（海康威视旗下）—— 渠道型对手（威胁度：🟡中）

- 全球收入份额17%第三，靠海康威视安防渠道放量，主打**成本战+渠道战**。
- **关键**：海康微影红外芯片外购，部分来自睿创——**竞合关系**，睿创是"卖水人"。
- 威胁集中在安防整机中低端，不直接侵蚀睿创的芯片/探测器核心利润区。
- **结论**：海康是整机端价格杀手，但对芯片端依赖暴露其上游短板，无法撼动睿创芯片龙头地位。

### 4.4 Teledyne FLIR / Lynred —— 高端收缩（威胁度：🟡中低）

- FLIR 2026年已推8μm Boson SX8（1280×1024），技术上未掉队，但**战略收缩**至高端国防/航天，放弃中低端民品。
- Lynred 2024年份额仅10%且出货下滑。
- **结论**：海外对手在中国市场民品份额极低，且受禁运政策保护了国产替代空间，威胁主要在未来高端军品+海外车载（Mobileye、安波福）。

### 4.5 份额争夺结论表

| 战场 | 谁是主敌 | 睿创处境 |
|---|---|---|
| 非制冷民用芯片 | 高德、海康微影（外购） | **绝对主导**，市占率>50% |
| 军工（非制冷配套） | 高德（制冷为主） | 配套率25%，非主战场 |
| 车载前装 | 高德（价格下沉） | **先发60%份额**，但被追 |
| 户外/消费 | 天眼、飞础科等 | 睿创为上游芯片，护城河在芯片 |
| 海外 | FLIR（高端） | 睿创出口+62%，在抢民用国际份额 |

## 五、技术路线与国产化：领先国际1-2代

### 5.1 两条技术路线对比

| 维度 | 非制冷（微测辐射热计） | 制冷（光子探测器） |
|---|---|---|
| 材料 | 氧化钒VOx（市占~75%）/ 非晶硅a-Si | 碲镉汞HgCdTe / 二类超晶格 |
| 优点 | 低成本、低功耗、长寿命、小型化 | 灵敏度高、探测距离远、高端军品必需 |
| 缺点 | 灵敏度、远距离探测弱 | 价格高、需制冷、系统复杂 |
| 应用 | 民用为主+部分军品（单兵/枪瞄） | 高端军用（制导/侦察）、航天 |

- 氧化钒TCR约2-3%/K，主流；非晶硅成本低但1/f噪声高（NETD差约2个数量级），17μm以下是氧化钒的天下。
- **睿创路线**：早期非晶硅→后期切氧化钒，走通两条路线，规模化能力最强。

### 5.2 像元尺寸军备竞赛：睿创碾压式领先

| 像元尺寸 | 睿创微纳 | 国内同行 | 国际对手 |
|---|---|---|---|
| 12μm | 已量产 | 高德、大立量产 | 主流 |
| 10μm | 已量产 | 高德量产 | 部分 |
| **8μm** | **全球首款量产（2021）** | 高德追赶中 | FLIR 2026年才推8μm SX8 |
| **6μm** | **全球首款发布（2024）** | 无 | 无 |

**芒格点评**：像元越小=芯片越小、功耗越低、成本越低，这是民用放量的命门。睿创在8μm领先1-2年、6μm独步全球，**技术代差=毛利率屏障**（毛利率52.51%+，2026Q1净利率提升至17.84%）。

### 5.3 国产化率

| 环节 | 国产化率 | 备注 |
|---|---|---|
| 非制冷探测器 | **超80%**（成本下降60%） | 已完全自主可控 |
| 军用制冷探测器 | 2023年35% → **2025年50%** | 高德（良率92%）牵头替代 |
| 高端材料（碲镉汞等） | 仍依赖进口 | 制冷高端短板仍在 |

**结论**：非制冷国产化已完成、实现反超；制冷高端仍有差距但正在加速替代。睿创卡位国产化最彻底的民用赛道。

## 六、车载红外：第二增长曲线的引爆点

### 6.1 睿创车载业务进展（2026年数据）

| 指标 | 数据 |
|---|---|
| 定点车企 | 比亚迪、吉利、长城、广汽、滴滴自动驾驶等**15+家**，覆盖20+款车型 |
| 代表车型 | 比亚迪仰望U8、方程豹豹8、长城坦克700、吉利极氪9X |
| 里程碑 | **2026年3月全球首款红外AEB量产落地**（极氪9X），红外从"看得见"升级为"主动安全决策" |
| 车规认证 | 国内唯一AEC-Q100车规双认证（MEMS芯片+ISP芯片） |
| 前装市占率 | **约60%**，绝对主导 |
| 产能 | 8英寸产线车载芯片年产能百万颗，支撑百万台级装车 |
| 海外对手 | Mobileye（与FLIR合作热成像）、安波福Aptiv（ADAS Tier1）尚未在国内形成规模 |

### 6.2 单车价值量与市场空间

| 阶段 | 单车价值量 | 渗透率 |
|---|---|---|
| 当前（夜视） | 3000-5000元/套 | 不足5% |
| 中期（红外AEB+雷达融合） | 5000-8000元/套 | 2028-2029年达8%+ |
| 远期（规模成本） | 降至2000元内 | 2030年15%+，市场破百亿 |

- Yole预测：全球车载红外2028年约**30亿美元**，若睿创取20-30%份额=40-60亿人民币增量收入，"再造一个睿创"。
- **竞争动向**：高德以2000-4000元/套价格带切入8-15万中端车型（2026H2全系标配），正在打价格战；睿创以先发份额+车规认证+全栈方案应对。

### 6.3 车载结论

**车载是睿创2026-2030最确定的第二曲线**，政策（夜间被动安全法规）+安全刚需（红外AEB）+成本下降三驱动。主要风险是**高德价格战压缩单车价值**，以及海外Mobileye/安波福渗透，但车规认证+量产验证需要3-5年，睿创领先2-3年。

## 九、风险提示（行业层面）

1. **价格战风险**：高德车载价格下沉（2000-4000元/套）、海康渠道成本战，民用毛利率存在被压缩压力。
2. **估值透支风险**：8/7单日+9.34%涨停，一周+25.4%，短期情绪过热，机构目标价均值已被超越。
3. **海外高端反制**：FLIR/Lynred收缩是战略性的，若重返中低端或海外车企导入Mobileye/安波福，车载竞争加剧。
4. **军工订单波动**：军工订单脉冲式交付，季度间波动大（高德18.51亿大单是特例，不具普适性）。
5. **技术路线风险**：制冷型军品、光子探测器等高端领域睿创未覆盖，若军品高端化加速，睿创受益有限。
