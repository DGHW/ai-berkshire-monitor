# 我武生物(300357.SZ) 行业竞争格局与竞争态势——芒格视角

> 分析框架：查理·芒格"行业竞争格局"视角——这门生意是否具有结构性竞争优势？护城河有多宽多深？长期确定性如何？价格是否合适？
> 现价：**约24.9元**（市值130.3亿 / 总股本5.2358亿股，2026-08-10）

---

## 一、行业规模与增长：脱敏治疗（AIT）的"长坡"与"低速"

### 1.1 中国过敏性鼻炎市场规模

| 指标 | 数据 | 来源/截止 |
|---|---|---|
| 中国过敏性鼻炎患者 | 超2.5亿（另有口径：患病率>17%、患者近2亿；沙利文2025年过敏性鼻炎2.479亿） | 行业报告/金赛-ALK合作新闻稿（2025-09） |
| 儿童发病率 | 约40% | 2025-10行业文章 |
| 接受脱敏治疗者 | 不足100万人 | 2025-10行业文章 |
| 脱敏治疗渗透率 | **不足4%** | 金赛药业合作公告口径 |
| 过敏性鼻炎用药市场规模 | 约449亿元（2025年，+12.3%） | 博研咨询（2026-05） |
| AIT（脱敏）市场规模 | 极小亚赛道：我武10.6亿营收仅占AR药物市场约2.4% | 本次测算 |

**判断：** 这是一条"患者基数巨大、渗透率极低"的长坡——2.5亿患者对4%不到的渗透率，理论上空间百倍。**但注意：这是"行业的坡"，不是"公司的坡"。** 脱敏治疗渗透率常年趴在4%以下，三大结构性障碍（基层诊疗认知不足、3-5年长疗程导致依从性差、变应原提纯技术壁垒高）十年未解，说明这是一条**爬坡极慢的长坡**——行业的真实增速仅为个位数至低双位数（2024年行业增速降至8%）。

### 1.2 过敏原的地域分布特征

- 尘螨过敏：**南方为主**，人群基数最大（我武主场）。
- 黄花蒿/艾蒿花粉过敏：**北方高发、南方低**，季节性（秋季花粉季）。
- 区域性决定：公司"粉尘螨+黄花蒿"双产品互补布局南方/北方市场，但黄花蒿本质是区域性利基，天花板远低于尘螨。

## 二、竞争格局：国内脱敏市场的"一超多强"

### 2.1 国内仅4款AIT药物获批（均为第一代天然提取物制剂）

| 产品 | 厂商 | 剂型 | 过敏原 | 中国状态 |
|---|---|---|---|---|
| **粉尘螨滴剂（畅迪）** | 我武生物 | **舌下含服（滴剂）** | 粉尘螨 | 已上市，**国内同类唯一获批的舌下脱敏制剂** |
| **黄花蒿花粉变应原舌下滴剂（畅皓）** | 我武生物 | 舌下含服（滴剂） | 黄花蒿/艾蒿 | 已上市（2021），**国内独家** |
| 安脱达（Alutard） | ALK-Abello（丹麦，全球最大脱敏药企） | 皮下注射 | 屋尘螨 | 已上市，**进口** |
| 阿罗格 | Allergopharma（默克旗下） | 皮下注射 | 螨变应原 | 已上市，**进口** |

### 2.2 我武生物的市占率地位

| 细分 | 市占率 | 说明 |
|---|---|---|
| 舌下脱敏治疗 | **>80%** | 国内独家生产两种获批舌下制剂 |
| 粉尘螨脱敏细分 | **>90%** | 远超竞品 |
| 黄花蒿花粉脱敏 | **100%** | 国内唯一获批产品 |
| 粉尘螨滴剂占公司营收 | **93.18%**（2025年9.90亿） | 单品极度依赖 |

**格局判断：** "一超多强"——我武垄断舌下赛道，进口厂商（ALK、默克）盘踞皮下注射赛道。**但垄断的来源是"注册管制"而非"技术代差"**：我武的粉尘螨滴剂是第一代天然提取物制剂，与ALK、默克的进口产品同为第一代技术，**并无技术领先**，真正的护城河是"国内唯一获批的舌下剂型"这一行政性牌照+专利期（粉尘螨滴剂专利保护至2032年）。

## 三、核心竞争者威胁：ACARIZAX"敲门"——垄断正在被攻破

### 3.1 最大威胁：ALK尘螨舌下片 ACARIZAX（全球金标准舌下剂型）

| 要素 | 详情 |
|---|---|
| 产品 | ACARIZAX（尘螨变应原舌下片，快速崩解片剂） |
| 地位 | **全球首款**获批用于过敏性哮喘+过敏性鼻炎的舌下免疫治疗片剂；已在欧美日澳等多国上市 |
| 中国进展 | 2022.03 豁免中国注册临床试验、按境外数据申报上市 → 2023.02 CDE受理（适应症：12-65岁持续性中重度尘螨过敏性鼻炎） → 2023.01 落地海南乐城先行区 |
| **关键转折** | **2025.09 金赛药业（长春高新）与ALK达成15亿元战略合作**，2025.10.01起接手安脱达等产品中国销售，并负责ACARIZAX中国临床开发与上市进程 |
| 冲击逻辑 | 与我武粉尘螨滴剂**同为尘螨过敏+舌下给药**，但剂型为片剂（一片/日更便捷）、国际多中心循证数据完备、背后有金赛（生长激素渠道之王）的儿科/呼吸销售网络 |

**这是本次研究最重要的发现：** 我武"国内唯一舌下脱敏"的垄断地位并非永续。ACARIZAX已于2023年获CDE受理，若在未来1-3年内获批上市，将**直接在同一赛道正面竞争**，我武"舌下唯一"的行政护城河即告失守。金赛15亿重金入局+全球最大脱敏药企背书，意味着这不是"会不会来"的问题，而是"何时来、怎么打"的问题。

### 3.2 其他威胁力量

- **优锐医药 × Stallergenes Greer（法国）**：就尘螨舌下脱敏片 Actair 在中国达成独家研发与商业化合作——又一家国际大厂押注舌下剂型。
- **诺华等外资**：公司投资者互动已公开面对"诺华、ALK等外资药企竞争"的提问。
- **我武的防守管线**：屋尘螨膜剂（粉尘螨滴剂升级剂型）2026.04 II期首例入组，**距上市至少3-5年**——远水难救近火。

### 3.3 共同做大 vs 分走份额

辩证地看，金赛/ALK入场会共同教育市场、做大AIT蛋糕，短期对我武未必纯利空。但结构性事实是：**一旦ACARIZAX获批，我武从"100%舌下垄断"变成"双雄竞争"，且对手的剂型（片剂）与渠道（金赛）均有优势。** 芒格会问：你愿意用"垄断溢价"买入一个即将失去垄断的生意吗？

## 四、护城河剖析：垄断的"宽度"与"深度"

### 4.1 护城河的"宽度"——宽（短期）

- 行政准入壁垒：国内唯一获批的标准化舌下脱敏制剂（粉尘螨滴剂），产品注册+变应原提纯工艺构成进入门槛。
- 专利保护至2032年：粉尘螨滴剂核心专利存续期约6年。
- 95%毛利率 + 46%净利率 + 3.7%负债率：定价权与财务质量顶级，几乎零杠杆。

### 4.2 护城河的"深度"——浅（长期）

- **无技术代差**：我武与ALK/默克同属第一代天然提取物制剂，ALK甚至已升级出片剂剂型（ACARIZAX）并在全球验证。我武的"技术护城河"实为"注册滞后红利"。
- **无网络效应/转换成本**：脱敏药不构成病患粘性的强锁定，疗效+价格+医生偏好决定处方流向。
- **无规模经济壁垒**：市场规模太小（我武仅10.6亿营收），不足以支撑压倒性成本优势。
- **单品依赖93%**：所有壁垒集中于粉尘螨滴剂一个品种，风险高度集中。

**芒格式比喻：** 这是一座"围墙很高、但地基很浅"的庄园——墙是政府注册审批砌的（有效期内固若金汤），但墙外已有翻墙工具（ACARIZAX国际数据+金赛商业化），且围墙2032年后自然坍塌（专利到期）。

## 五、长期确定性评估：双刃剑的渗透率故事

### 5.1 增长的"天花板"与"地速"

- **长坡成立**：渗透率<4%，即使每年提升0.1pp，绝对增量也可观。
- **爬坡极慢是现实**：行业增速8%（2024），我武粉尘螨滴剂增速已从2025年+11.80%降至**2026Q1 +7.81%**——核心单品进入低双位数/个位数时代。
- **第二曲线体量太小**：黄花蒿滴剂2025年收入仅5434.76万（+101.21%，翻倍但绝对量微小）；2026Q1非花粉季1645万（+76.89%）。皮肤点刺液2025年仅1354.69万。**"第二曲线"在财报上仍只是"第二涟漪"。**

### 5.2 财务质量的两点警示

- **2026Q1归母+60.38% vs 扣非+21.36%，背离32pp**：Q1归母1.19亿中含约2966万非经常性损益（增值税优惠等），**年化ROE 17.8%含此水分**。扣非口径下公司增速为+21%，仍稳健但远非"惊艳"。
- **2026Q1 OCF 5504.91万，同比-35.90%**，净现比仅0.46——现金流先行指标走弱，2025全年净现比1.11的优异状态未能在Q1延续。

### 5.3 政策风险

- 脱敏药物目前**未被纳入集采**，但ACARIZAX若获批，进口创新药大概率进入医保谈判或集采通道，**我武自费为主的定价体系（粉尘螨滴剂年治疗费用数千元）将面临价格压力**。
- 公司分红率仅约20%（10派1.5元），现金大量留存但资本开支需求低——资本配置效率一般。

## 六、芒格视角判定：这是一门"好生意"吗？

### 6.1 好的一面（芒格会点头）

- 95%毛利率、46%净利率、3.7%负债率——**财务上确实是一台"印钞机"**，且是极简生意（单一产品、单一赛道），符合芒格"简单生意"偏好。
- 行政性垄断在有效期内极为稳固：过去十年粉尘螨滴剂是唯一获批的舌下脱敏药。
- 渗透率<4%的长坡，理论空间巨大。

### 6.2 坏的一面（芒格会皱眉）

1. **护城河是"租约"而非"产权"**：垄断由注册审批+专利（至2032）构成，**有明确到期日**。芒格厌恶"租约型"垄断——他买的是可口可乐（品牌永续）、Costco（模式永续），不是"独占期有限的牌照"。
2. **敌人已在门外**：ACARIZAX获CDE受理已三年，金赛15亿+ALK全球最大脱敏药企的组合是"最强的攻城队"。舌下"唯一"地位被打破只是时间问题。
3. **无技术代差=无差异化防御**：同为第一代提取物，一旦进口舌下片获批，医生和患者没有非买我武不可的理由。
4. **增速降档**：核心单品+7.8%，第二曲线绝对量微小——市场为"渗透率故事"支付30倍PE，但现实增速只是"温和的现金牛"。
5. **盈利质量需打折**：2026Q1归母+60%靠非经常、OCF -35.9%，净现比0.46——"印钞机"短期有点卡顿。

### 6.3 芒格最终判定

> **"我武生物是一个'好而贵、且贵得缺依据'的垄断租约。95%毛利率说明这是一门好生意，但'唯一舌下脱敏'的牌匾是政府发给的、有期限的，而全球最强的对手已经在敲门。以30倍PE买入一家核心单品增速降到个位数、垄断即将被攻破的公司，是为'渗透率故事'支付了'永续垄断'的价格。好公司，坏价格，且垄断的确定性正在衰减。"**

## 七、量化估值与结论

### 7.1 估值测算（现价约24.9元，市值130.3亿）

| 指标 | 数值 | 说明 |
|---|---|---|
| 总股本 | 5.2358亿股 | 2025年报分红基数 |
| 2025归母净利 | 3.81亿（+19.86%） | 年报 |
| 2025扣非净利 | 约3.5亿（估） | 归母含非经常损益 |
| 2026E扣非净利 | 约4.1-4.3亿 | 按扣非+20% |
| PE-TTM（归母） | **30.6x**（Tushare 30.75一致） | 含2026Q1约2966万非经常收益 |
| **PE-TTM（扣非）** | **约35.7x** | 真实经营口径更高 |
| 2026E扣非PE | 约31x | 现价对应 |
| 股息率 | 约0.6% | 10派1.5元/24.9元，分红率约20% |

### 7.2 合理价值锚定

- **增速锚**：未来3年营收CAGR 12-15%（粉尘螨7-10% + 黄花蒿高增但基数小），扣非净利增速15-20% → 合理PE区间20-28x。
- **三情景（2026E扣非~4.2亿）**：
  - 乐观28x（ACARIZAX延后、渗透率提速）：117.6亿 ≈ 22.5元
  - 中性23x（ACARIZAX 2-3年内获批，份额温和分流）：96.6亿 ≈ 18.4元
  - 悲观17x（ACARIZAX 2027年获批+医保谈判降价）：71.4亿 ≈ 13.6元
- **加权（30/40/30）公允中枢：约18.5元** → 较现价24.9元**高估约-26%**。
- 敏感性：即便不苛刻（给中性25x），公允值约105亿/20.1元，仍低于现价约19%。

### 7.3 数据核验说明

- **ROE：⚠️ 口径存疑，速评卡高估。** 速评卡17.8% = 2026Q1单季加权4.45%×4年化；**2025年报加权ROE真值15.19%**（Tushare年化15.32%一致）。交叉验证工具输出共识16.56、偏差7.49%超阈值。且Q1归母含约2966万非经常（归母+60.38% vs 扣非+21.36%），**年化ROE含非经常水分，真实ROE约15%、扣非口径更低**。
- **PE-TTM：✓ 一致。** 速评卡30.6 vs Tushare 30.75，偏差0.25%达标。但注意归母PE含Q1非经常收益，扣非TTM PE约35.7x，比卡面更贵。
- **其余卡面数据**（毛利率95.2%、净利率46.1%、负债率3.7%、营收增速10.7%）与2026Q1财报基本吻合，但"营收增速10.7%"为Q1单季值，全年口径2025年为+14.81%。

## 量化结论

- 内在涨幅: **-26%**（现价约24.9元 vs 三情景加权公允中枢约18.5元；依据：2026E扣非净利约4.2亿×加权23x≈96.6亿市值，对应18.4元/股；考虑ACARIZAX获批风险、核心单品增速降至+7.8%、Q1净利含非经常水分，中性偏保守；即使按乐观25x亦仅20.1元，仍低于现价约19%）
- 击球区: 🔴 **未到**——现价扣非PE-TTM约35.7x、2026E约31x，对应PEG约2倍；"舌下脱敏唯一垄断"护城河是注册租约（专利至2032），而ALK尘螨舌下片ACARIZAX已获CDE受理3年、金赛15亿商业化推进中，垄断被攻破只是时间问题；核心单品增速2026Q1已降至+7.81%，第二曲线（黄花蒿5435万/点刺液1355万）体量微小，市场为"渗透率故事"支付的溢价无安全边际
- 目标建仓价: **16.0 元**（对应2026E扣非约19x、扣非TTM约23x；较公允中枢18.5元再留15%安全垫，充分计入ACARIZAX获批与核心单品增速继续降档的风险；若ACARIZAX获批落地、垄断溢价出清，此价位具备真正的安全边际）
- 二次补仓价: **13.5 元**（对应2026E扣非约16x，历史估值地板区域；该价位对应悲观情景17x附近，为"垄断被攻破+集采降价"双杀兑现时的深度安全垫）
- 数据核验: **⚠️ 部分跳过**（ROE口径存疑：速评卡17.8%为2026Q1单季4.45%×4年化，2025年报加权真值15.19%，偏差7.49%超阈值，且Q1归母含2966万非经常致归母+60.38% vs 扣非+21.36%背离32pp，已按年报真值15.19%重估；PE-TTM ✓ 30.6 vs Tushare 30.75一致；行业数据来自公开报道/券商研报/公司公告，截止2026-08-10）
