# 中信建投(601066) 商业模式分析 — 段永平视角

> 分析日期：2026-08-11 | 收盘参考：25.92元 | 市值：约2010.5亿 | 总股本77.57亿股
> 段永平式提问：这是门好生意吗？它有护城河和定价权吗？管理层本分吗？现在这个价格我愿意拿十年吗？

---

## 一、生意本质：自营占四成的"双重Beta生意"，一半利润在赌市场方向

段永平判断生意，先问"它赚的钱是不是它自己创造的价值"。中信建投2025年赚了94.39亿，但拆开看，**近一半是市场给的，不是自己挣的**。

### 1.1 收入结构：自营41.7%+经纪通道，靠天吃饭的组合

按2025年报口径（营收233.22亿，+22.41%）：

| 业务 | 2025年收入 | 占比 | 性质 |
|---|---|---|---|
| 自营投资 | 97.24亿 | **41.70%** | **拿股东的钱赌市场方向，首次突破40%** |
| 经纪业务 | 约60-65亿 | 约28% | 纯通道，佣金率长期下行 |
| 投行 | 约25-26亿 | 约11% | 行业龙头，但占比小 |
| 资管 | 约14亿 | 约6% | 管理费模式，但非头部 |
| 信用(利息) | 约5亿 | 约2% | 两融/股票质押，加杠杆赚息差 |

**核心判断：** 自营占41.7%，比2021年提升11.6个百分点——这不是管理层"更会投资了"，而是**市场好，自营天然赚得多**。2022年市场调整时，公司自营收入从89.87亿骤降至67.24亿，向下弹性同样巨大。加上经纪佣金（市场成交量Beta）+信用利息（两融余额Beta），**收入七成是市场Beta**。这不是"创造价值"的生意，是"市场景气的放大器"。

### 1.2 盈利波动的实锤：利润随牛熊坐过山车

- 归母净利：2021年92.17亿 → 2022年75.07亿 → 2023年87.21亿 → 2024年72.23亿 → 2025年94.39亿 → 2026Q1单季36.67亿(**+99.03%**)
- 2026Q1年化加权ROE 16.08%排行业第1，但**这是牛市爆发期的数字**：一季度沪深成交活跃+IPO回暖共振，净利翻倍是Beta不是Alpha。
- 段永平会问："如果明天市场冷三年，这家公司还能赚多少？"答案是：回落到2022-2024年的70-90亿区间，甚至更低。**盈利不可预测，等于看不懂。**

### 1.3 为什么"看不懂"就不碰

中信建投的利润一半以上靠自营交易，而自营仓位、衍生品敞口、两融风险**都不透明**。2025年自营赚97亿，2022年亏掉20多亿——这不是可以"拿十年"的盈利模式。段永平说过，券商的问题在于你不知道它明年赚多少，也不知道它资产里有没有雷。**负债率83.7%意味着8毛多钱是借来的，赚息差+市场钱，亏起来杠杆放大。**

**生意本质评分：2/10（很差）。** 这是"牌照加持下的高杠杆市场Beta生意"，与段永平喜欢的"十年可预测、产品有定价权"的生意完全相反。段永平大概率直接PASS。

---

## 二、护城河：投行龙头真实，但"窄且靠牌照关系"，不是品牌型护城河

### 2.1 投行确实是真龙头——这是中信建投最值钱的部分

- 2025H1 A股IPO承销金额84.31亿**行业第一**，断档领先第二名国泰海通(47.97亿)
- 2025全年IPO主承销12家（行业第3）、金额196.61亿（行业第2）；股权融资33家、917.73亿
- 2026H1股权承销约646亿**行业第2**，仅次于中信证券(1478亿)；科创债承销第3
- 投行业务2025年营收+25.76%，是增幅最大的板块

投行的护城河来自：**项目储备+地方/国资关系+投研人才+品牌信誉**。头部五大投行拿走80%股权承销份额，马太效应确实存在。这一点必须承认——**中信建投在投行业务上有真实的行业地位**。

### 2.2 但投行护城河有三条致命约束

1. **投行只占营收约11%**（2025H1口径11%）：龙头地位是"局部冠军"，撑不起整体生意质量。真正决定利润的是自营（41.7%）和经纪（28%），这两块没有护城河。
2. **IPO节奏不由公司掌控**：2023-2024年IPO收紧期投行收入大幅下滑，2025-2026回暖是政策给饭。投行是"政策周期股"。
3. **承销费率市场化下行**：IPO费率、债券承销费率竞争激烈，"三中一华"内卷，费率没有定价权。

### 2.3 其他业务无护城河

- **经纪**：纯通道，佣金率万2以下的价格战，无转换成本，客户随行情迁移。
- **资管**：受托资金5245亿但非头部，中信建投基金规模远逊易方达/华夏，且公募费率改革压毛利。
- **国际**：中信建投国际2025年净利8.91亿(+177.6%)占9.4%，是亮点，但体量小，且依赖港股IPO景气。

**护城河评分：3/10。** 投行"窄而真"的护城河是加分项，但占比太小，改变不了整体"无品牌、无网络效应、无转换成本"的生意底色。段永平会问："投行第一名的收入，能不能让公司穿越熊市还赚钱？"答案是——不能。

---

## 三、定价权：完全没有

段永平检验生意质量的核心问题："它提价容易吗？"

- **经纪佣金**：价格战打穿，只能降费抢量，从未见过券商提佣。
- **自营**：连"定价"都没有，随行就市，纯被动——**41.7%的收入是无定价权收入**。
- **投行费率**：项目制招标，承销费一降再降。
- **资管费率**：被动管理为主，主动管理费受监管压制。
- **信用利率**：市场定价，跟随LPR与资金成本。

**定价权评分：0/10。** 整个券商行业都没有定价权，中信建投也不例外。投行龙头的"品牌溢价"体现为**多拿项目**，而非**多收费率**——这是"关系/牌照型"优势，不是"品牌型"溢价。

## 四、企业文化与"本分"：国企双股东治理相对干净，但整合题材是"故事"不是"价值"

### 4.1 股权结构：北京国资+中央汇金+中信集团，三方博弈的"双重身份"

- **北京金控（北京国资）34.61%**：第一大股东，2020年由北京国管无偿划转，体现北京市国资对本地券商的整合意图
- **中央汇金约31%**：国务院金融出资平台，带来"国家队"背书
- **中信集团约5%**：历史渊源（2016年中信证券转让股权给北京国资，才形成今天格局）
- 国有股东合计持股超90%，**无实控人减持、无质押爆雷风险**——这是国企券商治理的相对干净之处。

### 4.2 合并/整合题材：反复炒作，官方多次否认

- 2020年"两中信合并"（中信集团收购汇金所持中信建投股权）传闻，公司深夜辟谣。
- 2024-2025年**北京打造券商航母**预期再起：北京国资体系有5家券商（北京证券、首创、第一创业、中信建投、金融街证券），中信建投被市场视为**整合主体**。
- 段永平怎么看：**整合是"催化剂"不是"价值"**。若真整合，摊薄还是增厚股东利益取决于方案；若不整合，则是概念炒作后的一地鸡毛。**不为故事付钱。**

### 4.3 加分项与减分项

加分：
- 上市以来**分红融资比251.96%（行业第2）**——IPO募资少，分红相对慷慨，国企中算本分
- 持续降薪（2025年仍在执行），响应金融让利导向，成本控制有纪律
- 无大股东减持、无质押风险

减分：
- **分红率仅约28-32%，股息率仅1.37%**（2025年每股分红0.34元）——赚了94亿只分26亿，对股东回报一般，与银行保险的高股息不可比
- **投行合规罚单**：2025年投行被监管点名整改（"以合规利剑斩沉疴"报道隐含处罚史），投行是高执业风险业务
- 高管频繁变动、行业降薪周期，"人"的稳定性存疑
- 股权结构复杂，三方股东博弈下的**战略摇摆风险**（合并传闻反复）

**企业文化评分：5/10（中性偏上）。** 无实控人减持、无质押、分红融资比高是国企本色；但分红率低、投行合规处罚、整合题材反复，谈不上"特别本分"。段永平会说："这家公司治理不算差，但也没好到让我忽略生意本身的平庸。"

## 五、估值：PB 2.33x显著高于行业龙头，安全边际为负

### 5.1 金融口径用PB（券商正确打开方式）

**数据核验（强制交叉验证）：**

| 指标 | 速评卡 | 核验结果 |
|---|---|---|
| ROE年化 | 11.9% | **⚠️ 口径存疑**：Tushare年化8.37%，交叉验证偏差17.42%。2025年报加权ROE约11.5%（94.39亿/平均净资产约817亿）与速评卡接近；**2026Q1年化16.08%为牛市景气口径不可外推**；Tushare 8.37%偏低（可能扣永续债/期初净资产口径）。**正常化参考值9-11%** |
| PE-TTM | 17.9 | ✓ 一致（Tushare 17.88，偏差0.07%）。但**周期顶部低PE陷阱**——TTM净利含2026Q1牛市爆发(36.67亿+99%)，静态PE(2025年报口径)21.33，若市场回落至2024年净利72亿则对应PE约28x |
| PB | 2.33 | ✓ 一致（无第二来源，速评卡2.33）。**券商关键锚** |
| 净利率47.7% | | 2026Q1单季口径(36.67/76.96=47.6%)，非年报口径(2025全年净利率40.5%) |
| 营收增速62.3% | | 2026Q1同比口径，非全年(全年+22.41%) |
| 负债率83.7% | | ✓ 券商正常杠杆水平(总资产6768亿/净资产约864亿) |

**估值锚：PB。** 现价25.92元对应：
- **账面PB 2.33倍**（净资产约864亿/77.57亿股≈11.14元/股）
- 对比：中信证券PB约1.25倍、国泰海通约1.0-1.2倍、华泰约1.3倍——**中信建投PB显著高于所有龙头**

**为什么PB 2.33？** 三个原因：①投行龙头溢价；②总股本仅77.57亿股（中信证券148亿），**流通盘小、易拉抬**；③北京券商整合题材。段永平视角：**这三点没有一个是"价值"**——投行只占11%营收，小盘是交易结构不是基本面，题材是故事。

**正常化盈利测算：** 正常化ROE取9-11%（2025年报11.5%已接近牛市顶部，2022-2024年在9-11%），净资产864亿 → 正常化归母净利**78-95亿**。ROE 9-11%的券商，合理PB区间约**1.0-1.4倍**，对应合理股价**11.1-15.6元**。现价PB 2.33x已隐含"牛市持续+整合落地"双乐观预期，**安全边际为负**。

### 5.2 三情景加权（段永平视角，对周期股保守取权重）

| 情景 | 假设 | 合理市值 | 对应股价 |
|---|---|---|---|
| 乐观(20%) | 牛市延续+北京整合落地，净利110亿，ROE 12.7% | PB 1.7倍≈1469亿 | 18.9元 |
| 中性(50%) | 市场平稳，盈利回归正常化80亿，ROE 9.3% | PB 1.3倍≈1123亿 | 14.5元 |
| 悲观(30%) | 市场转冷，盈利回落至60亿，ROE 7% | PB 1.0倍≈864亿 | 11.1元 |

**加权内在价值 = 1469×0.2 + 1123×0.5 + 864×0.3 ≈ 1115亿元**（约14.4元/股）

**对应当前市值2010.5亿（25.92元），内在涨幅约 -44%。**

### 5.3 段永平式结论

- 这不是好生意（自营41.7%无定价权+盈利不可预测），所以**不会用合理价买**，只会在"很便宜"时考虑。
- PB 2.33x对一个正常化ROE只有9-11%的杠杆生意来说，**明显偏贵**。对比成熟市场，大摩高盛ROE 13-15%也只给1.5-2x PB。
- 若PB回到**1.2x以下（约13.4元）**才初步进入"普通生意便宜价"；**1.0x（约11.1元）**才谈得上安全边际。
- 投行龙头、整合题材是**催化剂而非价值**——段永平不为概念付钱。

## 六、总结：为什么PASS

1. **生意本质差**：自营占41.7%+经纪通道+信用利息，七成收入是市场Beta；2026Q1净利+99%是牛市爆发不可外推，盈利十年不可预测，"看不懂"。
2. **护城河窄**：投行龙头（IPO承销第一、股权承销第2）真实，但只占营收11%，且靠牌照/关系非品牌，IPO节奏被政策控制；经纪、自营、资管无护城河。
3. **无定价权**：佣金价格战、承销费率下行、自营纯被动——41.7%的收入连"定价"都没有。
4. **治理中性**：国企双股东（北京金控34.61%+中央汇金31%）无减持无质押、分红融资比行业第2是本分；但分红率仅28-32%、股息率1.37%、投行合规罚单、合并题材反复，谈不上"特别本分"。
5. **价格贵**：PB 2.33x显著高于中信证券(1.25x)等龙头，正常化盈利对应内在涨幅约-44%，**安全边际为负**。周期顶部低PE(17.9)+小流通盘+整合题材撑起的股价，段永平不会碰。

> 段永平会说：**"这是一家好公司（行业地位），但不是好生意（无定价权+强周期），现在也不是好价格（PB 2.33倍）。投行龙头让我敬佩，但生意的一半利润在赌市场涨跌，我看不懂它明年赚多少。看不懂就不碰，宁可错过。"**

## 量化结论
- 内在涨幅: **-44%**（三情景加权内在中枢约1115亿/14.4元，vs 现价25.92元/市值2010.5亿）
- 击球区: 🔴未到 + 券商为"自营41.7%的市场Beta生意+投行窄护城河+无定价权"，现价PB 2.33x显著高于中信证券(1.25x)等龙头、正常化ROE仅9-11%对应安全边际为负，周期顶部低PE+整合题材撑价，不构成段永平意义上的买入机会
- 目标建仓价: **12.5 元**（约PB 1.12倍，投行龙头溢价后的"普通生意合理价上限"）
- 二次补仓价: **10.5 元**（约PB 0.94倍破净，正常化ROE 9-11%对应的安全边际区）
- 数据核验: ⚠️ 跳过-口径存疑（ROE速评卡11.9% vs Tushare年化8.37%偏差17.42%，2025年报加权约11.5%为牛市偏顶值、2026Q1年化16.08%为景气口径不可外推，正常化参考9-11%；PE-TTM 17.9 ✓一致、PB 2.33 ✓一致）
