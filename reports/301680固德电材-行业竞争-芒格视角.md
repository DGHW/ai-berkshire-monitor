# 固德电材(301680.SZ)行业竞争格局分析——芒格视角

> 报告人：industry-researcher-301680（芒格视角）
> 数据截止：2026-08-10（行情数据为2026-08-07收盘）
> 报告性质：行业竞争格局研判（非财务估值，财务数据以财务视角报告为准）

---

## 0. 一句话结论

**固德电材处在"需求真实增长但格局不断恶化"的电工绝缘/新能源材料行业中游。它是全球云母基电池热防护的老二，但却是三大上市公司中利润率最低、利润增速最弱、且唯一增收不增利的玩家——行业需求好，不代表行业里的公司是好生意。芒格视角：这不是一门"伟大生意"，现价无安全边际，🔴 观望。**

---

## 1. 公司业务定位（先弄清楚它到底在卖什么）

固德电材2008年从电力电工绝缘材料起家（发电机/特高压输配电），2016年切入新能源汽车热失控防护，2018年收购云母企业麦卡电工完成"云母化"转型，2026-03-06创业板上市。当前业务分三大块：

| 业务板块 | 2025年收入 | 占比 | 同比增速 | 说明 |
|---|---|---|---|---|
| 新能源汽车动力电池热失控防护零部件 | 5.65亿元 | 51.09% | **-14.46%** | 云母/高性能树脂基，覆盖电芯/模组/整包；**核心主业2025年收缩** |
| 电力电工绝缘产品 | 2.79亿元 | 25.24% | +31.79% | 绝缘树脂、云母制品、复合材料绝缘结构件；特高压/高压干式套管 |
| 铜铝复合材料 | 1.91亿元 | 17.24% | **+1655.88%** | 第二增长曲线；2025H1获宁德时代验证，用于电池极柱/母排 |
| 其他 | ~0.7亿元 | ~6.4% | - | 模具等 |

**核心发现：2025年公司整体营收+21.79%，但这是"拆东墙补西墙"式增长——增长引擎是铜铝复合（+1656%）和电力电工（+31.8%），而代表公司行业地位的核心主业（动力电池热失控防护）收入同比**下降14.46%**。市场宣传的"高成长"，主要来自体量极小的新业务基数放大。**

2026Q1进一步暴露结构问题：营收+48.92%但归母净利润仅+1.90%、扣非+2.89%，**"增收不增利"剪刀差扩大**。官方解释为：(1) 铜铝复合业务通过非全资子公司固瑞德运营，归母净利增幅小于营收增幅；(2) 内外销结构变化致毛利率下滑。

**对芒格框架的含义：营收增长≠价值增长。若利润不跟随营收增长，营收只是"规模幻觉"。**

## 2. 行业规模与增长：需求是真的，但没有想象中那么"性感"

### 2.1 市场规模（多口径，数据存在机构间差异，需谨慎采信）

| 口径 | 规模 | 增速 | 来源/截止 |
|---|---|---|---|
| 全球云母材料行业（宽口径含珠光材料） | 2025年约303.6亿元 | - | 财富号转载，2026-08 |
| 全球云母绝缘材料 | 2025年139亿元 → 2032年211.6亿元 | CAGR ~6.2% | 格隆汇，2026-01 |
| 电池系统安全防护中云母材料（狭义新能车） | 2024年33.5亿元；2025年~45亿元 | 2024-2029 CAGR **25.88%**；未来5年CAGR ~25% | 弗若斯特沙利文/雪球，2025-2026 |
| 全球电池包热失控阻隔材料 | 2025年136.9亿元（18.94亿美元）→2032年274.8亿元 | 2025-2032 CAGR ~10% | 恒州诚思，2026-07 |
| 全球云母复合热屏障片 | 2025年8.2亿美元→2032年17.11亿美元 | 2026-2032 CAGR 11.0% | QYResearch，2026-06 |
| 特高压用绝缘材料 | 2026年预计突破200亿元 | CAGR 15%+ | 行业预测，2026-02 |
| 电绝缘云母带 | 2025年全球5.56亿美元 | 高压电机用+35% | 财富号，2026-03 |

**判断：** 固德所立足的"动力电池云母热防护"细分市场2025年约45亿元、CAGR 20-26%，是云母行业里增速最快的子赛道，但**绝对体量小（约45亿元）**。而更广义的云母绝缘材料市场（139亿元）CAGR仅~6%，是"慢生意"。特高压绝缘（200亿元，CAGR 15%+）是另一个真实增长点，但固德该业务仅占总收入25%。

### 2.2 需求驱动力（真实且具有强制性）

1. **GB38031-2025"史上最严电池安全令"（2026-07-01正式实施）**：动力电池热失控后要求"2小时观察期不起火、不爆炸"（原为提前5分钟预警）。云母作为隔热/防火核心材料成为车企**强制性刚需**，单车云母价值量明确提升——这是全行业（荣泰、平安、固德都受益）的真实需求升级，也是当前云母板块整体高估值的核心叙事。
2. **特高压"十五五"建设翻倍**：国家电网宣布"十五五"特高压在建规模为"十四五"两倍，固德卡位特高压干式套管/变压器/互感器绝缘材料，客户含特变电工、思源电气、南京电气、中国西电。
3. **新能源渗透率突破60%、储能装机高增**：带动热防护零部件与铜铝复合排需求。

## 3. 竞争格局：三强鼎立，"一超两强"，固德是利润率最弱的一个

### 3.1 云母基电池热防护市占率

| 公司 | 全球市占率（云母基电池热防护） | 地位 |
|---|---|---|
| 浙江荣泰(603119) | ~22.6% | 全球第一；独家配套特斯拉；三维异形成型技术领先2-3年 |
| **固德电材(301680)** | **15-20%** | **全球第二/国内第一**（不同口径表述不一） |
| 平安电工(001359) | ~15% | 全产业链布局（原料→制品），制造业单项冠军 |
| 国际玩家 | - | SWECO、Isovolta（欧洲传统电气绝缘） |
| 其他中小企业 | 前五合计约30% | 行业公司数量多、集中度低 |

### 3.2 三大上市公司经营对比（2025年报）

| 指标 | 浙江荣泰 | 平安电工 | **固德电材** |
|---|---|---|---|
| 营收 | 13.8亿 (+21.2%) | 11.89亿 (+12.52%) | 11.06亿 (+21.79%) |
| 归母净利 | 2.78亿 (+20.9%) | 2.42亿 (+11.10%) | **1.79亿 (+4.30%)** |
| 毛利率 | 34.9% | ~35% | **30.24%**（2026Q1再降至28.24%） |
| 净利率 | 20.5% | 20.4% | **16.87%**（2026Q1降至15.71%） |
| 2026H1/新动态 | 2026H1净利+21.67%，新能源收入6.98亿(+51.32%) | - | 2026Q1归母+1.90%，中报8-25披露 |
| 特色 | 机器人丝杠第二曲线(KGG，毛利率45%)、服务全球前5车企中3家 | 特种石英纤维新产品 | 铜铝复合第二曲线（宁德时代验证） |

**芒格视角：竞争格局的关键信息——**
- 固德是三家上市公司中**毛利率最低（30.2% vs ~35%）、净利率最低（16.9% vs 20.4%）、利润增速最弱（+4.3% vs +11~21%）**的一家。
- 有研报直接点破：**固德"凭借低价策略（毛利率比平安电工低5-8个百分点）抢占国内二三线车企订单"**。这不是护城河，这是价格竞争的代名词——用更低的毛利换取收入规模。
- 荣泰在技术（三维异形）、客户（特斯拉独家）、第二曲线（机器人，毛利率45%）三维度全面压制；平安拥有原料端全产业链优势。
- 固德对外销售单价13.92万元/吨、毛利率40.53%，而内销仅约5万元/吨、毛利率从32.53%一路跌至25.63%——**"出海赚钱、国内血拼"**的剪刀差格局，本质是外销撑利润、内销走量。

### 3.3 客户结构与议价能力（核心劣势）

- 前五大客户占比：37.14%（2022）→39.90%→44.27%→41.94%（2025H1），**集中度中等偏高**。
- **宁德时代从2022年第一大客户，2023年降至第三，2024年掉出前五大**——曾在招股阶段被深交所两次问询。直接原因：国内价格竞争+宁德时代指定下游供应商间接采购分流。
- 公司自己承认：**国内动力电池市场集中度高，宁德时代/比亚迪话语权大，公司议价能力相对较弱**。
- 海外端：2025年前9月对通用汽车销售额-50.36%、大众-33.90%、特斯拉-0.55%——美国关税（2025-11-10起对美直接出口关税升至47.70%）与下游库存周期双重打击。
- 电力电工端客户为特变电工、思源电气、中国西电等设备商，电网侧招标方（国网/南网）同样强势。

**芒格视角：这完全不符合"定价权"标准。上游资源+下游巨头两头夹击，中游材料加工商是产业链价值分配中的弱势环节。**

## 5. 产业链分析：价值分配对固德不利

```
上游资源：云母矿(工业级600-1600元/吨；高端合成云母~3100美元/吨)、树脂(湖北隆胜四海为主要供应商)、玻纤布、超级棉/气凝胶
      ↓
中游加工：云母纸→云母带/板→绝缘结构件/热失控防护零部件（固德所在环节）
      ↓
下游客户：①电池厂（宁德时代、欣旺达——话语权极大，年年压价）
          ②整车厂（通用、特斯拉、大众、丰田、宝马、吉利、零跑、小鹏——价格战压价+关税影响）
          ③电网设备商（特变电工、思源电气、中国西电、东方电气——央企招标，强势）
```

**价值分配判断：**
- **上游**云母是资源品，天然云母全球分布广泛（中国新疆/四川、印度等），合成云母国产化推进中——固德对上游无垄断性控制，树脂仅依赖单一供应商（湖北隆胜四海）。
- **中游**加工环节本质是"来料加工+认证壁垒"的制造业，靠客户认证（车规级2-3年周期）形成一定粘性，但**无定价权**，毛利率逐年下滑即是明证。
- **下游**两头都是强势买方。海外整车厂（三元锂安全需求刚性）议价尚可（外销毛利率40%+），但受关税干扰；国内电池厂/车企压价能力极强（内销毛利率仅25%且在下降）。
- **结论：产业链价值分配明显不利于中游材料加工商。固德能赚钱主要靠海外高毛利订单和部分电力电工高壁垒产品，而这两块都面临关税与价格的双重不确定性。**

## 6. 行业趋势研判

1. **需求侧长期向上（真利好）**：GB38031-2025强制化提升单车云母价值量；特高压"十五五"翻倍；储能装机增长；新能源渗透率60%+。行业蛋糕在变大。
2. **供给侧恶化（真利空）**：参与者众多、集中度低、低价竞争常态化；整车价格战已导致汽车行业利润率降至4.1%（五年新低），零部件企业被"两头挤压"（2026年铜、铝、碳酸锂等原材料涨价叠加购置税减半）。
3. **高端化与国产替代**：合成云母、三维异形件、复合化是方向，但**固德并非技术引领者**（荣泰领先2-3年）。
4. **地缘与关税常态化**：对美关税47.7%、墨西哥/美国/德国产能布局——出海是必答题，但海外利润的稳定性存疑（通用采购腰斩是前车之鉴）。
5. **第二曲线（铜铝复合）**：宁德时代验证通过、2025年+1656%、毛利率转正至19.59%，方向正确；但当前毛利率仅19.59%（低于主业），且通过非全资子公司固瑞德运营，归母利润贡献打折——**对股价的叙事意义大于对报表的实际贡献**。

## 7. 芒格视角综合判定：这是一门好生意吗？

### 芒格"好生意"标准检验：

| 标准 | 判定 | 证据 |
|---|---|---|
| 定价权/提价能力 | ❌ 不具备 | 毛利率逐年下滑（内销32.5%→25.6%），增收不增利 |
| 高且稳定的ROE | ⚠️ 上市前高、上市后被稀释 | 上市募资11.76亿（>2025年中总资产11.3亿），净资产从~7.7亿翻倍至~19亿，ROE将被摊薄至~12% |
| 轻资本/现金流 | ⚠️ 一般 | 2026Q1经营现金流3027万(-36.87%)，每股经营现金流0.37<EPS 0.79 |
| 客户粘性/转换成本 | ⚠️ 有认证壁垒但非独家 | 车规认证2-3年周期有粘性；但荣泰独家特斯拉，固德无独家客户 |
| 行业竞争格局 | ❌ 不友好 | 三强中利润率最低、价格竞争、客户议价力强、集中度低 |
| 管理层/治理 | ⚠️ 有瑕疵 | 0元转让固瑞德5%给"同乡"；IPO一边大额分红(3年7476万)一边募资11.76亿补流3亿；募资额超总资产 |
| 长期成长空间 | ✅ 真实存在 | GB38031强制化+特高压翻倍+储能增长 |

### 最终判定

**固德电材不是芒格意义上的"伟大生意"（wonderful business），而是"一门公平的生意，身处竞争激烈的行业"。**它具备真实的需求增长、全球第二的卡位、健康资产负债表（负债率17.9%、质押0.36%），但缺乏核心的"定价权"与"结构性竞争优势"，且是三家中竞争实力最弱的一家（利润率最低、利润增速最弱、核心主业2025年收缩、增收不增利）。

**行业层面：新能源配套的绝缘/防护材料行业，整体属于"需求好、格局差"的内卷型行业**——与动力电池产业链一脉相承，强者（电池厂/车企）拿走价值，中游材料商被迫内卷。
