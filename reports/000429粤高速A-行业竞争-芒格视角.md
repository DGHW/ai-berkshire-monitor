## 二、竞争格局：高速公路公司的"路产质量"之战

### 2.1 行业竞争本质

高速公路公司之间**不存在价格竞争**（收费由政府核定），竞争体现在：
1. **路产区位**：是否处于高车流走廊（长三角/珠三角/成渝）
2. **路产剩余收费年限**：剩30年 vs 剩5年，价值天差地别
3. **路网替代压力**：周边是否有平行通道/高铁
4. **分红率与股息率**：红利资产的"收益率竞赛"

### 2.3 关键对比结论

- **粤高速资产质量：一流。** 控股306.78公里（权益折算295.88公里），三条核心路产（广惠+佛开+京珠广珠段）贡献98%营收，全部位于大湾区核心区。毛利率64.5%、净利率40%（归母口径），现金流净现比143%。

- **五年累计股息率（2021-2025）：** 山东高速20.16%、招商公路20.04%、宁沪19.45%、**粤高速19.36%**、皖通17.61%——粤高速在分红上处于第二梯队头部，但靠70%高分红率支撑，利润基数小。

## 三、核心竞争者威胁：四大替代/分流力量

### 3.1 高铁分流（最大长期威胁之一）

| 分流源 | 影响路产 | 影响程度 |
|---|---|---|
| 广深港高铁（广深段161对/日，**全国车次最多**） | 京珠广珠段（广州-珠海/深圳方向） | 中长途客运持续分流 |
| 广汕高铁、梅龙高铁、广惠城际铁路（2024年开通） | **广惠高速（2024年车流量已开始下滑）** | 中长途+城际客运分流 |
| 珠三角城际网（佛莞城际等） | 佛开高速 | 城际出行替代 |

**直接证据：** 2025年京珠高速广珠段通行费收入**-11.5%**，佛开高速**-4.8%**，部分受深中通道、南中高速分流叠加施工封闭影响，但高铁对中长途客流的侵蚀是结构性、不可逆的。

### 3.2 新建平行路网分流（同行业内耗）

- **深中通道（2024年6月通车）**：深圳-中山直连，2025年日均9.24万车次。分流虎门大桥/南沙大桥/广珠东沿线车流，间接冲击京珠广珠段、佛开高速。
- **南中高速**：直接分流京珠广珠段（2025年-11.5%的主因之一）。
- **赣康高速**：通行费收入**-8.45%**（区域路网竞争加剧的直接案例）。
- **判断：** 大湾区路网已超5300公里且密度超纽约东京湾区，**新增路网对存量路产的边际冲击将持续存在**。这是高速公路行业的"内卷"——所有人都想分一杯羹，蛋糕却不再变大。

### 3.3 免费政策（到期免费潮）

- 法律硬规定：《收费公路管理条例》——经营性公路最长收费25-30年，**期满必须终止收费，回归公益**。
- 全国2025-2030年约**2.1万公里**收费高速到期（占11.2%）；截至2026年4月约8000公里已免费。
- 广州周边已有**广佛高速（2022年免费）**、北环高速、华南快速一期（2026年8月7日到期免费）。
- **粤高速已亲身经历：** 广佛高速2022年3月停止收费，当时靠2020年收购广惠高速21%股权对冲。**收费到期=利润归零的"期限炸弹"，只有改扩建可"续命"。**

### 3.4 新能源汽车替代？

- **误判澄清：** 新能源汽车不减少通行费（不缴油税/养路费，但高速公路按里程收费，电动车照样缴费）。
- **真实影响：** ①ETC/数字化降低人工成本（利好）；②节假日免费政策下电动车增多增加节假日车流（利好）；③远期自动驾驶共享出行或减少私家车总量（利空，但10年+维度）。
- **结论：新能源车不是通行费威胁，反而是车流增长的潜在动力。**

### 4.1 收费年限到期——行业的"达摩克利斯之剑"

|---|---|---|---|

| 广惠高速（石湾-凌坑段） | 51% | 2027年8月 | 同上（改扩建含该段） |
| 京珠高速广珠段 | 参控股 | **2030年5月** | 改扩建（137亿，2023-2027） |

| 惠盐高速 | 参股 | 2047年2月 | — |

| 江中高速 | 参股 | 2027年8月 | — |
| 康大高速 | 参股 | 2037年12月 | — |

**核心矛盾：** 广惠高速（营收占比44.8%，第一大路产）**2027-2029年即到期**，公司豪掷305亿改扩建"续命"——但资本金财务内部收益率仅**5.08%**，且改扩建后的新收费期需省政府批准（尚未核定，猜测延长15年左右）。**花305亿买15年收费权，这笔投资回报率平庸。**

### 4.2 改扩建高峰期——现金奶牛的"失血期"

| 项目 | 预算 | 粤高速出资 | 工期 |
|---|---|---|---|
| 广惠高速改扩建 | 305亿元 | 约54.48亿（按51%股比） | 2025-2029/2030 |
| 京珠广珠东改扩建 | 137亿元 | 按股比 | 2023-2027 |
| 粤肇高速改扩建（参股） | 92亿元 | 按股比 | 2024-2027 |

- 2025年末资产负债率47% → 机构预计**2028年升至62%左右**。
- 改扩建期间施工封闭、车道减少，通行费短期承压（2025年京珠广珠段-11.5%已含此因素）。
- **分红承诺（2024-2026年≥70%）能否扛住资本开支+负债率上升，是红利逻辑的关键考验。**

### 4.3 REITs化——行业"退出通道"与估值锚

- **山东高速系最激进：** 高广高速类REITs 36.51亿（2024，银行间首单）→ 滨莱高速类REITs 79.84亿（2025，票面利率2.48%）→ 沈海高速持有型ABS 65.5亿（2026年8月申报）。
- **广连高速**：150亿持有型不动产ABS（2025年12月，机构间单笔最大）。
- **首单央企高速REITs**（2026年7月）正式发售。
- **对粤高速的含义：** REITs化是国资盘活存量、补充地方财政的手段。**粤高速尚未推出REITs**——若未来将成熟路产（如佛开）证券化，将一次性释放资产价值，但也可能被视为"剥离优质资产"。目前仅是期权，非现实收益。

## 五、产业链分析：价值分配与政企关系

### 5.1 价值链条

```
政府/交通主管部门（审批收费权、核定收费标准、批准改扩建延期）
        │
        ▼
路产资产（特许经营权，有期限）
        │ 垄断收费
        ▼
通行费收入（定价受管制，但车流增长由区域经济驱动）
        │ 运营成本低（养护+人工+折旧摊销）
        ▼
经营现金流（净现比>140%，A股最纯粹的现金奶牛）
        │ 分红率70%+
        ▼
股东分红（类债券收益）
```

### 5.2 价值分配特征（芒格会问：谁拿走了钱？）

1. **垄断但受管制：** 高速公路是政府授予的特许垄断，区域内无平行替代路（短期内），收费标准和期限全由政府核定——**盈利的天花板和寿命都在政府手里**。
2. **资本开支黑洞：** 高速公路行业整体"收支缺口"巨大（债务超6万亿）。行业长期需要改扩建输血，赚的钱一部分必然重新投入到路网升级中。粤高速的305亿广惠改扩建就是明证。
3. **政企利益绑定：** 粤高速是广东省交通集团A股唯一上市平台。母公司资产注入（2020年广惠21%股权、未来可能的更多注入）是双刃剑——既是成长期权，也是"接盘"义务（如收购作价24.9亿，隐含广惠估值约119亿，对价不便宜）。
4. **收费站利润率的真相：** 粤高速2025年报净利率40.3%（归母），看似极高，但这是**存量路产折旧期后的红利**——路产建成初期微利甚至亏损，成熟期才进入高利润阶段。改扩建会把新投入重演一遍"先亏后赚"。

## 六、芒格视角判定：高速公路是"一门好生意"吗？

### 6.1 好生意的一面（芒格会点头）

- **特许垄断+区域唯一性：** 大湾区西向（佛开）、南向（京珠广珠段）、东向（广惠）核心走廊，无平行替代。
- **极优现金流：** 2025年经营现金流35.59亿、净现比143%，纯现金奶牛，A股顶级。
- **高进入壁垒：** 新进入者无法复制路网，牌照+资金+区位三重壁垒。
- **低运营复杂度：** 商业模式简单到"无聊"，符合芒格"简单生意"偏好。

### 6.2 坏生意的一面（芒格会皱眉）

1. **有期限的收租：** 特许经营权不是永续资产。收费期一到，资产无偿移交，利润归零。**芒格厌恶"租约到期"的生意**——他买的是可口可乐（品牌永续）、喜诗糖果（品牌永续），不是租约。
2. **定价权缺失：** 收费标准由政府核定，车流增长依赖区域经济外生变量，公司自身无法提价对冲通胀。
3. **重资产再投入诅咒：** 收租收得爽，但305亿改扩建一来，利润重新转化为资产。改扩建资本金IRR仅5.08%——**这是用高回报的现金去换低回报的资产**。
4. **资本开支与分红矛盾：** 负债率将从47%升至62%，70%分红承诺能否长期兑现存疑。
5. **分流内卷：** 大湾区每开一条新通道（深中、南中、高铁），都从存量路产"抽血"。2025年京珠广珠段-11.5%已是现实。

### 6.3 芒格最终判定

> **"高速公路是一门口径极好、但寿命有界、天花板被政府定死的'半个好生意'。它像一张高息但会到期的债券，而不是永续增长的复利机器。好公司，但绝不便宜——现价支付的是'永续红利'的价格，买到的却是'限期收租+资本开支高峰'的现实。"**

## 七、量化估值与结论

### 7.1 估值测算（现价13.25元，2026-08-10除权后）

| 指标 | 数值 | 说明 |
|---|---|---|
| 总股本 | 约20.9亿股（A+B） | EPS 0.86元×20.9亿≈18.01亿归母 |
| 市值 | 约277亿元 | 13.25×20.9亿 |
| PE（2025归母18.01亿） | 15.4倍 | 含信用减值转回3.10亿的"水分" |
| **PE（2025扣非15.23亿）** | **18.2倍** | 真实经营口径 |
| PB | 约2.59倍 | 归母净资产约107亿 |
| 股息率 | 4.56% | 每股0.604元/13.25元 |
| 2025年归母+15.31% vs 扣非-7.4% | **背离22.7pp** | 归母增长靠减值转回，真实经营在下滑 |

### 7.2 合理价值锚定

- **股息率锚定法**（高速公路≈类债券，要求高于10年国债约3-4pp，叠加收费期限风险应要求更高安全边际）：
  - 5.5%股息率 → 合理价11.0元
  - 6.0%股息率 → 合理价10.1元（安全边际）
  - 7.0%股息率 → 深度价值8.6元
- **PE锚定法**（扣非EPS 0.73元，行业龙头宁沪12.6倍，粤高速质量略优给13-14倍）：
  - 13倍 → 9.5元；14倍 → 10.2元
- **合理价值中枢：10-11元**。现价13.25元较合理价值**高估约20-25%**。

### 7.3 数据核验提醒（供财务视角核对）

- 速评卡"净利率58.07%"：年报归母口径仅40.3%，58%接近含少数股东损益的总净利口径（24.89/44.7=55.7%）或TTM口径——**存在口径漂移，须核实**。
- 速评卡"毛利率68.22%"：年报口径（44.7-15.86）/44.7=64.5%，68%偏高，疑似Q1/TTM口径。
- 速评卡"PE 19.4"：与除权前14.8元×扣非15.23亿≈20.3倍接近，现价13.25元对应扣非PE 18.2倍、归母PE 15.4倍——**速评卡数据整体滞后于除权后现价**。
- 速评卡"ROE年化16.0%"：年报加权ROE 16.83%（归母含减值转回），扣非后约14.2%——**归母ROE含一次性收益，须以扣非口径重估**。
