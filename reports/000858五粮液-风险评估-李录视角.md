> **报告日期**：2026-08-09 | **速评卡**：PE23.1 / 市值2915.5亿 / 负债率34.3% / 营收增速33.7%

## ⚠️ 顶部重大风险警示

**本标的存在远超普通"白酒周期调整"的重大异常，建议全体成员在综合研判时重点引用：**

1. **两任董事长接连落马**：2026-02-28，董事长曾从钦因涉嫌严重违纪违法被宜宾市纪委监委立案调查并留置；其前任李曙光亦已被查处。
2. **303亿营收追溯调减（2026-04-30）**：公司在法定披露截止日压哨发布《前期会计差错更正公告》，将2025年前三季度营收从609.45亿重述为306.38亿（调减303.07亿），净利调减150.36亿。2025年报营收405.29亿（-54.55%）、归母净利89.54亿（-71.89%），ROE从23.35%暴跌至6.89%。
3. **深交所专项问询函**：2026-05-01凌晨深交所下发年报问询函，聚焦会计差错合规性、收入确认依据、内控缺陷及审计责任（注：官方渠道未正式全文披露，多家自媒体流传，存在争议，但新浪/东方财富等财经媒体均有报道）。
4. **市场质疑"财务洗澡/做低基数"**：调减的150亿利润中上半年占148亿，只动2025年账、不动2024年及以前，分析人士称"或已涉嫌信息披露违规"，质疑"混淆会计政策变更与会计差错，滥用会计准则规避严格审议程序"。
5. **业绩质量存疑**：2026Q1净利80.63亿（+82.57%）系低基数反弹（对应调整后低基数170.9亿，与调整前369.4亿比仍为负增长）；推算2026Q2单季净利仅6.67-11.37亿；2026Q1经营现金流转负（-116%）、应收类资产大幅攀升。

**结论预判：当前处于"管理层信任崩塌 + 行业深度调整 + 财务口径重构"三重叠加期，不满足李录框架下任何投资前提。**

## 一、管理层评估（李录视角核心项）

### 1.1 人事变动时间线（治理动荡直接证据）

| 时间 | 事件 |
|---|---|
| 2022年起 | 曾从钦同时执掌五粮液集团与上市公司 |
| 2026-02-28 | 曾从钦被宜宾市纪委监委立案调查并留置（涉嫌严重违纪违法） |
| 2026-04-30 | 压哨发布2025年报+会计差错更正（此前董事会无人愿为旧数据背书） |
| 2026-06-08 | 董事会免去曾从钦董事职务，补选邓敏 |
| 2026-06-27 | 股东会通过免职案；邓敏当选新任董事长 |
| 2026-07 | 管理层密集换防（高管批量更替） |

### 1.2 新董事长邓敏：化工老将，白酒门外汉

- 1970年生，1991年进入宜宾天原化工厂（氯碱/化工），历任天原股份董事长（2023-11起）、宜宾发展控股集团总经理（2025-09起），2025-10进入五粮液集团董事会，2026-06出任集团及股份公司董事长。
- **零白酒行业经验**，属宜宾国资体系内干部轮岗。长期履历在化工（天原股份为PVC/氯碱龙头），与白酒渠道、品牌、酿造无直接交集。
- 能力评估：管理大型国企的经验有，但对白酒行业周期、渠道利益格局、品牌打法缺乏实战验证。

### 1.3 管理层质量综合判断

- **诚信维度（李录最看重）：重大瑕疵。** 两任董事长接连因违纪违法落马，直接暴露内控与经销体系监管短板；"发货即确认收入"的激进口径运行多年，直到前任被查、无人背书才被迫挤水分——这属于**会计质量长期不诚实**的实证。李录在《文明、现代化、价值投资与中国》中反复强调管理层诚信是投资前提，此处**前提不成立**。
- **能力维度：中等。** 渠道改革（直营"三店一家"、云仓数字化、库存周转降至18天）有实质推进，高管薪酬与市场挂钩、末等调整机制有改革意愿；但核心产品量价平衡至今未解决。
- **股东回报态度：正面。** 分红率70%、百亿分红+80-100亿回购+大股东30-50亿增持，国资对市值管理有诉求。但增持执行缓慢（截至2026-08-06仅增持241万股/1.99亿，占计划下限30亿的6.6%）。

> **李录式拷问**：一个连续两任一把手落马、收入确认口径靠"压哨差错更正"来纠正的公司，你愿意把终身积蓄的10%交给它吗？答案是否定的。

## 二、行业风险

1. **第五轮深度调整、量价利三杀**：中酒协《2026中国白酒市场中期研究报告》：超86%调研企业利润率下滑，56.6%经销商反馈价格倒挂/库存高企；白酒产量连续第八年下滑，六年累计跌幅超52%。
2. **公务消费限制收紧**：2025年5月政策意见再度强调严禁白酒公务消费，"新禁酒令"明确公务接待工作餐不上酒；80.8%经销商反馈商务送礼需求减少，高端酒最依赖的政务商务场景被系统性压缩。
3. **消费税新规（2026-06-01落地）**：国税总局2026年第9号公告新增《白酒消费税计算明细表》《关联销售单位信息报告表》，引入"出厂价与关联方对外售价60%孰高"原则——专门针对酒企通过关联销售公司转移定价避税，**直指五粮液类"厂家→关联销售公司→经销商"结构**，可能抬升有效税负。
4. **库存周期远未见底**：高盛2026年1月判断行业最快2026下半年才可能触底，且建立在2025年6月极低基数之上；渠道库存仍在出清，报表增速领先于真实动销。
5. **批价回升是"假信号"风险**：2026-08初第八代五粮液批价上涨（郑州百荣市场单日涨90元/整箱），但本质是**厂家取消补贴、收紧市场政策被动抬价**，属供给端渠道治理修复，**不是需求回暖**；终端未跟涨，能否站稳取决于中秋真实动销（市场主流观点）。

## 三、竞争风险

1. **茅台压制**：高端（800元以上）"茅五泸"三家占95%+份额：茅台62-63%、五粮液22-23%、国窖1573约12-15%。茅台2026年3月、7月两次提价共140元，将价位天花板抬高，同时i茅台直销（MAU同比+40%）把渠道利润收归己有，对五粮液高端放量形成挤压。飞天批价2026年初一度跌破1490元，高端价格带整体承压。
2. **次高端内卷**：五粮液主品牌占比超75%，次高端由系列酒承接（五粮春300-350元/五粮特曲229-319元/五粮醇100-200元），与全国性次高端品牌及区域名酒正面竞争；酱香品牌（君品习酒586元、青花郎）以"向下兼容"定价分流，五粮液系列酒2025H1增速已从11.79%骤降至2.73%。
3. **酱香/清香分流**：酱香（茅台系、习酒、郎酒）占据高端话语权，清香（汾酒）在100-300元大众带快速增长，浓香在中低端市场被两头夹击。五粮液高端基本盘仍稳（"普五"品牌力第二），但金字塔腰部受挤压。
4. **经销体系利益受损**：2026年初经销商开票价下调（厂家让利），叠加追溯调减暴露"压货"历史，经销商信任受损；"金字塔要塌了？全价格带遭夹击，库存暴增四倍"的行业报道反映渠道信心问题。

## 四、业务风险

1. **直销改革成效有限**：直销占比已提升至约40%（2024年38.57%→目标45%），毛利率87%优于经销渠道78.8%，四年复合增速48.59%——这是结构性亮点；但直营扩张挤压经销商利益，且2026Q2单季净利仅6.67-11.37亿、经营现金流转负，说明**改革红利尚未转化为稳定盈利质量**。
2. **系列酒扩张承压**：系列酒2024年营收152.51亿（+11.79%）→2025H1增速2.73%大幅失速，四大单品（五粮春/五粮醇/五粮特头曲/尖庄）中部分区域库存压力大；"两个百亿级大单品"战略仍在培育期。
3. **收入确认口径重构后的真实盈利待验证**：调整后2025年净利89.54亿中，多少是真实经营利润、多少是出清/退税/口径因素，缺乏权威穿透披露；2026Q1利润高度集中于单季（占H1预告上限87%），季节性失真，**用TTM/正常化口径看盈利质量才是关键**。
4. **预收/合同负债信号**：2025年末合同负债134.6亿（+15.14%），显示经销商仍愿意打款，是少有的正面信号；但其与"监管商品款项"（负债278.27亿）并存，负债结构复杂化。

## 六、长期确定性（10年后看五粮液）

**不利面：**
- 年轻人绕开白酒：白酒消费人群中21-30岁仅占19%（中酒协），83%年轻人偏好20度以下低度酒；新酒饮市场4年从200亿→570亿（2026年预计突破5000亿）；30岁以下单次饮酒量五年降近四成。**人口与代际结构对白酒总量是长期逆风。**
- 总量萎缩：白酒产量六年跌52%，"量缩价稳"是主基调，行业从规模扩张转向价值深耕。
- 公务/商务场景被制度性压缩后，高端酒溢价逻辑弱化。

**有利面：**
- 高端白酒具备强社交/礼品/面子属性，品牌护城河深厚；茅五泸占高端95%+，**集中度持续提升**，五粮液"浓香第一、白酒第二"地位短期难以撼动。
- 商务替代消费（企业自饮、婚宴）部分承接；五粮液在宴席市场渗透力强。
- 若新管理层完成渠道出清、价格理顺，品牌价值仍在（普五批价745元回升即是明证）。

**10年推演**：最可能的情景是"量稳价弱、份额集中"——五粮液维持高端双寡头地位，营收/利润从低基数缓增（3-6%复合），ROE回归15-20%中枢，靠分红+回购贡献股东回报。**确定性强于多数消费品，但成长性显著低于过去十年。** 李录框架下，这属于"看得懂、但不是最优增长标的"的成熟价值股。

## 十、长期确定性判断

- **10年后白酒格局**：总量继续萎缩（产量六年-52%），但高端"茅五泸"集中度继续提升，五粮液作为浓香龙头+高端第二品牌，**地位大概率保住，但量价成长性明显弱化**。高端品牌力（普五）是核心资产，护城河真实存在。
- **最大长期威胁**：代际切换（年轻人喝低度酒/新酒饮）+商务场景制度性收缩，若10年内高端白酒的社交/礼品刚性被逐步侵蚀，品牌溢价逻辑弱化，估值中枢将系统性下移。
- **李录视角结论**：这是"看得懂的好生意+说不清的管理层+正在出清的行业"组合。**生意质量可接受，管理层前提不成立，当前价格无安全边际。**
