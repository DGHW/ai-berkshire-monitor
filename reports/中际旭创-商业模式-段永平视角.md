# 中际旭创(300308.SZ)商业模式分析 — 段永平视角

> 角色：business-analyst | 视角：段永平 | 日期：2026-08-08
> 定位：全球光模块龙头（800G/1.6T，AI算力核心受益者，英伟达链）

---

## 一、商业模式定性

### 1. 生意本质：AI算力时代的"卖水人"（但不是"提价权"生意）

中际旭创做的是**高速光模块**——连接GPU集群的"信息高速公路"。AI训练集群越大，网络带宽与低时延要求越高，光模块是AI资本开支最先、最直接受益的环节之一。

**用段永平的语言重新问一遍："这是不是一门能躺着赚钱的生意？"**

| 维度 | 判断 | 说明 |
|---|---|---|
| 需求确定性 | ★★★★★ | AI算力capex是当前确定性最高的产业趋势，北美云厂商持续追加，英伟达Rubin平台全面切换1.6T/3.2T |
| 护城河 | ★★★★☆ | 全球份额第一(21.2%)、客户认证壁垒、柔性量产+快速NPI、硅光技术全球首家规模商用、绑定上游激光芯片原厂 |
| 定价权 | ★★☆☆☆ | **关键弱点**：标准由芯片厂商（英伟达/博通/台积电）定义，光模块公司是"封装层适配者"而非"定义者"。产品每年价格年降正常，靠出货量增长撑利润 |
| 资产轻重 | ★★☆☆☆ | 重资产：计划3年新增5000万只/年产能，总产能至9000万只/年，80%以上面向1.6T+；H股募资163.5亿港元扩产 |
| 技术迭代风险 | ★★★☆☆ | 800G→1.6T→3.2T→CPO/NPO，公司多线布局对冲；但CPO等新路线若被芯片厂主导，公司可能从"方案商"沦为"组件封装商" |
| 现金流质量 | ★★★★☆ | 2025年经营现金流108.96亿元(+244%)，应收与利润匹配度高，增长是"落到账上的真金白银" |

**段氏结论：这是"看得懂需求、看不懂技术终局"的生意。** 需求端极硬（AI算力），但供给端公司不掌握标准定义权、无法自由提价、且需持续大额资本开支——并非段永平最偏爱的"强品牌+提价权+轻资产"型生意，属于**优秀但非卓越**的生意模式。

### 2. AI算力需求与英伟达链位置

- **2026年北美核心客户需求**：800G合计约1500万只（Meta 450万、谷歌350万、英伟达250万、亚马逊250万、微软200万）；1.6T合计约1000万只（英伟达450万、谷歌240-250万、微软150万、Meta 80万、亚马逊60万）。
- **出货节奏**：2026Q1公司800G出货超300万只、1.6T超100万只；Q2 800G预计300-400万只、1.6T约200万只；目标Q3完成全年出货80%，在手订单已覆盖2026全年，部分延伸至2027，头部客户已出具2028年NPO/2.4T大额采购指引。
- **1.6T降价传闻已澄清**：7月公司明确"能批量交付1.6T和800G的厂商极为有限，不存在无底线降价"，2027年1.6T需求依然强劲、客户数不降反增。
- **高盛行业口径**：2026全球光模块市场5088亿美元→2027年7259亿美元；800G硅光渗透率60%、1.6T达80%、3.2T全硅光。

### 3. 技术迭代：多代并进，全栈布局

- 主力：800G(成熟放量)+1.6T(批量出货，EML/硅光双平台，OSFP224 DR8/LPO)。
- 下一代：3.2T(研发完善中)、6.4T NPO、12.8T XPO、CPO光引擎、OCS光交换机；2027年CPO/NPO大规模放量（高毛利57%）。
- 硅光占比已超50%，是成本与毛利改善的核心引擎（2026Q1毛利率46.06% vs 2025年42%）。
- **风险点**：OFC 2026后行业共识是"光模块定义的是封装标准，不是芯片标准"，真正的权力在英伟达/博通/台积电手中。若CPO时代到来，光模块厂毛利结构可能被重塑——这是估值折价的核心理由。

## 二、财务与估值锚点（数据核验后）

| 指标 | 数值 | 备注 |
|---|---|---|
| 2025年营收/净利 | 382.4亿 / 107.97亿 | 同比+60.25% / +108.78% |
| 2026Q1营收/净利 | 194.96亿 / 57.35亿 | 同比+192.12% / +262.28% |
| 2026Q1毛利率/净利率 | 46.06% / 32.40% | 高端占比提升+硅光规模化 |

| 一致预期净利 | 2026E 328.5亿 / 2027E 611亿 / 2028E 870亿 | forward PE: 2026E 32.7x, 2027E 17.6x |
| 高盛(7.17) | 目标价2581元；净利2026-28E 384/801/1096亿 | 锚定2027年PE 35.8x，三年净利CAGR 69% |
| 一致预期目标价 | 1777元 | 较现价约+93% |

**估值透视（段永平式"毛估估"）：**
- 现价919.87元 ≈ 2026E一致预期净利328.5亿的**32.7x**。
- 即便按最乐观的高盛预测（2026E净利384亿），forward PE也达**28x**——市场已经把"2026高增长"完全定价。
- 若按2027E 611亿、给25x（无定价权重资产制造商的上限），合理市值1.53万亿、对应约1376元——这是"增长兑现+慷慨估值"双乐观的结果，不是安全边际。
- 中性内在价值估算：2027E净利611亿×22x≈1.34万亿→约1210元；以12%折现回今≈1080元。即**合理内在价值约1100-1200元，现价920元接近中性价值但无任何安全垫**。

## 三、段永平式定性结论

1. **好公司？** 是。全球龙头、需求最硬的赛道、现金流好、技术全栈、客户锁定。近三年净利CAGR 100%+。
2. **好价格？** 不是。PE(TTM) 71.98倍已透支两年高增长，forward PE仍30x上下。段永平名言"再好的公司，买贵了也是糟糕的投资"。周期成长股一旦AI capex放缓或CPO切换，戴维斯双杀空间远大于上行。
3. **看得懂吗？** 需求看得懂（AI算力是时代趋势），**技术终局看不懂**（1.6T之后是CPO/NPO，公司是被芯片厂定义的"封装层"，长期格局非其所能主导）。这触及"能力圈"边界。
4. **挥不挥棒？** 现价不挥。目标价位在合理价值以下留足安全边际（约6折），且设二次补仓位应对"技术路径切换+资本开支下修"的悲观情景。

---

## 量化结论
- 内在涨幅: +20%（中性：2027E净利611亿×22x≈1210元，12%折现约1080元；较现价919.87元）
- 击球区: 🔴 现价已定价近两年高增长且无定价权、技术终局被芯片厂定义，安全边际不足，不追高
- 目标建仓价: 680 元（≈2026E 328.5亿×23x / 2027E 611亿×12.4x，合理价值约6折）
- 二次补仓价: 520 元（≈2026E 16x / 2027E 9.5x，贴近年内低点505元，深度安全边际）
- 数据核验: ⚠️ ROE存在来源偏差（速评卡70.2% vs Tushare年化44.16%，共识中位数57.18%，偏差22.77%）；PE 71.98、市值10760亿、现价919.87元与行情数据一致
