## 一、行业规模与趋势：一个"小而美"但增速快于全球的赛道

### 1.1 市场规模（多源交叉验证）

| 口径 | 数据 | 来源 |
|---|---|---|
| 全球CMP抛光材料市场 | 2025年 33.8–38.0亿美元（约270亿人民币）；2026E 42亿美元(+10.3%) | TECHCET / Market Growth Reports |
| 其中抛光液占比 | 约60%（约20–23亿美元 / 2025年） | 多家机构一致 |
| 全球CMP材料增速 | 2025–2030 CAGR 8.8%；2025–2034 CAGR 4.5%（另一口径） | TECHCET / Market Growth Reports |
| 中国市场 | 2021年22.3亿 → 2025年57.3亿元（5年CAGR 26.5%）；2030E突破80亿元 | 雪球综合 |
| 中国CMP抛光液国产化率 | 约30%，2027年有望突破50% | 行业分析 |
| 下游半导体行业毛利率 | 18%左右（对比：中游抛光液55%） | 产业链分析 |

**芒格判断 [B级，中高置信]**：这是一个全球仅约270亿人民币的"小池塘"，但中国市场的增速是全球的3倍（26.5% vs ~5–8%）。**生意不大，但"卖铲子"属性极佳**——抛光液是晶圆制造的消耗品，重复采购，无库存周期风险，且随制程越先进用量越大（先进制程CMP步骤数翻倍）。这是芒格最喜欢的"耗材+必需"模式，而非一次性资本开支。

### 1.2 行业结构性趋势

1. **量增逻辑 > 涨价逻辑**：CMP是量增+国产替代驱动，非涨价暴涨型（CMP抛光液整体涨幅温和，高端存储抛光垫2026年内涨幅35%、钨/硅系抛光液长协上调25–40%，但持续性存疑）[B级]
2. **先进制程拉动单耗**：14nm→7nm→3nm，CMP工艺步骤数持续增加；2nm工艺配套产品安集已进入台积电试样
3. **先进封装/HBM开辟第二战场**：TSV平坦化、混合键合、3D集成将CMP从前道制造拓展至后道封装；HBM需求CAGR约40%（德银预测至2030），单片芯片CMP抛光次数大幅提升 [B级，中高置信]
4. **存储扩产是国产材料最大Beta**：长江存储"史诗级扩产"、长鑫科技扩产，2026年国内存储扩产资本开支155–180亿美元；本土厂商获得导入窗口 [B级]

- 全球CMP抛光材料美日龙头合计占据近80%份额，中国厂商整体仍处于"追赶+替代"位。

## 三、核心竞争者逐家分析（威胁度排序）

### 3.1 美国 Cabot Microelectronics（Entegris旗下）— 威胁：🔴 最强
- 全球份额约35%，先进制程(7nm以下)配方仍领先，价格高于安集约30%
- 弱点：本土服务响应慢、中美地缘政治下中国晶圆厂"去美化"意愿强烈、供应链安全顾虑
- **对安集的实质威胁在下降**：国产晶圆厂为供应链安全主动导入国产，Cabot在中国市场被"制度性挤出"而非单纯技术替代

### 3.2 日本 Fujimi — 威胁：🟡 中等
- 全球25%份额，技术迭代慢，2024年营收增速仅8%，PE约72倍（估值高于安集）
- 产品线以硅系/氧化物系见长，在先进铜/阻挡层、HBM场景落后
- 威胁主要在海外市场（台积电、三星本土产线），对中国大陆渗透力弱

### 3.3 韩国 KCTech — 威胁：🟡 中等（结构性）
- TSV/先进封装抛光液全球领先，深度绑定三星、SK海力士，直接受益HBM浪潮
- 安集已通过SK海力士TSV通孔小批量供货，正面交锋开始，但KCTech在先进封装暂时领先
- **这是HBM时代对安集威胁最大的海外对手** [B级]

### 3.4 国内 鼎龙股份 — 威胁：🟡 中等（长期最大国内威胁）
- 抛光垫国产龙头（38.5%份额），2025年抛光垫收入10.91亿(+52.3%)，抛光液2.94亿(+36.8%)，与长江存储/长鑫科技深度绑定（前两大客户）
- **关键差异**：鼎龙在抛光液单赛道体量小（2.94亿 vs 安集20.4亿），缺乏安集的先进逻辑(7/14nm铜阻挡层)能力与台积电供应链卡位
- 但鼎龙"垫+液"协同、存储绑定深，若未来向先进制程进攻，是安集国内第一对手 [B级，中高置信]

### 3.5 其他 — 上海新阳(电镀液)、华海清科(设备非材料)、陶氏(抛光垫) 
- 上海新阳：电镀液是安集第二曲线的直接对手
- 陶氏/Dupont：抛光垫端垄断，安集未直接参与，但"垫+液"配套销售逻辑下存在间接竞争

## 四、行业趋势：三大引擎与一个隐忧

### 4.1 趋势一：国产替代加速（确定性最高）
- 地缘政治驱动下，中国晶圆厂国产化率从30%快速向50%+跃迁；CMP抛光液国产化率约30%→2027年50%+
- 安集是国内>50%份额的绝对龙头，是国产替代最确定、最直接的受益者 [A级，高置信]

### 4.2 趋势二：存储/逻辑扩产（Beta最大）
- 长江存储、长鑫科技扩产周期启动，带动CMP材料需求；安集为长鑫科技IPO战略配售名单中唯一CMP抛光液企业
- 逻辑端中芯国际、华虹持续扩产成熟制程+先进制程

### 4.3 趋势三：先进封装/HBM（增量最大）
- HBM需求CAGR约40%（远超DRAM约21%），TSV、混合键合、3D IC拉高CMP单耗
- 安集先进封装用电镀液及添加剂已多款量产销售（凸点、RDL、异质集成）；TSV抛光液覆盖SK海力士
- **注意**：先进封装抛光液是KCTech的强项，安集在此是追赶者

### 4.4 隐忧：行业天花板与价格竞争
- 全球CMP材料市场仅约38亿美元，中国2025年57.3亿人民币——**即使2030年翻倍到80亿，仍是个小市场**
- 28nm成熟制程国产化率突破50%后，本土玩家增多，价格竞争加剧，氧化物系抛光液毛利率仅15–21%（显著低于公司整体55.5%）
- 芒格提示：**"小池塘里的大鱼"成就了安集，但也意味着增长最终要依赖全球份额提升和品类扩张（湿电子化学品、电镀液），而非单靠行业空间**

## 五、产业链与价值分配：上游掐脖子→中游吃肉→下游量大但利薄

### 5.1 产业链结构

```
上游（磨料+化学品）          中游（CMP材料）            下游（晶圆厂）
纳米磨料(硅溶胶/氧化铈)  →  抛光液(价值占比60%)    →  中芯国际/长江存储
氧化剂/表面活性剂/缓蚀剂  →  抛光垫(占比30%,陶氏75%+) → 长鑫存储/台积电/三星
高纯化学品                       清洗液/电镀液
```

### 5.2 价值分配（关键洞察）

| 环节 | 毛利率/价值 | 议价权特征 |
|---|---|---|
| **上游磨料** | 高（但此前被海外垄断） | **卡脖子环节**：直接材料占安集成本75.14% |
| **中游抛光液** | 整体55%；钨系67–82%、硅/铜系57–61%、氧化物系15–21% | 认证壁垒深，客户切换成本极高，粘性强 |
| **下游晶圆厂** | 18%左右 | 量大但利薄，需持续资本开支 |

### 5.3 产业链关键变量：磨料自主化（安集的护城河补强）

- 过去国产抛光液"号称国产、核心磨料进口"，利润被上游卡死且有断供风险（AGC-TW断供事件警钟）
- **安集已突破**：参股公司硅溶胶多款已量产应用；自研氧化铈磨料多款通过客户验证、进入量产供应；自建纳米磨料产线稳定供货
- 芒格判断 [B级，中高置信]：**上游磨料自主可控是安集区别于所有国内同行的"第二条护城河"**——不仅防断供，更意味着成本结构改善与配方Know-how的完整闭环。这是巴菲特/芒格看重的"供应链内化"特质。

### 5.4 客户结构（双刃剑）

- 前五大客户贡献70–80%收入，中芯国际占比超50%（早期约六成）
- **正面**：认证壁垒深，客户一旦认证极少切换——"客户即护城河"
- **负面**：客户集中度高，中芯国际资本开支周期直接决定安集短期业绩；单一大客户依赖是芒格反感的"集中风险"

## 六、芒格式行业定性与评分

### 6.1 生意属性打分（10分制）

| 维度 | 得分 | 理由 |
|---|---|---|
| 行业空间 | 6.5 | 全球市场小（38亿美元），但中国高增（26.5% CAGR），且"耗材"模式可重复 |
| 竞争格局 | 8.5 | 美日垄断80%但安集是全球唯一中国玩家；国内"一超"格局 |
| 护城河 | 8.5 | 认证壁垒+配方Know-how+客户粘性+上游磨料自主化，四重叠加 |
| 增长确定性 | 8.0 | 国产替代（30%→50%）+存储扩产+HBM，三引擎 |
| 行业波动性 | 6.0 | 半导体周期波动大，但耗材端相对设备端平滑 |
| **综合** | **7.5** | **好行业里的好公司，但行业本身不大** |

### 6.2 芒格核心定性

> **"安集是在一个不太大的池塘里长成的大鱼，它的价值不在于池塘有多大，而在于它是唯一一条能游进全球主流供应链的中国鱼。国产替代给了它确定的成长性，磨料自主化给了它对抗上游的底气。但正因为它好，市场给了它极高的价格——芒格的纪律是：好公司≠好价格。"**

**关键投资结论**：
1. **行业面**：半导体材料国产替代是未来3-5年确定性最强的产业趋势之一，安集是CMP抛光液国产替代的唯一最大受益者
2. **竞争面**：全球对手（Cabot/Fujimi/KCTech）在高端各有领先，但安集的综合卡位（全品类+全球主流客户+磨料自给）无国内对手，全球可类比"追赶中的挑战者"
3. **风险面**：小市场天花板、客户集中（中芯>50%）、H股发行摊薄、成熟制程价格战
4. **估值面**：PE 69.6倍（TTM约95倍）处于历史高位区间，已透支2026-2027年高增长，安全边际不足
