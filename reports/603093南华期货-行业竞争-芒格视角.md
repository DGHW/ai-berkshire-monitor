# 南华期货（603093.SH）行业竞争格局分析——芒格视角

> 分析框架：芒格"行业竞争格局"五问——这门生意在行业里处于什么位置？护城河多宽？行业天花板多高？格局友好还是内卷？这门生意值不值得长期持有？
> 报告人：industry-researcher-603093（芒格视角）
> 数据截止：2026-08-10（现价为2026-08-08收盘价）

## 〇、核心结论速览

| 维度 | 判断 |
|---|---|
| 行业性质 | 期货公司=**"通道+利息+服务"生意**：经纪同质化、价格战激烈（量增价跌），强周期；细分蓝海在境外业务/风险管理/资管 |
| 公司地位 | 非金融系期货公司**全国第1**（2023总收入行业第8）；**境外收入行业第1**（2024）；横华国际净利4.6亿占归母净利94.68% |
| 行业天花板 | 期货市场资金总量2万亿→2.8万亿（2026-05单日），成交额2026H1同比+42%，**规模天花板持续打开**，但150家分食110亿净利，单体天花板受牌照与资本约束 |
| 行业景气 | **高景气周期**：2026H1行业净利69.08亿(+36.15%)；但高景气由"地缘冲突推升波动率"驱动，属周期高位而非稳态 |
| 增长引擎 | 境外金融服务（中企出海套保+全球清算，毛利率66.26%）、品种扩容（LNG/电力期货）、风险管理（场外衍生品+基差+做市）、资管 |
| 护城河 | 全球牌照网络（19个交易所会员+15个清算资质）+20年先发优势+LME/ICE/伦交所资质+资本扩容（H股募资24亿港元），**境外厚、境内薄** |
| 芒格判定 | **"中上等生意、强周期行业"**——境外业务是差异化护城河（中企出海卖水人），但本质仍由市场波动率驱动，盈利不可线性外推 |
| 击球区 | 🟡 现价18.05元基本反映正常化价值+2026高增预期，无显著折价；等回调至16.5元或中报/波动率见顶后验证 |

**一句话**：期货行业整体是"150家分食110亿净利"的内卷通道生意，但南华用20年把境外业务（横华国际）做成了占净利95%的差异化金矿——这是它区别于永安/瑞达/弘业的唯一变量；然而2026年利润爆发由地缘冲突推升的波动率驱动，芒格会说"别把周期高位当稳态"。

**结构判断**：①行业总盘子小（150家全年仅110亿净利，平均每家0.73亿），但头部集中（56家公司合计净利93亿，前10名均超1亿，19家破亿）；②2025年净利+16.66%而营收仅+2.22%，说明利润改善来自**降本+利息收入+投资收益**而非佣金率提升；③**期货公司牌照已冻结多年，存量竞争、无增量牌照**。

### 1.3 佣金率长期趋势（核心痛点）

| 区间 | 成交量 | 成交额 | 手续费收入 | 结论 |
|---|---|---|---|---|
| 2013-2023 | **+312%** | **+113%** | **仅+88%** | 量增价跌，佣金率长期下行 |
| 2025年 | 南华经纪手续费5亿(+12.10%) | — | 行业增速更高 | 南华经纪增速**跑输行业**（费率下滑所致） |

**佣金率是行业的达摩克利斯之剑**：期货公司为抢客户普遍"零手续费+高返佣+利息返还"，导致"量增价跌"。**转折信号**：2025-08-01中期协发布《期货公司经纪业务不正当竞争行为管理规则（征求意见稿）》，禁止低于交易所标准/低于服务成本的费率，2026年落地。**反内卷若严格执行，行业经纪利润率有望企稳，但弹性有限**（反内卷历史上普遍执行打折）。

**竞争位次**：2025年上市期货公司中，永安>瑞达>南华>弘业（净利）；但**2026Q1南华反超瑞达**（2.05亿 vs 2.04亿）。南华2025年营收行业第2、净利第3（4家上市口径），全市场口径位列前10（中信10.72、国君9.36、永安6.52、中信建投6.51之后）。**南华的差异化：别人卷境内，它卷全球。**

### 2.2 南华 vs 核心对手的业务结构对比

| 维度 | 南华期货 | 永安期货 | 瑞达期货 | 券商系(中信/国君) |
|---|---|---|---|---|
| 经纪（境内） | 4.75亿(34.2%)，跑输行业增速 | 第一大收入，规模第一 | 最大营收来源 | 依托券商通道，市占12%+ |
| **境外业务** | **7.58亿(54.6%)，毛利率66.26%，行业第1** | 有布局但非主力 | 无 | 中信近年加大，但非核心 |
| 资管 | 南华基金亏0.17亿（拖累） | 有 | **爆发式增长（最大亮点）** | 弱于公募系 |
| 风险管理 | 南华资本净利仅0.01亿（场外新增名义本金749亿） | 强（创利主力） | 强（三大业务线之一） | 依托母公司资本 |

**核心洞察**：南华是"**境外单腿走路**"——横华国际2025年净利4.6亿占公司归母净利94.68%；境内业务（经纪+风管+资管）整体仅贡献约5%利润，且南华基金还在亏钱。**这意味着南华的估值本质是"中国出海金融服务的期权"+"境内期货龙头壳"的叠加。**

### 2.3 芒格式护城河评估

| 护城河来源 | 强度 | 说明 |
|---|---|---|
| 境外牌照网络（19个全球交易所会员+15个清算资质） | **强** | 香港/芝加哥/新加坡/伦敦四大中心、覆盖三大时区，全球清算牌照重资产+监管审批，短期难复制 |
| 先发优势 | **强** | 2006年首批出海（全国首家A股上市期货公司），20年国际化积累，董事长罗旭峰亲历 |
| 资质纵深（2025-2026新增） | **中强** | LME首批仓单持有机构（2025-07）、欧洲ICE清算会员（2025-08）、伦敦证交所非交易会员+新证券资质（2026-07） |
| 资本金支撑 | **中强** | H股募资净额12.03亿港元+2026-02增资12.03亿港元，全部充实横华国际资本，境外客户权益233亿港元（2025末） |
| 境内经纪 | **弱** | 价格战红海，佣金率下行，经纪手续费增速跑输行业 |
| 客户转换成本 | **弱** | 通道业务同质化，互联网开户降低切换成本 |

**结论：护城河"境外厚、境内薄"。** 境外业务有真实的牌照+先发+资本壁垒（类似"中企出海的卖水人"），但境内基本盘（经纪/风管/资管）乏善可陈，护城河宽度依赖单一境外主体，**地域集中与盈利集中风险并存**。

## 三、核心竞争者威胁

### 3.1 佣金率下行（行业性威胁，持续性：中高）
- 量增价跌：2013-2023成交量+312%但手续费收入仅+88%；
- 2025-08反内卷新规出台、2026年落地，**中期边际利好**，但历史经验（券商佣金战）显示执行有折扣；
- 南华2025年经纪手续费5亿(+12.10%)仍**跑输行业成交增速**，印证境内费率承压——这是其境内业务的长期吸血点。

### 3.2 券商系期货挤压（境内业务，持续性：高）
- 中信期货净利10.72亿、国泰君安期货净利9.36亿，均为南华4.86亿的**2倍以上**；
- 券商系依托母公司的资本、投研、客户与网点资源，在境内经纪、风管、机构业务上全面碾压纯期货系；
- **但券商系的境外布局相对滞后**（中信在推进，尚未成规模），这是南华相对券商系的暂时性护城河——**窗口期红利，需警惕中信等加码境外**。

### 3.3 境外业务竞争（南华核心战场，持续性：中）
- 中企出海浪潮下，中信期货、永安期货、以及外资期货（摩根大通、高盛等）均在加大境外布局；
- 南华的相对优势=先发20年+全链条能力（船运+报关+仓单+套保+仓单融资）+港交所LME仓单持有机构（首批）；绝对壁垒仍受制于全球宏观与监管环境（如欧美对中国金融机构准入的潜在收紧）；
- **瑞达期货"券商梦"**（5.89亿参股申港证券）反映行业向券商/金融控股方向整合的趋势，券商系对纯期货系的资本碾压将进一步加深。

### 3.4 金融科技与合规（中性）
- 互联网开户+程序化交易普及压低手续费、提升服务同质化；
- 监管处罚趋严（瑞达2026-08因互联网营销违规被责令改正、总经理被点名；南华2025年也曾被处罚、高管涨薪引发舆论）——合规成本上行，行业出清加速，对头部规范公司反而是利好。

## 四、行业趋势：三大结构性红利 + 一个周期开关

### 4.1 结构性红利
1. **境外业务（最大成长极，也是南华的主场）**：中企出海+套保需求爆发，南华境外客户权益233亿港元（2025末，2022末+49.6%）、境外资管34亿港元(+70%)；2026H1业绩+62~75%主要由此驱动；"一带一路"定价权争夺叙事（LME仓单、ICE会员）打开想象空间。
2. **品种扩容**：证监会明确"推动液化天然气期货期权上市，支持电力等基础性、战略性期货品种研发"（2026-06陆家嘴论坛吴清表态）；上海明确"加快推出LNG期货、研发电力/算力期货"。**新品种=增量保证金+增量手续费**，行业天花板持续打开。
3. **风险管理/场外衍生品**：2025年场外衍生品新增名义本金高增（南华单家749亿），"保险+期货"、基差贸易、做市业务扩容；产业客户持仓占比持续提升——这是从"通道"向"服务"转型的必经之路。

### 4.2 周期开关（关键）
- 期货公司盈利与**全球市场波动率**高度正相关：2026年地缘冲突+海外利率反复+大宗商品供需分化→波动率抬升→成交量+42%、行业净利+36%；
- **波动率是均值回归的**：2025年波动率回落时，南华全年营收仅+2.45%、净利仅+6.18%，与2026H1的+62~75%形成鲜明对照——**同一家公司，两个世界**。
- 芒格视角的纪律：对强周期生意，**估值必须用正常化盈利**，不能把周期顶部的EPS线性外推。

## 五、产业链分析：价值分配

```
上游（交易所/清算所）→ 中游（期货公司）→ 下游（投资者/产业客户）
上期所/大商所/郑商所/中金所    南华/永安/中信等150家    套保企业/机构/散户
ICE/LME/港交所(境外)         横华国际(境外主体)       出海企业(南华核心客户)
```

| 环节 | 参与者 | 利润分配 | 议价力 |
|---|---|---|---|
| 交易所（境内） | 上期所/大商所/郑商所/中金所 | **拿走产业链最大蛋糕**（交易所利润远高于全部期货公司之和） | 垄断，定价权集中 |
| 清算所（境外） | ICE/LME/港交所 | 固定清算费 | 垄断 |
| **期货公司（境内经纪）** | 150家 | 手续费+客户保证金利息，**薄且同质化** | 弱（价格战） |
| **期货公司（境外服务）** | 南华/中信等少数 | **境外毛利率66.26%，产业链最肥的一段** | 中强（牌照+先发） |
| 风险管理子公司 | 95家 | 场外衍生品/基差/做市，资本消耗型 | 中 |
| 下游客户 | 产业套保企业/机构 | 用风险管理工具对冲价格波动 | 套保刚需，对费率敏感但粘性随服务深化提升 |

**芒格式价值分配结论**：
- 境内环节：**交易所吃大头，期货公司吃残渣**（150家分110亿净利，而交易所利润数百亿）——这是通道生意的宿命；
- 境外环节：**南华吃到了产业链最肥的一段**（66%毛利率、占净利95%），因为它提供的不是通道，而是**中企出海不可或缺的风险管理基础设施**（全球清算+仓单+套保一体化）；
- 但要注意：**客户保证金利息收入**（负债率92.6%对应的客户保证金）是期货公司隐性利润池，低利率环境下这块承压；**境外业务的利润对波动率的beta极高**，周期性显著。

## 六、芒格视角判定：期货公司是"一门好生意"吗？

### 6.1 五力模型总结

| 竞争力量 | 强度 | 说明 |
|---|---|---|
| 行业内竞争 | **高** | 150家同质化经纪，价格战延续数十年，仅2025-08起反内卷边际改善 |
| 新进入者 | **低** | 牌照冻结20余年，无新增；但券商系通过并购/子公司曲线进入 |
| 替代品 | **中** | 场内衍生品vs场外/OTC/跨境互换；银行/券商衍生品业务分流 |
| 供应商（交易所）议价力 | **极强** | 交易所垄断规则与费率，期货公司无谈判空间 |
| 买方（投资者）议价力 | **强** | 通道同质化，散户/机构均可压价（零手续费时代） |
| **综合（境内经纪）** | **差生意** | 通道+周期+价格战，内卷型 |
| **综合（境外服务）** | **中上等生意** | 牌照+先发+刚需，差异化明显，但强周期 |

### 6.2 芒格判定：南华是"中上等生意里的强周期玩家"，非"伟大生意"

**加分项（好生意的证据）**：
- 境外业务构成**真实护城河**：19个全球交易所会员+15个清算资质+20年先发+LME/ICE/伦交所资质，资本扩容24亿港元——这是**牌照型垄断租金**，竞争对手短期无法复制；
- 高毛利（境外66.26%）+高净利率（2026Q1 47.4%），**商业模式有印钞机特征**；
- **中企出海是十年维度的结构性需求**（不只是周期），南华是"出海金融服务第一股"，享受稀缺性估值溢价；
- 2026H1预告净利3.75~4.05亿(+62~75%)，业绩弹性大。

**减分项（伟大生意的障碍）**：
- **强周期是原罪**：利润由市场波动率驱动（2025年营收仅+2.45% vs 2026H1 +60%+），波动率均值回归时业绩会显著回落——芒格会怀疑"这门生意的盈利可预测性"；
- **盈利集中度畸形**：横华国际单主体贡献94.68%净利，境内业务（经纪/风管/资管）几乎不赚钱，南华基金还在亏损——**鸡蛋全在一个篮子里**；
- **境内基本盘内卷**：经纪手续费增速跑输行业，佣金率长期下行，反内卷改善有限；
- **券商系碾压**：中信净利是南华2.2倍，且境外布局在加速，南华的窗口期红利需要资本和先发持续兑现；
- **监管与地缘风险**：境外业务受国际监管环境、中美博弈、汇率波动影响大（波动率既是利润来源也是风险来源）。

> **芒格原话的映射**："我们寻找的是能在未来10-20年稳定产生现金流的生意。"南华的境外业务有牌照租金+结构需求的确定性，但盈利跟随波动率大起大落，更像"高质量周期的黄金开采商"而非"稳定的收费桥"。**值得在便宜时买入，但绝不应为2026年周期顶部的利润支付高价。**

### 6.3 行业研究员视角的风险清单（供风险同事交叉验证）
1. **波动率均值回归**：地缘冲突缓和→全球波动率回落→成交量与境外业务利润双杀（2025年已示范：营收+2.45%）；
2. **盈利单一主体依赖**：横华国际占净利94.68%，境外监管/汇率/资本管制任一环节出问题即伤筋动骨；
3. **券商系境外加码**：中信等若加大境外投入，南华先发优势被稀释；
4. **境内基本盘持续失血**：佣金率下行+资管（南华基金亏损）拖累；
5. **H股解禁与AH价差**：H股1.08亿股（发行价12港元）解禁后存在抛压；2025-12上市时国际发售仅0.99倍认购（认购不足），说明国际投资者认可度有限。

## 量化结论

- 内在涨幅: **+10%**（中性情景正常化净利6亿×22x合理PE=132亿≈18.4元 vs 现价18.05元仅+2%；乐观情景2026E净利8亿×18x=144亿≈20.1元即+11%——取中性~乐观中枢。**芒格纪律提示：若按周期顶部EPS线性外推给20x+则会严重高估，故保守情形（波动率回落、正常化5.5亿×20x=110亿≈15.3元）存在-15%回撤风险**）
- 击球区: 🟡 期货行业整体是"150家分食110亿净利"的内卷通道生意，但南华以境外业务（横华国际净利占94.68%、毛利率66.26%）实现差异化，牌照+先发+资本构成真实护城河，享受中企出海结构性红利；**弱点在强周期（利润由波动率驱动）+盈利单一主体集中（境内基本盘几乎不赚钱）**——现价18.05元已反映2026高增预期，无显著安全边际，等回调或中报验证后再定
- 目标建仓价: **16.5 元**（对应2026E净利8亿的约15x PE / 正常化净利6亿的约20x PE，市值约118亿——接近中性内在价值打9折，留出波动率回落的缓冲）
