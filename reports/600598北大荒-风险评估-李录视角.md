### 1.2 近年管理层改善评估（2014-2026）

**正面**：
- 2012年12月新管理层到位后"止血止亏、关停并转"：剥离米业、停产纸业/希杰、麦芽出租、鑫亚清理整顿，主业归农；
- 盈利连续12年修复：2015年后专注"耕地发包"收租模式，2022-2025年净利9.75→10.64→10.87→11.66亿稳定增长；
- 高分红：2025年现金分红9.78亿、**分红率83.84%**、累计派现募资比751.83%（种植业行业第1）；
- 负债结构干净：2026Q1有息负债率仅0.09%，账上现金+理财约38亿。

**反面（必须扣分）**：
- **税务合规是反复发作的硬伤**：2018年补税3.06亿（2016-2017年企业所得税，银行账户曾被冻结）；2026年6月再次被追缴14.1亿（2021-2025年企业所得税10.24亿+滞纳金3.86亿）。**2024年7月公司还在投资者互动平台声称"目前不存在需要补税的情况"**，一年内即被证伪——管理层的税务判断力与诚信记录存疑；
- 连续两轮同类型税务问题（非职工承包费不享受免税），说明内控与政策跟踪机制至今未建立到位；
- 大股东绝对控股64.14%，职业经理人市场化激励有限，决策以行政考核为导向，中小股东话语权弱。

**管理层结论**：能力上"止血"成功、近年经营稳健；诚信与合规上是"有前科、仍再犯"——治理改善未达到一流标准，按李录标准属于"需要更高安全边际补偿"的类型。

## 二、治理结构

| 维度 | 情况 |
|---|---|
| 控股股东 | 黑龙江北大荒农垦集团持股**64.14%**（11.40亿股/总股本17.78亿） |
| 实控人 | 财政部（100%持有集团） |
| 土地权属 | 上市公司**不拥有土地所有权**（国有土地归国家），通过承包方式取得**耕地承包经营权**（1158万亩耕地/总面积1296万亩），再发包给家庭农场收取土地承包费——本质是"二级地主"收租模式 |
| 与集团关系 | 上市公司土地经营权来源于集团体系；历史上米业剥离、土地使用权等均与集团关联交易，定价公允性有过被质疑记录 |
| 分红政策 | 2025年10派5.5元，分红率83.84%，股息率4.56%（按12.06元）；连续多年高分红，累计派现121.3亿 vs 募资16.1亿 |
| 关联交易风险 | 土地承包费（37.5亿）为公司向农户收取；支付给集团体系的土地/管理相关成本不透明，存在定价调节空间 |

**治理结构结论**：股权集中稳定、分红慷慨是优点；但"上市公司-集团-财政部"三层架构下，**土地资产在集团体内、盈利在上市公司体内**，未来资产注入既是期权也是关联交易风险点。

## 五、下行风险量化（最坏情景测算）

**正常稳态（已含税负冲击）**：
- 2025年净利11.66亿 → 补税后未来每年新增所得税约2.05亿（补缴10.24亿/5年=年均2.05亿税 → 对应应税承包费8.2亿/年 → 未来每年×25%≈2.05亿）
- **稳态净利中枢降至约9.5亿/年**（机构测算区间8-9亿，本报告取9.5亿偏乐观口径）

**2026年一次性冲击**：
- 上半年预亏5.37亿（Q2单季亏损超11亿，上市以来最差单季）；全年预计亏损约2-4亿
- 货币资金（发完分红后22.26亿）已不足支付补缴款14.1亿，需动用理财资产（交易性金融资产36.5亿）

**最坏情景（气候灾害+粮价下跌+补贴退坡叠加）**：

| 冲击 | 假设 | 净利影响 |
|---|---|---|
| 气候灾害 | 承包费下降10%（农户减产违约） | -3.7亿 |
| 新增税负 | 非职工承包费正常缴税 | -2.0亿 |
| 农资/贸易亏损 | 投入品价格下行+坏账 | -1.0亿 |
| **最坏情景净利** | | **约2.8亿（正常年）**；若叠加2026年补税则**当年亏损5-6亿** |
| 基准情景净利 | 无重大灾害 | 9.5亿 |
| 波动区间 | | 2.8亿~9.5亿，振幅大 |

**PE 17.7能否支撑？**
- 按12.06元、2025年EPS 0.66元：静态PE 18.3（未反映税负）；
- 按补税后稳态EPS 0.53元（9.5亿）：**真实PE约22.6**；
- 按机构悲观稳态8亿（EPS 0.45）：PE 26.8；
- 2026年实际亏损，TTM PE失真。
**结论：17.7的PE显著高估了补税后的盈利中枢，当前估值不便宜。**

## 六、李录评估框架（买入成本/基本面下行/治理诚信/长期确定性）

1. **买入成本（安全边际）**：每股净资产4.50-4.83元，PB 2.82倍——对"收租型"国企偏高（市场支付了土地隐性价值+资产注入期权溢价）；股息率4.56%尚可但税负后分红能力将缩水20-25%。**无安全边际。**
2. **企业基本面下行风险**：税收优惠永久性取消（每年-2亿）、托市价长期下行、气候风险集中、毛利率8连降——**基本面存在真实的、已兑现的下行压力**。
3. **治理与诚信**：历史有*ST、保留意见、罚单、利益输送质疑、两次补税（2018+2026）、声明与实际不符（2024年称无需补税）——**按李录标准"治理不通过"，需要大幅折价补偿**。
4. **长期确定性（10年后）**：
   - **能活**：粮食安全是国家战略，北大荒"国家队"身份+1158万亩稀缺黑土，收租模式10年后大概率仍在；
   - **颠覆收租模式的三个因素**：①土地流转改革全面放开→其他区域低成本土地供给增加，挤压其稀缺性溢价；②转基因在黑龙江放开→单产提升（+8.9%）→粮价下行→承包费提价空间被压；③人口老龄化+人均大米消费量长期下降→粮价承压→"地主"提价权被削弱；
   - **最大变量是资产注入**：集团8310万亩体外土地若注入，EPS大幅增厚（利好）；但注入定价若不透明，历史教训（米业低价剥离）可能重演（利空）。

**李录式结论**：北大荒是一门"有护城河但增长平庸、治理有瑕疵、政策依赖度高"的收租生意。好生意（收租）+ 中等管理（税务合规差）+ 差价格（PB2.8/PE22.6）→ **不具备"买入成本"优势，属于"看得懂但不便宜、且刚踩了雷"的标的。**

## 量化结论

**核心估值假设**（取保守口径）：
- 补税后稳态净利：9.5亿/年（若承包费提价能覆盖，乐观至10.5亿；若气候灾害+粮价下行，悲观至6亿以下）
- 给予15倍PE（成熟收租型+低增长+治理折价+政策依赖，不给成长溢价）
- **内在价值 = 9.5亿 × 15 / 17.78亿股 ≈ 8.0元**（区间7.0-9.5元）

- 内在涨幅: **(8.0/12.06 - 1) ≈ -33.7%**（对当前价12.06元）
- 击球区: 🔴 **红色**——刚发生永久性税负冲击（年盈利中枢-18%~-25%）、2026年确认亏损、治理存疑、无安全边际，当前估值未反映盈利下移
- 目标建仓价: **6.4元**（内在价值8.0×0.8）
- 二次补仓价: **5.2元**（内在价值8.0×0.65）
- 数据核验: ✓ 全部关键数据（补税14.1亿、2026H1预亏5.37亿、持股64.14%、承包费37.5亿、分红率83.84%、PB2.82、股价12.06元）均经≥2个独立来源（上交所公告、证监系媒体、东财/新浪/雪球数据、税务文件）交叉验证；速评卡ROE 28%已纠正为14.9%

**风险提示（本报告最需要关注的三点）**：
1. **补税14.1亿是"永久性盈利中枢下移"，不是一次性利空出尽**——未来每年还要多缴约2亿所得税（从11.66亿中枢降到9.5亿），市场可能已部分消化但未必充分；
2. **公司尚未给出应对方案**：是否提高承包费、是否调整承包结构（职工化）、是否向集团争取补偿，8月28日中报和后续公告是观察窗口；
3. **正面期权**：集团8310万亩土地资产注入若落地（4500万亩核心耕地估约9000亿），将彻底改写估值框架——这是当前股价相对内在价值的唯一支撑，也是散户博弈的核心，需警惕2013年米业"低价剥离"式定价不透明风险重演。
