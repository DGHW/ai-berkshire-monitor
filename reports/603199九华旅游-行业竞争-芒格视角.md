## 一、行业规模与增长：大行业、缓增长、政策友好

### 1.1 行业大盘（官方数据）

| 指标 | 数值 | 数据来源 |
|---|---|---|
| 2025年国内居民出游花费 | **6.3万亿元**，约占居民总消费支出15.2% | 中国网（2026-05） |
| 2025年前三季度国内出游 | 49.98亿人次 | 文旅行业报告（2025-11） |
| 2025年入境游客 | 1.545亿人次（+17.1%）；外国游客3517万人次（+30.6%） | 文旅部2025年统计公报（2026-06） |
| 旅游及相关产业增加值占GDP | 约4.35% | 中国网（2026-05） |
| 2026年五一假期 | 全国出游3.25亿人次（+3.6%）、花费1854.9亿（+2.9%） | 文旅部（2026-05） |

**解读**：
- 行业总量巨大且仍在增长，但**增速已进入低个位数区间**（2026五一全国出游仅+3.6%），整体市场从"高速增长"转向"存量内卷+结构性分化"。
- **入境游是最大增量**：2025年外国游客+30.6%，政策上持续放开免签，对名山景区是中长期利好（黄山/峨眉山均已在抢抓入境游）。
- 政策基调明确友好：国务院2025年1月印发《关于进一步培育新增长点繁荣文化和旅游消费的若干措施》，文旅列为扩内需抓手，各地发消费券、推免票。

### 1.2 佛教文旅/寺庙经济：千亿级细分赛道

- 2025年寺庙经济整体市场规模**突破千亿**，年均增速保持在两位数（约10%）——观察家/行业报告口径（2026-08）。
- 驱动因素：年轻人"上香/祈福/求手串"成为情绪消费出口（灵隐寺、雍和宫单日客流爆满）；九华山、峨眉山等佛教名山直接受益。
- **结构变化**：从"门票+香火"向"深度祈福游、禅修养心、康养度假"升级，停留时间与客单价双升——对九华旅游这类经营"山上吃住行"的上市公司是结构利好。

### 1.3 门票降价/免票潮（行业最重要的政策性变量）

- 文旅部口径：**2025年国内5A景区门票收入占比已降至28%，餐饮、住宿、文创等二次消费占比超60%**。
- 各地免票潮持续：江西庐山整月免票、安徽黄山对女性游客阶段性免费、衢州13个核心景区打包开放。
- **对九华旅游的特殊意义（关键差异化）**：九华旅游**不经营进山门票**（门票归九华山风景区管委会所有），上市公司核心资产是**索道缆车、旅游客运、酒店、旅行社**。因此门票降价/免票趋势对公司**并非利空而是中性偏利好**——降低游客进入门槛→客流放大→索道/客运/住宿需求提升。这与峨眉山A（自营游山票）形成鲜明对比：峨眉山2025年因"中低山区免票+徒步游客占比扩大"直接导致营收-7.88%、净利-6.23%。

**要点提炼**：
1. **四大佛教名山中仅两座上市**：峨眉山A（1997）、九华旅游（2015）；普陀山IPO于2018年因"佛教商业化"争议被撤回，五台山至今未上市。**稀缺性本身就是准入门槛**——九华山的竞争对手要么不在A股，要么是不同属性的山。
2. **2025年九华旅游是名山景区中少数"量价齐升、营收净利双增"的标的**：黄山游客创历史新高但"增收不增利"（散客化/优惠化侵蚀客单价），峨眉山量增价减，唯有九华山在客流+8.77%背景下营收+14.93%、净利+14.42%——**全产业链（索道+客运+酒店+旅行社）一体化运营的协同效应在兑现**。
3. **佛教信仰属性带来结构性差异**：九华山是地藏菩萨道场，香客/祈福游的**复游率与刚性需求**显著高于纯观光山（"有愿必还"逻辑），对宏观消费降级的抗性更强。峨眉山2024年入境游客+202%亦证明佛教名山对入境客群的吸引力。
4. **体量对标**：九华旅游营收/净利约为黄山旅游的42%/73%——体量小、弹性大，但利润规模与净利率（24.2%）均优于峨眉山（23.6%）。

## 三、核心竞争者威胁：谁在分流九华山的客流与利润？

### 3.1 景区间竞争（游客分流）
- **直接竞争有限**：佛教名山客群具有强目的地绑定属性（朝圣/还愿），游客"去九华山"与"去峨眉山"并非同质替代关系；长三角客群（九华山腹地市场）去五台山/峨眉山的地理与时间成本高。**真实竞争来自"非佛教"文旅新目的地**：网红城市（淄博/哈尔滨/重庆）、主题公园、县域"宝藏"景区，分流的是游客的**假期预算与出行天数**，而非信仰性客流。
- **九华山自身防御力**：2025年游客+8.77%、2026春节53.85万人次（较2025年春节47万+14.6%）、2025五一+29.93%——在行业低个位数增长背景下持续跑赢，说明稀缺资源+信仰属性的引流能力强劲。

### 3.2 区域竞品：周边文旅资源对九华山的虹吸
- 池州境内黄山、宏村、天柱山等皖南文旅集群既是分流对手，也是"环九华山片区"协同受益者。**池黄高铁（2024年4月开通）改变格局**：一年发送旅客超300万人次，九华山站成为长三角两小时圈直达点；**合肥—池州铁路在建**，将进一步提升通达性。交通改善带来的**增量客流 > 区域分流损失**（青阳县2025年游客+近两成佐证）。

### 3.3 OTA/平台议价（携程、美团、抖音）
- 景区公司对OTA的议价能力总体偏弱（佣金侵蚀），但九华旅游的**客流以信仰性散客+旅行社团为主**，且自有旅行社业务（2025年+23.9%）可作为分流通道。公司2026年7月公告正推进**旅行社板块结构性重塑与专业化整合**——主动应对渠道变局。
- 更关键的护城河：**索道/客运属于"山上唯一通道"型垄断**，OTA无法替代，游客必须消费，平台只能截流门票/住宿预订佣金，无法撼动交通型业务的基本盘。

### 3.4 新项目威胁/机会
- **狮子峰客运索道在建**（2025年前三季度管委会重点推进项目）——新索道意味着新增客流承载与收入曲线，是稀缺的"第二增长曲线"。
- 传统山地景区的**承载量硬约束**（环保、限流）是双刃剑：既保证稀缺性溢价，也封死爆发式增长可能。

## 五、产业链分析：价值分配谁占优？

```
游客 ──▶ OTA/旅行社（携程/美团/自有旅行社）
              │ 佣金/差价（~8-15%）
              ▼
        九华旅游（上市公司）
         ├─ 索道缆车（毛利85.4%，独家经营权）◀── 最赚钱
         ├─ 旅游客运（毛利52.6%，景区内交通垄断）◀── 次之
         ├─ 酒店（毛利13.4%，山上8家酒店，旺季供不应求）
         └─ 旅行社（毛利10.6%，低毛利引流通道）
              ▲
        九华山管委会（门票+资源授权，不在上市公司内）
```

**价值分配判断（芒格式"产业链利润往哪走"）**：
1. **利润最厚的环节在"山上交通"**——索道（85.4%毛利）+客运（52.6%毛利）合计贡献约六成毛利润，而这两项是**政策特许+地形限制+资本门槛三重垄断**的生意，类似"收费桥梁"，不受门票降价、OTA议价、消费降级影响，且边际成本极低。
2. **低毛利板块（酒店13.4%、旅行社10.6%）拖累整体ROE**——这是公司ROE"只有"13.55%而非20%+的原因。若管理层聚焦索道/客运、弱化低效板块，盈利质量仍有改善空间（但国企属性下难以激进剥离）。
3. **资源授权方（管委会）拿走门票大头**，上市公司赚"服务环节"的钱——结构上略逊于黄山/峨眉山（门票自营），但**换来的是对免票潮/降价政策的免疫**，一进一出打平甚至占优。
4. **价值分配结论：产业链中"唯一通道型基础设施"是最大价值捕获者，九华旅游恰好卡位这一环节。**

## 六、芒格视角判定：九华旅游是一门好生意吗？

### 6.1 用芒格"好生意"清单检验

| 芒格检验项 | 判定 | 依据 |
|---|---|---|
| 是否拥有不可复制的护城河？ | ✅ 强 | 四大佛教名山唯一性+索道独家经营权+信仰复购 |
| 是否需要持续大额资本开支？ | ✅ 轻资产 | 存量索道/酒店基本折旧即可，狮子峰索道是稀缺扩张 |
| 是否被政府/政策"管制利润"？ | ⚠️ 部分 | 门票不在报表，索道定价受政府指导，但盈利能力强 |
| 定价权（能否提价跑赢通胀）？ | ⚠️ 中等 | 门票/索道价格受发改委约束，提价慢，靠量不靠价 |
| 增长天花板 | ❌ 明显 | 山地承载量+客流增速放缓（2026Q1营收+0.17%） |
| 现金流与负债 | ✅ 优秀 | 经营现金流3.12亿（+19%），负债率12.9%，现金奶牛 |
| 管理层与治理 | ⚠️ 风险 | 国企+2026年反腐风暴（副总经理被留置），治理需跟踪 |
| ROE质量 | ✅ 良好 | 2025年13.55%，无杠杆驱动，纯经营盈利 |

### 6.2 核心结论：**"优秀的现金牛"，但不是"伟大的成长股"**

- **好生意的部分**：索道+客运是教科书级的"收费桥"型垄断资产，毛利85%/52%，现金转化率高，零负债，40%分红。这符合芒格"寻找拥有定价权、低成本、不需重投入的企业"的标准。
- **天花板的部分**：a) 客流受承载量约束，行业整体进入低个位数增长；b) **2026Q1营收增速骤停（+0.17%）是重要的边际信号**——2025年高铁红利+报复性出行的高基数正在回落；c) 定价权受限（门票/索道受政府指导）；d) 低毛利酒店/旅行社板块拉低整体回报。
- **芒格会怎么想**：这类生意的正确买法是"以合理的价格买入，赚现金流+股息+低速复利"，而非期待爆发。**关键安全边际 = 估值足够低 + 生意足够稳**。当前PE 16.8x、十年8.4%分位、股息率约2.4%，属于"好生意遇上合理偏低价格"，但尚未到"好生意+极低价格"的击球区中心。

### 6.3 增速骤停的行业归因——"量增价减"比"增长停滞"更危险（重要）
2026Q1营收+0.17%、净利+1.31%，叠加2026年2月春节客流53.85万（+14.6%）但公司收入几乎零增长——**量增价减**特征明显：门票优惠/免票区域扩大降低客单价，游客结构向低消费力（徒步/短途/周边）倾斜，二次消费转化率承压。**更危险的是**：客流增长但收入不涨，意味着索道/客运乘次转化率在恶化（免票/徒步分流直接绕过上市公司收入环节），这会直接压制公司最赚钱的两块业务（索道+客运合计贡献约六成毛利）。这与峨眉山2025年遭遇的结构性问题（免票区+徒步分流，营收-7.88%）**同型**，是名山景区行业性趋势而非九华山独有——"客流增长≠公司利润增长"。**8月20日中报是本判断的第一验证点**：若Q2客流持续增长而收入停滞，则量增价减确认；若收入随客流回升，则Q1仅为短期扰动。
