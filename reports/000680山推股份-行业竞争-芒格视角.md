> 基准：2026-08-05收盘约11.11元 / 总市值约167-170亿 / 总股本15.00亿股 / PE(TTM) 13.1倍 / PB约2.5倍

## ⚠️ 头部关键提示（必读）

1. **山推是四家公司中周期位置最好的一个**：工程机械处"复苏中前期"——2026H1挖掘机销量15.23万台（+26.4%），6月单月2.54万台（+35.3%，连续4个月破2万台）；三一/徐工/柳工对主力产品提价3-5%（告别低价内卷）。设备更新周期（2026-2028）+出口高增（H1出口356亿美元，+20.5%）双轮驱动。
2. **但销量高增与开工率低增并存（需反面检验）**：2026年6月工程机械平均开工小时数73.8小时，同比-4.48%——**本轮复苏靠"设备更新替换+出口"拉动，非新增需求**。国内中大挖增速平缓（对应地方债开工差），小挖占77%（靠特别国债）。需求质量不如表观增速光鲜。
3. **估值合理但非低估**：PE(TTM) 13.1倍（10年24.6%分位）、2026E净利14.82亿对应约11倍。增长逻辑已部分被定价，且**汇兑损失（人民币升值侵蚀出口利润）与海外竞争是现实风险**。

## 一、公司定位：推土机利基全球龙头

- **山东重工集团**旗下工程机械板块领头羊（国企，山东济宁），1997年上市，2026年5月H股发行获证监会备案（融资扩张）。
- 市占率（弗若斯特沙利文，2025年）：**推土机全球份额10.2%、中国份额63.0%、全球工程机械份额仅0.9%**。
- 产品矩阵：推土机（绝对主力）、挖掘机（战略并购切入）、装载机、道路机械、矿卡（TEH260刚性矿卡）、新能源混动（DEH100混动推土机）等。
- 海外：13家海外子公司、销售网络覆盖160+国家和地区；**海外销售占比约63%（2025年口径）**，2026年力争海外销售收入105亿元。
- 全球战略：2028年营收225亿 → 2030年300亿 → 2035年500亿（**目标激进，需逐年验证**）。

## 二、工程机械行业格局与周期

### 2.1 行业周期：复苏中前期（四家公司中位置最佳）

| 指标 | 2026年数据 | 判断 |
|---|---|---|
| 挖掘机销量（H1） | 15.23万台，+26.4%（国内+20.4%、出口+33.5%） | 内外共振复苏 |
| 挖掘机销量（6月单月） | 2.54万台，+35.3%，连续4月破2万 | 旺季延续 |
| 工程机械出口（H1） | 356.27亿美元，+20.5%；6月单月64.69亿美元创历史新高（+25.5%） | 出海强劲 |
| 开工小时数（6月） | 73.8小时，同比-4.48% | **警示：需求质量弱于销量** |
| 行业动态 | 三一/徐工/柳工主力产品提价3-5% | 格局改善、告别内卷 |

- 周期驱动：①2016-2020年上轮销售高峰设备进入更新期（2026-2028集中替换）；②出口（一带一路/海外采矿城建）；③国内小挖靠特别国债，中大挖受地方债制约。
- **芒格关注点**：这是典型的"设备更新+出口"驱动的周期回升，不是建筑投资全面繁荣。国内地产基建仍弱，复苏的斜率与持续性依赖出口与更新节奏。

### 2.2 竞争格局

| 领域 | 主要对手 | 山推地位 |
|---|---|---|
| 推土机（国内） | 国产厂商为主 | **第一，63%份额** |
| 推土机（全球） | **卡特彼勒、小松**（合计主导全球高端） | 第三梯队，10.2%份额，主攻性价比/新兴市场 |
| 挖掘机 | 三一、徐工、柳工、卡特、小松 | 后进者（并购切入），无优势 |
| 矿卡/新能源机械 | 同图/湘电等 | 差异化新增长点 |

- **卡位结论**：推土机是利基细分（全球市场体量有限），山推是国内绝对龙头但全球份额小；挖掘机等大品类竞争中不占优。**本质是"小而强"的细分龙头，全球化是其主要成长空间。**

## 三、核心竞争者威胁逐家分析

1. **卡特彼勒/小松（推土机高端威胁）**：全球推土机高端市场霸主，技术/品牌/渠道领先。山推以性价比+新兴市场+本地化服务切入，正面争夺高端份额难度大，但大马力/电动化/智能化是突破点（DEH100混动）。
2. **三一重工/徐工机械/中联重科（同赛道扩容威胁）**：挖掘机/起重机领域巨头，正提价改善盈利。山推在挖掘机领域是追随者，需靠山东重工集团协同（潍柴动力发动机配套）打差异化。
3. **海外本土厂商（新兴市场）**：印度/东南亚/非洲本地组装厂，价格竞争。
4. **汇兑风险（非竞争者但关键）**：人民币升值直接侵蚀出口利润——H1行业出口高增但多家被汇兑吃掉利润，山推海外占比63%，**汇率是比竞争对手更现实的利润变量**。

## 四、行业趋势

1. **设备更新周期（2026-2028）**：确定性最高的国内需求支撑，替换量快速提升。
2. **出海高增延续但斜率放缓**：出口增速20%+（高于2025年8%），海外基建/采矿需求景气；但基数抬升+汇率+贸易壁垒是隐忧。
3. **电动化/智能化**：混动推土机、电动挖掘机（H1电动挖机出口135台）——山推卡位新能源转型，但规模尚小。
4. **国内地产基建拖累**：中大挖增速平缓，复苏高度受制于财政/地方债落地节奏。

## 五、产业链与价值分配

```
上游（发动机[潍柴协同]/液压件/钢材/电池）→ 主机厂（推土机/挖掘机/矿卡）→ 经销/服务网络（160+国家）
→ 下游（基建/矿山/地产/农业/市政）
```

- 价值分配：行业从"低价内卷"转向"提价+服务增值"（三一/徐工提价3-5%），主机厂利润修复中；核心零部件（发动机、液压件）仍部分受制于人，但山推有潍柴协同优势。
- 山推利润来源：推土机国内垄断性份额（63%）提供基本盘+出口高毛利+矿卡/新能源增量。

## 六、芒格视角综合评判

### 6.1 芒格式提问

1. **这是"受迫选择"的生意吗？** 不是。工程机械是强周期制造业，但推土机利基+国内63%份额使其具备一定"细分垄断"特征——接近"平庸行业中不错的细分冠军"。
2. **行业格局在改善吗？** 是。供给出清+龙头提价+设备更新+出口，行业正从底部回升，格局优于前三家分析对象（维生素/硫磺/电解铝均处周期高位，工程机械处复苏中前期）。
3. **竞争优势可持续吗？** 推土机国内垄断可持续（品牌+服务网络+集团协同）；但全球拓展需长期投入，且大品类（挖机）无竞争优势。护城河"细分且不深"。
4. **在周期什么位置买入？** 复苏中前期，PE(TTM)13倍/2026E约11倍，估值合理。**但开工小时数下滑提示需求质量存疑，若出口放缓或汇兑放大，复苏斜率下修。**

### 6.2 评分（满分10）

| 维度 | 评分 | 理由 |
|---|---|---|
| 行业竞争格局 | 6.5/10 | 集中度提升+提价改善，但强周期+国内基建弱 |
| 公司竞争卡位 | 7/10 | 推土机国内63%/全球10.2%细分龙头，但整体份额仅0.9% |
| 行业周期位置 | 6.5/10 | 复苏中前期，优于同批其他三家 |
| 新进入者/竞争威胁 | 6/10 | 卡特/小松高端压制，三一/徐工挖机赛道竞争 |
| 行业长期需求 | 6.5/10 | 设备更新+出海双驱动，但地产基建拖累+汇率风险 |
| **综合** | **6.5/10** | **细分龙头+周期复苏，四家中最积极，但非"一眼胖瘦"的好生意** |

## 量化结论

- 内在涨幅: **+15%**（当前约11.11元/市值约167亿；2026E净利14.82亿给复苏期14-16倍≈207-237亿市值；但开工率弱+汇率风险制约上限）
- 击球区: **🟡 黄色（偏积极）** — 推土机细分垄断+行业复苏+估值合理，是四家公司中竞争卡位与周期位置最佳者；但"销量高增/开工率下滑"的需求质量隐忧+出口汇率风险，尚不到击球区核心
- 目标建仓价: **9.8 元**（对应市值约147亿、2026E净利×约10倍，留出复苏不及预期+汇兑冲击缓冲）
- 二次补仓价: **8.3 元**（对应市值约125亿，出口放缓/开工率进一步下滑的悲观情形）
- 数据核验: **⚠️ 部分跳过** — 挖掘机销量/出口/开工小时数/提价等已用工程机械工业协会+海关+多源验证✓；山推市占率（弗若斯特沙利文）为第三方口径✓；但H股发行进度、2026H1财报（8月底披露）未出，2026E净利为11家机构预测
