## 一、速评卡指标核验（本报告最核心的口径排查）

速评卡给出：**PE 17.2 / ROE年化 19.8% / 市值 905.7亿 / 毛利 30.6% / 净利 17.5% / 负债率 25.3% / 营收增速 7%**。

逐项验算后发现：**速评卡多数指标取自 2026Q1 单季数据（含年化/单季净利率），与全年口径存在系统性偏差**。

### 1.1 工具验证记录

**① 市值验算 ✅**
```
命令：financial_rigor.py verify-market-cap --price 50.76 --shares 17.84e8 --reported 905.7e8 --currency CNY
计算市值：905.6 亿 | 报告市值：905.7 亿 | 偏差：0.02% ✅ 验证通过
```

**② ROE 交叉验证 ❌（速评卡 19.8% 是 Q1 年化陷阱）**
```
命令：financial_rigor.py cross-validate --field roe --values '{"速评卡Q1年化":19.8, "年报2025加权":13.02, "Q1单季加权":4.96}' --unit '%' --ts-code 000538.SZ
  Tushare 独立源：13.07%（年化）
  速评卡Q1年化：19.80%  ← 偏差 +51.8% ❌
  年报2025加权：13.02%  ← 偏差 0.18% ✅
  Q1单季加权：  4.96%   （4.96% × 4 = 19.84%）
  → 共识值（加权中位数）：13.04%
```
**结论：速评卡 19.8% = 2026Q1 单季加权 ROE 4.96% × 4 的年化值（工具验算 19.84%）。2025 年报真实加权 ROE = 13.02%（Tushare 独立验证 13.07%）。ROE 年化口径严重高估，全年 ROE 应为 13% 而非 19.8%。**

**③ 估值验算 ✅**
```
命令：financial_rigor.py verify-valuation --price 50.76 --eps 2.95 --bvps 22.44
PE(TTM) = 50.76 / 2.95 = 17.21x | 盈利收益率 5.81% | PB = 2.26x | 隐含 ROE = 13.15%
```
（EPS-TTM 2.95 = TTM 归母净利 52.56 亿 ÷ 17.84 亿股；TTM 净利 = 2025 全年 51.53 − 2025Q1 19.34 + 2026Q1 20.37 ≈ 52.56 亿）

## 六、安全边际与巴菲特式评价

### 6.1 安全边际要素

✅ **有利项**：
1. 品牌中药双龙头（国家绝密配方之一），百年品牌护城河，定价权极强（核心药品持续提价）；
2. 5.1% 股息率 + 90% 分红率 + 连续 25 年分红，股东回报现金化；
3. 净现金 163 亿（占市值 18%），零金融杠杆，负债率 26%；
4. PE 17.2x 处于自身 10 年 1.6% 分位，且低于同业与行业均值；
5. 盈利质量优秀：现金流/净利 89%、销售收现 110%。

🟡 **不利项/需警惕**：
1. 61% 收入来自 6.7% 毛利率的商业分销，"大象体重"拖累整体 ROE 至 13%（仍低于 15% 的一流标准）；
2. 营收增速仅 2.9%（2025），净利增速 8.5%，**成长性平庸**——属于"收息 + 缓慢复利"型而非"高成长"型；
3. 2026Q1 的高净利率（17.6%）有季节性，全年净利率 12.6%，**不可外推**；
4. 板块情绪极弱（中药指数 3.69% 分位），短期无催化剂，估值修复可能需要以"年"为单位等待。

### 6.2 巴菲特视角总评

> "以合理价格买入伟大公司，好过以便宜价格买入平庸公司。"

云南白药是**"接近伟大、价格合理"**的标的：品牌与盈利质量属一流（若剥离商业板块，工业资产 ROE 高达 40%+），但整体报表 ROE 13%、成长 5-8%，本质是**"高股息、低增速的成熟消费龙头"**。17.2x PE 提供了足够的安全边际——下行有 5% 股息 + 18% 净现金 + 品牌托底，上行靠估值修复到行业均值即可获得 15-30% 空间。**它不是最便宜的票，但大概率是最"睡得着"的票。**
