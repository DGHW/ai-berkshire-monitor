## 一、生意本质（段永平第一问：这到底是一门什么生意？）

**新锐做的是"挖矿人的耗材"——凿岩工具（牙轮钻头、顶锤钎具、潜孔钻具、滚刀）+ 硬质合金，是采矿过程中高频消耗的"铲子"。**

用段氏语言重述：**"淘金的人不一定赚钱，但卖铲子的人大概率能赚到钱。"** 矿业资本开支是周期性的，但矿山只要在产，钻头钎具就必须持续更换——这是**刚需耗材**，不是项目制生意。

| 维度 | 判断 | 说明 |
|---|---|---|
| 需求确定性 | ★★★★☆ | 矿产开采是永久需求；新矿加深+在产矿品位年均下滑1-2% → 单位产出耗材量上升；矿业巨头2026-27加码资本开支（BHP/Rio/Vale均表态） |
| 客户粘性 | ★★★★★ | **核心护城河**：矿山客户认证周期6-12个月、替换成本极高；直销绑定BHP/力拓/FMG/淡水河谷/智利铜业等全球矿业巨头；"硬质合金+工具+配套服务"一站式，单客户复购率极高 |
| 定价权 | ★★★★☆ | 同类产品寿命达海外高端竞品80%，价格仅30-50%，单位耗材成本显著占优 → 对客户是纯收益，可主动提价（2026/3/11全系提价，毛利率跳升至47%） |
| 竞争格局 | ★★★☆☆ | 全球仍被山特维克+安百拓垄断约80%；但公司已做到**国内牙轮钻头市占率第一（50%+）、全球凿岩工具1.5-2%**、澳洲/南美区域前三，从1.5%→5%+的份额迁移是核心成长引擎 |
| 周期属性 | ★★★☆☆ | 收入随矿业景气波动，但**连续11年经营利润增长**（2025净利较2015翻10倍），证明穿越周期能力——矿业低谷不亏钱，这是"好生意"的重要证据 |
| 现金流/资产 | ★★★☆☆ | 2025经营现金流1.55亿、净利现金含量仅68%（偏低）；扩产需资本开支（定增12.4亿），资产负债表在变重（并购+负债率将升至~55%） |

**段氏判断：这是一门"看得懂的好生意"。** 矿山永远要打洞、钻头永远要磨损更换、客户一旦认证就不轻易换供应商——需求稳定、粘性极强、有真实提价能力。比光模块（被芯片厂定义、无定价权）强一个档次。但**不是"卓越生意"**：ROE基线仅9.9%（远不如茅台的卓越ROE）、有矿业周期、重资产化+并购商誉在累积。

## 二、三大成长逻辑（"为什么十年后它还在，且更大？"）

### 1. 国产替代 + 钨资源垄断（政策红利，物理性护城河）
- 中国占全球钨储量50%+、供应量80%+；2025年中起实施史上最严钨开采管控+出口管制，钨价一年半最高涨超600%。
- **禁止对日出口钨原料** → 日系厂商（久保田/古河/三菱/小松，合计占全球凿岩工具12-15%）成本推升20%+；海外钨价较国内溢价20-30%。
- 公司海外收入占比40%+、出口毛利率稳定，是本轮钨管制下**最受益的中国凿岩工具企业**。原材料壁垒是物理性的，不以政策意志为转移。

### 2. 耗材粘性 + 产品矩阵协同（卖铲人复购经济）
- 牙轮钻头占耗材使用量10-12%，顶锤钎具+潜孔钻具合计70-80%；公司通过收购（新锐惠沣、智利Drillco）补齐产品矩阵 → 捆绑销售，客户采购额放大50%+。
- 收购Drillco切入南美（淡水河谷、智利铜业）供应链，复制澳洲区域前三的成功路径，**"再造一个新锐"**。

### 3. 产能扩张 + 估值锚（量价齐升）
- 定增12.4亿已获证监会注册批复（7/16），凿岩工具产能将增至3倍；达产后凿岩工具年收入约30亿、净利约6亿（仅凿岩业务对应150-180亿市值体量）。
- 2026H1净利+425%~524%已初步验证（量+价+并表三重共振）。

**段氏视角的"确定性排序"**：客户粘性（5星）> 钨资源垄断（4.5星）> 国产替代份额迁移（4星）> 产能扩张（3.5星）。前两条是"十年后还在"的根基，后两条决定"能长多大"。

## 三、必须警惕的三个"不做什么"（段永平 Stop Doing List）

1. **不把涨价红利当护城河**：2026Q1毛利率47%是"原材料涨价→提价"的被动传导，**不是商业模式变好了**。钨价已于3月见顶、7月回落约60%（碳化钨粉920-951元/公斤 vs 高位），H2毛利率回落至35-40%是确定性事件，2026E净利按11.5-12.5亿（非13亿+）估算。
2. **不买贵**：股价一周暴涨31.83%（7/31-8/7），市场情绪亢奋、曾触发临时停牌。现价63元对应2026E约19x、2027E约15x——**合理但无安全边际**。段永平名言："再好的公司，买贵了也是糟糕的投资。"
3. **不忽视并购整合风险**：连续并表Drillco/Drillers World/德锐宝/富邦/慧联（慧联一笔商誉约4亿），负债率将升至55%。矿业下行周期+商誉减值=潜在双击风险。

## 四、毛估估（段永平式估值：以合理价格买入，赚成长的钱）

**盈利路径（取中性）：**
- 2026E：H1 5.3-6.3亿，H2涨价红利消退但量增+并表延续 → **11.5-12.5亿**
- 2027E：凿岩扩产+慧联满产+南美放量，但钨价红利消退 → **15亿**（+25%）
- 2028E：产能爬坡 → **18亿**（+20%）

**估值锚：**
- 现价63元 = 2026E 11.5亿×19.5x = **2027E 15亿×15x**——市场已把"2026高增长"定价，但未透支2027。
- 合理价值中枢：**2027E 15亿×20x = 300亿**（对应每股78元，摊薄后约73元），12%折现回今 ≈ **70元**。
- 概率加权（悲观30%：2027E 11亿×18x→52元；中性50%：→70元；乐观20%：2028E 18亿×22x折现→82元）≈ **72元**。

**结论：内在价值约70-73元，较现价63元有 +11%~+16% 空间，取 +15%。** 好生意、合理价，但**没有"弯腰捡钱"的便宜**。

## 五、段永平式总结

1. **好生意？** 是。卖铲人逻辑+耗材刚需+客户认证壁垒+钨资源物理护城河，看得懂、可持续、有真实提价能力。连续11年经营利润增长是"生意韧劲"的铁证。
2. **好公司？** 是。国内牙轮钻头市占率第一、绑定全球矿业巨头、创始人吴何洪技术派实干、深耕硬质合金全产业链。
3. **好价格？** **现在不是。** 一周+32%、TTM PE约45x、动态约19x，只算合理不算便宜。涨价红利正在消退，市场情绪却在高点。
4. **挥不挥棒？** 现价**不挥**。这是"看得懂、愿意等"的公司——等市场先生把价格送回52元以下（对应2026E 16x、2027E 12x），再用力挥棒。

- 内在涨幅: **+15%**（概率加权内在价值约72元 vs 现价63.00元；区间0%~+30%，好生意但价格只算合理）
- 击球区: 🟡 **黄灯** — 卖铲人+耗材粘性+国产替代是好生意，但一周暴涨32%、钨价红利消退、现价无安全边际，等回调到52元以下再击球
- 目标建仓价: **52 元**（2026E 11.5亿×16x≈184亿市值，对应每股52元；较现价回调17%，贴近8/3盘中低点46.98元上方的支撑区）
- 二次补仓价: **42 元**（2026E 11.5亿×13x≈150亿市值；计入钨价回落+矿业周期下行+并购商誉减值+定增摊薄的悲观情景，深度安全边际）
