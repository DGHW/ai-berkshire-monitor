## 执行摘要

招商轮船是招商局集团旗下"油、散、气、车、集"全业态航运平台，VLCC（51-53艘）与VLOC（37艘）船队规模均居全球第一，2025年归母净利60.12亿创历史新高，2026H1预告归母净利66-73亿（同比+214%~248%），上半年盈利已超2025全年。管理层资本配置纪律优秀（分红率43%+回购，总回报率48%；逆周期造船、处置老船），这是本报告中**唯一可以给高分**的维度。

但从李录"安全边际优先、周期股买在无人问津处"的视角，本标的当前处于**明确的卖出区域而非买入区域**：

1. **价格透支周期**：PE(TTM) 18.25倍、处于10年分位60.5%；股价一年上涨207%~286%，从5.5元区涨至18元区。当前市值1451.8亿已对应"超级周期持续兑现"的乐观情景。
2. **周期见顶三信号同步出现**：运价已从3月峰值20万美元/天回落至11-13万；霍尔木兹/红海通航恢复释放有效运力2-3%；二股东中石化在历史高位首度减持套现。
3. **"超级周期"论断需反面检验**：公司管理层判断2025H2起超级周期启动，但该论断与其大额造船、增发回报诉求存在利益绑定；历史上2022年俄乌时也曾宣称超级周期，2023-2024运价即回落。IEA预测炼油品需求2027年见顶。
4. **周期高位大规模扩产**：10艘VLCC+5艘阿芙拉+6艘VLOC+8艘集运+2艘穿梭油轮，新增订单总投资超170亿元，其中49.3亿元为关联交易。2007-2008年造船潮→2011-2020年行业长期低迷的历史教训犹在。
5. **杠杆资金过热**：融资余额22.47亿元，占流通市值1.55%，超过历史90%分位——散户/杠杆资金拥挤，向下波动易放大。

**综合判断：击球区🔴。当前价格没有安全边际。李录式操作是"等待"——等运价回落、盈利正常化、市场抛弃周期股时再建仓。**

## 一、管理层评估（李录最看重维度之一）

### 1.1 背景与体制

- **实控人**：招商局集团（央企，国务院国资委直管）。第一大股东招商局轮船有限公司持股54.48%。
- **董事长**：冯波鸣（1969年生，香港大学工商管理硕士），兼任招商局集团副总经理、辽宁港口集团董事长、中国外运董事长。2026-07-29 连任第八届董事会董事长，副董事长刘振华、张日勇。
- **核心管理层**：王永新（董事，南开硕士，中国船东协会副会长，2017年加入招商局）；吴泊（第七届副董事长，招商局集团财务公司董事长，分管资本运作，近20年航运+金融经验）。

**评估**：央企体制赋予极强的融资能力、船台资源（大船集团优先船台）与战略纵深，管理层具备"周期底部敢于逆势下单、周期顶部敢于分红回馈"的产业经验与资源匹配。李录欣赏的"优秀的生意人+靠谱的大股东"在此处**部分成立**。但央企体制下管理层与股东利益绑定弱于市场化企业，董事长系集团高管兼任，决策更多服务于集团战略与国资委考核导向。

### 1.2 资本配置能力（本报告最亮眼维度）

| 动作 | 内容 | 评价 |
|---|---|---|
| 分红 | 2025年度末期10派2.5元+中期10派0.7元，合计25.84亿，分红率43%（同比+3pct） | 优秀 |
| 回购 | 2025年回购3.11亿元注销 | 优秀 |
| 股东总回报 | 分红+回购占归母净利48.14% | 优秀，A股航运板块第一梯队 |
| 船队更新 | 2025年新增16艘新船、处置5艘老船、购入1艘年轻二手油船；平均船龄10.4年（行业13.2年） | 优秀，资产质量行业领先 |
| 逆周期布局 | 2026年3月锁定10艘VLCC（2028-2030交付）+8艘集运船，8月加订5艘阿芙拉 | 战略意图合理，但时点处于周期高位（见风险） |
| 三年回报规划 | 2024-2026年承诺分红（含回购）40%左右 | 稳定可预期 |

**评价**：在"回报股东"与"船队扩张"之间，公司选择了"高分红+回购+用自有现金流造船"的组合，不靠增发摊薄。这一资本配置风格值得肯定，是李录会欣赏的"把股东当合伙人"的央企特例。

### 1.3 治理风险

- **关联交易密集**：与招商银行存贷款、与招商局财务公司金融服务协议、与招商局集团财务公司金融服务协议、2026年7月由大股东招商局轮船提案新建6艘VLOC（49.3亿元关联交易，船厂同为中船系关联方）。全部依法披露、经董事会/股东会审议，合规但**关联交易频率与金额偏高**，需持续关注定价公允性。
- **二股东减持**：中石化集团2026年4月首度减持8074.54万股（套现约15.41亿），5-6月再减持6074.43万股（0.75%），后"提前终止"减持计划。二股东在历史高位套现，是**周期顶部的重要外部信号**。
- **高管减持**：2025年8-11月，三位高管（徐晖、胡斌、孔康）减持股权激励所得共42.9万股，套现约392万元——金额极小，属正常解锁，不构成风险信号。
- **股权激励**：公司有股权激励（高管持股合计约0.037%），但比例极低，激励约束力弱。

**治理综合评级：中等偏上。**合规披露良好、回报意识强，但关联交易频繁、央企多层治理、管理层持股激励不足是长期瑕疵。

## 二、行业风险（核心风险区，🔴高危）

### 2.1 油运周期见顶风险

- 公司管理层自称"油轮超级周期2025年H2正式启动"，依据：供给端船队老龄化（2030年前超40% VLCC船龄超18年退出）、造船产能瓶颈（未来5年VLCC退出约180艘 vs 新增120-130艘）、需求端"西油东运、东油西运"贸易格局拉长运距。
- **反面检验（A级信息）**：
  1. 该论断是公司自身及卖方一致预期，与公司大额造船、提升股东回报的诉求存在利益绑定，**"超级周期"一词天然带有推销色彩**。
  2. 2022年俄乌冲突爆发时市场同样喊出"超级周期"，2023-2024年运价即回落至亏损线附近——**历史经验表明这类论断多数被事后证伪**。
  3. 需求端：IEA预测全球炼油品需求**2027年见顶（8630万桶/日）**，能源转型是确定性逆风；OPEC虽反驳"未达峰"，但OPEC有保油价利益动机，其预测同样不可全信。
  4. 供给端：2028年后本轮造船潮（含招商轮船自身订单）开始集中交付，**2028-2030年供给缺口逻辑可能被证伪**。
  5. 结论：**"超级周期"是概率事件而非确定性事件，按其乐观假设定价=把不确定性当成确定性来支付价格。**

### 2.2 运价暴跌风险（已发生，且高波动将持续）

| 时间 | 运价水平 | 事件 |
|---|---|---|
| 2026年2月 | TD3C约20万美元/天 | 油运市场基本面强+地缘溢价 |
| 2026年3月初 | 20万+美元/天 | 霍尔木兹危机恐慌峰值 |
| 2026年4月 | 14-15万美元/天 | 3月初42.4万→4月中暴跌超60%（TD3C） |
| 2026年5月 | 最低8-9万美元/天 | 霍尔木兹通航恢复，运距缩短，有效运力+2-3% |
| 2026年6-7月 | 回升至11-13万美元/天 | 美伊第一阶段协议后补库 |

- 公司自己在2026年1月调研中明确："**2026年VLCC运价波动预计较2025年更加剧烈**"——管理层亲口承认波动性风险加剧。
- 单一季度运价从20万跌至8-9万美元/天，区间振幅超60%。**任何基于当前运价线性外推的盈利预期都极其脆弱**。

### 2.3 OPEC+ 政策风险

- 2026年8月2日，OPEC+七国决定9月继续增产18.8万桶/日；2026年Q1暂停增产、4月重启。OPEC+潜在增产量约324万桶/天（占全球海运量约8%）。
- **双刃剑**：增产→增加原油海运量→短期利好油轮；但增产→油价下行→产油国财政压力→未来可能反向减产；且美国对伊朗/委内瑞拉制裁政策随时可变，制裁放松将冲击"黑油转白"逻辑。
- 政策路径高度不确定，构成油运需求的黑箱。

### 2.4 地缘缓和风险（最大的"预期差"风险）

- 当前运价中仍含显著地缘溢价。美伊第一阶段协议后，霍尔木兹海峡油轮通行量已恢复至战前近半水平；红海航线恢复→航距缩短→**有效运力增加2-3%**。
- 若全面缓和：运距缩短+绕行取消+浮仓释放（海上库存约1.1亿桶凝析油）→运价溢价大幅消退→盈利回落。
- 公司自己也承认"长期看油轮市场必回归供需基本面，地缘只带来阶段性波动"。**市场当前定价的，恰恰是这部分阶段性波动。**

### 2.5 干散货/LNG/集运等多元业务风险

- 干散货：BDI 2026H1同比+82%，8月3日报2843点创近期新高，景气上行。VLOC 37艘绑定淡水河谷（份额超60%）、COA长协，是盈利"压舱石"。但干散货同样强周期，BDI可从2800点快速腰斩。
- LNG：卡塔尔S4/S6长协曾宣布不可抗力（公司称无实质影响），2026-2028年全球LNG运力集中交付，供给过剩风险曾被市场担忧。
- 集运/滚装：规模小，贡献有限。
- **多元化的本质是"多个周期叠加"而非"消灭周期"**——全行业下行的年份，任何板块都难以独善其身（2023年即是例证）。

## 三、业务风险

### 3.1 船队结构与船龄

- 自有船舶235艘，3884.59万载重吨，手持订单64艘；自有/租赁载重吨91.5%/8.5%。
- 平均船龄仅10.4年（行业13.2年），EEXI/CII环保新规下合规优势明显——**这是真正的护城河式优势**，也是李录会看重的资产质量。
- VLCC 51-53艘全球第一，VLOC 37艘全球第一，规模效应与客户绑定（淡水河谷等）构成一定进入壁垒。

### 3.2 新船交付与订单风险（周期高位扩产）

- 2025年新增16艘、2026年预计交付28艘新船；订单：10艘VLCC（约85亿+，2028-2030交付）、5艘阿芙拉（24.85亿，2029-2030交付）、6艘VLOC（49.3亿关联交易，2029-2030交付）、8艘集装箱船、2艘穿梭油轮。**新增订单总投资超170亿元。**
- **反面检验**：管理层称"锁定2030年前超40%老龄运力退出的缺口、船台紧张优先排期"，逻辑自洽。但：
  1. 造船订单集中下在**运价与资产价格双高位**，单船造价处于周期顶部区间；
  2. 2028-2030年交付高峰若恰逢需求下行（IEA预测2027年见顶），将形成"高成本资产+低运价"的双杀；
  3. 2007-2008年造船潮→2011-2020年行业十年低迷，是航运业最经典的周期教训；
  4. 公司自身也承认"若2030-2031年造船产能仍无法释放，缺口将进一步扩大"——把宝押在供给约束持续上，逻辑成立但脆弱。

### 3.3 环保合规（EEXI/CII）

- 船队年轻是最大合规优势，2030年前船龄超18年的VLCC强制退出/降效，对招商轮船**净利好**（其船队年轻+新船双燃料预留）。
- 风险点：环保新规执行节奏（IMO中期措施）、双燃料改造成本、碳税若落地将抬高全行业运营成本，但头部船东通过新船转嫁能力更强——**此项对龙头是加分项**。

## 四、财务风险

| 指标 | 数值 | 评估 |
|---|---|---|
| 资产负债率 | 46.26%（2026Q1） | 航运企业中偏低，可控 |
| 总资产 | 820.55亿（2025末，+16%） | 扩张主要来自造船资本投入 |
| 每股经营现金流 | 1.12元（2025） | 良好，90亿级经营现金流 |
| 财务费用 | 3.24亿（2026Q1） | 造船借款推升，但压力可控 |

- **正面**：46.3%负债率在航运业属健康水平，经营现金流（90亿级）足以覆盖分红（25.8亿）+部分造船款，不依赖增发摊薄。
- **风险点**：
  1. 2026-2030年集中交付期，造船资本开支高峰与运价回落期若重叠，自由现金流将转负；
  2. 财务费用随造船借款上升（2026Q1已3.24亿）；
  3. 若运价崩跌（回到8-9万美元/天以下）+新船集中付款，双重挤压下资产负债表韧性将接受考验——不过以当前46%负债率+90亿现金流，**不至于出现偿付危机，属"承压但可控"级别**。

## 五、长期确定性：10年后的油运格局

### 5.1 支撑长期格局的因素

1. **贸易格局刚性**："西油东运、东油西运"——大西洋盆地向亚洲、中东/印度成品油回流欧洲，运距拉长是30年趋势，不因短期地缘改变。
2. **供给约束**：造船产能（船台+熟练工人+核心设备）全方位受限，未来5年VLCC退出180艘 vs 新增仅120-130艘。
3. **资产属性重估**：产业资本/石油公司愿意以高于二级市场的价格锁定长协与收购资产（Frontline等交易案例），油轮从"运输工具"向"战略硬资产"演变。

### 5.2 能源转型的长期逆风（李录最关注的"十年后"问题）

1. **IEA**：全球炼油品需求2027年见顶（8630万桶/日），之后渐进下降——**这是油运需求的长期天花板**。
2. **OPEC**：否认见顶，称2025-2050年持续增长——但OPEC有保油价利益，其预测可靠性低。
3. **2030年前后**多数机构预测供需"双达峰"；电动车渗透、化工原料替代交通燃料是确定性趋势。
4. **10年维度判断**：油运需求大概率在2027-2030年触顶，之后**缓慢下行**；但下行斜率温和（原油在化工、航空、航运领域短期难替代），叠加供给端老龄船退出刚性，**油运行业有望在"需求缓降+供给更紧"中维持高于历史均值的运价中枢**——即"量缩价稳"格局。

**李录式判断**：油运是一个**需求长期见顶的行业**（逆风），即使供给约束带来5-8年的好日子，也不构成"可长期复利持有十年"的特许经营生意。这与李录偏爱的"需求永不消失+定价权"的消费/公用事业类企业有本质差异。**可以在底部周期买，但不可以作为永久持仓。**
