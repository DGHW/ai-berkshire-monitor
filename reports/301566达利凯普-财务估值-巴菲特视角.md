### 1.2 关键趋势解读（巴菲特视角）

1. **营收呈现明显周期波动而非持续成长**：2022年4.77亿为峰值 → 2023-24年连续两年下滑（-27.5%、-6.5%）→ 2025年恢复+12.1%至3.62亿。**2025年营收仍低于2022年峰值24%**，所谓"13.9%增速"是**低基数上的恢复性增长**，并非高确定性扩张。

2. **净利弹性远大于营收**：2025年营收仅+12.1%，净利却+39.9%——利润弹性主要来自毛利率大幅提升（60%→66.2%）与费用摊薄，而非量的爆发。这种"利润率驱动"的增长可持续性存疑。

3. **2026Q1净利增速断崖**：营收+13.9%但**归母净利仅+4.75%**（扣非+13.02%），显示利润率提升红利已进入尾声，毛利率进一步上行空间有限。

4. **现金流质量优秀**：2025年OCF/净利=97.8%，2024年为84.7%，盈利真金白银含量高。但2026Q1 OCF仅0.21亿（占净利39%），有季节性因素，需中报验证。

**结论：速评卡"ROE 14.4%"= 2026Q1单季年化（Tushare roe_yearly 20260331 = 14.41%），而2025年报加权ROE = 11.29%**。偏差12.12%，属于典型的单季年化陷阱。

- ROE轨迹：2021年24.4% → 2022年29.6%（上市前高ROE）→ 2023年12.8% → 2024年8.7% → 2025年11.3%
- **上市融资后ROE被摊薄**：2023年12月IPO募资后净资产从~9.4亿升至14.7亿（2025年报），ROE中枢从上市前的25%+降至10-12%
- 从巴菲特视角：**11.3%的ROE对于61.6x的PE而言完全不匹配**。即便用2026Q1年化的14.4%，P/ROE也高达4.3倍

### 2.2 毛利率与净利率 — 顶级但已是高位

- 毛利率：55.9%(2021) → 66.2%(2025) → 67.6%(Q1'26)，5年提升近12pct，反映产品结构高端化（半导体射频电源/军工/医疗占比提升）
- 净利率：32.2%(2021) → 43.9%(2025) → 47.0%(Q1'26)，远超一般电子元器件公司（行业净利率普遍5-15%）
- **费用结构**（2025年报）：
  - 销售费用 1641万（占营收4.5%）—— 军工/工业客户直销，销售费用低
  - 管理费用 3769万（占营收10.4%）
  - 研发费用 1785万（占营收4.9%）—— **研发占比偏低**，对一家声称"材料配方壁垒"的公司，4.9%的研发费用率不算高（对比：三环集团研发费率~7%）
  - 财务费用 -545万（净利息收入，因大量现金理财）
- **巴菲特警示**：47%净利率看似惊艳，但需注意其含约9.9亿现金理财产生的利息收入；剔除后经营净利率仍很高（~42%），但**高净利率+低ROE的组合意味着大量冗余现金未被有效利用**（详见资产负债表节）

### 5.3 内在价值粗算（正常化盈利法）

- 正常化盈利：2023-2025三年净利均值 = (1.25+1.14+1.59)/3 = **1.33亿**；考虑2026年恢复增长，取1.5-1.6亿
- 给予合理PE：考虑顶级财务质量+稀缺属性，给予**25-30x**（巴菲特式合理偏保守）
- 内在价值 = 1.5~1.6亿 × 25~30 = **37.5~48亿** → 每股 **9.4~12.0元**
- 现金调整：即使把9.6亿净现金全额加上（乐观），内在价值中枢约**13-15元**
- **当前市值99.6亿元 = 内在价值上沿的2倍以上**

**巴菲特会怎么做：** 把达利凯普放进"好公司、坏价格"的观察清单，耐心等待市场先生给出错误定价。以61.6x PE买入一家ROE 11.3%、营收增速12%的公司，即使质地再好，也违背"用合理价格买好公司"的第一原则。**挥棒等待。**
