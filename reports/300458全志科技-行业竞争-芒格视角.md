# 全志科技（300458.SZ）AIoT芯片行业竞争格局 — 芒格视角

> 分析日期：2026-08-10 | 速评卡：PE 92.0 / 市值 343.8 亿 / 毛利率 40.2% / 净利率 22.3% / 营收增速 47.1%
> 数据口径：IDC、弗若斯特沙利文、公司 2025 年报/2026 一季报/半年报预告、东方财富/雪球/百家号产业分析，多源交叉
> 方法论：芒格「行业格局是否友好 × 公司是否行业内最优」双检验；半导体是周期性+技术迭代的"艰难生意"，先判断生意本质，再判断人与价格

## 一、行业核心事实：端侧AI是真实的大浪潮，但AIoT SoC是一桩"艰难生意"

### 1.1 行业规模与增速（多源数据）

| 指标 | 数据 | 来源/置信度 |
|---|---|---|
| 全球AI终端SoC市场 | 2025年 **450亿美元** → 2030年 **1438亿美元**，CAGR **23.6%** | 弗若斯特沙利文 [A级] |
| 2026Q1全球端侧AI芯片出货量 | 同比 **+45%**（另口径 +78%），中低端IoT/工业端侧芯片增幅 **破110%** | IDC [A级，口径有出入] |
| 云端AI芯片出货量 | 2026Q1 同比仅 **+12%**（增速大幅放缓）——算力正从云向端下沉 | IDC [A级] |
| 2026年端侧AI渗透率 | 预计突破 **54%** | IDC [A级] |
| 中国端侧AI市场规模 | 2026年 **8661亿元**，2025年3219亿 → 2029年1.22万亿 | IDC [A级] |
| 人形机器人/具身智能 | 2026-2030 复合增速 **73%-106%**，端侧AI芯片是其"大脑+小脑" | 摩根士丹利/赛迪研究院 [B级] |
| AI眼镜SoC | 占BOM成本约 30% | 产业分析 [B级] |

**芒格解读**：端侧AI大模型（3B/7B参数级离线部署）、AI眼镜、扫地/割草机器人、四足机器狗、车载座舱——这些是**真实的结构性需求**，不是讲故事。但必须同时看到硬币另一面：**这个行业的进入壁垒不在牌照而在技术迭代与客户关系，竞争者多如牛毛**。与电解铝"4500万吨产能天花板=类公用事业"完全不同，AIoT SoC没有供给约束，供给会随利润扩张而扩张——**这是芒格意义上的"艰难生意"（tough business）**。

### 1.2 半导体周期位置：一半是周期潮水，一半是AI曙光

- 2026年上半年全球电子业承受**存储价格暴涨、芯片基板/PCB紧缺**，端侧AI公司**不仅没被压缩利润，反而通过提价消化成本**——需求强到可以向下游传导成本（知乎/雪球产业复盘 [B级]）。
- 行业分析明确指出：全志科技、北京君正、安凯微**上半年利润弹性相当一部分来自涨价传导，本质是行业上行周期**；而星宸、瑞芯微、晶晨的涨价更多伴随产品结构向AI升级，内生竞争力占比更高（百家号产业分析 [B级]）。
- 2021年主控芯片（SoC）缺货涨价的剧本曾在2023-2024年因供给过剩演变为全行业亏损——**周期记忆不能丢**。

> **芒格解读**：当一只半导体股利润暴增2-3倍，第一反应应该是"这是周期还是成长？"涨价驱动的利润会在供给释放后回吐。全志2026H1净利预告 +195%~220%，必须拆开看：多少是行业缺货涨价（周期性），多少是产品结构/份额提升（结构性）——**行业共识是"周期成分不小"**。芒格买周期股只买在行业亏损期，绝不在盈利历史极值期追入。

### 2.3 芒格"行业内最优"检验：不通过

- 论规模：瑞芯微净利10.4亿是全志2.62亿的 **4倍**，且增速更快（+74.8% vs +57.2%）。
- 论盈利质量：瑞芯微/星宸毛利率41-46%，全志32.88%（2026Q1涨价后升到40.21%，但含周期成分）。
- 论技术高地：瑞芯微有RK3588/RK182X（全球首颗3D堆叠AI协处理器）、晶晨有6nm A311Y3、星宸有安防视觉全球第一的垄断地位——全志主打"够用就好"的性价比路线。
- **在芒格框架里，全志不是"第一名的冠军"，是"第二梯队里跑得最快的追赶者"**。好生意里的第二名可能活得不错，但拿不到最肥的利润。

## 三、核心竞争者威胁逐家分析

### 3.1 瑞芯微（603893）——正面最强者 🔴 高威胁
- 2025年净利10.4亿（+74.8%），全球AIoT SoC份额4.5%列第四、国产第一，客户超5000家，覆盖消费/机器人/汽车/工业视觉/安防七大场景。
- RK3588M车规芯片定价仅为高通8155的 **60%**，用性价比反向挤压——这正是全志的生存逻辑被更强的对手复制。
- 扫地机器人领域RK3566方案服务科沃斯/石头，智能音箱RK3326占40%份额——**直接侵入全志的腹地**。
- **威胁本质**：瑞芯微用更高的算力+更低的价格上下夹击，全志若不能在细分场景绑定客户，性价比空间会被持续压缩。

### 3.2 晶晨股份（688099）——跨界的压路机 🔴 高威胁
- 营收67.93亿（净利8.73亿），全球电视盒子SoC第一，基本盘稳固。
- 2025年推出 **6nm高算力通用AI端侧平台A311Y3**，已立项数十个项目，覆盖AINAS/算力卡/智能平板/机器人/工业控制/智能汽车——**全志的T系列/MR系列正撞上晶晨的枪口**。
- 晶晨毛利37.97%、全球化布局、估值相对亲民，是"稳"的代表。

### 3.3 星宸科技——视觉AI的隐形冠军 🔴 高威胁
- 安防视觉AI SoC全球市占率第一（弗若斯特沙利文口径），2026Q1净利+330%、毛利率46%——**在AI视觉（全志V8系列的主战场）拥有"垄断定价权"级别地位**。
- 车载SPAD/激光雷达芯片与机器人算力芯片在商业化前夜。
- **对全志的视觉AI眼镜/安防业务构成直接压制**：同赛道里人家是第一，全志是追赶者。

### 3.4 恒玄科技——音频/穿戴地盘的钉子户 🟡 中威胁
- TWS/智能音频+可穿戴主控，华为/小米等绑定，2025H1出货量+47%、净利+106%。
- 与全志业务交叉有限（音频 vs 应用处理器），但端侧AI向穿戴延伸时可能短兵相接。

### 3.5 国际巨头：联发科/高通 🟡 中威胁（结构性）
- 联发科、高通持续加码端侧AI（手机/平板/座舱），是"天花板级"对手。全志守住的是它们"看不上"的中低端长尾市场。
- 联发科在中低端平板/物联网的下沉会挤压全志的平板基本盘。

### 3.6 紫光展锐/地平线/爱芯元智/北京君正/炬芯/翱捷 🟡 中威胁
- 紫光展锐中低端手机SoC市占14%，向IoT延伸。
- 地平线座舱SoC国产市占超10%，挤压车载。
- 爱芯元智全球第五大视觉端侧推理芯片（市占6.8%）。
- 北京君正、安凯微、炬芯在中低端性价比市场与全志同质化竞争——**这个赛道拥挤到可以用"红海"形容**。

> **芒格解读**：把竞争对手列一遍就明白——**全志面对的不是一个敌人，而是一整支军团**：上有高通/联发科/晶晨/瑞芯微的算力碾压，中有星宸/爱芯的视觉垄断，下有北京君正/安凯微/炬芯的价格血拼。在一个"每个缝隙都站着至少一个第一名"的赛道里，第二梯队公司的利润率必然被反复击穿。这是芒格最警惕的生意类型之一。

## 四、行业趋势：端侧AI大模型、RISC-V、制程迭代

### 4.1 端侧AI大模型下沉（最强趋势）
- 算力从云向端迁移：2026Q1云端芯片出货仅+12%，端侧+45%，中低端IoT端侧+110%。
- 端侧典型算力需求6-12 TOPS、功耗<1W、支持离线3B/7B大模型；瑞芯微RK182X（高带宽嵌入式DRAM）已成范式。
- **全志的机会**：V881/V883（4T算力）、T527（2T NPU）+ 扫地机器人/AI眼镜/工业视觉场景工程化能力——**趋势对其有利，但算力参数落后于瑞芯微/星宸是硬伤**。

### 4.2 RISC-V架构（全志的差异化武器）
- RISC-V在IoT/边缘渗透率突破25%，已纳入ISO国际标准；2026年国产RISC-V AI芯片从"嵌入式配角"向"AI算力主角"跃迁。
- 全志V881已采用高性能RISC-V处理器+专用NPU，T527为8核A55+RISC-V协处理器；**公司目标2026年RISC-V收入占比过半**。
- 逻辑：RISC-V可免ARM授权费、可深度定制——是全志对冲ARM授权成本、做差异化的真实抓手 [A/B级]。

### 4.3 制程迭代（成熟制程是国产AIoT的主战场）
- 中国在28nm及以上成熟制程已安全可控；中芯国际/华虹28nm产能年增12%+，中芯月产能（折8寸）首破百万片=台积电1/3。
- **台积电明确退出成熟制程**，中芯/华虹24小时运转接盘——国产AIoT SoC的晶圆供给与成本环境反而受益。
- 全志产品集中在28nm及以下成熟制程，**不受先进制程卡脖子，但也不享受先进制程的性能红利**——与瑞芯微（部分7nm）存在代差。

### 4.4 涨价周期的两面性
- 2026年存储涨价+基板PCB紧缺 → 全志2026年4月宣布AIoT芯片提价 → Q1毛利率从32.88%跳升到40.21%。
- **警示**：涨价是周期的礼物，也会是周期的报复。2023-2024年供给过剩全行业亏损的剧本随时可能重演（扩产+需求放缓）。

## 五、产业链与价值分配：Fabless生意里，设计公司的命运在"迭代速度"不在"制造"

### 5.1 产业链结构

| 环节 | 代表 | 价值特征 |
|---|---|---|
| IP授权 | ARM/RISC-V | 架构授权费（RISC-V可绕开） |
| **设计（Fabless）** | 瑞芯微/全志/晶晨/星宸 | 附加值最高，毛利30-46%；**但需持续高研发投入，研发占营收20%+是常态** |
| 代工制造 | 中芯国际/华虹（28nm+成熟制程）、台积电 | 成熟制程产能国产化，供给充足 |
| 封测 | 长电/华天/通富 | 附加值低，周期性强 |

### 5.2 全志在链条中的位置
- **纯Fabless**：固定资产轻，负债率仅18.73%，财务干净。
- **代价**：研发投入5.97亿占营收21.03%、研发人员占83.67%——**在28nm成熟制程上，设计与代工没有差异化保护，唯一的护城河是产品定义+软件生态+客户绑定**。
- 价值分配格局：**芯片设计吃技术溢价，代工/封测吃规模与周期**。全志2025年毛利32.88%低于行业平均36.92%，说明其技术溢价不足——处于"设计环节里偏下游的卡位"。

> **芒格解读**：Fabless生意的本质是"用高研发强度换设计溢价"。只有持续领先对手一代产品的公司才能维持毛利。全志的研发强度（21%）达标，但毛利落后同行4个点，证明**产品差异化还不够强到支撑溢价**。芒格会说：这不是"被特许经营"的生意（franchise），是"技术工人"的生意（skilled worker）——工人永远比老板累，还容易失业。

## 六、芒格式综合判断

| 维度 | 判断 |
|---|---|
| 行业趋势 | ✅ **强且真实**：端侧AI（+45%~78%出货量）、机器人（CAGR 73-106%）、AI眼镜——结构性需求确认 |
| 行业格局 | 🔴 **艰难生意**：无供给约束、玩家众多、巨头下沉、价格战常态——与"类公用事业"的电解铝形成鲜明对比 |
| 公司竞争地位 | 🟡 **细分冠军、整体第二梯队**：扫地机器人市占第一、AI视觉有工程实力、车载约10%；但毛利率低于行业平均、算力参数落后瑞芯微/星宸 |
| 盈利质量 | 🟡 2026H1 +195%~220%含**较大周期成分**（涨价传导），非纯结构性成长 |
| 技术路线 | 🟡 RISC-V是差异化抓手（2026年目标收入过半），但ARM/RISC-V切换期充满不确定性 |
| 财务稳健性 | ✅ 负债率18.73%、净现金、分红+转增——资产负债表干净 |
| 估值 | 🔴 **偏贵**：TTM口径PE 92（2025年归母2.62亿对应静态PE超130倍），即便按2026E约9-10亿净利，forward PE仍达35-38倍 |

**芒格式结论**：端侧AI是真实的产业浪潮，全志科技是浪潮里**有真卡位的追赶者**（扫地机器人/视觉/车载），管理层在RISC-V上押注正确、财务干净。但——**这是一个"艰难生意"里的第二梯队公司，盈利含周期水分，当前价格已把未来3年的乐观预期定价**。芒格的话放在这里很合适："**任何聪明的投资都不能弥补糟糕的价格**"（No amount of brilliance can overcome a bad price）。行业趋势 🟢，公司质地 🟡，价格 🔴。

## 量化结论

- 内在涨幅: **-15%**（当前市值343.8亿已透支：2026E净利按9-9.5亿（H1预告4.75-5.15亿+H2环比略增的乐观假设），第二梯队+周期盈利合理PE给25-30x → 合理市值260-285亿 vs 现价343.8亿，估值中枢约-15%；若涨价周期见顶回落，下行空间更大）
