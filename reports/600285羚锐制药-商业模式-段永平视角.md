## 摘要（先给结论）

羚锐制药是一台**"贴膏印钞机"**——高毛利（80%）、高ROE（23.9%）、强现金流（净现比>1.2）、零有息负债、分红率82%的类债券现金牛。但它的增长已从"渠道放量"切换到"提价+并购"驱动，内生主业处于**量缩价增的存量博弈**。护城河是真实存在的，但属于**品牌+渠道型消费品的浅护城河**，而非技术型深护城河，且正在被奇正/云南白药/华润天和及化药凝胶贴膏缓慢侵蚀。**市场16.6x PE的定价没有明显看错，不存在非共识的认知差机会**——买它=买5%股息+8%内生增长，预期年化总回报10-13%，下行有底、上行需等超预期。

## 一、商业模式本质：卖的不是"药"，是"国民级膏药心智"

### 1.1 生意定义

贴膏剂OTC龙头，核心资产是**一张处方（独家）+ 一张渠道网（70万家药店）+ 一个国民品牌（羚锐/两只老虎）**。

- **核心大单品**：通络祛痛膏（独家品种，基药+医保乙类+OTC乙类+中药二级保护，年销超10亿元）、壮骨麝香止痛膏/麝香壮骨膏/伤湿止痛膏（"两只老虎"系列，合计年销超10亿贴）
- **第二梯队**：芬太尼透皮贴剂（2025年首次破亿，2026进基药）、培元通脑胶囊、丹鹿通督片、参芪降糖胶囊
- **并购新增**：银谷制药（90%股权，约7亿元现金，2025年3月并表），核心品种苯环喹溴铵鼻喷雾剂（1类新药）

### 1.3 三个反直觉的商业本质特征

1. **它赚的是"品牌+渠道"的钱，不是"药"的钱**：销售费用率47.46%，意味着80%毛利里约6成被营销吃掉，真实"经济毛利"仅约32%，与快消品无异。贴膏本质是**低价高频的OTC消费品**（单贴均价1.28元），消费决策由"医生/药师推荐+复购体验"主导。
2. **它是"弱周期+弱集采暴露"的防御资产**：院外零售占比超70%，院内不足30%，远离集采主战场——这是医药行业里极其稀缺的结构。
3. **它是提价驱动型，不是放量驱动型**：2022年以来经营逻辑彻底转向"不赚走量薄利钱，只赚高毛利品质钱"（详见反面检验5.1）。

## 二、护城河逐项验证（事实+证据+评级）

### 2.1 品牌认知度——**真实但分层**（评分 7/10）

| 事实/证据 | 来源 |
|---|---|
| 羚锐商标是国内橡胶膏剂药业首个"中国驰名商标"，1988年建厂深耕30余年 | 公开资料 |
| "两只老虎"系列年销超10亿贴；通络祛痛膏年销超10亿元 | 2025年报 |
| 2025年零售药店终端中成药贴膏剂品牌TOP20中**羚锐上榜5个（行业最多）**，通络祛痛膏/壮骨麝香止痛膏/麝香壮骨膏均进前十 | 米内网 |
| 壮骨麝香止痛膏零售端市占率第一；通络祛痛膏骨科贴膏零售市占率超40%（一说） | 米内网/同花顺 |
| 用户复购率60%+ | 2026Q1分析 |

**观点**：品牌强度分两层——**通络祛痛膏**（独家+基药+医保）有真实消费者心智壁垒，患者"用一次有效就复购同牌子"；**"两只老虎"普药贴膏**同品名竞争者众多（壮骨麝香止痛膏在销厂家≥10家），品牌粘性弱于云南白药膏，主要靠渠道推力与低价维持。这一层被很多研报夸大——"羚锐=膏药"的国民认知真实存在，但换算成定价权，普药端是打折扣的。

### 2.2 渠道网络——**最硬的护城河**（评分 6.5/10）

| 事实/证据 | 来源 |
|---|---|
| 覆盖31省市、70万家药店终端，覆盖率超50%，下沉到县乡基层，渗透率60% | 同花顺/公开资料 |
| 院外零售占比超70%，院内不足30% | 公开资料 |
| 自营推广队伍+经销商+零售药店+电商（经分销+直销） | 2025年报 |

**反面论据**：华润三九（天和）、云南白药、奇正藏药的渠道网络同样密。70万网点是**行业龙头标配**，不是羚锐独有。渠道是"必要条件"而非"充分壁垒"——它决定了你能守住份额，但决定不了你能否增长。真正的差异在于：羚锐以5个品牌上榜零售TOP20，单品牌SKU复用同一渠道，边际渠道成本低——这是规模效应的体现。

### 2.3 医院学术推广——**真实增量但规模有限**（评分 6/10）

| 事实/证据 | 来源 |
|---|---|
| 通络祛痛膏2024年公立基层终端破4亿元，2025Q1-Q3同比+22.9% | 米内网 |
| 芬太尼透皮贴剂2026年纳入国家基药目录，基层强制配货，Q1院端销量+20%+ | 2026Q1分析/雪球 |
| 院内处方溢出效应→患者出院后OTC复购 | 雪球长文 |

**反面论据**：院内贴膏市场**奇正消痛贴膏才是老大**（公立医院终端超9亿元、9连涨），羚锐院内地位低于奇正；基层终端云南白药膏（超8亿）也领先通络祛痛膏。羚锐在院内是"追赶者"，学术推广是"补课"而非"优势"。

### 2.4 规模效应——**真实但被原料周期对冲**（评分 6/10）

| 事实/证据 | 来源 |
|---|---|
| 贴膏销量约17亿贴/年，全国第一，国家级智能制造示范工厂 | 年报/同花顺 |
| 2025年贴膏毛利率83.80%（+4.85pct），十年最高 | 年报 |
| 2025年毛利率提升主因：收入结构变化+中药材成本下行 | 管理层业绩说明会 |

**反面论据**：规模优势的毛利率红利**高度依赖中药材价格低位**。雪球深度复盘指出"药材成本很难成为长期护城河"——2023-2024中药材大涨、2025回落，成本红利是一次性的；原料上行周期回归时毛利率将反向回落。智能制造降本是真实的，但占比有限。

### 2.5 技术壁垒——**最被高估的一环**（评分 5/10）

| 事实/证据 | 来源 |
|---|---|
| 通络祛痛膏发明专利2026年11月到期，但中药二级行政保护延续至2030年 | 雪球/年报 |
| 芬太尼透皮贴剂国内独家骨架型工艺，专利保护至2030年 | 雪球/年报 |
| 47项专利，激光超微切孔/绿色热压工艺 | 同花顺 |

**反面论据（重点）**：
- 雪球分析直言"通络祛痛膏为传统橡胶膏剂，**技术门槛不高**"，专利/行政保护是"政策给的壁垒"，非技术本身。
- **化药凝胶贴膏正在降维冲击**：氟比洛芬凝胶贴膏已有7家企业过评（北京泰德14年独占期被打破），洛索洛芬钠贴膏集采降价2026年全面显现，九典等厂商以"凝胶贴膏+集采低价"渗透OTC止痛场景。
- 中药贴膏新药加速入场：九典椒七止痛凝胶贴膏（中药1.1类）报产在审，**目标患者与通络祛痛膏高度重合**；健民小儿牛黄退热贴膏已获批。

**结论**：技术壁垒是"政策性+阶段性"的，**不是"人无我有"的深技术**。TDS（经皮给药）平台故事在营销上成立，在技术上被夸大。

## 三、定价权：三档分化，总体中等偏上但有天花板

### 3.1 OTC核心品种：有自主定价权，已兑现但空间收窄

| 事实/证据 | 来源 |
|---|---|
| 通络祛痛膏不属于集采、不属于医保谈判品种，企业自主定价 | 雪球 |
| 2022-2024年分批完成终端挂网价/供货价上调，2025年终端均价较2021年**+30%** | 雪球十年复盘 |
| 2025年"两只老虎"袋装提价10%；贴膏均价1.06→1.28元/贴（+20.8%） | 雪球 |
| 贴膏毛利率77.5%（2021）→83.8%（2025），十年最高 | 雪球 |

**反面论据**：**需求价格弹性不为零**。袋装提价10%后该低端品类销量下滑，拖累2025年贴膏总销量-14.95%（16.97亿贴）。OTC普药贴膏是"低价刚需品"，消费者的绝对价格敏感度低（一贴1块多），但**渠道/零售商对毛利分配敏感**，提价要分利润给终端，否则动销承压。通络祛痛膏提价能力强，普药提价有反噬风险——这是"定价权分层"的核心。

### 3.2 原材料成本传导：成本红利是一次性，非定价权

- 2025毛利率+4.21pct主因中药材成本下行+银谷并表结构；2026Q1毛利率78.19%（+1.42pct）仍在受益。
- **反面**：中药材价格周期波动剧烈（2023-2024大涨、2025回落）。80%毛利率是"成本低位+结构升级"双重红利的结果，若原料上行周期回归，毛利率将自然回落——**这暴露的是周期属性，不是护城河**。

### 3.3 处方药端：无定价权

- 参芪降糖胶囊集采降价 → 内分泌板块收入-16.17%。
- 培元通脑胶囊2026年11月专利到期**且无中药行政保护**——这是短期最直接的风险敞口，专利悬崖后仿制药竞争将压制价格与毛利。

### 定价权小结（评分 6/10）

| 层级 | 定价权 | 证据 |
|---|---|---|
| 通络祛痛膏（独家+基药） | 强 | 终端均价3年+30%兑现 |
| 两只老虎普药 | 中 | 提价10%即引发销量下滑 |
| 处方药（集采品种） | 无 | 参芪降糖-16%、培元通脑专利到期 |

## 四、段永平"好生意"三标准：逐项打分

| 标准 | 打分 | 理由（证据） |
|---|---|---|
| **① 差异化**（用户为何选你不选别人） | **6.5/10** | 通络祛痛膏=独家+基药+医保+中药保护，真实差异化；"两只老虎"普药同品名竞争≥10家，无差异化，靠渠道和品牌惯性。差异化集中在1个品种上，抗集采、抗模仿能力中等 |
| **② 定价权**（能否不降成本提价） | **6/10** | OTC端自主定价已兑现+30%，但普药提价引发销量下滑、处方药零定价权；综合看"有定价权但有天花板"，比不了茅台/片仔癀 |
| **③ 可持续竞争优势**（10年后还在吗、以什么质量存在） | **6.5/10** | 品牌+70万渠道+老龄化+中药保护(2030年前)=大概率"还在"；但行业进入存量竞争、份额被云南白药/华润天和追赶、化药贴膏降维，竞争优势的**强度在缓慢侵蚀** |

**段永平式定性**：这不是一门"伟大生意"（无定价权的顶端+无颠覆性产品+增长天花板），但是一门**"好生意"**——高ROE 23.9%、净现比>1.2、零有息负债、82%分红率，管理层本分、专注细分赛道。符合段永平"看得懂、睡得着"的标准，但不符合"躺着也能赚"的标准，需要持续经营投入。

## 五、反面检验（重点）：生意是否在变差？"10年后还在吗"？

### 5.1 增长在"变差"吗？——成色在变差，短期未恶化

**事实（2025年报）**：
- 收入+10.07%，但**约1/3增量来自银谷并表**（贡献收入2.66亿、净利2848万，净利率仅10.7%，远低于主体19.8%）
- 内生看：贴剂+2.62%（**销量-14.95%**，靠均价+20.8%撑住）、胶囊-4.55%、内分泌-16.17%
- 归母净利+5.11% < 扣非+10.81%（非经常性损益基数高，2024年有较高非经常收益）

**事实（2026Q1）**：营收+10.32%、归母净利+13.61%、经营现金流+128.24%——**短期反而加速**，并未恶化。

**判断**：主业"量缩价增"是2022年以来的**既定经营策略**（贴膏毛利率77.5%→83.8%），不是突然变差。真正变差的是**增长成色**——越来越依赖提价和并购，而非需求自然扩容。这是投资隐含假设的核心：**买羚锐=买"提价+并购"的执行力，不是买"行业β"**。

### 5.2 老龄化悖论（本报告最重要的非共识论据）

| 事实 | 数据 |
|---|---|
| 2016→2026年60岁以上人口 | 2.31亿→3.31亿（**+44%**） |
| 同期羚锐贴膏总销量 | 十年仅+19%，**2023年后连续下滑** |
| 2026Q1云南白药膏零售端增速 | **+45.59%** |
| 2026Q1华润天和骨通贴膏增速 | **+44.70%** |
| 2026Q1羚锐贴剂收入增速 | 个位数 |

**判断**：老龄化只守住行业需求底盘，**新增需求被杂牌低价品和强敌分流**。羚锐零售端份额第一（5个品牌上榜）是守成能力强的证据，但**增长领先性正在被追赶**。市场用"银发经济受益股"给羚锐定价，但这只是底盘逻辑，不是增量逻辑——增量逻辑目前看是弱的。

### 5.3 竞争全面恶化

- **奇正**：消痛贴膏公立医院终端9亿+、9连涨，院内一哥
- **云南白药**：云南白药膏基层终端第一，零售端+45.59%放量
- **华润三九天和**：骨通贴膏+44.70%
- **化药凝胶贴膏**：氟比洛芬7家过评、洛索洛芬集采降价2026全面显现，渗透OTC场景
- **新药**：九典椒七止痛凝胶贴膏（目标患者与通络祛痛膏重合）、健民小儿牛黄退热贴膏获批

**含义**：贴膏赛道从"半封闭"走向"群雄割据"。羚锐的份额（约13.6%，行业TOP3）是护城河，但**竞争对手增速显著快于它**，份额天平在缓慢倾斜。

### 5.4 费用率上升侵蚀利润

- 销售费用率47.46%（+1.84pct）、管理5.60%（+0.83pct）、研发4.39%（+0.63pct）、期间费用率2026Q1达52.3%
- 销售费用率提升主因：银谷并表后市场/学术推广投入加大+金尔力OTC渠道建设
- 净利率19.79%（-0.85pct）——**收入增速快于利润增速，费用扩张吞噬毛利红利**
- 银谷净利率仅10.7%，并购**稀释盈利质量**；账上新增4.8亿商誉

### 5.5 "10年后还在吗"？——大概率在，但形态会变

- **在的理由**：中药保护至2030年、芬太尼专利至2030年、基药+医保地位、70万药店网络、复购粘性、老龄化底盘
- **形态变化的理由**：贴膏主业增长天花板明显（渗透率已高+提价空间收窄），未来十年羚锐更可能演变为"**贴膏现金牛+多板块并购集团**"（银谷-呼吸、金尔力-骨质疏松、莫匹罗星-皮肤），而不是"贴膏高增长冠军"

**最终判断**：这是一门**能收股息的好生意，但不是能翻倍的伟大生意**。段永平会买它当"现金牛仓"，但不会把它当"重仓成长股"。
