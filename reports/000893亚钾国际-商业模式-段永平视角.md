## 0. 一句话结论

亚钾国际是一门**"低成本 + 战略资源 + 产能成长"三重叠加的钾肥资源股**：生意本质是标准化大宗商品（氯化钾），全球价格接受者，**谈不上"差异化"，但拥有极低的完全成本（约1000元/吨，全球新建产能最低档）和国家战略加持（中老联合声明首次写入钾肥基地）**。段永平视角下，这是一门**"好资源、中等偏上生意、差在管理层可信度与周期位置"**的公司——资源护城河真实，但产能兑现历史信用受损、治理有瑕疵、现价无安全边际。

## 1. 商业模式本质：它到底靠什么赚钱？

### 1.1 生意定位
- 主营业态：在老挝甘蒙省开采钾盐矿，加工生产氯化钾（KCl，钾肥），销往国内（经中老铁路陆运 + 老越永安码头海运双通道）。
- 收入结构（2025年报）：氯化钾销售收入 52.02 亿元，占总营收 53.25 亿元的 **97.7%**；其余为溴素等非钾副产品（投资收益 2200 万元量级）。
- 商业模式类型：**资源型大宗商品制造**——买入的是"矿权 + 开采成本曲线"，卖出的是全球统一定价的氯化钾。公司是**价格接受者**，赚钱的公式非常简单：

> **单吨利润 = 氯化钾全球/国内价格 − 完全成本（约1000元/吨）**，再乘以销量。

### 1.2 单位经济模型（2025 年实际）
| 指标 | 数值 | 说明 |
|---|---|---|
| 2025 年产量 | 201.15 万吨（+10.8%） | 产销量双双破 200 万吨，创新高 |
| 2025 年销量 | 204.57 万吨（+17.5%） | |
| 2025 年平均不含税售价 | 3132.32 元/吨（+26.94%） | 量价齐升 |
| 2025 年单吨营业成本 | 约 1000-1042 元/吨（+2.5%） | 全成本口径 |
| 2025 年单吨毛利润 | 1528 元/吨（+~40%） | 毛利率 59.10%（氯化钾业务） |
| 2025 年前三季单吨净利润 | 约 894 元/吨（+114%） | 净利率 35.2% |
| 2026Q2 单吨净利润（券商估算） | 约 1000 元/吨 | 受海运费上涨压制 |

**段永平视角点评**：这个生意的盈利核心只有一个变量——**氯化钾价格**。成本端相对稳定（矿权 + 人力成本固化，规模效应持续摊薄），所以利润弹性几乎全部来自价格。这类"利润=价格−成本×销量"的生意，段永平会直白地判断：**不是最好的生意**——因为产品无差异化、无定价权、利润不可预测。但它的"好"在于：成本曲线足够低、资源储量足够厚、需求足够刚性（粮食安全）。

### 1.3 产能扩张是第二增长引擎（也是最大的不确定性）
| 时间 | 产能节点 | 状态 |
|---|---|---|
| 2020-2024 | 25万吨 → 200万吨 | 已兑现 |
| 2025年12月 | 300万吨（第三座百万吨） | 投料试车成功，正式迈入 300 万吨时代 |
| 2026年 | 500万吨目标 | 第二座百万吨矿建接近尾声 + 新增爬坡；**存疑** |
| 2027年 | 700万吨目标 | **存疑** |
| 中长期 | 800-1000万吨 | 远期愿景 |
| 已受理 | 第四、五座百万吨（彭下-农波矿区 +200万吨） | 申报受理 |

**关键信用瑕疵**：第二座百万吨项目（179矿）的**2号主斜井**（核心运输生命线）因井下渗水反复承诺修复、屡次落空，最终于 2025 年报**全额计提减值 3.12 亿元**——这是"归母净利 16.73 亿 < 扣非净利 18.56 亿"的原因（一次性非经常损失）。对段永平而言，**管理层连续多年"投产、治水成功、限时复产、年内修复"的承诺全部阶段性落空，是最严重的扣分项**："做对的事、把事做对"首先是**说真话、守承诺**。

## 2. 护城河分析（真实性与深度）

段永平讲护城河，核心问三件事：**是不是别人很难复制？是不是能持续赚超额利润？是不是真能挡住对手？** 逐条检验：

| 护城河 | 真实性 | 深度 | 段永平评价 |
|---|---|---|---|
| ① 资源储量 | ✅ 真实 | 老挝甘蒙省 158 km² 钾盐矿权，探明氯化钾储量 9.84 亿吨，可开采百年以上 | 资源是硬资产，但全球钾盐储量超 48 亿吨，中国不缺资源、缺的是"可低成本开发 + 政治安全"的矿。老挝矿的稀缺性**不在矿本身，而在区位与政策** |
| ② 低成本开采 | ✅ 真实 | 完全成本约 950-1000 元/吨、现金成本 650-750 元/吨；对比 Nutrien 2024 年单吨营业成本约 104 美元（≈750元）、Mosaic 约 200 美元（≈1440元） | **最核心的护城河**。成本曲线底部意味着：价格下跌时别人亏、你还能赚；行业性减产最先轮不到你。这是资源股的"类定价权" |
| ③ 战略资源属性 | ✅ 真实但非公司可控 | 2026年6月5日中老联合声明**首次**写入"支持中方企业加快在老挝建设钾肥生产基地"，从企业行为升格为国家战略 | 中国钾肥表观消费 1910 万吨/年、进口依赖度 70%、俄白加三国占进口 72.4%；亚钾 2025 年已占老挝对华进口 18%。**政策背书降低海外经营的政治风险**，但这份红利属于"国家意志"，公司只是受益者 |
| ④ 扩产产能 | ⚠️ 存疑 | 300 万吨已试车；500/700 万吨目标未经受大考 | **2号主斜井全额减值证明"规划 ≠ 兑现"**。护城河要从"图纸上的产能"变成"报表上的产量"才算数 |
| ⑤ 品牌/渠道/转换成本 | ❌ 无 | 氯化钾是标准品，按 K2O 含量定价，客户无粘性 | 段永平最看重的那类护城河（如茅台、苹果生态）**在这里不存在**，必须靠成本和资源取胜 |

**综合判断**：护城河是**"成本 + 资源"型的，真实但窄**。它能让公司在行业低谷活下来、在行业景气期赚大钱，但**撑不起"非卖品"级别的确定性**。段永平对这类生意的态度：可以赚周期的钱，但**仓位与估值都必须按周期股纪律对待**，不能用消费股的确定性给溢价。

## 3. 用户/客户价值：为什么客户非买不可？

- **需求刚性**：钾肥是三大基础肥之一，不可替代，直接关系粮食单产。全球人口增长 + 耕地面积有限 → 钾肥需求长期缓增（约2-3%/年）。**这是生意里最"护城"的部分——需求端完全不用操心**。
- **进口替代价值**：中国钾肥 70% 依赖进口，长期被国际寡头（Nutrien/Mosaic/BPC/乌拉尔）"卡脖子"。亚钾是国内企业唯一在境外拥有百万吨级量产钾肥基地的标的，**每进口一吨老挝钾肥，就少一吨俄白加外汇**。这是国家层面的"用户价值"。
- **客户结构**：以国内贸易商、农资经销商、复合肥厂为主，集中度低、无大客户依赖。价格透明、按全球行情结算，**公司对客户没有溢价权，但客户对"低价货源"有稳定需求**。
- **段永平点评**：用户价值是"刚需 + 战略"，真实且长期；但**客户价值 ≠ 公司定价权**。它解决的是"卖得掉"的问题，不解决"卖得贵"的问题。真正决定赚钱的是全球钾肥供需，不是国内农户的忠诚度。

## 4. 钾肥价格周期位置（估值的前提）

段永平："买股票就是买公司，买公司就是买它未来现金流的折现。" 对周期股，未来现金流的高度依赖价格周期位置。**当前钾肥价格处于什么位置？**

| 指标 | 数值 | 时间 |
|---|---|---|
| 国内氯化钾全国均价 | 约 3030 元/吨 | 2026年7月底（CBC金属网） |
| 港口 60% 老挝白粉 | 3050 元/吨（政策价）/ 3200-3350 元（市场价） | 2026年7月下旬 |
| 国产青海盐湖/藏格 60% | 2800 元/吨 | 2026年7月 |
| 2026Q2 国内均价 | 约 3300 元/吨（环比+100） | 券商测算 |
| 2026Q2 东南亚 CFR | 392 美元/吨（环比+40） | 券商测算 |
| 近一年价格中枢 | 站稳 3200 元/吨以上 | 粮食ETF机构观点 |
| 2026 年印度大合同 | 383 美元/吨 CFR（白俄/以化 vs IPL） | 2026年5月 |
| 2026 年中国进口大合同 | 348 美元/吨 CFR | 2026年 |
| 港口库存 | 325 万吨（同比+140万吨） | 2026年7月下旬 |
| 全球价格底部 | 已被抬升至 CFR 280 美元/吨 | 白俄绕道俄罗斯出口、陆运距离 600→2000+ 公里 |

**周期判断**：
- **利好**：俄乌/中东地缘 + 欧盟对俄白制裁 → 全球供应链重构，成本底抬高；印度大合同 383 美元较 2021 年制裁前 247 美元高 55%，**全球钾肥已告别低价区间**；白俄协调减产、设备检修减产约 90-100 万吨（占全球 1.5%）。
- **利空**：**中国港口库存 325 万吨、同比高 140 万吨**，7 月价格已从 4-5 月高位回落转弱；下半年夏肥备肥空窗期，需求低迷。保供稳价政策压制国内涨幅天花板。
- **结论**：钾肥处于**中周期高位、短期库存压力显现**的位置。价格中枢系统性上移（地缘抬底），但**短期上行斜率已钝化**。这是"高景气顶部区域波动"而非"周期起涨点"。

**对估值的含义**：当前 3000-3300 元/吨的价格下，单吨净利 900-1000 元，对应公司盈利处于**周期偏顶部**。若价格回落至 2500 元/吨（仍高于历史均值），单吨净利将大幅缩水——**估值必须对价格敏感性做压力测试，不能线性外推当下盈利**。

## 5. 段永平视角判定：PE 24.5x 配得上营收 +22.7% 吗？

### 5.1 估值快照（2026-08-07）
| 指标 | 数值 |
|---|---|
| 股价（2026-08-07 收盘） | 48.23 元 |
| 总市值 | 约 446 亿元 |
| 总股本 | 约 9.24 亿股 |
| PE(TTM) | 约 24.5x（与速评卡一致；7月31日高点时曾 26.32x / 59.8% 历史分位） |
| PE 历史 30% 分位 | 17.32x |
| 2026H1 业绩预告 | 归母净利 12.85-15 亿元（+50.31%~+75.46%） |
| 券商 2026E 归母净利 | 33.22 亿元（华金/中性偏乐观） |

### 5.2 盈利情景测算（2026E）
| 情景 | 2026E 归母净利 | 逻辑 | 对应 PE@446亿 |
|---|---|---|---|
| 保守 | 25 亿 | H1 中值 13.9 亿 + H2 仅 11 亿（库存高企价格回落 + 300万吨爬坡不及预期） | 17.8x |
| 中性 | 28 亿 | H2 与 H1 持平，300万吨满产爬坡 + 价格维持 | 15.9x |
| 乐观（券商） | 33 亿 | 价格中枢上移 + 500万吨部分兑现 | 13.5x |

### 5.3 段永平的三个问题
1. **"这是我能看懂的好生意吗？"** —— 生意本质简单（价格-成本-销量），但**周期拐点不可预测**。段永平多次强调"看不懂周期股、不做周期股"。钾肥价格受地缘、制裁、寡头博弈影响，**预判价格=能力圈之外**。→ 扣分。
2. **"管理层值得信任吗？"** —— 2号主斜井从2023年渗水到2025年全额减值，**连续三年的复产承诺全部落空**；前董事长 2026年2月涉职务犯罪被起诉；原大股东中农集团 2025年12月-2026年2月套现减持 913.5万股（1%）；现第一大股东汇能集团持股仅 14.05%，**无控股股东、股权分散**。→ **严重扣分**。
3. **"这个价格有安全边际吗？"** —— 现价 446 亿市值，对应 2026E 中性净利 15.9x。对于一个盈利处于周期顶部、产能兑现存疑、治理有瑕疵的资源股，**15.9x 并无安全边际**——它已经把"300万吨达产 + 价格不跌"的乐观假设计入了价格。即便券商乐观 33 亿也只对应 13.5x，**好价格根本谈不上**。→ 扣分。

**总判定**：**营收 +22.7% 是真实且可观的**（量价齐升 + 产能爬坡），但 PE 24.5x（TTM）买的是"周期顶部盈利 + 尚未兑现的产能 + 有前科的管理层"。**"成长性支撑估值"在段永平体系里站不住脚——除非你能证明成本护城河让它在价格回落时仍能维持 ROE 15%+，而这需要等到下一次价格下行周期来验证。**

## 7. 段永平式总结

> 好公司 ≠ 好生意，好生意 ≠ 好价格。
> - **资源与成本是真的好**：全球最低成本档 + 9.84 亿吨储量 + 粮食安全刚需，这门生意"亏不死、活得起、景气时赚大钱"。
> - **生意模式是中等的**：标准化商品、价格接受者、利润看天（地缘与库存），不属于段永平偏爱的"差异化 + 定价权"型生意。
> - **管理层与兑现是最大的不确定性**：承诺频失信、股权分散、原大股东撤离——这些在段永平体系里是**一票否决项**级别的扣分。
> - **价格不便宜**：24.5x TTM / 15.9x 2026E，买在盈利周期顶部附近，**没有犯错空间**。

**结论：可跟踪、可等待，当前不满足"好生意 + 好价格"同时出现。** 把它放入观察名单：等两个信号——①钾肥价格与港口库存的拐点（库存去化确认）；②500 万吨产能兑现或至少 300 万吨满产持续 2-3 个季度；③管理层变更后治理改善。信号出现后，在足够安全边际下再考虑。

## 量化结论
- 内在涨幅: **-8%**（计算依据：2026E 中性归母净利 28 亿 × 合理 PE 15x = 420 亿，对应 45.5 元；vs 现价 48.23 元，隐含 -5.7%；若按保守 25 亿 × 15x = 375 亿 → 40.6 元，隐含 -15.8%；取中枢约 420 亿市值、相对现价 446 亿，内在涨幅约 -6%~-8%。合理 PE 15x 依据：成长型资源股中枢，叠加治理折价与产能兑现不确定性后给 15x 而非 18-20x）
- 击球区: 🟡（低成本+战略资源是真护城河，但生意是价格接受者、管理层兑现信誉受损、现价无安全边际——黄灯，等回调或等信号，不追）
