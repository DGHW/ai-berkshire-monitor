# 长川科技(300604.SZ)行业竞争分析——芒格视角

> 研究员：md-industry | 视角：查理·芒格（行业格局 / 竞争壁垒 / 逆向思考）
> 报告日期：2026-08-11
> 速评卡参照：PE 116.2 / 市值 1828.4亿 / 毛利率 56.8% / 净利率 26.1% / 负债率 49.4% / 营收增速 69.1%（ROE 28.7%）

---

## 〇、芒格开场判断

> "反过来想，总是反过来想。当所有人都在为一个'卖铲子'的故事欢呼时，先问一句：**这个铲子市场里，谁定价？谁说了算？如果需求退潮，这把铲子还值多少钱？**"

长川科技正处于一个**"完美叙事 + 极端估值 + 周期高位"的三重共振点**：
- 行业逻辑极佳：全球后道测试设备270亿美元市场，高端被爱德万/泰瑞达双寡头垄断>90%，国产化率仅约20%（高端数字/SoC测试机<10%），**国产替代是国家级刚需 + AI算力/HBM扩产的结构性双击**；
- 公司卡位极佳：A股唯一全品类覆盖（测试机+分选机+探针台+AOI）的测试设备平台，分选机国内市占率第一（47-58%），SoC数字测试机D9000国内首个批量打入AI/GPU链；
- 但市场先生正为一个 **116倍PE、市值1828亿** 的公司定价——这个价格已经把未来3-5年甚至更久的国产替代红利一次性贴现了。

**核心问题：这是一门好生意，但这是不是买入的好时点？** 芒格的答案是：**生意是A+，但价格是F。好公司+疯狂价格=坏投资。**

## 一、行业规模与趋势：千亿美元赛道，国产化刚刚起步

### 1.1 市场规模与增长数据

| 指标 | 数据 | 来源/时间 |
|------|------|------|
| 全球后道测试设备市场 | 约270亿美元 | 2025年行业综述 |
| 全球测试机市场规模(泰瑞达指引) | 2030年达 **200亿美元** | 泰瑞达2026Q2 |
| 全球SoC测试机市场 | 2023年33亿→2026E 91亿美元，CAGR约40% | 东财研究院 |
| 2025年全球半导体测试设备销售额 | 预计+48.1%（SEMI，2025年初预期） | SEMI |
| 中国ATE测试机市场 | 2025年约138.6亿元 | 行业研报 |
| 测试机/分选机在后道设备价值占比 | 测试机约60-63% + 分选机约20% ≈ 80%+ | 行业拆解 |
| HBM存储测试设备国内需求 | 2026年同比 **+70%** | 行业调研 |

### 1.2 三个核心行业变量（芒格视角）

**① AI超级周期：设备需求是"卖铲人"逻辑中最确定的环节**
- 泰瑞达2026Q2收入13.3亿美元（同比 **+104%**），营业利润4.5亿美元（同比 **+373%**），计算业务收入同比 **+近600%**；
- 爱德万2026Q2收入3675亿日元（+39%），净利1748亿日元（+93.8%），**大幅上修全年指引**（收入预期上修21%、净利上修42%），2025财年净利+132.9%；
- 晶圆厂扩产：台积电2026 CAPEX 520-560亿美元；长鑫科技2026年月产能扩5-6万片（设备采购约350-430亿元）；长江存储三期设备约200亿元。
- **芒格解读**：AI测试需求不是故事，是全球两大测试巨头营收翻倍背书的事实。**但恰恰因为增长太猛，更要警惕"周期顶部买盈利"的经典错误**——泰瑞达/爱德万自身就是最强周期信号灯。

**② 国产替代：从"验证导入"进入"批量放量"，但结构分化极大**
- 测试设备整体国产化率约20%；模拟/功率测试机国产化率70-80%（华峰测控主导）；
- 高端数字/SoC测试机国产化率 **<10%**（这是长川D9000的战场）；
- 政策目标：半导体检测设备国产化率目标提升至35%（2025年政策口径）；
- **芒格解读**：国产替代的红利是真的，但"最容易的替代已经替完"——剩下的都是最硬的骨头（最先进SoC、HBM存储、车规大算力），**越往后替代越慢、壁垒越高，兑现节奏会低于市场线性外推**。

**③ 行业强周期属性：测试设备是半导体资本开支的"后周期杠杆"**
- 实证：长川2023H1因行业景气下行，扣非归母净利 **亏损0.85亿元**；
- 2023-2024年全行业经历下行，2024年下半年才复苏，2025-2026爆发；
- **芒格解读**：这是一门典型的强周期生意（订单集中在封测/晶圆厂资本开支），不是"永续成长"。当前处于AI超级周期上行中段，**但周期上行越陡峭，未来下行越残酷**。泰瑞达Q2收入+104%本身就是"过热信号灯"。

## 二、竞争格局：双寡头垄断，国产"三杰"错位竞争

### 2.1 全球格局（高端市场被两家吃掉90%）

| 公司 | 全球份额 | 强势领域 |
|------|---------|---------|
| **爱德万(Advantest)** | 约32-35% | 存储测试机全球约**60%**、SoC/系统级测试 |
| **泰瑞达(Teradyne)** | 约35-40% | SoC测试机全球约**51%**、UltraFLEXplus/高端数字 |
| 科休(Cohu)、Xcerra等 | 其余 | 分选/测试接口 |
| 国产合计(长川/华峰/悦芯等) | 全球<5%，国内约20% | 中低端+部分高端突破 |

- 中国大陆高端市场：爱德万+泰瑞达合计约80%份额；
- **芒格解读**：双寡头垄断本身说明这个行业**技术壁垒极深、客户粘性极强**——AT E设备与芯片量产深度绑定，测试程序库+售后响应构成"转换成本护城河"。反过来说明：**国产替代是一场艰苦的阵地战，而非扫尾战**。长川喊出的"国内30%市占率"（当前约10%）目标，本质是要从双寡头嘴里抢下最硬的20个百分点。

### 2.2 国内格局：长川 = 唯一平台型选手

| 维度 | **长川科技** | 华峰测控(688200) | 精测电子 | 悦芯科技 |
|------|------|------|------|------|
| 测试机(数字/SoC) | **国内突破者**(D9000批量) | 聚焦模拟/数模混合 | 前道量检测 | T800系列(SoC，2023年已交付400台+) |
| 分选机 | **国内第一(47-58%)** | 无 | 无 | 无 |
| 探针台 | 布局 | 无 | 无 | 无 |
| AOI检测 | 有(STI海外技术) | 无 | 前道为主 | 无 |
| 平台完整性 | **A股唯一全品类** | 测试机占88% | 错位 | 单一SoC |
| 毛利率 | 55-57% | 70%+(模拟) | ~45% | - |

**芒格点评**：
- **华峰测控**是"单点冠军"——模拟测试机国内市占率超50%，毛利率70%+，但它缺数字测试机和全流程方案，天花板清晰。模拟赛道国产化率已70-80%，**它吃的是已经替完的饭**。
- **长川**是"全能选手"——全品类布局使它能做**成套销售**（测试机+分选机打包），客户粘性更强、研发摊薄更充分。2025年测试机+分选机占收入90%+，测试机毛利率62.25%是利润池，分选机41.34%拖累整体但贡献份额。
- **悦芯科技**是潜在威胁——T800 SoC测试机2023年已交付400+台，但主要供货第三方测试厂，未获头部AI客户深度绑定。
- **芒格结论**：国产阵营中，长川是**唯一有资格挑战双寡头高端市场**的公司，竞争卡位最优。但这不改变"双寡头90%垄断"的大局。

## 三、护城河分析：真实但尚未完工

### 3.1 护城河的三个支柱

**① 客户认证壁垒（最硬）**
- 半导体测试设备验证周期长达 **2-3年**，测试程序库与芯片产线深度耦合，一旦导入极难更换；
- 深度绑定国内三大封测厂：**长电科技、华天科技、通富微电**；供货华润微、士兰微等晶圆厂；客户含**华为海思**；
- 客户结构=A股封测/设计/制造核心圈全覆盖。

**② 全品类平台（独一份）**
- 测试机+分选机+探针台+AOI四大品类，后道价值量80%+全覆盖；
- "测试机+分选机"成套销售提升客户粘性，摊薄研发投入；
- 海外并购补全拼图：STI（新加坡，2019年4.9亿，2D/3D AOI+国际客户+海外服务网络）、EXIS（马来西亚，2023年2.77亿收购长奕科技，转塔式高端分选机）；
- 专利1400+项。

**③ 性价比+本地化服务**
- 高端产品价格比海外低30-50%，交付周期更短，国产替代政策+供应链安全需求（地缘风险）推动国内厂商优先采购；
- "双平台测试"现象验证：客户采用"长川初筛 + 爱德万复测"模式——**国产已进入量产线，但最终把关仍靠外资**，说明长川的真实定位是"第二供应商"而非"全面替代"。

### 3.2 护城河的短板（反面检验）

| 短板 | 细节 | 影响 |
|------|------|------|
| **最先进SoC/HBM仍受制于人** | 泰瑞达UltraFLEXplus/爱德万仍绝对主导最先进制程、HBM存储测试 | 高端替代是慢变量 |
| **D9000风冷 vs 对手液冷** | 大算力芯片高功耗散热需求，长川风冷方案可能支撑不了最高端芯片测试 | 最肥的AI GPU测试蛋糕啃不动 |
| 模拟/功率国产化率已70-80% | 长川在华峰测控的主场份额有限 | 最易替代的已替代完 |
| 存储测试机刚起步 | HBM测试机国产化率极低，EXIS转塔分选主要在设计验证阶段 | 存储红利尚需时间 |

**芒格解读**：护城河是**真实存在但尚未完工**的。分选机第一+全品类+客户认证是"已完成的部分"；最先进SoC/HBM测试机突破是"施工中的部分"。**市场目前的定价假设是"施工部分必然完工且按时完工"——这恰恰是芒格最不敢下注的部分。**

## 四、行业景气周期位置：AI超级周期上行中段，但已现过热信号

| 信号 | 读数 | 含义 |
|------|------|------|
| 泰瑞达Q2收入 | +104% | 全球测试设备需求爆发，历史罕见 |
| 爱德万全年指引上修 | 收入+21%、净利+42% | 龙头自身仍在加速 |
| 长川2026H1预告 | 归母9-10亿(+110-134%) | 国内放量兑现 |
| 长川HBM存储测试订单 | 2025年+200% | 存储超级周期 |
| 半导体设备资本开支 | 2026-2027维持高位 | 景气扩张区间 |
| 长川历史参照 | 2023H1扣非**亏损0.85亿** | 周期下行时的盈利底 |

**芒格解读**：
- 当前处于AI驱动的半导体资本开支超级周期的**上行中段**，逻辑上2026-2027年需求仍强；
- 但必须记住三句话：
  1. **"周期股最危险的时候，是所有人相信这次不一样的时候。"** 泰瑞达收入+104%、存储毛利84.9%，这轮AI周期比历史上任何一轮都陡峭；
  2. 测试设备是资本开支的**后周期环节**——晶圆厂/封测厂先扩产，设备商后确认收入，**当设备商的报表最漂亮时，往往离资本开支拐点不远**；
  3. 长川2023年扣非亏损0.85亿的教训表明：**这个生意的盈利可以在一夜之间从巅峰跌入谷底**。2023年离2022年的业绩巅峰只隔了半年。

## 五、治理与资本运作：景气高位暴露的杂音（负面信号）

芒格对管理层的要求是"可预测的理性"。长川近期动作显示**资本运作痕迹明显**：

| 事项 | 细节 | 芒格定性 |
|------|------|------|
| 高位减持 | 实控人一致行动人长川投资2025年8-9月减持1121.99万股，均价96.32元，套现3.92亿——恰逢三季报预增连续涨停巅峰期 | 🔴 精准套现，利益导向 |
| 大额定增 | 2025年6月定增31.32亿（21.92亿研发+9.4亿补流），实控权稀释 | 🟡 高位圈钱+稀释 |
| 警示函 | 2025年1月收警示函：定增募投项目延期、并购推高商誉 | 🟡 合规瑕疵 |
| 商誉 | STI形成商誉余额约2.34亿+长奕/EXIS并购商誉 | 🟡 减值悬顶 |
| 现金流 | 2025H1经营现金流转负(-8042万)；2025前三季度经营现金流与净利严重不匹配 | 🔴 利润含金量存疑 |
| 存货 | 从22亿飙升至39亿（2026H1） | 🟡 备货激进/滞销两说 |
| 中期分红 | 2026-07董事长提议10派1元（约6340万，分红率极低） | 🟡 象征性安抚 |

**芒格解读**：治理瑕疵不改变生意本质（行业格局是真的），但**它要求更高的估值安全边际来补偿**。当一家公司在股价巅峰精准减持、随后大额定增、又收警示函时，市场给它116倍PE，等于是在说"这些都不重要"。芒格会说：**"在别人贪婪时恐惧"——这些动作就是别人贪婪的最好证据。**

## 六、芒格式评分与终局判断

### 6.1 行业/公司特征评估

| 评估维度 | 评分 | 说明 |
|---------|------|------|
| 行业增长空间 | ★★★★★ | 全球测试机2030年200亿美元，国产化率20%→35%+，空间数倍 |
| 竞争格局稳定性 | ★★★★☆ | 双寡头垄断即壁垒证明，长川国内卡位最优 |
| 护城河深度 | ★★★★☆ | 客户认证2-3年+全品类平台+海外网络，但高端未完 |
| 商业模式质量 | ★★★★★ | 测试机毛利62%，后道价值量80%+，卖铲人逻辑纯正 |
| 盈利周期属性 | ★★☆☆☆ | **强周期**：2023H1扣非亏损0.85亿实证，周期顶部风险大 |
| 技术变革风险 | ★★★☆☆ | D9000风冷vs对手液冷短板，最先进制程仍受制于人 |

| 估值安全边际 | ★☆☆☆☆ | PE-TTM 116x / PB约33x，严重透支 |
| 行业贝塔 | 高 | 与AI资本开支强绑定，波动极大 |

### 6.2 芒格终局判断：长川会是国产测试设备"最后的赢家"吗？

**大概率是，但市场已经提前为这个"是"付了全款。**

- 从行业终局看：国产测试设备需要一家平台型龙头对抗双寡头，**长川是唯一够格的候选人**（全品类+分选机第一+SoC突破+海外网络）。10年维度，它成为"中国的泰瑞达"的路径是清晰的。
- 但投资不是选美，是**出价**：
  - 2026E净利（H1 9-10亿 + H2旺季）约20-23亿，当前1828亿市值对应 **2026E PE约85倍**；
  - 即便2027年净利+35%达29亿，对应 **2027E PE仍63倍**；
  - 一台"2023年还在亏钱、2025年才刚盈利爆发、经营现金流转负、存货39亿"的强周期设备股，芒格的历史经验是——**这类股票在周期顶部给的PE从来不可持续**。
- 合理的"正常化估值"：若2028-2030年净利兑现30-35亿（全球200亿美元市场的国产龙头份额），给予设备龙头合理30-40x，合理市值约 **1000-1200亿**，对应当前市值仍有 **35-45% 的下行空间**。

### 6.3 什么会推翻"好生意"的判断？
- AI资本开支骤降（2027年云厂商CAPEX增速转负）→ 行业从"供不应求"瞬间转"砍单"；
- D9000在最高端AI芯片测试始终无法突破（风冷散热天花板）→ 高端替代叙事证伪；
- 存货39亿中滞销部分减值 + 商誉减值 → 盈利质量暴雷；
- 双寡头降价反击（泰瑞达/爱德万在华降价）→ 性价比优势被侵蚀。

**芒格名言应验**：
> "投资是延迟满足的游戏。好生意值得等待，**但等到一个好价格，才是真正的胜利。**" 长川是"好的生意"，但1828亿不是"好的价格"。

## 七、核心数据来源（2025-2026年最新）
